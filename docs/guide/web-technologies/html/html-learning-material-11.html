ホーム HTML 第11章
第11章 所要時間: 約40分

CSSとの連携入門

第1章で触れたとおり、HTML は「構造・意味」、CSS は「見た目」を担当します。この章では、いよいよ CSS の入口に足を踏み入れます。CSS の書き方3種類、セレクタの基本、色・文字サイズ・余白といった最小限のプロパティ、そしてすべての土台となるボックスモデルの考え方を学び、最後に自分の手で style.css を作成済みのページへ適用します。

この章で学ぶこと

  • HTML と CSS の役割分担を、実際の見た目の変化で説明できる
  • CSS の書き方3種類（インライン・style要素・外部ファイル）を書き分けられる
  • 要素・class・id の3種類のセレクタを使い分けられる
  • 色・文字サイズ・余白（margin/padding）の基本プロパティが書ける
  • ボックスモデル（content・padding・border・margin）の考え方を説明できる
  • 作成済みのページに style.css を適用し、見た目を整えられる

11.1 HTML と CSS の役割分担（再確認）

第1章で「HTML は骨組み、CSS は内装」という家づくりのたとえを紹介しました。ここまでの10章では、ずっと骨組み（構造）を作る練習をしてきました。見出し・段落・リスト・リンク・画像・表・フォーム・セマンティック要素 — どれも「意味」を表すためのタグであり、色や余白のような「見た目」の指定はほとんど登場していません。

CSS（Cascading Style Sheets、カスケーディング・スタイルシート）は、この「見た目」を担当する言語です。同じ HTML でも、CSS の有無や内容によって印象がまったく変わります。次の例で確認してみましょう。左は HTML だけの素の状態、右は CSS を適用した状態のイメージです。

CSS を適用する前（ブラウザの標準スタイル）

自己紹介

こんにちは、山田太郎です。よろしくお願いします。

CSS を適用した後

自己紹介

こんにちは、山田太郎です。よろしくお願いします。

HTML のタグは一切変えていません。変わったのは背景色・見出しの色・内側の余白だけです。このように「構造はそのままに、見た目だけを差し替えられる」ことが CSS の最大の強みです。この章からは、いよいよこの「見た目」を自分の手でコントロールしていきます。

用語: CSS の名前の意味

CSS の「カスケーディング（cascading）」とは「滝のように上から下へ流れ落ちる」という意味です。複数の指定がぶつかったとき、後から書かれたルールや、より詳しく指定されたルールが優先される仕組みを表しています。この章では基本のみを扱いますが、名前の由来として覚えておくとよいでしょう。

11.2 CSS の書き方3種類

CSS を HTML に適用する方法は3種類あります。それぞれの書き方と特徴を、実際のコードで見ていきましょう。

方法1: インライン style 属性

タグに直接 style 属性を書く方法です。その要素だけにスタイルを適用したいときに使えますが、同じ指定を何度も書くことになりやすく、あとで見直すのも大変です。

inline.html 
<!-- タグに直接 style 属性を書く -->
<h1 style="color: navy; font-size: 28px;">自己紹介</h1>
<p style="color: gray;">こんにちは、山田太郎です。</p>

方法2: style 要素（内部スタイルシート）

<head> の中に <style> 要素を置き、その中にまとめて CSS を書く方法です。同じページ内であれば繰り返し指定できますが、ページが増えるたびに同じ <style> をコピーする必要があります。

internal.html 
<head>
  <meta charset="UTF-8">
  <title>自己紹介</title>
  <style>
    /* head の中にまとめて CSS を書く */
    h1 { color: navy; font-size: 28px; }
    p  { color: gray; }
  </style>
</head>

方法3: 外部ファイル（推奨）

CSS だけを別ファイル（例: style.css）に書き、HTML からは <link> タグで読み込む方法です。この方法が最も推奨されます。

index.html 
<head>
  <meta charset="UTF-8">
  <title>自己紹介</title>
  <!-- rel="stylesheet" で「これはCSSファイルです」と伝える -->
  <link rel="stylesheet" href="style.css">
</head>
style.css 
/* style.css: HTMLとは別ファイルに書く */
h1 {
  color: navy;
  font-size: 28px;
}
p {
  color: gray;
}
書き方 書く場所 向いている場面 推奨度
① インライン タグの style 属性 その場限りの確認・検証 低い
② style 要素 <head> 内 1ページだけの小さな検証 中くらい
③ 外部ファイル 別の .css ファイル 通常のWeb制作すべて 高い（推奨）

外部ファイルが推奨される理由は主に3つあります。①複数ページで使い回せる（サイト全体のデザインを1つの style.css で統一できる）、②役割がはっきり分かれる（HTML＝構造、CSS＝見た目という第1章の原則を、ファイルレベルでも守れる）、③修正がラク（デザインを変えたいとき、style.css の1箇所を直すだけで全ページに反映される）という点です。

重要ポイント

迷ったら常に「③外部ファイル」を選ぶと覚えておけば十分です。インラインと style 要素は「こういう書き方もある」という知識として押さえておけば、実務のコードを読むときに困りません。

11.3 セレクタの基本

CSS のルールは「どの要素に（セレクタ）」「どんなスタイルを当てるか（プロパティと値）」の2つで構成されます。まずは「どの要素に」を指定するセレクタの基本3種類を押さえましょう。

style.css 
/* ① 要素セレクタ: タグ名をそのまま書く */
p {
  color: gray;
}

/* ② classセレクタ: 先頭にドット(.) */
.highlight {
  color: crimson;
}

/* ③ idセレクタ: 先頭にシャープ(#) */
#site-title {
  font-size: 32px;
}
セレクタ CSS の書き方 HTML 側の対応 特徴
要素セレクタ p { ... } 指定なし（タグ名で自動一致） 同じタグ全部に一括適用
class セレクタ .highlight { ... } class="highlight" 同じ class を複数要素に何度でも使える
id セレクタ #site-title { ... } id="site-title" 1ページに1回だけ使う一意な指定

第10章で学んだ class と id 属性が、ここでようやく本領を発揮します。class は「同じグループに繰り返し使うタグ」、id は「ページの中でそこだけの、一意な目印」という違いを思い出しておきましょう。迷ったときは、まず class を使うのが基本です。

この3種類のセレクタが同じ要素に対して異なる指定をした場合、すべて同じ強さで競合するわけではありません。id セレクタ > class セレクタ > 要素セレクタの順に優先度（詳細度）が高く設定されており、優先度が高いほうの指定が採用されます。たとえば p { color: gray; } と .highlight { color: crimson; } が同じ <p class="highlight"> に当たっている場合、class セレクタのほうが優先されて文字は crimson になります。

よくある間違い

class セレクタは .（ドット）、id セレクタは #（シャープ）を付け忘れやすいポイントです。CSS 側で highlight { ... } のように書いてしまうと、それは「highlight という名前のタグ」を探すことになり、意図どおりに適用されません。必ず記号を付けましょう。

11.4 プロパティと値の書き方

セレクタで「どの要素に」を決めたら、次は { } の中に「プロパティ: 値;」という形式でスタイルを書きます。プロパティは「何を変えるか」（色・サイズ・余白など）、値は「どう変えるか」（具体的な色名や数値）を表します。コロン（:）と、行末のセミコロン（;）を忘れないことが最初の関門です。

style.css 
.profile-card {
  /* プロパティ: 値; の形式で1行ずつ書く */
  color: #333333;        /* 文字色 */
  font-size: 18px;        /* 文字サイズ */
  margin: 16px;           /* 要素の外側の余白 */
  padding: 12px;          /* 要素の内側の余白 */
}

まずは、どんなページでも必ずと言っていいほど使う4つのプロパティを覚えましょう。

プロパティ 意味 値の例
color 文字の色 navy・#333333
font-size 文字の大きさ 16px・1.2em
margin 要素の外側の余白 16px・0 auto
padding 要素の内側の余白 12px・8px 16px

margin と padding はどちらも「余白」ですが、要素の枠の外側か内側かという決定的な違いがあります。この違いは次の 11.5 のボックスモデルで、図を使ってじっくり確認します。

豆知識: 単位 px と em

px（ピクセル）は画面上の点の数を直接指定する単位で、初心者にも分かりやすいのが利点です。em は「基準となる文字サイズの何倍か」を表す相対単位で、慣れるとレスポンシブなデザインに便利です。まずは px から始めて問題ありません。

11.5 ボックスモデルの考え方

CSS では、すべての要素が四角い箱（ボックス）として扱われます。見出しも段落も画像も、ブラウザの内部では長方形の箱として計算されています。この考え方をボックスモデルと呼び、箱は内側から順に4つの層で構成されます。

④ margin（マージン）— 他の要素との間の、外側の余白

③ border（ボーダー）— 箱を取り囲む枠線

② padding（パディング）— 枠線の内側の、内側の余白

① content（コンテンツ）

文字や画像など、実際の中身

層 名称 役割 主なプロパティ
① content（内容） 文字・画像など実際の中身 width・height
② padding（内側の余白） 中身と枠線の間の余白 padding
③ border（枠線） 箱そのものを囲む線 border
④ margin（外側の余白） 他の箱との間の距離 margin

たとえば写真立てで考えると分かりやすいかもしれません。content は写真そのもの、padding は写真と額縁の間にある白い縁、border は額縁そのもの、margin はその写真立てと隣の写真立てとの間の距離です。「余白が思ったところに出ない」と感じたら、まず margin と padding のどちらを触っているのか、この4層を思い出して確認しましょう。

もう1点、つまずきやすい注意点があります。既定（box-sizing: content-box）では、width は①の content 部分だけの幅を指し、②padding と③border はその外側に追加されます。そのため「padding を足しただけなのに箱全体が想定より大きくなってはみ出した」という事態が起こりがちです。この挙動を変えて「width に padding と border を含める」ようにする box-sizing: border-box という指定もあるので、頭の片隅に置いておきましょう。

重要ポイント

ボックスモデルは CSS レイアウトのすべての土台です。この先どんなに高度なレイアウト技術（Flexbox・Grid など）を学んでも、最終的には「箱をどう並べ、どう余白を取るか」という、このボックスモデルの考え方に帰ってきます。

11.6 実践: 作成済みのページに style.css を適用する

ここまでの知識を使って、これまでの章で作成してきたページに、実際に外部CSSファイルを適用してみましょう。手順は3ステップです。

  1. ステップ1 — index.html と同じフォルダに style.css という新規ファイルを作る
  2. ステップ2 — index.html の <head> 内に <link rel="stylesheet" href="style.css"> を1行追加する
  3. ステップ3 — style.css に CSS ルールを書き、保存してブラウザを再読み込みする

今回スタイルを当てる対象は、次のような index.html です。名前の部分だけを <span class="highlight"> で囲んでいる点に注目してください。

index.html（body抜粋） 
<body>
  <h1>自己紹介</h1>
  <p>こんにちは、<span class="highlight">山田太郎</span>です。</p>
</body>
style.css 
/* ページ全体の基本設定 */
body {
  color: #333333;
  padding: 24px;
}
/* 見出しに色と下線を付ける */
h1 {
  color: #2c5282;
  border-bottom: 3px solid #2c5282;
}
/* class="highlight" が付いた要素を赤字・太字で目立たせる */
.highlight {
  color: #c53030;
  font-weight: bold;
}

保存してブラウザを再読み込みすると、HTML の構造は何も変えていないのに、見た目が次のように変化します。

style.css を読み込む前

自己紹介

こんにちは、山田太郎です。

style.css を読み込んだ後

自己紹介

こんにちは、山田太郎です。

見た目が変わらないときは

よくある原因は3つです。① <link> タグの href のファイル名やパスが違う、② style.css の保存を忘れている、③ ブラウザの再読み込み（Ctrl+R または Cmd+R）をしていない。この3つを順に確認すれば、たいてい解決します。

やってみよう 11-1: 自分のページに CSS を適用しよう

これまでの章で作ってきた自分のページ（index.html）に、外部CSSファイルを適用してみましょう。

手順

  1. 1 index.html と同じフォルダに style.css を新規作成する。
  2. 2 index.html の <head> に <link rel="stylesheet" href="style.css"> を追加する。
  3. 3 11.6 の style.css の例を参考に、body・h1・任意の class にスタイルを書いてみる。
  4. 4 保存してブラウザを再読み込みし、見た目が変わったことを確認する。
  5. 5 余裕があれば margin・padding の数値を変えてみて、余白の変化を観察する。

思いどおりの見た目にならなくても大丈夫です。数値を変えて保存し、ブラウザで確認する — この繰り返しが CSS 上達の一番の近道です。次の第12章では、この知識も使ってプロフィールページを最初から作り上げます。

理解度確認クイズ

  1. Q1. CSS を書く3種類の方法を挙げ、そのうち最も推奨される方法とその理由を説明してください。

    回答を表示

    ①インラインstyle属性、②style要素（内部スタイルシート）、③外部ファイルの3種類です。最も推奨されるのは③外部ファイルで、複数ページで使い回せる、HTML（構造）とCSS（見た目）の役割を分離できる、修正が1箇所で済む、という理由からです。

  2. Q2. class セレクタと id セレクタは、CSS でそれぞれどんな記号を先頭に付けて書きますか。また、両者の使い分けの違いを説明してください。

    回答を表示

    class セレクタはドット（.）、id セレクタはシャープ（#）を先頭に付けます。class は同じグループの複数の要素に繰り返し使えるのに対し、id はページ内で1回だけ使う一意な指定です。

  3. Q3. ボックスモデルを構成する4つの層を、内側から外側の順に答えてください。

    回答を表示

    内側から順に、content（内容）→ padding（内側の余白）→ border（枠線）→ margin（外側の余白）です。padding は枠線の内側、margin は枠線の外側（他の要素との距離）という違いがあります。

  4. Q4. 外部CSSファイルをHTMLに読み込むには、head内にどのようなタグを書けばよいですか。style.css を読み込む例で答えてください。

    回答を表示

    <link rel="stylesheet" href="style.css"> と書きます。rel="stylesheet" で「これはスタイルシートである」ことを、href で読み込むファイルのパスを指定します。
