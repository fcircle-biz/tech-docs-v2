ホーム HTML 第5章
第5章 所要時間: 約30分

リスト

前章までで、見出し・段落・文字の装飾によって「読ませる文章」を組み立てる方法を学びました。この章では、情報を並べて見せるための道具、リストを扱います。買い物リストや手順書、用語集やナビゲーションメニューまで、Webページの至るところにリストは登場します。3種類のリストを使い分けられるようになりましょう。

この章で学ぶこと

  • 箇条書きリスト（ul）・番号付きリスト（ol）・説明リスト（dl）を場面に応じて使い分けられる
  • ol の start・type・reversed 属性で番号の見せ方を変えられる
  • リストを入れ子にして、階層のあるメニューや目次を作れる
  • リストが崩れる典型的な原因を理解し、正しいマークアップで防げる

5.1 リストが必要な理由と3種類の使い分け

文章の中に「材料は、卵、小麦粉、牛乳です」と書くよりも、1行ずつ縦に並べたほうが読みやすいことがあります。このように関連する項目を並べて見せるためのタグがリストです。HTML には目的の異なる3種類のリストが用意されており、内容に応じて選びます。

タグ 名称 使いどころ
<ul> 箇条書きリスト（Unordered List） 順序に意味がない項目の並び（買い物メモ・タグの一覧など）
<ol> 番号付きリスト（Ordered List） 順序に意味がある項目の並び（作業手順・ランキングなど）
<dl> 説明リスト（Description List） 用語と説明のペア（用語集・プロフィール項目など）

迷ったときは「その順番を入れ替えても意味が変わらないか」を考えてみましょう。入れ替えても問題なければ <ul>、順番自体に意味があれば <ol>、用語とその説明のペアなら <dl> という判断が基本になります。

flowchart TD A["並べたい情報"] --> E{"用語と説明のペアか？"} E -->|"はい"| F["dl で説明リスト"] E -->|"いいえ"| B{"順序に意味があるか？"} B -->|"意味がない"| C["ul で箇条書きリスト"] B -->|"意味がある"| D["ol で番号付きリスト"]

見た目ではなく意味で選ぶ

「番号が表示されると見た目がうるさいから ul にする」といった見た目だけを基準にした選び方は避けましょう。番号を消す・並べ方を変えるといった見た目の調整は、後の章で学ぶ CSS の役目です。まずは「意味」で正しいタグを選ぶことを優先してください。

5.2 箇条書きリスト（ul・li）

箇条書きリストは <ul> タグで作ります。<ul> は「リスト全体の入れ物」、その中の1つ1つの項目を <li>（List Item）タグで囲みます。<ul> の直下に置けるのは <li> だけという決まりを覚えておいてください。

書いた HTML

hobby.html 
<h2>好きな飲み物</h2>
<ul>
  <li>コーヒー</li>
  <li>紅茶</li>
  <li>緑茶</li>
</ul>

ブラウザでの表示イメージ

好きな飲み物

  • コーヒー
  • 紅茶
  • 緑茶

<li> の中には文字だけでなく、リンクや画像など他のタグを入れることもできます。実際、次に学ぶナビゲーションメニューは、<li> の中に <a>（リンク）タグを入れて作られています。「1項目 = 1つのまとまった内容」であれば、中身は自由です。

5.3 番号付きリスト（ol・start／type／reversed 属性）

番号付きリストは <ol> タグで作ります。中に入れるのは <ul> と同じく <li> です。何も指定しなければ 1, 2, 3... と自動で番号が振られますが、次の3つの属性で番号の振り方を変更できます。

属性 効果 指定例
start 番号の開始値を指定する start="6" → 6 から開始
type 番号の表記形式を指定する type="A" のように書く。値は 1（数字）A（大文字）a（小文字）I（ローマ数字大）i（ローマ数字小）
reversed 番号を逆順（大きい数字→小さい数字）にする 値を書かず reversed とだけ書く

reversed のように、値を持たず属性名だけを書く「論理属性（真偽属性）」もあります。第3章で学んだ「属性名="値"」の形が基本ですが、値の有無で on／off を表す属性もあると覚えておきましょう。

書いた HTML

ranking.html 
<h2>人気メニュー ランキング</h2>
<ol reversed>
  <li>から揚げ定食</li>
  <li>オムライス</li>
  <li>ラーメン</li>
</ol>

ブラウザでの表示イメージ

人気メニュー ランキング

  1. から揚げ定食
  2. オムライス
  3. ラーメン

reversed を指定すると、項目数（この例では3項目）から数えて 3, 2, 1 という順で番号が振られます。「1位が一番下に来るランキング表」のような表現に便利です。

start と type は同時に指定することもできます。次の例は「6番目からA, B, C...と続く」表現です。

書いた HTML

agenda.html 
<ol start="6" type="A">
  <li>予算確認</li>
  <li>スケジュール調整</li>
</ol>

ブラウザでの表示イメージ

  1. F. 予算確認
  2. G. スケジュール調整

5.4 説明リスト（dl・dt・dd）

説明リストは「用語」と「その説明」をペアで並べるためのリストです。<dl>（Description List）が全体の入れ物、<dt>（Description Term）が用語、<dd>（Description Details）がその説明を表します。用語集だけでなく、プロフィールの項目（氏名・出身地など）を表すのにもよく使われます。

書いた HTML

glossary.html 
<h2>用語集</h2>
<dl>
  <dt>HTML</dt>
  <dd>Webページの構造を表すマークアップ言語</dd>
  <dt>CSS</dt>
  <dd>Webページの見た目を整えるための言語</dd>
</dl>

ブラウザでの表示イメージ

用語集

HTML
Webページの構造を表すマークアップ言語
CSS
Webページの見た目を整えるための言語

1つの <dt> に対して <dd> は複数書くこともできます（1つの用語に補足説明を並べたい場合など）。ul・ol と違い、あまり目にする機会は多くありませんが、「用語 + 説明」という組が出てきたら dl を思い出してください。

5.5 リストの入れ子と実践

<li> の中には、また別の <ul> や <ol> を入れることができます。これをリストの入れ子（ネスト）と呼び、階層のある目次や、サブメニュー付きのナビゲーションを作るときに使います。

次の例では <a href>（リンク、第6章で学びます）と <nav>（第10章で学びます）を先取りして使っています。ここではまだ詳しく理解しなくてもかまいません。リストが入れ子になっている形に注目してください。

書いた HTML

nav.html 
<nav>
  <ul>
    <li><a href="#">ホーム</a></li>
    <li>
      <a href="#">商品</a>
      <ul>
        <li><a href="#">新商品</a></li>
        <li><a href="#">セール品</a></li>
      </ul>
    </li>
    <li><a href="#">お問い合わせ</a></li>
  </ul>
</nav>

ブラウザでの表示イメージ

  • ホーム
  • 商品
    • 新商品
    • セール品
  • お問い合わせ

気づいたでしょうか。世の中の多くのWebサイトのナビゲーションメニュー（サイト上部の「ホーム」「会社概要」などのリンク一覧）は、この <ul> ＋ <li> ＋ <a> の組み合わせで作られています。実際の見た目では点（マーカー）が消えて横並びになっていることが多いですが、それは CSS で装飾しているためで、HTML の骨組みはリストのままです。第10章で学ぶ <nav> タグと組み合わせるのが定番の作り方です。

リストが崩れる典型的な原因

リストの表示がおかしくなる原因のほとんどは、次の2つです。

  • </li> の閉じ忘れ — 例: <li>りんご<li>みかん</li></ul> のように書いても、文法上は </li> の省略が許容されるため2項目として解釈されます。ただし入れ子リストがあると意図しない階層になりやすいため、本教材では常に </li> を書きます。実際にリストが崩れる主因は </ul>・</ol> の閉じ忘れです。
  • <ul>／<ol> の直下に <li> 以外を置く — 例: <ul><p>メモ</p></ul> のように <p> を直接入れると、文法違反となり HTML バリデータでエラーになります。支援技術がリストの項目数を正しく伝えられなくなる原因にもなります。

重要ポイント

<ul>・<ol> の子要素は必ず <li> だけにし、<li> は必ず </li> で閉じる。この2点さえ守れば、リストが崩れることはほぼありません。第3章で学んだ「入れ子のルール」がここでも活きています。

やってみよう 5-1: プロフィールページに3種類のリストを追加しよう

第2〜4章で作ってきた index.html（自己紹介ページ）を開いて、ul・ol・dl をそれぞれ1つずつ追加してみましょう。

手順

  1. 1 <h2>好きなもの</h2> という見出しを新しく追加し、その下に <ul> を置き、<li> を3つ並べて趣味や好物を書く。
  2. 2 「1日のスケジュール」や「自己紹介の手順」のような見出しを追加し、<ol> で3つのステップを書く。
  3. 3 「基本情報」という見出しを追加し、<dl> で「出身地」「趣味」などの用語と説明のペアを2つ書く。
  4. 4 保存してブラウザで再読み込みし、点付きの箇条書き・番号付きリスト・用語と説明の並びがそれぞれ正しく表示されるか確認する。

余裕があれば、趣味のリストの1項目にサブ項目（例: 「読書」の下に好きなジャンルの入れ子リスト）を追加して、入れ子の書き方も試してみましょう。

理解度確認クイズ

  1. Q1. ul・ol・dl はそれぞれどのような場面で使うか、一言ずつ説明してください。

    回答を表示

    ul は順序に意味のない箇条書き（材料・タグ一覧など）、ol は順序に意味のある番号付きリスト（手順・ランキングなど）、dl は用語とその説明のペア（用語集・プロフィール項目など）を表すときに使います。

  2. Q2. <ol reversed> を指定すると、番号の表示はどうなりますか？

    回答を表示

    番号が逆順になります。例えば項目が3つある場合、上から 3, 2, 1 という順で番号が振られます。1位を一番下に表示したいランキング表などで使われます。

  3. Q3. <ul> や <ol> の直下に置けるタグは何ですか？また、それ以外を直接置くとどうなりますか？

    回答を表示

    置けるのは <li> だけです。<p> などそれ以外のタグを直接置くとルール違反となり、ブラウザが独自に解釈して表示が崩れる原因になります。

  4. Q4. 多くのWebサイトのナビゲーションメニューは、内部的にどのタグの組み合わせで作られていることが多いですか？

    回答を表示

    <ul>（または <ol>）の中に <li> を並べ、その中に <a> リンクを入れる組み合わせで作られています。見た目は CSS で点や縦並びを消して横並びのメニューに変えていますが、骨組みはリストです。
