HTMLの基本構造とタグのルール

この章では、HTML の「文法」にあたる部分を整理します。要素・開始タグ・終了タグ・内容といった用語の意味、閉じタグを持たない空要素、タグに情報を追加する属性、要素を正しく入れ子にするネストのルールを学びます。さらに、すべての HTML ファイルの冒頭に書く定型（お決まりの型）の意味を理解し、文字化けを防ぐ方法とコメントの書き方まで身につけます。

この章で学ぶこと

  • 要素・開始タグ・終了タグ・内容の関係を自分の言葉で説明できる
  • 空要素と属性（属性名="値"）を正しく書ける
  • 要素を正しく入れ子にし、階層をインデントで表現できる
  • HTML文書の定型と文字コード指定の役割を理解し、文字化けに対処できる

3.1 要素・開始タグ・終了タグ・内容

第1章・第2章では「タグ」という言葉を使ってきましたが、ここで正確な用語を整理しておきましょう。HTML の1つのまとまりは、次の4つの部分から成り立っています。

例 
<p>こんにちは、HTMLの世界へようこそ。</p>
用語 意味 この例では
要素（element） 開始タグ・内容・終了タグをまとめた1つのかたまり <p>...</p> 全体
開始タグ（opening tag） 要素の始まりを示す印。<要素名> の形 <p>
内容（content） 開始タグと終了タグに挟まれた実際のデータ こんにちは、HTMLの世界へようこそ。
終了タグ（closing tag） 要素の終わりを示す印。</要素名> の形（スラッシュ付き） </p>

用語: 「タグ」と「要素」は厳密には別物

日常会話では「pタグ」のようにタグという言葉がよく使われますが、厳密にはタグは開始タグ・終了タグそのもの（印）を指し、要素はタグと内容をまとめた全体を指します。この教材でも会話的には「タグ」を使う場面がありますが、正確な意味は覚えておきましょう。

3.2 空要素 — 終了タグを持たないタグ

すべての要素に終了タグがあるわけではありません。「改行する」「画像を1枚挿入する」のように、そもそも中に文章を入れる必要がない要素は、開始タグだけで完結します。これを空要素（void element）と呼びます。

<br>

改行を1つ入れる。文章の途中で行を変えたいときに使う。

<img>

画像を1枚埋め込む。表示する画像ファイルは属性で指定する（第7章で詳しく学ぶ）。

<hr>

水平線を1本引く。話題の区切りを表す。

ほかにも、文字コードを指定する <meta>（3.6で学びます）や、入力欄を作る <input>（第9章で学びます）なども空要素です。空要素かどうかは要素ごとに決まっているため、まずは「終了タグがない要素も存在する」ということを覚えておけば十分です。

index.html（一部） 
<p>1行目です。<br>2行目です。</p>
<hr>
<p>区切り線のあとの文章です。</p>

よくある間違い

<br></br> のように空要素に終了タグを書くのは誤りです。空要素はそもそも中身を持たないため、閉じる必要がありません。なお <br /> のようにスラッシュを付けた書き方を見かけることもありますが、これは古い記法（XHTML）の名残で、現在の HTML では付けても付けなくても構いません。この教材ではスラッシュなしの <br> で統一します。

3.3 属性 — タグに情報を追加する

タグには、そのタグに関する追加情報を持たせることができます。この追加情報を属性（attribute）と呼びます。属性は開始タグの中に、属性名="値" という形で書きます。

例 
<img src="sea.jpg" alt="海の写真" width="400">
<a href="https://example.com">サンプルサイトへ</a>

1つの要素は複数の属性を持てます。属性どうしは半角スペースで区切り、値はダブルクォート（"）で囲むのがこの教材のルールです。仕様上はシングルクォートや、値によっては引用符の省略も許されていますが、記法を統一しておくとミスが減り、他の人が書いたコードとの相性も良くなります。

属性 役割 よく使われる要素
src 読み込む画像などのファイルの場所を指定 img
href リンク先のURLを指定 a
alt 画像が表示できないときの代替テキスト img
id / class 要素に名前を付け、CSSやJavaScriptから指定できるようにする ほぼすべての要素
lang 言語を指定（本章3.5で登場） html

重要ポイント

属性は開始タグの中だけに書きます。終了タグに属性は書きません（</p attribute="x"> のような書き方は誤りです）。また属性名は英小文字で書くのが慣習です。

3.4 入れ子（ネスト）と正しい階層・インデント

要素は、別の要素の中に入れることができます。これを入れ子（ネスト）と呼びます。たとえばリストの1項目の中に、強調したい部分だけ <strong> を入れる、といった具合です。<ul>・<li> は第5章、<strong> は第4章で学びます。ここでは入れ子の形だけ見てください。

正しい入れ子とインデント 
<ul>
  <li><strong>重要:</strong> 早めに提出する</li>
  <li>通常の項目</li>
</ul>

ここで重要なルールが1つあります。内側の要素は、外側の要素が閉じるより先に、自分自身を閉じなければならないということです。タグの開閉が交差してはいけません。

タグの交差はNG

誤り: <strong><em>強調</strong></em> — em を開いたのに、先に strong を閉じてしまっている（交差している）

正しい: <strong><em>強調</em></strong> — 後から開いた em を先に閉じている

階層が深くなってくると、コードを目で追うのが大変になります。そこで、入れ子の深さに合わせて行頭に空白（インデント）を入れる習慣を付けましょう。1段深くなるごとに、決まった量（この教材では半角スペース2つ）だけ字下げします。インデントをそろえるだけで、どの要素がどの要素の中にあるのかが一目で分かるようになります。

VS Code は自動でインデントしてくれる

第2章で紹介した Visual Studio Code は、<ul> の中で Enter を押すと自動的に字下げしてくれます。手でスペースを数える必要はほとんどありません。ずれてしまった場合は、行を選択して Shift+Tab（戻す）／Tab（進める）で調整できます。

3.5 HTML文書の定型

第2章では最小限の2行だけを書きましたが、本来 HTML ファイルには共通の定型があります。ここでその定型を学びましょう。これはどの HTML ファイルにも共通して書く「定型」で、意味も込みで覚えてしまうと、この先ずっと迷わずに済みます。

index.html（定型） 
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>わたしのページ</title>
</head>
<body>
  <p>ここに書いた内容が画面に表示されます。</p>
</body>
</html>
記述 意味
<!DOCTYPE html> ブラウザに「このページを標準のルールどおりに表示してください」と伝えるための決まり文句。古い互換モードで表示されるのを防ぐため、必ずファイルの1行目に書く
<html lang="ja"> 文書全体を1つに囲む要素（ルート要素）。lang="ja" で「日本語のページです」と伝える
<head> 画面には表示されない「ページの設定情報」を書く場所。文字コードやタイトルなど
<body> 画面に実際に表示される内容を書く場所。見出し・段落・画像などはすべてここに書く

全体の関係を図にすると、次のような階層構造になります。

flowchart TD A["DOCTYPE宣言
文書の種類を伝える"] --> B["html要素（ルート）
lang属性で言語を指定"] B --> C["head要素
画面には表示されない設定情報"] B --> D["body要素
画面に表示される内容"] C --> C1["meta要素（文字コード）"] C --> C2["title要素（タブに出る名前）"] D --> D1["h1・p・ul などの要素"]

重要ポイント

head と body は必ず html の中に、この順番（head が先、body が後）で1つずつ置きます。「画面に映るかどうか」で置き場所が決まる、と覚えると迷いません。

3.6 文字コードとタイトル、文字化けの対処、コメント

<head> の中に書く2つの要素、<meta charset="UTF-8"> と <title> の役割を詳しく見ておきましょう。

<meta charset="UTF-8"> は、「このファイルは UTF-8 という文字コード（文字をコンピュータが扱うための番号表）で保存されています」とブラウザに伝えるものです。UTF-8 は日本語・絵文字を含む世界中のほぼすべての文字を扱える現在の標準の文字コードで、迷ったら常にこれを使います。<title> は、ブラウザのタブに表示される名前であり、ブックマークの名前や検索結果の見出しにも使われる、地味ながら重要な要素です。

文字化けの主な原因

文字化けの多くは「実際に保存されている文字コード」と「meta charset で宣言している文字コード」がずれることで起こります。VS Code は既定で UTF-8 で保存します。<meta charset="UTF-8"> を書いたまま保存していれば基本的に文字化けは起きません。もし画面が「文字化けした記号の羅列」になったら、VS Code 画面右下の文字コード表示を確認し、UTF-8 になっているかをチェックしましょう。

最後に、コードの中にメモを残せるコメントを紹介します。<!-- と --> で挟んだ部分は、ブラウザの画面には一切表示されません。作業メモや、あとで直したい箇所の目印として使えます。

コメントの例 
<!-- ここから自己紹介セクション -->
<p>こんにちは、山田太郎です。</p>
<!-- TODO: あとで写真を追加する -->

コメントの便利な使い方

コメントは、コードの一部を一時的に無効化したいときにも便利です。動作確認のために特定の行だけ表示を止めたいとき、削除せずにコメントで囲んでおけば、あとで簡単に元に戻せます。

やってみよう 3-1: index.html を育ててみよう

第2章で作った index.html を開いて、この章で学んだ属性・空要素・入れ子・コメントを実際に使ってみましょう。なお <strong> は第4章で学ぶタグです。ここでは入れ子の形だけ体験します。

手順

  1. 1 VS Code で index.html を開き、3.5 で学んだ定型（DOCTYPE → html → head → body）を使って全体を書き直す。<title> には「〇〇の自己紹介ページ」のように自分の名前を入れ、第2章で書いた <h1> と <p> は <body> の中へ移す。
  2. 2 <body> の中に <p> を1つ追加し、文章の途中に <br> を入れて改行を体験する。
  3. 3 追加した <p> の中の一部の言葉だけを、さらに <strong> で入れ子にして強調する。
  4. 4 追加した行の上に <!-- 自己紹介 --> のようなコメントを書き足す。
  5. 5 保存してブラウザで再読み込みし、①タブに新しいタイトルが表示されていること、②文字化けしていないこと、③強調した文字が太字になっていることを確認する。

コメントに書いた文字は画面に出てきません。「消えているのが正解」なので、表示されていたらコメントの書き方（<!-- と -->）を見直してみましょう。

理解度確認クイズ

  1. Q1. 「要素」「開始タグ」「終了タグ」「内容」の関係を、<p>こんにちは</p> を例に説明してください。

    回答を表示

    <p> が開始タグ、「こんにちは」が内容、</p> が終了タグです。そしてこの3つをまとめた <p>こんにちは</p> 全体を要素と呼びます。

  2. Q2. 空要素とは何ですか。具体例を2つ挙げて説明してください。

    回答を表示

    空要素とは、中に内容を入れる必要がないため終了タグを持たない要素のことです。改行を表す <br> や、画像を埋め込む <img>、水平線の <hr> などが該当します。

  3. Q3. 属性はどのように書きますか。基本の構文と、値を囲む記号のルールを説明してください。

    回答を表示

    属性は開始タグの中に 属性名="値" の形で書きます。複数の属性は半角スペースで区切り、値はダブルクォート（"）で囲むのがこの教材のルールです（例: <img src="sea.jpg" alt="海の写真">）。

  4. Q4. 文字化けはなぜ起こりますか。原因と、疑わしいときに確認すべき場所を説明してください。

    回答を表示

    ファイルが実際に保存されている文字コードと、<meta charset="UTF-8"> で宣言している文字コードがずれていると文字化けが起こります。疑わしいときは VS Code 画面右下の文字コード表示を確認し、UTF-8 になっているかをチェックします。
