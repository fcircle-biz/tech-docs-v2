文字とテキストのスタイル

Webページの印象と読みやすさの大部分は、文字まわりのスタイルで決まります。この章では、フォントの指定方法（font-family）から大きさ・太さ、読みやすさを左右する行の高さ・字間、揃え方や装飾、最後にWebフォントの使い方までを一通り学びます。地味に見えて、実は一番読者の体験に直結する分野です。

この章で学ぶこと

  • font-family でフォントの優先順位（フォールバック）を指定できる
  • font-size・font-weight・font-style で文字の大きさ・太さ・傾きを指定できる
  • line-height と letter-spacing を調整し、読みやすい行間・字間を作れる
  • text-align・text-decoration・text-indent で文章の見た目を整えられる
  • Webフォント（Google Fonts）を読み込んで使う流れを理解する

5.1 font-family（フォントの指定）

font-family は、文字をどの書体（フォント）で表示するかを指定するプロパティです。ここで注意したいのは、CSSは「このフォントを使え」と一方的に命令しているのではなく、「できればこの順番で試してほしい」という優先順位リストを渡しているという点です。

なぜリストにする必要があるのでしょうか。表示に使われるフォントは、原則として閲覧者の端末にあらかじめインストールされているものに限られます（Webフォントという例外は5.5で扱います）。WindowsとMac、スマートフォンでは標準搭載のフォントが異なるため、1つのフォント名だけを指定すると、それを持たない端末ではブラウザ既定のフォントに置き換わってしまいます。そこで複数の候補をカンマ区切りで並べ、先頭から順に「端末にあるか」を確認していく仕組みが使われます。これをフォールバックと呼びます。

flowchart TD A["最初の候補
Hiragino Sans を探す"] --> B{"端末にある？"} B -->|ある| C["Hiragino Sans を使用"] B -->|ない| D["次の候補
Noto Sans JP を探す"] D --> E{"端末にある？"} E -->|ある| F["Noto Sans JP を使用"] E -->|ない| G["総称ファミリー
sans-serif を使用"]

フォントは大きく3つの総称ファミリー（グループ名）に分類されます。リストの一番最後には、必ずこのいずれかを書いておきます。候補がすべて見つからなくても、近い雰囲気のフォントが最終的に選ばれるようにするための「保険」です。

sans-serif（ゴシック体）

線の太さが均一で飾りの少ない書体。画面での可読性が高く、本文にも見出しにもよく使われます。

読みやすい文章 Aa

serif（明朝体）

線の端に「うろこ」と呼ばれる飾りがある書体。伝統的・上品な印象があり、長文の読み物に使われます。

読みやすい文章 Aa

monospace（等幅）

どの文字も同じ幅で並ぶ書体。文字の桁が揃うため、プログラムのコード表示によく使われます。

読みやすい文章 Aa

日本語サイトでは、欧文フォント・日本語フォント・総称ファミリーの3段構えで指定するのが定番です。次の例を見てみましょう。

style.css 
/* 日本語サイトでの定番的な指定例 */
body {
  font-family:
    "Helvetica Neue", Arial,   /* 欧文フォント（Mac/Windows） */
    "Hiragino Sans",           /* 日本語フォント（Mac） */
    "Noto Sans JP",            /* 日本語フォント（Web/多くの環境） */
    sans-serif;                /* 総称ファミリー（最終手段） */
}

ルール: フォント名にスペースがあれば引用符で囲む

"Hiragino Sans" のようにフォント名の途中にスペース（空白）が含まれる場合は、必ずダブルクォート（またはシングルクォート）で囲みます。Arial のように1単語だけの名前は省略できますが、迷ったら常に引用符をつけておくと安全です。総称ファミリー名（sans-serif など）には引用符を付けません。

5.2 文字の大きさ・太さ・スタイル

文字の見た目を整える基本の3プロパティです。font-size は大きさ、font-weight は太さ、font-style は斜体（イタリック）にするかどうかを指定します。

ブラウザには既定のスタイルがあり、何も指定しなければ本文（body）の文字サイズは16pxです。この16pxという数字は読みやすさの基準としてよく使われ、本文の文字はだいたい16px前後（15〜18px程度）に収めておくと読みやすいとされています。見出しはこれより大きく、注釈や補足は少し小さく——というようにメリハリをつけましょう。

キーワード 数値 説明
normal 400 標準の太さ（既定値）
bold 700 太字。見出しや強調に使う
数値指定 100〜900 100刻みで細かく指定（例: 300はやや細め）

表示見本（Tailwindの標準クラスで再現）

text-sm・font-normal：小さめの注釈テキスト

text-base・font-normal：標準的な本文テキスト

text-lg・font-bold：やや大きめの強調テキスト

text-xl・font-bold・italic：見出し＋斜体

style.css 
/* 見出しと本文でメリハリをつける */
h2 {
  font-size: 24px;
  font-weight: 700;   /* bold と同じ意味 */
}

p {
  font-size: 16px;
  font-weight: 400;   /* normal と同じ意味 */
  font-style: normal;
}

注意: bold を指定しても太くならないことがある

指定したフォントに太字（bold）用の書体データが用意されていない場合、ブラウザが文字を無理やり太らせて表示する疑似太字（フェイクボールド）になることがあります。輪郭がにじんだような見た目になりがちです。日本語フォントは欧文フォントに比べてウェイト（太さ）の種類が少ないことが多く、特に起こりやすい現象です。

5.3 line-height（行の高さ）と letter-spacing（字間）

line-height は、1行分のテキストが占める高さ（行の高さ）を指定するプロパティです。数あるCSSプロパティの中でも読みやすさに与える影響が最も大きいと言われるほど重要な存在です。行間が詰まりすぎると窮屈で読みにくく、逆に空きすぎると文章のまとまりが感じられなくなります。

行間が詰まりすぎ（leading-none）

CSSでは行の高さを調整することで、文章の読みやすさを大きく改善できます。詰まりすぎると目で追いにくくなります。

ゆったり読みやすい（leading-loose）

CSSでは行の高さを調整することで、文章の読みやすさを大きく改善できます。適度な余白が目の動きを助けてくれます。

line-height の値には 24px のような絶対値も指定できますが、実務では単位を付けない数値（例: 1.7）を指定するのが基本とされています。理由は継承のされ方にあります。

単位なしの数値は「その要素自身のfont-sizeの何倍か」という比率として扱われ、子要素にもこの比率がそのまま継承されます。そのため子要素で文字サイズが変わっても、行の高さは常にその子要素の文字サイズに合わせて自動的に再計算されます。もし 24px のような絶対値を指定してしまうと、その固定値がそのまま子要素に継承されるため、文字サイズが大きい子要素では行間が詰まりすぎる、といった崩れが起こりやすくなります。

style.css 
/* 単位なしの数値で行の高さを指定する */
p {
  font-size: 16px;
  line-height: 1.7;        /* font-sizeの1.7倍 ≒ 約27px */
  letter-spacing: 0.02em;  /* 字間をわずかに広げる */
}

letter-spacing は文字と文字の間隔（字間）を調整します。正の値で間隔が広がり、負の値で詰まります。見出しや英字ロゴを少し広めにして上品に見せたり、逆に詰めて力強く見せたりする演出によく使われ、単位は文字サイズ基準の相対単位である em がよく使われます。

重要ポイント

本文の行間で迷ったら line-height に単位なしの数値（日本語なら1.6〜1.8程度）を指定しておけば、まず失敗しません。「px」や「%」ではなく数値だけを書く、という点を体に覚えさせましょう。

5.4 揃え方と装飾（text-align・text-decoration・text-indent）

text-align は文字の横方向の揃え方を指定します。値は4種類、覚えてしまいましょう。

left（既定値）

左揃えの文章です。

center

中央揃えの文章です。

right

右揃えの文章です。

justify（両端揃え）

両端が揃うよう字間を微調整する文章です。

text-decoration は下線・打ち消し線などの装飾を指定します。特によく使うのがリンクの下線を消す・付ける調整です。既定で <a> タグには下線が付きますが、デザインに合わせて消し、マウスを乗せたとき（hover）だけ表示する、という使い方がよくされます。

text-indent は段落の1行目だけを字下げします。日本語の書籍でおなじみの「段落の先頭を1文字分下げる」表現は text-indent: 1em; で再現できます（1em はその要素の文字サイズ1文字分、という意味の単位です）。

style.css 
/* リンクの下線を消し、ホバー時だけ表示する */
a {
  text-decoration: none;
}
a:hover {
  text-decoration: underline;
}

/* 段落の先頭を1文字分ぶら下げる */
p {
  text-indent: 1em;
}

配慮: 下線を消しすぎない

リンクの下線をすべて消してしまうと、色の違いだけがリンクの目印になり、色を判別しにくい方には見分けが付きにくくなります。下線を消す場合は、色を変える・ホバー時に下線を表示するなど、別の手がかりを残す工夫をしましょう。

5.5 Webフォント（Google Fonts）

5.1で学んだ font-family は、あくまで閲覧者の端末にすでにあるフォントの中から選ぶ仕組みでした。候補がどれも見つからなければ、結局ブラウザ既定のフォントに戻ってしまいます。

Webフォントを使うと、この制約がなくなります。フォントのデータそのものをサーバーから読み込んで使う仕組みのため、閲覧者の端末に何がインストールされているかに関係なく誰が見ても同じフォントを表示できます。代表的なサービスが Google が無料で提供する Google Fonts（fonts.google.com）です。

使い方の流れは、次の3ステップです。

  1. Google Fonts のサイトで使いたいフォントを選び、埋め込み用の <link> タグを取得する
  2. 取得した <link> タグを、自分のページの <head> 内に貼り付ける
  3. CSSの font-family に、そのフォント名を指定する
index.html（headの中） 
<head>
  <!-- Google Fontsの読み込み -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP&display=swap"
        rel="stylesheet">
</head>
style.css 
/* 読み込んだWebフォントを指定する */
body {
  font-family: "Noto Sans JP", sans-serif;
}

注意: 日本語Webフォントは容量が大きい

日本語フォントは、ひらがな・カタカナに加えて数千字の漢字を収録しているため、欧文フォントに比べてファイルサイズがはるかに大きくなりがちです。読み込みに時間がかかりページ表示が遅くなる原因になるため、見出しなど使う箇所を絞る・必要なウェイト（太さ）だけを読み込むといった配慮が大切です。

5.6 まとめ：読みやすい本文スタイルを組み立てる

この章で学んだプロパティのうち、フォント・大きさ・行の高さ・色の4つを body にまとめて指定するだけで、ページ全体の読みやすさが見違えるほど改善します。まずはこの「型」をそのまま使えるようにしておきましょう。

style.css 
/* 読みやすい本文スタイルの基本形 */
body {
  font-family: "Hiragino Sans", "Noto Sans JP", sans-serif;
  font-size: 16px;
  line-height: 1.7;
  color: #333333;
}

4行それぞれの役割を振り返っておきましょう。font-family はフォールバック付きでフォントを指定し、font-size は基準となる文字サイズ、line-height は単位なしの数値で行の高さ、color は文字色（次章で詳しく学びます）を担当します。この4つが本文スタイルの土台です。

重要ポイント

迷ったら「フォント指定＋16px前後＋行間1.6〜1.8＋適度なコントラストの文字色」を body に書いておく。この基本形さえ押さえておけば、どんなページでも最低限の読みやすさを確保できます。

やってみよう 5-1: 本文の読みやすさを整えよう

これまでの章で作ったページ（なければ、いくつか <p> を書いた簡単なHTMLファイルでOK）の本文に line-height と font-family を設定し、変更前後で読みやすさがどう変わるか比べてみましょう。

手順

  1. 1 練習用のHTMLファイルを用意し、まずは何もCSSを当てていない状態の本文を眺めておく。
  2. 2 body セレクタに font-family: "Hiragino Sans", "Noto Sans JP", sans-serif; を追加し、保存してブラウザで確認する。
  3. 3 同じ body に line-height: 1.7; を追加し、再読み込みして行間の変化を観察する。
  4. 4 開発者ツール（F12）の Styles パネルで line-height の行のチェックを外したり戻したりして、リアルタイムに違いを比較する。
  5. 5 余裕があれば letter-spacing: 0.02em; も加え、字間の変化も確認してみる。

「正解の値」はありません。文章量やフォントによって心地よい行間は変わります。1.5〜1.8程度の範囲でいくつか試し、自分が一番読みやすいと感じた値を選ぶという体験そのものが大切です。

理解度確認クイズ

  1. Q1. font-family に "Hiragino Sans", "Noto Sans JP", sans-serif のように複数のフォント名をカンマ区切りで指定するのはなぜですか。

    回答を表示

    フォールバックの仕組みを使うためです。表示に使えるフォントは閲覧者の端末にインストールされているものに限られ、環境によって異なります。先頭から順に「端末にあるか」を確認し、最初に見つかったフォントを使うことで、多くの環境で近い見た目を再現できます。最後に総称ファミリー（sans-serifなど）を書いておけば、候補がすべてなくても近い雰囲気のフォントが最終的に選ばれます。

  2. Q2. line-height に line-height: 1.7; のように単位なしの数値を指定するのが推奨されるのはなぜですか。

    回答を表示

    単位なしの数値は「その要素自身のfont-sizeの何倍か」という比率として継承されるため、子要素の文字サイズが変わっても、その都度ふさわしい行の高さに自動で再計算されます。pxなどの絶対値で指定すると、その固定値がそのまま子要素に継承されてしまい、文字サイズが違う子要素で行間が詰まりすぎるといった崩れが起こりやすくなります。

  3. Q3. リンクの下線を消すにはどのプロパティを使いますか。また、下線を完全に消してしまうときに気をつけるべき点は何ですか。

    回答を表示

    text-decoration: none; で下線を消せます。ただし下線をすべて消してしまうと、色の違いだけがリンクの目印になり、色を判別しにくい方には見分けが付きにくくなります。色を変える、ホバー時だけ下線を表示するなど、別の手がかりを残す工夫が必要です。

  4. Q4. 日本語のWebフォント（Google Fontsなど）を使うときに注意すべき点は何ですか。

    回答を表示

    日本語フォントは数千字の漢字を含むため、欧文フォントに比べてファイルサイズが非常に大きくなりがちです。読み込みに時間がかかりページ表示が遅くなる可能性があるため、見出しなど使用箇所を絞る、必要なウェイト（太さ）だけを読み込む、といった配慮が必要です。
