CSSの書き方と適用方法

前章でCSSの全体像をつかんだので、この章ではいよいよ実際に手を動かしてCSSを書いていきます。学習環境の準備、CSSの基本文法（ルールセット）、CSSをHTMLに適用する3つの方法、そして学習の相棒になるブラウザの開発者ツールの使い方までを一通り体験します。

この章で学ぶこと

  • テキストエディタ（VS Code）とブラウザを使った学習環境を整えられる
  • 「セレクタ { プロパティ: 値; }」というCSSのルールセットの文法を説明できる
  • CSSをHTMLに適用する3つの方法を理解し、実務での使い分けが分かる
  • 実際に index.html と style.css を作成し、ブラウザで表示を確認できる
  • コメントの書き方と、ブラウザ開発者ツールでスタイルを調べる方法が分かる

2.1 学習環境を整える

この章から実際に手を動かしていきます。特別なソフトの購入は不要です。テキストエディタ（コードを書くためのソフト）と、普段使っているWebブラウザの2つがあれば、CSSの学習はすぐに始められます。

テキストエディタは Visual Studio Code（VS Code）を推奨します。Microsoft製の無料エディタで、Windows / macOS / Linux のいずれでも動作し、コードを色分け表示（シンタックスハイライト）してくれるため打ち間違いに気づきやすくなります。メモ帳や TextEdit でも学習は可能ですが、色分けや入力補完がなくミスに気づきにくいため、早めに VS Code へ移行するのがおすすめです。ブラウザは普段使っている Chrome・Edge・Firefox・Safari のどれでも構いません。この章の後半で使う「開発者ツール」さえ使えれば十分です。

道具が決まったら作業用のフォルダを1つ作りましょう。デスクトップなど分かりやすい場所に css-lesson のような名前のフォルダを作り、中に次の2つのファイルを用意します。

作業フォルダの構成（例） 

css-lesson/            ← 作業用フォルダ（名前は自由）
├── index.html         ← HTML（内容・構造を書くファイル）
└── style.css          ← CSS（見た目を書くファイル）

HTML用とCSS用のファイルを分けて2つ用意するのが基本形です。第1章で確認した「構造と見た目の分離」をそのまま実践する形であり、2.3節で学ぶ「外部スタイルシート」という適用方法にそのまま対応しています。

ファイル名・フォルダ名は半角英数字で

日本語やスペースを含む名前は、環境によっては読み込みエラーの原因になります。css-lesson や style.css のように、半角の英数字・ハイフン・アンダースコアだけで名付ける習慣を最初から身につけておきましょう。

2.2 CSSの文法（ルールセット）

第1章で、CSSの指示はいつも「どこに」「何を」「どうする」の3点セットだとお伝えしました。これをそのままCSSの書き方に当てはめたものが、次のルールセット（1つのスタイル指定のかたまり）です。

CSSのルールセットの構造

h1 { color: orange; }

セレクタ

「どこに」

{ }（宣言ブロック）

指定をまとめる部分

プロパティ

「何を」

値

「どうする」

「プロパティ: 値;」という1組を宣言と呼びます。1つのセレクタに対して宣言はいくつでも書け、複数書くときはセミコロン（;）で1つずつ区切ります。

style.css 
/* 見出しの見た目をまとめて変える */
h1 {
  color: orange;      /* 文字色 */
  font-size: 32px;    /* 文字の大きさ */
  text-align: center; /* 中央寄せ */
}

初心者がつまずきやすいポイント

  • セミコロン忘れ: 宣言の末尾の ; を忘れると、次の宣言が正しく認識されないことがあります。
  • 波かっこの閉じ忘れ: { は書いたのに } を忘れると、それ以降の指定がすべて壊れます。
  • 全角記号の混入: 日本語入力モードのまま打つと color： orange； のように全角の「：」「；」が紛れ込みます。見た目はそっくりですがCSSとして認識されません。記号はすべて半角で入力しましょう。

2.3 CSSを適用する3つの方法

CSSの書き方が分かったところで、次はそれをHTMLに「適用する」方法です。実はCSSは3つの異なる場所に書くことができます。同じ「お知らせ文をteal色（青緑）にする」を、3通りで実現してみましょう。

① 外部スタイルシート（<link>タグ）

CSSを別ファイルにし、<head> 内で <link> タグを使って読み込みます。style.css 側には .notice { color: teal; } と書くだけです。2.1節の index.html / style.css の構成がこの方法にあたります。

index.html（head内） 
<!-- style.css を読み込む -->
<link rel="stylesheet" href="style.css">

② <style>タグ（内部スタイルシート）

別ファイルを作らず、<head> 内の <style> タグにCSSを直接書き込みます。

index.html（head内） 
<style>
  /* お知らせ文の文字色を変える */
  .notice { color: teal; }
</style>

③ style属性（インラインスタイル）

タグの中に直接 style="..." という属性を書き込みます。その要素1つだけにスタイルが適用されます。

index.html 
<!-- style属性に直接CSSを書く -->
<p style="color: teal;">お知らせがあります</p>

3つとも見た目の結果は同じです。書く場所と影響範囲が違うだけ、という点を比較表で確認しましょう。

方法 書く場所 メリット デメリット
① 外部スタイルシート 別ファイル（.css） 複数ページで使い回せる。HTMLがすっきりする ファイルを2つ管理する必要がある
② <style>タグ HTMLの<head>内 1ファイルだけで完結する ページが増えると同じ記述を繰り返すことになる
③ style属性 タグの中に直接 その場ですぐ指定できる 量が増えると管理できなくなる（詳細度の問題は第4章）

結論: 実務では外部スタイルシートが基本

保守のしやすさと使い回しやすさから、実務では①外部スタイルシートが基本です。②は検証用の一時的な確認、③はJavaScriptで動的に値を変える場合など、限られた場面で使われます。この教材でも、以降は外部スタイルシートを使って進めます。

2.4 はじめてのCSSを書いてみる

理屈が分かったところで、実際に手を動かしてみましょう。2.1節で作った作業フォルダに、外部スタイルシート方式で2つのファイルを作成します。

  1. 1 VS Codeで作業フォルダを開く — 「ファイル」→「フォルダを開く」から css-lesson を選択する。
  2. 2 index.html を新規作成 — 下記の内容を入力し、半角のファイル名で保存する。
  3. 3 style.css を新規作成 — 下記の内容を入力し、index.html と同じフォルダに保存する。
  4. 4 index.html をブラウザで開く — エクスプローラー（Finder）でダブルクリックするか、ブラウザへドラッグ＆ドロップする。
  5. 5 表示を確認する — 見出しがオレンジ色の背景・白い文字になっていれば成功。
index.html 
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>はじめてのCSS</title>
  <!-- style.css を読み込む -->
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>はじめてのCSS</h1>
  <p>この文章はCSSで見た目を変えています。</p>
</body>
</html>
style.css 
/* 見出しの文字色と背景色を変える */
h1 {
  color: #ffffff;
  background-color: #f97316;
  padding: 12px;
}

/* 段落の文字色を少し薄くする */
p {
  color: #475569;
}

ブラウザでの表示イメージ

はじめてのCSS

この文章はCSSで見た目を変えています。

見た目が変わらないときのチェックリスト

  • ファイルを保存したか（VS Codeのタブに ● が出ていないか確認）
  • href="style.css" のファイル名が実際のファイル名と一致しているか
  • index.html と style.css が同じフォルダに入っているか
  • ブラウザを再読み込み（F5キー）したか

2.5 コメントの書き方と開発者ツール

最後に、これから何度も使う2つの道具を紹介します。CSSファイルの中にメモを残す「コメント」と、ブラウザに標準搭載されている「開発者ツール」です。

コメントの書き方

CSSのコメントは /* … */ で囲みます（HTMLの <!-- … --> とは書き方が異なります）。ブラウザはコメントを無視するので、メモを残したり、指定を一時的に無効にする「コメントアウト」に使えます。

style.css 
/* 見出しの色をオレンジにする */
h1 {
  color: orange;
}

/* 一時的に無効化（コメントアウト） */
/* p { font-size: 20px; } */

ブラウザ開発者ツールを開く

開発者ツールは、ページのHTML構造とCSSをその場で調べたり試したりできる機能です。F12 キー（Macは Option + Command + I）か、右クリック →「検証」で開きます。よく使うのは、HTML構造がツリー表示されるElements（要素）パネルと、選んだ要素に効いているCSSが一覧表示されるStyles（スタイル）パネルの2つです。Stylesパネルの値はその場でクリックして書き換え、結果をすぐ確認できます。

flowchart LR A["F12で開発者ツールを開く"] --> B["Elementsパネルで要素を選択"] B --> C["Stylesパネルで適用中のCSSを確認"] C --> D["値をクリックして書き換える"] D --> E["画面がリアルタイムに変化"] E --> F["再読み込みすると元に戻る（未保存）"]

壊れる心配はありません

開発者ツールでの変更はブラウザ上の表示だけを一時的に書き換えるもので、実際の style.css は変わりません。再読み込みすれば必ず元に戻ります。気に入った値が見つかったら、エディタ側のCSSファイルにも書き写して保存するのを忘れないようにしましょう。

やってみよう 2-1: 見出しの色と背景色を変えてみよう

2.4節で作った index.html と style.css を使って、今度は自分で値を選んで見た目を変えてみましょう。

手順

  1. 1 index.html の <h1> の中身を、自分の名前に書き換える。
  2. 2 まず開発者ツール（F12）のStylesパネルで color と background-color の値をいろいろ試す（例: red、blue、green、hotpink など英単語の色名で構いません）。
  3. 3 気に入った組み合わせを、style.css の h1 の宣言ブロックに書き写して保存する。
  4. 4 ブラウザを再読み込みし、開発者ツールを閉じても変更が残っていることを確認する。

色の指定方法は色名以外にもたくさんの種類があります（第6章）。ここではまず「値を変えると見た目が変わる」感覚をつかむことが目的です。セミコロンや波かっこを忘れていないか、2.2節も見返しながら進めましょう。

理解度確認クイズ

  1. Q1. CSSのルールセットにおける「セレクタ」とは何を指定する部分か、説明してください。

    回答を表示

    「どこに」スタイルを当てるか、つまりどの要素にスタイルを適用するかを指定する部分です。例えば h1 と書けば、すべての見出し1（h1要素）が対象になります。

  2. Q2. 次のCSSには、よくある入力ミスが1つあります。どこが誤りか指摘してください。

    h1 { color: red font-size: 20px; }

    回答を表示

    color: red の後にセミコロン（;）がありません。宣言の区切りにはセミコロンが必須で、書き忘れると意図したとおりにスタイルが適用されないことがあります。正しくは color: red; font-size: 20px; です。

  3. Q3. CSSをHTMLに適用する3つの方法を挙げ、実務で基本となるのはどれか答えてください。

    回答を表示

    「外部スタイルシート（<link>）」「<style>タグ（内部）」「style属性（インライン）」の3つです。複数ページで使い回せて保守しやすいことから、実務では外部スタイルシートが基本となります。

  4. Q4. 開発者ツールでCSSの値を書き換えて確認した内容は、ページを再読み込みするとどうなりますか。理由もあわせて答えてください。

    回答を表示

    元の状態に戻ります。開発者ツールでの編集はブラウザ上の表示を一時的に変えているだけで、実際のCSSファイルそのものは書き換わっていないためです。変更を残したい場合は、値をエディタ側のCSSファイルへ書き写して保存する必要があります。
