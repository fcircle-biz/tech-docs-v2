CSS Gridでレイアウト

前章の Flexbox は「一列に並べる」ための道具でした。この章で学ぶ CSS Grid は、縦と横を同時に扱える二次元のレイアウト方式です。列の定義の仕方から、画面幅に応じて列数が自動で変わる実用的なカード一覧、ページ全体の骨組みの組み方まで、順を追って身につけていきましょう。

この章で学ぶこと

  • CSS Grid が「縦横（二次元）」でレイアウトを組む仕組みであることを、Flexboxとの違いから説明できる
  • grid-template-columns と fr 単位、repeat() を使って列を定義できる
  • minmax() と repeat(auto-fit, ...) を使い、画面幅に応じて列数が自動で変わるカード一覧を作れる
  • grid-template-areas でページ全体の骨組みを組み、Flexbox と Grid を適切に使い分けられる

10.1 CSS Grid とは

CSS Grid（グリッドレイアウト）は、要素を縦横の格子（グリッド）状に並べるためのレイアウト方式です。並べたい親要素に display: grid; を指定すると、その要素はグリッドコンテナになり、直属の子要素がグリッドアイテムとして格子のマス目に配置されます。

第9章の Flexbox は「1本の線に沿って並べる」一次元のレイアウトでした。横に並べるか縦に並べるか、どちらか一方しか一度には扱えません。これに対して Grid は、列（縦の並び）と行（横の並び）を同時に定義できる二次元のレイアウトです。表計算ソフトのマス目をイメージすると分かりやすいでしょう。

Flexbox ＝ 一次元

横一列、または縦一列。1本の軸に沿って要素を並べる。ナビゲーションやボタン列が得意（第9章）。

Grid ＝ 二次元

縦と横を同時に管理。ページ全体の骨組みやカード一覧など、格子状のレイアウトが得意（この章）。

Grid の基本用語を先に押さえましょう。格子の縦の並びを列（column）、横の並びを行（row）、列と行が交差してできる1マスをセル（cell）と呼びます。次の例は3列2行、合計6セルのグリッドです。

display: grid; だけではまだ1列のまま

display: grid; を指定しただけでは、列や行の数はまだ決まっていません。何も指定しなければ子要素は縦に1列で並びます。次の10.2で、列の幅と数を指定する方法を学びます。

10.2 列を定義する（grid-template-columns）

列の幅と数は grid-template-columns で指定します。書き方には主に3つのパターンがあります。

style.css（① 固定値で指定） 
.container {
  display: grid;
  /* 200pxの列を3つ並べる(合計600px固定) */
  grid-template-columns: 200px 200px 200px;
}

固定値はシンプルですが、画面の幅が変わっても列幅が変わらないため、余白が余ったりはみ出したりします。そこで使うのがfr 単位（fraction＝割合の意味）です。

style.css（② fr単位で指定） 
.container {
  display: grid;
  /* 余った幅を 1:2:1 の比率で分け合う */
  grid-template-columns: 1fr 2fr 1fr;
}

fr は「コンテナの余った幅を指定した比率で分け合う」単位です。1fr 1fr 1fr なら3等分、1fr 2fr 1fr なら中央の列だけ2倍の幅になります。gap（余白）の分は先に差し引いてから計算されるため、% 単位のように余白の計算を自分でする必要がありません。

同じ幅の列を何個も並べたいときは、repeat() でまとめて書けます。

style.css（③ repeat()で指定） 
.container {
  display: grid;
  /* 1frを3回繰り返す。上の指定と同じ結果になる */
  grid-template-columns: repeat(3, 1fr);
}

固定値と fr は混在できる

grid-template-columns: 240px 1fr; と書けば「幅240pxの固定サイドバー＋残り全部が本文」という定番レイアウトが1行で作れます。実務でとてもよく使う書き方です。

10.3 行の定義と gap

行（横の並び）の高さは grid-template-rows で指定します。書き方は列とまったく同じで、固定値・fr・repeat() がそのまま使えます。実務では行の高さを中身に合わせて自動で決めたい場面が多いため、auto（内容に合わせる）と組み合わせることがよくあります。

style.css 
.page {
  display: grid;
  /* ヘッダー100px・本文は残り全部・フッター60px */
  grid-template-rows: 100px auto 60px;
}

セルどうしの余白は gap でまとめて指定します。行の間だけ変えたいときは row-gap、列の間だけ変えたいときは column-gap を個別に使えます。

style.css 
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  row-gap: 24px;    /* 行の間は広め */
  column-gap: 12px; /* 列の間は狭め */
}

gap-1（狭い）

gap-4（広い）

重要ポイント

gap はセルの外側の余白ではなく、セルどうしの間だけに効きます。マージンのように端の余白が二重になる心配がなく、等間隔に並べたいときにとても扱いやすいプロパティです。

10.4 レスポンシブに効く書き方（minmax と auto-fit）

repeat(3, 1fr) は列数が「3」に固定されています。PCでは3列がちょうど良くても、スマートフォンの狭い画面では3列とも細くつぶれてしまいます。かといって画面幅ごとに列数を書き分けるのは面倒です。ここで役立つのが minmax() と auto-fit の組み合わせです。

minmax(最小値, 最大値) は、1つの列に対して「これより狭くはならないが、これより広くはならない」という範囲を指定する書き方です。たとえば minmax(240px, 1fr) は「最低240px、余裕があれば1fr分まで広がってよい」という意味になります。

これを repeat() の繰り返し回数の位置に auto-fit というキーワードを入れて組み合わせると、「幅240px以上を保てる範囲で、入るだけの列数を自動計算して並べる」という指定になります。数字を一切書かずに、画面幅に応じて列数が変わるカード一覧が完成します。

style.css 
.cards {
  display: grid;
  /* 最低240pxを保ちつつ、入るだけ列を自動生成する */
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}

画面幅によって、実際にはおおよそ次のように列数が変化します（minmax(240px, 1fr)・gap: 16px の場合の目安です）。

コンテナの幅 列数の目安 画面のイメージ
1200px以上 4〜5列 PCの広いウィンドウ
700〜900px 2〜3列 タブレットや小さめのウィンドウ
400px以下 1列 スマートフォン

メディアクエリなしで列数が変わる

この書き方の最大の利点は、@media（第11章で学びます）を1行も書かずに列数が自動調整される点です。「カード一覧」「商品一覧」「画像ギャラリー」など、同じ形の要素をたくさん並べる場面では、まずこのパターンを検討すると効率的です。

10.5 grid-template-areas で骨組みを組む

Grid には、レイアウトの各パーツに名前を付けて配置できる grid-template-areas という書き方があります。文字列そのものが完成図のように見えるため、CSSを読むだけでページの構造がひと目で分かるのが大きな利点です。

使い方は2ステップです。まず各要素に grid-area で名前を付け、次にコンテナ側の grid-template-areas に、配置したい形のまま文字列として書きます。

style.css 
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  /* 文字列がそのまま完成図になる */
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

"header header" のように同じ名前を横に並べると、その名前のパーツが2列分を占めます。ブラウザで実際に描画すると、次のような配置になります。

grid-template-areas の見た目

header
sidebar
main
footer

よくあるエラー: 長方形になっていない

grid-template-areas の文字列は、同じ名前どうしが必ず長方形の形になっている必要があります。L字形のような並びはエラーになります。空けておきたいマスには、名前の代わりに .（ピリオド）を書きます。

10.6 Flexbox と Grid の使い分け

Flexbox と Grid は、どちらか一方が優れているというものではなく、得意な場面が違う道具です。判断に迷ったときのために、特徴を表で整理しておきましょう。

観点 Flexbox Grid
次元 一次元（横 or 縦の一列） 二次元（行と列を同時に）
得意なこと ナビゲーション・ボタン列・カード内部の並び ページ全体の骨組み・カード一覧・ギャラリー
考え方 中身のサイズを基準に並ぶ 先に格子の枠を決め、中身を当てはめる
主なプロパティ flex-direction / justify-content / align-items grid-template-columns / rows / areas

判断に迷ったときは、次のように考えると整理しやすくなります。

flowchart TD A["配置したい要素がある"] --> B{"1方向だけに並べればよいか？"} B -->|はい：横一列 または 縦一列| C["Flexbox が向いている"] B -->|いいえ：行と列を両方使いたい| D["Grid が向いている"] C --> E["例：ナビゲーション・ボタン群・カード内部の並び"] D --> F["例：ページ全体の骨組み・カード一覧・ギャラリー"]

重要ポイント: 併用するのが普通

実務では、ページ全体の骨組みは Grid で組み、その中の要素（ヘッダー内のロゴとメニューなど）は Flexbox で並べる、という組み合わせがよく使われます。どちらか一方だけを使い切る必要はありません。第14章の総合演習でも、この組み合わせ方を実践します。

やってみよう 10-1: 列数が自動で変わるカード一覧を作る

10.4で学んだ repeat(auto-fit, minmax(...)) を実際に手を動かして試し、ブラウザの幅を変えるだけで列数が変化する様子を自分の目で確認しましょう。

手順

  1. 1 練習用フォルダに cards.html を作り、下のHTMLのようにカードを6枚用意する。
  2. 2 同じフォルダに style.css を作り、下のCSSのように .cards に repeat(auto-fit, minmax(220px, 1fr)) を指定する。
  3. 3 ブラウザで cards.html を開き、ウィンドウの端をドラッグして幅を広げたり狭めたりする。カードの列数が自動で増減する様子を観察する。
  4. 4 発展: minmax(220px, 1fr) の220pxを350pxに変更して再読み込みし、列数の変わり方を比べてみる。
cards.html 
<!-- カードを6枚並べる -->
<div class="cards">
  <div class="card">カード1</div>
  <div class="card">カード2</div>
  <div class="card">カード3</div>
  <div class="card">カード4</div>
  <div class="card">カード5</div>
  <div class="card">カード6</div>
</div>
style.css 
.cards {
  display: grid;
  /* 最低220pxを保ちつつ列数を自動計算する */
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
.card {
  background-color: #ffedd5;
  border-radius: 8px;
  padding: 24px;
  text-align: center;
}

列数をどこにも数字で書いていないのに、ブラウザが幅を見て自動的に列数を計算してくれる — これが実務で最もよく使われる Grid の定番パターンです。次章のメディアクエリと組み合わせると、さらに細かく調整できるようになります。

理解度確認クイズ

  1. Q1. Flexbox と CSS Grid の根本的な違いを、「次元」という言葉を使って説明してください。

    回答を表示

    Flexbox は一次元（横一列、または縦一列に要素を並べる）、Grid は二次元（行と列を同時に管理する）のレイアウト方式であるという違いです。1本の軸だけで済むならFlexbox、行と列を両方使いたいならGridが向いています。

  2. Q2. grid-template-columns: 1fr 2fr 1fr; と指定すると、3つの列の幅はどのような比率になりますか。

    回答を表示

    余った幅（gapなどを除いた分）を1:2:1の比率で分け合います。真ん中の列だけが両端の2倍の幅になります。fr は「fraction（割合）」の意味で、コンテナの余り幅を基準に計算されます。

  3. Q3. repeat(auto-fit, minmax(240px, 1fr)) という指定は何をしてくれるか説明してください。

    回答を表示

    各列の最小幅を240pxに保ちながら、コンテナの幅に収まるだけの列数を自動的に計算して配置してくれます。メディアクエリを1行も書かなくても、ウィンドウ幅を変えるだけで列数が自動的に増減するレスポンシブなカード一覧が作れます。

  4. Q4. grid-template-areas を使う利点は何ですか。また、実務では Flexbox と Grid をどのように使い分けるのが一般的ですか。

    回答を表示

    grid-template-areas は、レイアウトの見た目を文字列としてそのまま表現できるため、CSSを見ただけでページの構造が直感的に分かるのが利点です。実務では、ページ全体の骨組みは Grid で組み、その中の要素（ナビゲーションやボタン列など一列に並べたいもの）は Flexbox で並べる、というように併用するのが一般的です。
