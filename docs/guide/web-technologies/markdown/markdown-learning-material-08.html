表（テーブル）

表（テーブル）は、複数の項目を列と行に整理して見やすく見せるための記法です。Markdown では、縦棒とハイフンだけを使ったシンプルなルールで表を作成できます。この章では、表の基本形から、列の揃え方、表の中で使える装飾と制約、そして表を楽に書くコツまでを学びます。

この章で学ぶこと

  • 表の基本記法（縦棒で列を区切り、区切り行を書く）を使って表を書ける
  • ヘッダー行・区切り行・データ行という3点セットの役割を説明できる
  • 列を左揃え・中央揃え・右揃えにする書き方を使い分けられる
  • 表の中で使える装飾と、セル内改行の書き方（制約）が分かる
  • 縦棒の位置を厳密に揃えなくてよいことなど、表を楽に書くコツを知る

8.1 表の基本形 ── 縦棒と区切り行

Markdown で表を作るために覚えるルールは、たった2つだけです。1つ目は、|（縦棒／パイプ）で列と列の間を区切ること。2つ目は、1行目（見出しの行）の直後に、---（ハイフン）だけを並べた特別な行を1行はさむことです。この特別な行を区切り行と呼びます。区切り行があることで、パーサー（Markdown を HTML に変換するツール）は「これは表だ」と認識できます。

言葉で説明するよりも、実際に書いたテキストと表示結果を見比べたほうが早く理解できます。次の例を見てみましょう。

書いたテキスト（Markdown）

members.md 
| 名前 | 担当 |
| --- | --- |
| 田中 | フロントエンド |
| 佐藤 | バックエンド |

表示イメージ

名前 担当
田中 フロントエンド
佐藤 バックエンド

コードの1行目が見出し（列名）、2行目が区切り行、3行目以降が実際のデータになっています。この並び順はとても重要で、次の8.2で詳しく見ていきます。

ヒント: 先頭と末尾の縦棒は省略できる

各行の先頭と末尾の | は、実は省略しても動作します。ただし、書いておいたほうが「表の範囲」がひと目で分かりやすいため、この教材では省略せずに書くスタイルで統一しています。

8.2 ヘッダー行・区切り行・データ行という3点セット

Markdown の表は、必ず次の3種類の行が、この順番で並ぶという決まった構造でできています。それぞれの行が持つ役割を整理してみましょう。

行の位置 名前 役割
1行目 ヘッダー行 各列の見出し（タイトル）になる
2行目 区切り行 --- だけを並べる行。表であることの目印で、それ自体は画面に表示されない
3行目以降 データ行 実際に表示される値。必要なだけ何行でも追加できる

実際に3列の表で確認してみましょう。

weather.md 
| 曜日 | 天気 | 気温 |
| --- | --- | --- |
| 月曜日 | 晴れ | 28℃ |
| 火曜日 | くもり | 24℃ |
| 水曜日 | 雨 | 20℃ |

1行目が「曜日・天気・気温」というヘッダー行、2行目が --- だけの区切り行、3行目以降がデータ行です。ヘッダー行・区切り行・データ行は、それぞれの縦棒で区切られた列の数をそろえるのが基本です。この例ではどの行も3列（縦棒が4つ）になっています。列の数が行によってバラバラだと、表が崩れたり意図通りに表示されなかったりする原因になります。

重要ポイント

「ヘッダー行 → 区切り行 → データ行」という順番を守ることが表作りの命です。区切り行を書き忘れると、Markdown はそれを表だと認識せず、ただの文章として表示してしまいます。

8.3 列の揃え方 ── 左揃え・中央揃え・右揃え

区切り行の書き方を少し変えるだけで、それぞれの列の文字を左揃え・中央揃え・右揃えに指定できます。ポイントは、区切り行のハイフンの前後に :（コロン）を付けるかどうかです。

書き方 揃え方 説明
--- 左揃え（既定） コロンを付けない場合。何も指定しないのと同じ扱い
:--- 左揃え 左側にコロンを付ける。結果は無指定のときと同じ見た目
:---: 中央揃え 両側にコロンを付ける
---: 右揃え 右側だけにコロンを付ける。金額などの数値でよく使われる

3つの揃え方を1つの表の中で組み合わせた例を見てみましょう。

書いたテキスト（Markdown）

items.md 
| 商品名 | 価格 | 評価 |
| :--- | ---: | :---: |
| ノートPC | 98,000円 | ★★★ |
| マウス | 1,500円 | ★★ |

表示イメージ

商品名 価格 評価
ノートPC 98,000円 ★★★
マウス 1,500円 ★★

価格のような数値の列は右揃えにすると桁がそろって読みやすくなります。評価のような短い記号は中央揃えが向いています。文章が入る列は、基本の左揃えのままで問題ありません。

8.4 表の中で使える装飾と制約

表のセルの中では、これまでの章で学んだ太字・インラインコード・リンクなどの記法がそのまま使えます。ただし、1つのセルは基本的に「1行の文章」として扱われるため、いくつか制約もあります。まずは例を見てみましょう。

tools.md 
| 項目 | 内容 |
| --- | --- |
| 重要度 | **高** |
| インストール | `npm install` |
| 公式サイト | [Markdown Guide](https://www.markdownguide.org/) |
| 対応OS | Windows<br>macOS<br>Linux |

表示イメージ

項目 内容
重要度 高
インストール npm install
公式サイト Markdown Guide
対応OS Windows
macOS
Linux

セルの中で使うときに、覚えておきたい制約が3つあります。

  • リストや引用、コードブロックのような「複数行にまたがる書き方」はセルの中では使えません（1つのセルは1行のテキストとして扱われるため）
  • セルの中で改行したいときは、空行ではなく HTML の <br> タグを使います。表では空行を入れるとそこで行が終わったと判断され、表の構造が崩れてしまうためです
  • セルの中に縦棒をそのまま書きたい場合は、\| のように直前に \（バックスラッシュ）を付けてエスケープします（列の区切りと区別するため）

8.5 表を楽に書くコツ

表は縦棒の数が多く、慣れないうちは面倒に感じるかもしれません。ですが、いくつかのコツを知っておくと驚くほど楽になります。

縦棒の位置は完璧に揃えなくてよい

実は、各行の縦棒の位置を几帳面にそろえる必要はありません。パーサーは縦棒の数と並びだけを見ているので、次の2つのコードは見た目が違うだけで、結果はまったく同じ表になります。

きれいに揃えた例

score.md 
| 名前   | 得点 |
| ------ | ---- |
| 田中   | 90   |
| 佐藤   | 85   |

揃えなくても動く例

score.md 
| 名前 | 得点 |
| --- | --- |
| 田中 | 90 |
| 佐藤 | 85 |

どちらも結果は同じ表になるので、まずは揃えることを気にせず、崩れを恐れずにどんどん書いてみましょう。

エディタの整形支援を頼る

第2章で紹介した拡張機能「Markdown All in One」を VS Code に入れておくと、表の上にカーソルを置いた状態でコマンドパレット（Ctrl+Shift+P、Mac は Cmd+Shift+P）から「Format Table（表の整形）」を実行するだけで、縦棒の位置が自動できれいに揃います。手作業で空白の数を数える必要はありません。

オンラインツールで自動生成する

行数や列数が多い表を1から手で書くのは大変です。「Markdown Tables Generator」のようなオンラインツールに Excel や CSV のデータを貼り付けると、Markdown の表を自動生成してくれます。既存の表データを Markdown 化したいときは、こうしたツールをぜひ活用しましょう。

よくある失敗

  • 区切り行（--- の行）を書き忘れる → 表ではなくただの文章として表示されてしまう
  • 行によって縦棒（列）の数が違う → 表が崩れたり、意図しない列に値が入ったりする
  • 区切り行のハイフンを0個にしてしまう → 表として認識されないことがある。各列3個以上のハイフンを書くのが安全

やってみよう 8-1: 好きなものリストを表にしてみよう

自分の好きな映画・本・ゲームなどを3つ選んで、実際に表を作ってみましょう。区切り行と揃え方を自分の手で書くことで、この章の内容がしっかり身に付きます。

手順

  1. 1 VS Code で新しい .md ファイルを作成し、「作品名 | ジャンル | おすすめ度」というヘッダー行と、その下に区切り行を書く。
  2. 2 お気に入りの作品を3つ、データ行として追加する。「おすすめ度」の列だけ区切り行を :---: にして、中央揃えにしてみる。
  3. 3 プレビュー（Ctrl+Shift+V）で表示を確認したら、あえてどれか1行だけ縦棒を1つ減らしてみて、表の見た目がどう崩れるかも観察してみよう（確認できたら元に戻す）。

理解度確認クイズ

  1. Q1. Markdown で表を作るとき、ヘッダー行の直後に書く必要がある特別な行を何と呼びますか。また、どのような記号で構成されますか。

    回答を表示

    「区切り行」と呼びます。各列につき ---（ハイフンを3個以上）を並べて書きます。この行があることで、パーサーは直前の行を表のヘッダーとして認識します。

  2. Q2. 列の文字を右揃えにしたいとき、区切り行はどのように書きますか。また、どのような列に使うと便利ですか。

    回答を表示

    ハイフンの右側にコロンを付けて ---: のように書きます。金額や数量など、桁をそろえて読みたい数値の列で使うと読みやすくなります。

  3. Q3. 表のセルの中で文章を改行したいとき、空行を入れる方法が使えないのはなぜですか。代わりに何を使えばよいですか。

    回答を表示

    表では空行を入れると、そこで行が終わったとパーサーに判断され、表の構造が崩れてしまうためです。代わりに HTML の <br> タグをセルの中に書くことで、改行を表現できます。
