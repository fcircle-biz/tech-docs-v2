第4章 所要時間: 約30分

文字の装飾

見出しや段落で文書の骨組みができたら、次は文中の一部の文字を目立たせる「装飾」を学びましょう。太字・斜体・太字＋斜体・打ち消し線・インラインコードという5種類の書き方と、それぞれをどんな場面で使うとよいかを、記法と表示結果を見比べながら身につけていきます。

この章で学ぶこと

  • 太字（**太字**）で重要な語句を強調できる
  • 斜体（*斜体*）と太字＋斜体（***太字＋斜体***）の書き方が分かる
  • 打ち消し線（~~打ち消し~~）とインラインコードの使いどころが分かる
  • 装飾がうまく効かないときの原因（記号と文字の間のスペースなど）が分かる

4.1 文字を装飾するとは

第3章では、# で見出しを作ったり、空行で段落を分けたりと、文書全体の骨組みを作る記法を学びました。この章で学ぶのは、その骨組みの中、つまり文章の一部分だけを目立たせたり、特別な意味を持たせたりする「インライン装飾」の記法です。用語解説: インラインとは「行の途中に差し込む」という意味です。見出しのように独立した1行を占めるのではなく、文中の一部だけに効果をつけます。

Markdown には、次の5種類の装飾が用意されています。まずはざっと全体像をつかみ、詳しい書き方は 4.3 以降で1つずつ確認していきましょう。

  • 太字 — **太字** のように挟む。重要な語句を強く見せる
  • 斜体 — *斜体* のように挟む。軽い強調やニュアンスを添える
  • 太字＋斜体 — ***太字＋斜体*** のように挟む。特に強い強調に使う
  • 打ち消し線 — ~~打ち消し~~ のように挟む。取り消した情報を示す
  • インラインコード — バッククォートで `コード` のように挟む。コマンドやファイル名を文中で示す

豆知識: 装飾の正体もHTMLタグ

第1章で学んだとおり、Markdown はパーサーによって HTML に変換されます。太字は <strong> タグ、斜体は <em> タグ、打ち消し線は <del> タグ、インラインコードは <code> タグに変換されています。記号を覚えるだけで、裏側では正しい HTML タグが自動的に組み立てられているのです。

4.2 書いた記法 と 表示イメージ を見比べてみよう

言葉で説明するより、実際の例を見たほうが早く理解できます。社内の「お知らせ」を題材に、複数の装飾を組み合わせて書いた例を見てみましょう。左が書いたテキスト（Markdown）、右がその表示イメージです。

書いたテキスト（Markdown）

notice.md 
## 今週のお知らせ

**会議室が変更**になりました。

*当日は10分前に集合*してください。

~~旧会議室（3F）~~ → 新会議室（5F）

不明点は `slack-channel` で質問してください。

表示イメージ

今週のお知らせ

会議室が変更になりました。

当日は10分前に集合してください。

旧会議室（3F） → 新会議室（5F）

不明点は slack-channel で質問してください。

**・*・~~・バッククォートといった記号が、それぞれ太字・斜体・打ち消し線・インラインコードに変身していることに注目してください。ここからは、1つずつの書き方を詳しく見ていきましょう。

4.3 太字にする（**太字**）

太字にしたい文字を、アスタリスク記号（*）2つで両側から挟みます。掛け算などで使う「*」の記号です。

この機能は**重要**です

この機能は重要です

表示すると ** の記号は消え、挟まれていた文字だけが太く表示されます。結論・キーワードの初出・注意してほしい語句など、読者に「ここだけは見逃さないで」と伝えたい部分に使うと効果的です。

4.4 斜体にする（*斜体*）

斜体にしたい文字を、アスタリスク1つで両側から挟みます。太字が記号「2つ」だったのに対して、斜体は「1つ」だけという違いに注意しましょう。

これは*参考資料*です

これは参考資料です

斜体は、太字ほど強くはないけれど軽くニュアンスを添えたいときや、書籍・作品のタイトル、外来語などに使われます。

注意: 日本語の斜体は分かりにくいことがある

英語のフォントには「斜体専用のデザイン」が用意されていることが多い一方、日本語のフォント（特にゴシック体）は斜体専用のデザインを持たないものが多く、画面が文字を無理やり傾けて表示する「疑似斜体」になりがちです。そのため日本語の文章では、傾きが小さくて気づきにくかったり、環境によってはほとんど変化しなかったりします。日本語で強調したいときは、まず太字を検討するのがおすすめです。

4.5 太字と斜体を組み合わせる（***太字＋斜体***）

太字と斜体を同時に使いたいときは、アスタリスク3つで両側から挟みます。「太字の2つ」と「斜体の1つ」を足した記号、と覚えると理解しやすいでしょう。

***締切は本日中***です

締切は本日中です

太字よりもさらに強い、最上級の強調として使います。ただし目立ちすぎるため、1つの文書の中で使うのは多くても数回程度にとどめるのがコツです。

4.6 打ち消し線を引く（~~打ち消し~~）

打ち消し線を引きたい文字を、チルダ記号（~）2つで両側から挟みます。用語解説: チルダとはキーボードにある波形の記号「~」のことです。

~~1,000円~~ 800円

1,000円 800円

「取り消した」「古くなった」という意味を視覚的に伝えられるので、価格の変更・完了したタスク・修正前の情報を示すときによく使われます。なお打ち消し線は GitHub などで広く使われている拡張記法で、対応状況は環境によって少し異なります（詳しくは第9章で扱います）。

4.7 インラインコードで示す（`コード`）

文中でコマンドやファイル名などを示したいときは、バッククォート（`）で両側から挟みます。用語解説: バッククォートはシングルクォート（'）とよく似ていますが別の記号です。多くの日本語（JIS）キーボードでは「Shift」を押しながら「@」キーを押すと入力できます。英語配列のキーボードでは数字キー「1」の左隣にあります。

`git status` を実行します

git status を実行します

インラインコードにすると、等幅フォント（文字の幅がそろったフォント）と薄い背景色で表示され、普通の文章と区別がつきやすくなります。コマンド名・ファイル名・変数名・短いコードの一部などを文中で説明するときに使いましょう。複数行にわたる長いコードを示したいときは、このインラインコードではなく「コードブロック」という別の記法を使います（第7章で学びます）。

4.8 記法まとめと実践のコツ

ここまで5種類の装飾を見てきました。最後に一覧表で全体を振り返り、実践でつまずきやすいポイントを確認しておきましょう。

記法 効果 表示結果
**太字** 重要な語句を強く見せる 太字
*斜体* 軽い強調・ニュアンスを添える 斜体
***太字＋斜体*** 太字と斜体を同時に使い、さらに強く強調する 太字＋斜体
~~打ち消し~~ 古い情報や取り消した内容を示す 打ち消し
`コード` コマンド・ファイル名・変数名などを文中で示す コード

注意: 記号は文字にぴったりくっつける

記号と、装飾したい文字の間にスペースや改行を入れると、装飾として認識されません。アスタリスクなどの記号は、対象の文字にすき間なく、ぴったりとくっつけて書きましょう。

NG（記号の内側にスペースがある）

** 太字 **

表示: ** 太字 **（記号のまま残る）

OK（記号が文字にくっついている）

**太字**

表示: 太字

重要ポイント

装飾は「本当に目立たせたい部分」だけに使うのが鉄則です。文章のあちこちを太字や斜体だらけにすると、かえってどこが重要か分からなくなります。特に日本語の斜体は変化が分かりにくいことがあるため、強調したいときはまず太字を検討し、記号は必ず対象の文字にぴったりくっつけて書きましょう。

やってみよう 4-1: お知らせ文を装飾してみよう

第2章で準備したエディタを使って、実際に文字を装飾してみましょう。頭で理解するだけでなく、自分の手で書いて確かめることが上達の近道です。

手順

  1. 1 VS Code で practice04.md という新しいファイルを作成する。
  2. 2 好きなテーマ（自己紹介・お知らせなど）で3〜4行の文章を書き、**太字**・*斜体*・~~打ち消し線~~・`インラインコード`を1つずつ使ってみる。
  3. 3 プレビュー（Ctrl+Shift+V）を開き、記号が消えて意図した装飾に変わっているかを確認する。
  4. 4 わざと ** 太字 ** のように記号と文字の間にスペースを入れて書き、装飾が効かなくなることも体験してみる。

理解度確認クイズ

  1. Q1. 「重要」という文字を太字にしたいとき、どのように書けばよいですか？

    回答を表示

    **重要** のように、アスタリスク（*）2つで文字の両側を挟んで書きます。記号は表示されず、挟まれた文字だけが太字で表示されます。

  2. Q2. アスタリスク1つで文字を挟む（*文字*）と斜体になり、2つで挟む（**文字**）と太字になります。では3つで挟む（***文字***）とどうなりますか？

    回答を表示

    太字と斜体が同時に適用されます（太字＋斜体）。「太字の2つ」と「斜体の1つ」を足したアスタリスク3つと覚えると分かりやすいです。目立ちすぎるため使いすぎには注意しましょう。

  3. Q3. ** とても重要です ** と書いたつもりが、プレビューでも記号が消えずそのまま表示されてしまいました。考えられる原因は何ですか？

    回答を表示

    記号（**）と文字の間にスペースが入っていることが原因です。Markdown では記号を装飾したい文字にぴったりとくっつけて書く必要があり、間にスペースや改行があると装飾として認識されず、記号がそのまま文字として表示されてしまいます。**とても重要です** のようにすき間なく書けば正しく太字になります。
