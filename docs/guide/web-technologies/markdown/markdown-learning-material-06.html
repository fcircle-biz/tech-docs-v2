リンクと画像

この章では、文章の中から他のページへ移動できるリンクと、文書に彩りを加える画像の埋め込み方を学びます。書き方はどちらもよく似ていて、先頭に「!」が付くかどうかだけの違いです。マスターすれば、あなたの Markdown 文書は一気に実用的で伝わりやすいものになります。

この章で学ぶこと

  • リンク記法 [表示テキスト](URL) とタイトル付きリンクの書き方が分かる
  • URL をそのまま書く方法と、<URL> による自動リンクの違いが分かる
  • 画像を埋め込む記法 ![代替テキスト](URL) とリンクとの違いが分かる
  • 相対パスと URL の使い分け、alt テキストの役割、画像サイズの変更方法を理解する

6.1 リンクを書こう

文中の言葉から別のページへ移動できるようにするのがリンクです。Markdown では [表示テキスト](URL) という形で書きます。[ ] の中に画面に表示したい文字を、続く ( ) の中にリンク先の URL を書くだけです。

書いたテキスト（Markdown）

links.md 
詳しくは [Markdown公式サイト](https://daringfireball.net/projects/markdown/) をご覧ください。

[GitHubのトップページ](https://github.com "GitHubのホーム画面")

ブログ記事はこちら → [続きを読む](https://example.com/blog)

表示イメージ

詳しくは Markdown公式サイト をご覧ください。

GitHubのトップページ
（マウスを乗せると「GitHubのホーム画面」と表示される）

ブログ記事はこちら → 続きを読む

2つ目の例のように ( ) の中で URL の後ろに半角スペースを空けて "タイトル" を追加すると、リンクにマウスを乗せたときだけ表示される補足説明（ツールチップ）を付けられます。必須ではありませんが、リンク先が分かりにくいときに便利です。

豆知識: HTML の <a> タグとの対応

この記法は HTML の <a href="URL">表示テキスト</a> というタグに変換されます。第1章で学んだとおり、書く人は Markdown の簡単な記号だけを覚えれば十分です。

6.2 URL をそのまま書く方法（自動リンク）

「わざわざ [ ] や ( ) を書くのが面倒」というときのために、Markdown には URL をそのまま書くだけでリンクにする方法もあります。

autolink.md 
https://example.com

<https://example.com>

1行目のように URL を裸のまま書いても、GitHub をはじめ多くのサービスは自動でリンクとして認識してくれます（これを自動リンクと呼びます）。ただしこの挙動はサービスによって差があるため、確実にリンクにしたいときは2行目のように < >（半角の山かっこ）で URL を囲む書き方が安心です。こちらは CommonMark（Markdown の標準仕様）で定められた、どの環境でも動く正式な自動リンク記法です。

豆知識: メールアドレスも自動リンクにできる

<info@example.com> のようにメールアドレスを山かっこで囲むと、クリックしたときにお使いのメールソフトが起動する mailto: リンクになります。

6.3 画像を埋め込もう

画像を文書に埋め込むときは ![代替テキスト](画像のURLまたはパス) と書きます。リンクの記法 [ ]( ) の先頭に「!」（半角のびっくりマーク）を付けるだけで、リンクではなく画像として表示されます。

書いたテキスト（Markdown）

images.md 
![夕焼けの空の写真](images/sunset.jpg)

![会社ロゴ](https://example.com/logo.png)

表示イメージ

画像が表示される

alt: 夕焼けの空の写真

画像が表示される

alt: 会社ロゴ

リンクと画像は仲間同士の記法です。「!」があるかないかだけを覚えておけば、混同することはありません。

6.4 相対パスと URL の使い分け

画像やリンクの場所を指定する方法には、大きく分けて2種類あります。相対パスは「今開いている .md ファイルから見た位置」を表す書き方で、URLはインターネット上の住所をそのまま指定する方法です。

フォルダ構成の例 

my-profile/
├── profile.md          ← このファイルから見て
└── images/
    └── sunset.jpg       ← 相対パスは "images/sunset.jpg"
指定方法 書き方の例 向いている場面
相対パス images/sunset.jpg 文書と画像を同じフォルダ（リポジトリ）で一緒に管理したいとき
URL（絶対パス） https://example.com/logo.png すでにインターネット上にある画像や、別のサイトのページを参照したいとき

注意: 相対パスがずれると画像が表示されない

相対パスは「.md ファイルの場所」が基準です。ファイルを別のフォルダへ移動したり、画像だけ削除・移動したりすると、パスがずれて画像が表示されなくなります。表示されないときは、まずファイル同士の位置関係を確認しましょう。

6.5 画像にリンクを付ける／alt テキストの役割

画像の記法 ![ ]( ) を、リンクの記法 [ ]( ) でさらに囲むと、「クリックできる画像」を作れます。バナーやアイコンを押すと公式サイトに飛ぶ、といった作りでよく使われる組み合わせです。

badge.md 
[![公式サイトのロゴ](images/logo.png)](https://example.com)

外側の [ ]( ) が「リンク先」を、内側の ![ ]( ) が「表示する画像」を担当しています。かっこの対応が分かりにくいときは、まず画像だけの記法を書いてから、その外側を [ ]( ) で包むようにすると間違えにくいです。

ここで欠かせないのが、画像記法の [ ] の中に書く代替テキスト（alt）です。単なる飾りではなく、次のような大切な役割を持っています。

  • 読み上げソフトのため — 目の不自由な方が使う「スクリーンリーダー」（画面の内容を音声で読み上げる支援ソフト）は、画像の代わりに alt テキストを読み上げる
  • 表示できないときの代わり — 通信状況が悪い、URL が切れているなどで画像が読み込めないとき、代わりに alt テキストが表示される
  • 検索エンジンのため — 画像の内容を検索エンジンに伝える手がかりになり、記事が見つけてもらいやすくなる

「その画像が何を表しているか」が伝わる、短く具体的な言葉を書くのがコツです。画像1 のような中身のない alt テキストは避けましょう。

6.6 画像サイズを変えたいときは

![代替テキスト](URL) という Markdown 標準の記法には、実は表示サイズを指定する仕組みがありません。大きすぎる画像を縮小したいときなどは、HTML の <img> タグをそのまま .md ファイルの中に書く方法を使います。

resize.md 
<img src="images/sunset.jpg" alt="夕焼けの空の写真" width="400">

Markdown は「文中に HTML タグをそのまま書いてもよい」という決まりになっているため、対応サービスであればこのように width（幅）を指定して表示サイズを調整できます。alt 属性は Markdown の代替テキストと同じ役割なので、こちらも忘れずに書きましょう。

重要ポイント

基本は Markdown の ![ ]( ) で十分です。サイズ調整など「Markdown だけでは足りないとき」に限って HTML タグを使う、と覚えておけば OK。使いすぎると素のテキストが読みにくくなるので、ここぞという場面だけにとどめましょう。

やってみよう 6-1: プロフィールにリンクと画像を追加しよう

第2章で作った profile.md（無ければ新しく作成）に、リンクと画像を実際に追加してみましょう。

手順

  1. 1 好きな Web サイトへのリンクを1つ、[表示テキスト](URL) の形で追加する。
  2. 2 profile.md と同じフォルダに images フォルダを作り、適当な画像ファイルを1枚入れて、相対パスで ![ ]( ) を使って埋め込む。alt テキストは具体的に書く。
  3. 3 その画像をクリックすると Web サイトに飛ぶように、[![ ]( )]( ) の形に書き換えてみる。
  4. 4 VS Code のプレビュー（Ctrl+Shift+V）で、リンクと画像が正しく表示されているか確認する。

理解度確認クイズ

  1. Q1. リンクの記法と画像の記法は、書き方がほぼ同じです。何が違うか説明してください。

    回答を表示

    先頭に「!」（半角のびっくりマーク）が付いているかどうかです。[表示テキスト](URL) はリンク、![代替テキスト](URL) は画像になります。

  2. Q2. 相対パスと URL（絶対パス）の違いと、それぞれをどんな場面で使うとよいかを説明してください。

    回答を表示

    相対パスは今開いている .md ファイルから見た位置を表す書き方で、文書と同じフォルダで画像を一緒に管理したいときに向いています。URL はインターネット上の絶対的な住所で、すでに公開されている画像や別サイトを参照したいときに使います。

  3. Q3. 画像に代替テキスト（alt）を付けるべき理由を、2つ以上挙げてください。

    回答を表示

    例: (1) スクリーンリーダーが画像の代わりに読み上げてくれるため（アクセシビリティ）、(2) 画像が読み込めなかったときに代わりに表示されるため、(3) 検索エンジンが画像の内容を理解する手がかりになるため、などです。
