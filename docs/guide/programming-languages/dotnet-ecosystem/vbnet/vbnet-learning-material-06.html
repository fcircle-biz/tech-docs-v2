ホーム VB.NET入門 第6章
第6章 所要時間: 約90分

データをまとめて扱う - 配列とコレクション

前章では For Each の説明の中で配列に少し触れました。この章では、同じ種類のデータをまとめて扱う仕組みを本格的に学びます。基本となる「配列」の宣言・要素番号（インデックス）・二次元配列を理解したうえで、サイズを気にせず使える List(Of T) と、キーと値のペアで管理する Dictionary(Of TKey, TValue) という便利なコレクションを紹介します。

この章で学ぶこと

  • 配列がなぜ必要かを理解し、要素番号（インデックス）が0から始まることを説明できる
  • 配列の宣言・代入・For / For Each による全件処理ができる
  • ReDim Preserve と二次元配列の使い方が分かる
  • List(Of T) と Dictionary(Of TKey, TValue) を使い分けられる

6.1 配列とは

5人分のテストの点数を変数で管理しようとすると、次のように score1、score2...と、点数の数だけ変数を用意しなければなりません。人数が30人、100人と増えたらどうなるでしょうか。変数名を100個考え、100行のコードを書くのは現実的ではありません。

変数を並べる場合（不便な例） Sub Main内に記述 
' 5人分でもこんなに大変…人数が増えたら管理しきれない
Dim score1 As Integer = 80
Dim score2 As Integer = 75
Dim score3 As Integer = 90
Dim score4 As Integer = 60
Dim score5 As Integer = 85
' 合計を求めるにも、すべて足し算で書かないといけない
Dim total As Integer = score1 + score2 + score3 + score4 + score5

こうした「同じ種類のデータをたくさん扱いたい」という悩みを解決するのが配列（はいれつ）です。配列は、同じデータ型の値を、1つの変数名でまとめて管理できる仕組みです。よく「番号のついたロッカー」にたとえられます。ロッカー全体に1つの名前（配列名）を付け、その中の1つ1つの棚には番号が振られていて、番号を指定するだけで目的の棚（データ）を出し入れできるイメージです。

最重要ポイント: 番号（インデックス）は0から始まる

VB.NETに限らず、多くのプログラミング言語では配列の要素番号（インデックス）は0から数えます。「1番目のロッカー」は番号0、「2番目のロッカー」は番号1です。この「1つずれる」感覚に最初は戸惑いますが、非常に重要なルールなのでここでしっかり押さえておきましょう。

flowchart LR subgraph 配列scores A["scores(0) = 80"] --- B["scores(1) = 75"] --- C["scores(2) = 90"] --- D["scores(3) = 60"] --- E["scores(4) = 85"] end

図の説明: 配列 scores には5個の要素が入っており、それぞれに0番から4番までの番号（インデックス）が振られています。「1番目のデータ」はインデックス0の scores(0) であることに注意してください。

6.2 配列の基本操作

配列を使うには、まず要素数（何個入るか）を決めて宣言します。ここでも初心者がつまずきやすい落とし穴があります。

配列の宣言・代入・取り出し Sub Main内に記述 
' 「4」は最大インデックス番号。要素数は0～4の5個になる
Dim scores(4) As Integer

' インデックスを指定して値を代入する
scores(0) = 80
scores(1) = 75
scores(2) = 90

' インデックスを指定して値を取り出す
Console.WriteLine(scores(0))   ' 80 と表示される

注意: Dim scores(4) は「5個」の意味

Dim scores(4) As Integer の 4 は「要素数」ではなく「使える最大のインデックス番号」です。そのため要素数は 0, 1, 2, 3, 4 の5個になります。「4個の配列」だと思って scores(4) にアクセスするとエラーではありませんが、「5個の配列のつもりで scores(5) にアクセスする」と、存在しない番号を指定したことになり IndexOutOfRangeException（インデックスが範囲外です）という実行時エラーになります。

最初から入れる値が決まっている場合は、初期化構文を使うと1行で宣言と代入をまとめて書けます。要素数は自動的に値の個数に合わせられるため、() の中に数字は書きません。

配列の初期化 Sub Main内に記述 
' {}の中に値を並べるだけで、要素数3の配列ができる
Dim names() As String = {"佐藤", "鈴木", "田中"}

' Lengthプロパティで要素数（個数）が分かる
Console.WriteLine(names.Length)   ' 3 と表示される

配列の全件を処理するには、前章で学んだループを使います。要素数がわかっている前提で番号を回す For と、番号を意識せず先頭から順に取り出す For Each の両方を使えるようにしましょう。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        Dim scores() As Integer = {80, 75, 90, 60, 85}

        ' Forで番号（インデックス）を0からLength-1まで回す
        For i As Integer = 0 To scores.Length - 1
            Console.WriteLine($"{i}番目: {scores(i)}点")
        Next

        ' For Eachは番号を意識せず、値だけを順番に取り出す
        Dim total As Integer = 0
        For Each score As Integer In scores
            total += score
        Next
        Console.WriteLine($"合計: {total}点、平均: {total / scores.Length}点")
    End Sub
End Module

用語: 合計・平均・最大値の定番パターン

「合計を求める変数を0で初期化 → ループで足し込む」という書き方は、配列を扱うプログラムの定番パターンです。最大値を求めたい場合も同様に、まず配列の先頭の値を「今のところの最大値」としておき、ループの中で If score > maxScore Then maxScore = score のように更新していきます。

6.3 配列のサイズ変更と二次元配列

配列は宣言のときに要素数を決めますが、あとから要素数を変更したくなることがあります。そのときに使うのが ReDim 文です。ただし、そのまま使うと配列の中身がすべて消えてしまう点に注意が必要です。

ReDim と ReDim Preserve の違い Sub Main内に記述 
Dim scores() As Integer = {80, 75, 90}

' ReDimだけだと、要素数を変える代わりに中身が消えて0になる
ReDim scores(4)
Console.WriteLine(scores(0))   ' 0 と表示される（80は消えた）

' Preserveを付けると、既存の値を残したまま要素数を変えられる
Dim names() As String = {"佐藤", "鈴木"}
ReDim Preserve names(3)
Console.WriteLine(names(0))    ' 佐藤 のまま残っている

注意: Preserveを付け忘れると中身が消える

ReDim だけを使うと、要素数は変わりますがそれまで入っていた値はすべて初期値（数値なら0、文字列なら Nothing）に戻ります。既存の値を残したまま要素数を増やしたい場合は、必ず ReDim Preserve を使いましょう。

ここまでの配列は「1列に並んだロッカー」でしたが、VB.NETでは表（行と列）のようにデータを並べる二次元配列も扱えます。教室の座席表や、掛け算の九九の表のようなデータをイメージすると分かりやすいでしょう。

二次元配列の宣言と利用 Sub Main内に記述 
' 3行（0～2）×4列（0～3）の表形式の配列
Dim table(2, 3) As Integer

' table(行, 列) の形で値を指定する
table(0, 0) = 1
table(1, 2) = 5

' 二重ループで表全体を処理する
For row As Integer = 0 To 2
    For col As Integer = 0 To 3
        Console.Write(table(row, col) & " ")
    Next
    Console.WriteLine()
Next
表記 意味
table(0, 0) 1行目・1列目のマス
table(1, 2) 2行目・3列目のマス
table(2, 3) 3行目・4列目のマス（右下の端）

6.4 List(Of T) - サイズを気にしない配列

配列は便利ですが、「あとで要素を1個増やしたい／減らしたい」というたびに ReDim Preserve を書くのは面倒です。そこでVB.NETには、要素数を自動で伸び縮みさせてくれる List(Of T)（リスト）という便利な部品が用意されています。T の部分には String や Integer など、扱いたいデータ型を入れます。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' Newを使ってString型のListを作る
        Dim members As New List(Of String)

        members.Add("佐藤")       ' 末尾に追加
        members.Add("鈴木")
        members.Insert(1, "田中") ' 指定位置(1)に挿入
        members.Remove("佐藤")    ' 値を指定して削除
        members.RemoveAt(0)       ' 位置(0)を指定して削除

        For Each name As String In members
            Console.WriteLine(name)
        Next
        Console.WriteLine($"人数: {members.Count}人")
    End Sub
End Module

Contains で「その値が含まれているか」を調べたり、Clear で全件を空にしたりもできます。配列と List(Of T) はどちらもデータをまとめて扱う仕組みですが、次のように使い分けると良いでしょう。

項目 配列 List(Of T)
要素数 基本的に固定（変更には ReDim が必要） 自由に増減できる
追加・削除 手軽にはできない Add / Remove で簡単
要素数の取得 Length Count
向いている場面 件数があらかじめ決まっているとき 件数が実行中に増減するとき（名簿など）

用語: コレクション

配列や List(Of T) のように、複数のデータをまとめて扱う仕組みを総称してコレクションと呼びます。迷ったときは「件数が固定なら配列、変わるなら List(Of T)」を目安にすると良いでしょう。実務では多くの場合 List(Of T) が使われます。

6.5 Dictionary(Of TKey, TValue) - キーと値のペア

配列や List(Of T) は「0番目、1番目...」という番号でデータを管理します。しかし「商品名から価格を調べたい」というように、番号ではなく名前（キー）で調べたい場面もよくあります。そんなときに使うのが Dictionary(Of TKey, TValue)（辞書）です。国語辞典で「見出し語（キー）」から「意味（値）」を引くのと同じ感覚で使えます。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' キー(String)と値(Integer)のペアで管理するDictionary
        Dim prices As New Dictionary(Of String, Integer)
        prices.Add("りんご", 150)
        prices.Add("バナナ", 100)

        ' キーを指定して値を取り出す
        Console.WriteLine($"りんごは{prices("りんご")}円")

        ' キーが存在するか確認してから取り出すと安全
        If prices.ContainsKey("みかん") Then
            Console.WriteLine(prices("みかん"))
        Else
            Console.WriteLine("みかんは登録されていません")
        End If

        ' For Eachで全ペアを列挙する（KeyValuePair型）
        For Each pair As KeyValuePair(Of String, Integer) In prices
            Console.WriteLine($"{pair.Key}: {pair.Value}円")
        Next
    End Sub
End Module

注意: 存在しないキーへのアクセス

登録されていないキーを指定して prices("みかん") のように値を取り出そうとすると、実行時エラー（KeyNotFoundException）になります。取り出す前に必ず ContainsKey でキーの存在を確認する習慣をつけましょう。

重要ポイント

配列・List(Of T)・Dictionary(Of TKey, TValue) は、いずれも「複数のデータをまとめる」という目的は同じでも、得意なことが違います。順序どおり・件数固定なら配列、件数が増減するなら List(Of T)、名前で引きたいなら Dictionary、という基準で選べるようになりましょう。

やってみよう 6-1: 点数集計プログラムと名簿プログラムを作ろう

配列と List(Of T) を実際に使い、動きの違いを体感してみましょう。

手順

  • 1 5人分のテストの点数を配列に入れ、For Each を使って合計・平均・最高点を求めて表示するプログラムを作る。
  • 2 最高点を求める部分は、まず配列の先頭の値を「今のところの最高点」として、ループの中で比較しながら更新する方法で書く。
  • 3 List(Of String) を使い、名前を3件 Add したあと、1件 Remove し、最後に Count と全件の名前を表示する「簡単な名簿プログラム」を作る。
  • 4 余裕があれば、配列のインデックスをわざと範囲外（例: scores(5)）にして実行し、IndexOutOfRangeException が発生することを確認してみる。

解答例（点数集計）

Module Program
    Sub Main()
        Dim scores() As Integer = {80, 75, 90, 60, 85}
        Dim total As Integer = 0
        Dim maxScore As Integer = scores(0)

        For Each score As Integer In scores
            total += score
            If score > maxScore Then
                maxScore = score
            End If
        Next

        Console.WriteLine($"合計: {total}点")
        Console.WriteLine($"平均: {total / scores.Length}点")
        Console.WriteLine($"最高点: {maxScore}点")
    End Sub
End Module

解答例（名簿プログラム）

Module Program
    Sub Main()
        Dim members As New List(Of String)
        members.Add("佐藤")
        members.Add("鈴木")
        members.Add("田中")

        members.Remove("鈴木")   ' 鈴木さんが抜けた

        Console.WriteLine($"現在の人数: {members.Count}人")
        For Each name As String In members
            Console.WriteLine(name)
        Next
    End Sub
End Module

理解度確認クイズ

  • Q1. Dim scores(4) As Integer と宣言したとき、この配列の要素数はいくつですか？ また、最初の要素にアクセスするときのインデックス番号は何ですか？

    回答を表示

    要素数は5個です。(4) は要素数ではなく「使える最大のインデックス番号」を表すため、インデックスは 0, 1, 2, 3, 4 の5個分になります。最初の要素は scores(0) でアクセスします。

  • Q2. 配列の要素数を ReDim で変更するとき、既存の値を消さずに残したい場合はどのキーワードを付ける必要がありますか？

    回答を表示

    Preserve です。ReDim Preserve 配列名(新しい番号) のように書きます。Preserve を付けずに ReDim だけを使うと、それまでの値はすべて初期値に戻ってしまいます。

  • Q3. 配列と List(Of T) の違いとして、もっとも重要な点は何ですか？

    回答を表示

    配列は要素数が基本的に固定であるのに対し、List(Of T) は Add や Remove によって要素数を自由に増減できる点です。件数が実行中に変わる場合は List(Of T) が向いています。

  • Q4. 「商品名」から「価格」を調べるように、番号ではなく名前でデータを引きたいときに適したコレクションは何ですか？ また、値を取り出す前に何を確認すると安全ですか？

    回答を表示

    Dictionary(Of TKey, TValue) です。キーと値のペアで管理し、キーを指定して値を取り出せます。存在しないキーを指定するとエラーになるため、取り出す前に ContainsKey でキーの存在を確認すると安全です。
