VB.NETプログラミングの世界へようこそ

いよいよプログラミング学習のスタートです。この章では「プログラミングとは何か」「VB.NETとはどんな言語か」という基礎からはじめ、実際に手を動かす準備として開発環境（Visual Studio 2022 Community）を整え、最初のプログラム「Hello, World!」を動かすところまでを丁寧に進めます。

  • Visual Studio 2022 Community を使った開発環境を自分のパソコンに用意できる

各コード例の右上のラベルで「コードを書く場所」を示します。左側にはファイル名を表示します。

1.1 プログラミングとは何か

プログラミングとは、コンピュータに「何を、どの順番でやってほしいか」を、コンピュータが理解できる言葉（プログラミング言語）で書き出す作業のことです。コンピュータはとても高速で正確ですが、自分で考えることはできません。人間が手順を1つずつ細かく指示してはじめて、計算をしたり、画面に文字を表示したり、売上を集計したりできます。

この「手順を書いたもの」をプログラム（ソースコード）と呼びます。料理にたとえると、プログラムはレシピです。「材料を切る → 炒める → 味付けする」という手順を順番どおりに書いておけば、誰が読んでも同じ料理が作れます。コンピュータもレシピ（プログラム）どおりに、上から順番に処理を実行していきます。

そして、どんなに複雑なプログラムも、実はたった3つの基本パターンの組み合わせでできています。この3つを制御構造と呼び、本ガイドでも第4章・第5章で詳しく学びます。

順次

書いた順番に、上から下へ1行ずつ実行していく、いちばん基本の流れです。

分岐

「もし〜なら」で処理を切り替えます。合格・不合格の判定などに使います。

繰り返し

同じ処理を何度も実行します。100件のデータ処理も数行で書けます。

用語: ソースコードとコンパイル

人間が書いたプログラム（ソースコード）は、そのままではコンピュータが直接実行できません。コンピュータが分かる形に「翻訳」する必要があり、この翻訳作業をコンパイルと呼びます。VB.NETでは、書いたコードをコンパイルしてから実行します（詳しくは 1.2 で解説します）。

1.2 VB.NETとはどんな言語か

VB.NET（ブイビー・ドットネット、正式名称 Visual Basic .NET）は、マイクロソフトが開発したプログラミング言語です。2002年に登場して以来、日本の業務システム開発で非常に多く使われてきました。販売管理、在庫管理、会計処理といった企業の基幹システムには、今でも VB.NET で作られたものがたくさん動いています。

VB.NET の最大の魅力は、英語の文章に近い読みやすい書き方です。たとえば処理の終わりは End Sub、繰り返しの終わりは Next のように、記号ではなく単語で書きます。記号だらけのコードに比べて、初心者でも「何をしているか」が想像しやすいのが特長です。

読みやすい文法

英語の文章のような書き方。記号が少なく、初学者がつまずきにくい言語です。

業務システムに強い

画面付きアプリやデータベース処理を作りやすく、企業システムで実績豊富です。

.NETの資産が使える

C#と同じ豊富な部品（クラスライブラリ）をそのまま利用できます。

.NET と VB.NET の関係

VB.NET は単独で動いているわけではなく、.NET（ドットネット）という土台の上で動きます。.NET はマイクロソフトが提供するアプリを動かすための共通の仕組みで、「プログラムを実行するエンジン」と「よく使う機能をまとめた部品集（クラスライブラリ）」がセットになったものです。

あなたが書いた VB.NET のコードは、まず中間言語（IL）という共通の形にコンパイルされます。そしてプログラムを動かすときに、CLR（共通言語ランタイム）がその中間言語をパソコンが直接実行できる形に変換して動かします。この「いったん共通の形にする」仕組みのおかげで、VB.NET と C# は同じ .NET の部品を共有できるのです。

flowchart LR A["あなたが書く
VB.NETコード (.vb)"] --> B["コンパイル"] B --> C["中間言語 IL
(.exe や .dll)"] C --> D["CLR
（.NET ランタイム）"] D --> E["実行"] F["C#コード (.cs)"] --> B

図の説明: VB.NET で書いたコードはコンパイルによって中間言語（IL）に変換され、実行時に CLR がそれを解釈して動かします。C# のコードも同じ中間言語になるため、両者は .NET の部品を共有できます。

VB6（旧Visual Basic）との違い

名前が似ているため混同されがちですが、1998年までの VB6（Visual Basic 6.0） と VB.NET は別の言語といってよいほど中身が異なります。学習の際に古い VB6 向けの情報を参考にすると混乱するため、違いを押さえておきましょう。

オブジェクト指向 限定的（継承なし） 本格対応（継承・インターフェース）

用語: Visual Studio とは

Visual Studioは、マイクロソフトが提供する統合開発環境（IDE）です。コードを書くエディタ、コンパイラ、プログラムの動きを1行ずつ確認できるデバッガ、画面を部品のドラッグで作れるデザイナーなどが1つにまとまっています。VB.NET の学習では、この Visual Studio を使うのがもっとも近道です（次の 1.3 で導入します）。

1.3 開発環境を準備する

VB.NET のプログラムを書いて動かすために、開発環境を用意します。個人学習や小規模開発なら、無償の Visual Studio 2022 Community を使えば、必要なものが一度にそろいます。

道具 役割
Visual Studio 2022 Community コードを書く・実行する・デバッグするための統合開発環境。無償で利用できます。
.NET SDK（.NET 8 以降） VB.NETをコンパイルして動かす本体。Visual Studio と同時にインストールされます。
.NET デスクトップ開発ワークロード コンソールアプリと Windows Forms（第13章）を作るための機能一式。

手順1: Visual Studio 2022 Community のインストール

マイクロソフトの公式サイトから Visual Studio Community 2022 のインストーラーをダウンロードして実行します。途中で「インストールする内容を選ぶ画面（ワークロード選択）」が表示されるので、「.NET デスクトップ開発」に必ずチェックを入れてから［インストール］をクリックしてください。ダウンロードとインストールには数十分かかることがあります。

注意: ワークロードのチェック忘れに気をつけて

「.NET デスクトップ開発」にチェックを入れずにインストールすると、プロジェクト作成画面に VB.NET のテンプレートが表示されません。その場合は Windows のスタートメニューから「Visual Studio Installer」を起動し、［変更］から「.NET デスクトップ開発」を追加インストールしてください。

手順2: インストールの確認

インストールが終わったら、.NET が正しく入ったかを確認しましょう。Windows のスタートメニューから「コマンドプロンプト」または「PowerShell」を開き、次のコマンドを入力します。

コマンドプロンプト — .NETの確認 
# .NET のバージョンを確認するコマンド
dotnet --version

# 例: 次のように表示されればOK
# 8.0.401

準備ができたかチェック

  • Visual Studio 2022 が起動し、スタート画面が表示される
  • dotnet --version でバージョン番号が表示される
  • 新しいプロジェクトの作成画面で、言語に「Visual Basic」が選べる

1.4 最初のプログラム「Hello, World!」

いよいよ最初のプログラムを書きます。プログラミングの世界では、画面に「Hello, World!」と表示するプログラムを最初に作るのが伝統です。まずはプロジェクトを作りましょう。

手順1: プロジェクトを作る

Visual Studio を起動し、次の順に操作します。プロジェクトとは、1つのアプリを作るために必要なファイルをまとめて管理する入れ物のことです。

  • スタート画面で「新しいプロジェクトの作成」をクリック
  • 言語のドロップダウンで「Visual Basic」、種類で「コンソール」を選ぶ
  • 一覧から「コンソール アプリ」を選んで［次へ］
  • プロジェクト名に HelloWorld と入力して［次へ］
  • フレームワークで「.NET 8.0 (長期的なサポート)」を選び［作成］

用語: コンソールアプリ

コンソールアプリとは、黒い画面（コマンドプロンプトのような画面）に文字を表示したり、キーボードから文字を受け取ったりするだけのシンプルなアプリです。画面の見た目を作る手間がないぶん、プログラムの仕組みそのものに集中できるため、学習の最初に最適です。ボタンや入力欄のある画面付きアプリは第13章で作ります。

手順2: コードを書く

プロジェクトを作成すると Program.vb というファイルが開きます。中身を次のコードに書き換えてみましょう。

Program.vb 完全なプログラム 
' これが最初のVB.NETプログラムです
Module Program
    ' Sub Main: プログラムはここから実行が始まる
    Sub Main()
        ' 画面に文字を表示する命令
        Console.WriteLine("Hello, World!")
    End Sub
End Module

まだ意味が分からない部分があっても大丈夫です。今は「こう書くと動く」という感覚をつかめれば十分です。それぞれの言葉の意味は、これからの章で少しずつ学んでいきます。各行のおおまかな役割だけ確認しておきましょう。

  • Module Program — プログラムの入れ物（モジュール）。処理をまとめる箱だと考えてください。
  • Sub Main() — プログラムの実行が始まる場所。VB.NET のお約束です（第7章で学びます）。
  • Console.WriteLine(...) — 画面に文字を表示し、改行する命令です。
  • '（シングルクォート）から行末まで — コメント。人間向けのメモで、プログラムの動作には影響しません。
  • End Sub / End Module — 「ここで終わり」を表します。VB.NET は始まりと終わりを単語で書きます。

手順3: 実行する

画面上部の緑の三角ボタン（▶ HelloWorld）をクリックするか、キーボードの F5 キーを押すと、プログラムがコンパイルされて実行されます。黒い画面が開き、次のように表示されれば成功です。

実行結果 
Hello, World!

プログラムを書いてから結果が出るまでの流れを、あらためて図で確認しておきましょう。

flowchart TD A["コードを書く
Program.vb"] --> B["F5キーを押す"] B --> C["コンパイル
（中間言語に翻訳）"] C --> D{"エラーはある？"} D -->|ある| E["エラー一覧に表示
→ コードを修正"] E --> A D -->|ない| F["CLRが実行"] F --> G["画面に結果が表示される"]

図の説明: コードを書いて実行すると、まずコンパイルが行われます。書き間違いがあればエラーとして知らされるので修正して再挑戦し、問題がなければ CLR がプログラムを実行して結果が表示されます。

注意: エラーが出たときの確認ポイント

実行できないときは、まず全角文字が混ざっていないかを確認してください。コードの記号（( ) "）はすべて半角で入力する必要があります。日本語入力がオンのまま書いてしまうのは、初学者にいちばん多いつまずきです。文字列の中（"..." の内側）だけは日本語を書いてかまいません。

重要ポイント

画面に「Hello, World!」と表示されたら、あなたは初めて自分でコンピュータを動かしたことになります。プログラミング学習で大切なのは、小さくても自分の手で動かしてみること。これからも「読む」だけでなく、必ず「書いて動かす」を続けていきましょう。

やってみよう 1-1: 自己紹介プログラムを作ろう

Hello, World! が動いたら、次は表示する文章を自分で変えてみましょう。コードを少し書き換えるだけで、結果が変わることを体験します。

手順

  • 1 "Hello, World!" の部分を、自分の名前を含む文章（例: "私の名前は山田です"）に書き換える。
  • 2 Console.WriteLine(...) の行をもう1行コピーして、好きな言葉（趣味など）を2行表示してみる。
  • 3 Console.WriteLine() を Console.Write() に変えて実行し、改行の有無がどう変わるか確かめる。
  • 4 もう一度 F5 で実行して、思ったとおりに表示されるか確認する。

解答例

Module Program
    Sub Main()
        ' 2行に分けて自己紹介を表示する
        Console.WriteLine("私の名前は山田です")
        Console.WriteLine("趣味は読書です")
    End Sub
End Module

理解度確認クイズ

  • Q1. プログラミングとは何をする作業ですか？ 料理にたとえて説明してください。

    回答を表示

    コンピュータにやってほしい手順を、コンピュータが分かる言葉（プログラミング言語）で書き出す作業です。料理でいえば、手順を書いた「レシピ」を用意することにあたります。コンピュータはそのレシピ（プログラム）どおりに上から順番に処理を実行します。

  • Q2. VB.NET で書いたコードは、実行されるまでにどのような形に変換されますか？ また、それを実行する仕組みの名前は何ですか？

    回答を表示

    コンパイルによって中間言語（IL）に変換されます。それを実行するのが CLR（共通言語ランタイム）です。C# も同じ中間言語になるため、VB.NET と C# は .NET の部品を共有できます。

  • Q3. VB.NET のコンソールアプリで、プログラムの実行が最初に始まる場所はどこですか？

    回答を表示

    Sub Main() です。プログラムを実行すると、必ずここから処理が始まります。

  • Q4. コードの中に人間向けのメモ（コメント）を書きたいとき、行の先頭に付ける記号は何ですか？

    回答を表示

    シングルクォート ' です。この記号から行末まではコメントとして扱われ、プログラムの動作には影響しません。処理の意図を書き残すために積極的に使いましょう。
