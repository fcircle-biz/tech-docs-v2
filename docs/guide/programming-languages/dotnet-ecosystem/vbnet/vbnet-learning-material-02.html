データを入れる箱 - 変数とデータ型

前章で「Hello, World!」を動かしたあなたは、次にプログラムの中で数値や文字などのデータを扱いたくなるはずです。この章では、データを一時的に覚えておく仕組みである「変数」と、扱うデータの種類を決める「データ型」を学びます。あわせて、キーボードから入力を受け取る方法も体験します。

この章で学ぶこと

  • 「変数」がデータを覚えておく箱であることを理解し、Dim で宣言・代入できる
  • 代表的なデータ型（Integer・Double・String など）を使い分けられる
  • Option Strict On の重要性を理解し、型変換関数や TryParse を使える
  • Console.ReadLine() でキーボード入力を受け取り、簡単な対話プログラムを作れる

2.1 変数とは何か

プログラムは、計算した結果や入力された文字などのデータを、処理の途中で一時的に覚えておく必要があります。この「データを覚えておく場所」のことを変数（へんすう）と呼びます。変数は、名前が付いた箱だとイメージするとわかりやすいです。箱に「age」という名前を付けておけば、その箱の中に年齢の数値を入れておき、あとで「age の中身は？」と取り出して使うことができます。

VB.NET で変数を使うには、まず宣言という手続きが必要です。宣言とは「これからこの名前の箱を使います」とコンパイラに伝えることです。宣言には Dim キーワードを使います。

変数の宣言と代入 Sub Main内に記述 
' 「age」という名前のInteger型の箱を用意する
Dim age As Integer

' 箱に値を入れる（代入）
age = 20
Console.WriteLine(age)     ' 20 と表示される

' 同じ箱に別の値を入れると、前の値は上書きされる
age = 21
Console.WriteLine(age)     ' 21 と表示される

Dim 変数名 As 型 という書き方が基本の形です。As の後ろに書くのがデータ型（2.2 で学びます）で、「この箱には整数だけを入れます」というように、箱の種類をあらかじめ決めておきます。= は数学の「等しい」ではなく、右側の値を左側の変数に入れる（代入する）という意味で使われる点に注意してください。

flowchart LR A["箱 age
（空）"] -->|"age = 20"| B["箱 age
中身: 20"] B -->|"age = 21"| C["箱 age
中身: 21
（20は消える）"]

図の説明: 変数に代入するたびに、箱の中身は新しい値で上書きされます。上書きされた古い値は残らないため、前の値も同時に使いたい場合は別の変数を用意する必要があります。

変数名の付け方

変数名は自由に決められますが、後で自分やほかの人がコードを読んだときに意味がわかるように付けることが大切です。a や x1 のような名前より、age（年齢）や userName（ユーザー名）のように役割がわかる名前を選びましょう。

意味のわかる名前

age や totalPrice のように、何が入っているか一目でわかる名前を付けます。

使える文字

半角英数字と _（アンダースコア）が使えます。先頭は数字にできません。

大文字・小文字は区別されない

Age と age は VB.NET では同じ変数として扱われます。

用語: キャメルケース

複数の単語をつなげて変数名を作るとき、userName のように最初の単語は小文字、2つ目以降の単語の先頭を大文字にする書き方をキャメルケースと呼びます。VB.NET の変数名でよく使われる慣習です（本ガイドでもこの書き方を使います）。

2.2 データ型

変数を宣言するとき、なぜ As Integer のように型を指定する必要があるのでしょうか。それは、扱うデータの種類によって必要なメモリの大きさやできる計算の種類が変わるからです。整数専用の箱に小数を入れようとしたり、数値専用の箱に文字を入れようとしたりすると、コンパイラがすぐにミスとして教えてくれます。型を決めておくことは、プログラムを安全に保つための最初の防御線なのです。

代表的なデータ型

型名 用途 値の例・範囲の目安
Integer 整数（個数・年齢など） 約 -21億 〜 21億
Long とても大きな整数 約 -922京 〜 922京
Double 小数（一般的な計算・平均値など） 例: 3.14、-0.5
Decimal 正確な小数（金額計算専用） 例: 1980.00円
String 文字列（名前・住所など） 例: "山田太郎"
Boolean 真偽値（はい／いいえ） True または False
Date 日付・時刻 例: 2026/08/24
Char 1文字だけの文字 例: "A"c

小数を扱う型には Double と Decimal の2種類があり、使い分けが重要です。Double はコンピュータ内部で近似値として扱われるため、わずかな誤差が発生することがあります。一方 Decimal は誤差が出ないよう設計されており、金額の計算では必ず Decimal を使うのが業務システム開発の基本ルールです。1円のズレも許されない請求書や会計処理で、この違いは非常に重要になります。

重要ポイント: 金額には Decimal

売上・単価・合計金額など「お金」を表す値は、誤差が許されないため Decimal を使います。Double は科学計算のような「多少の誤差が許される」場面に向いています。迷ったら「お金かどうか」で判断しましょう。

2.3 変数の宣言と初期化

2.1 では宣言と代入を別々の行に分けましたが、実際にはまとめて1行で書くことが多いです。宣言と同時に最初の値を入れることを初期化と呼びます。

変数の初期化と定数 Sub Main内に記述 
' 宣言と同時に値を入れる（初期化）
Dim age As Integer = 20
Dim userName As String = "田中花子"
Dim price As Decimal = 1980.0D

' 同じ型なら、カンマで区切って1行にまとめられる
Dim width As Integer = 10, height As Integer = 20

' 定数: 一度決めたら変更できない値。名前は大文字で書く
Const TAX_RATE As Double = 0.1
Console.WriteLine(price * (1 + TAX_RATE))

Const は「定数」を宣言するキーワードです。変数と違い、一度値を決めたらプログラムの実行中に書き換えることができません。消費税率のように「途中で変わっては困る値」に使います。慣習として、定数名は TAX_RATE のようにすべて大文字＋アンダースコアで書き、変数と見分けやすくします。

なお、変数は宣言した場所（ブロック）の中でしか使えないという決まりがあります。これをスコープ（有効範囲）と呼びます。今の段階では「変数には使える範囲がある」ということだけ覚えておけば十分で、詳しくは Sub や Function を学ぶ第7章で扱います。

2.4 型の安全性と型変換

VB.NET には、初期設定のままだと文字列と数値を暗黙のうちに変換してくれる「お節介」な機能があります。便利に見えますが、これは思わぬバグの原因になります。そこで、プロジェクトの設定で Option Strict On を有効にすることを強く推奨します。

注意: Option Strict Off の危険性

Option Strict Off（初期設定）のままだと、Dim result As Integer = "abc" のような、本来ならおかしいコードでもコンパイルが通ってしまいます。しかし実行してみると、文字列を数値に変換できずに実行時エラーでプログラムが止まってしまいます。Option Strict On にしておけば、この種のミスを実行前（コンパイル時）に発見できます。

Option Strict On にすると、型の異なる値をそのまま代入しようとするたびにコンパイルエラーになります。数値と文字列を変換したいときは、変換することをコード上ではっきり示す必要があります。そのための代表的な変換関数が次の表です。

変換関数 変換先の型 例
CInt(...) Integer CInt("20") → 20
CDbl(...) Double CDbl("3.14") → 3.14
CStr(...) String CStr(20) → "20"
CDate(...) Date CDate("2026/08/24")

もう一つ、数値専用の Integer.Parse(...) という書き方もあります。ただし CInt や Integer.Parse はどちらも、変換できない文字列（例えば "abc"）を渡すと例外（エラー）を発生させてプログラムを止めてしまいます。ユーザーが何を入力するかわからない場面では、これは危険です。そこで使うのが Integer.TryParse(...) です。

Parse と TryParse の違い Sub Main内に記述 
Dim input As String = "20"

' Integer.Parse: 変換に失敗すると例外が発生してプログラムが止まる
Dim number1 As Integer = Integer.Parse(input)

' Integer.TryParse: 変換の成功・失敗をTrue/Falseで受け取れる（安全）
Dim number2 As Integer
Dim success As Boolean = Integer.TryParse(input, number2)

If success Then
    Console.WriteLine("変換に成功: " & number2)
Else
    Console.WriteLine("数値に変換できませんでした")
End If

TryParse は、変換した結果を第2引数の変数（ここでは number2）に書き込み、変換できたかどうかを True / False の戻り値で教えてくれます。ユーザーからの入力を扱うプログラムでは、突然止まってしまわないように TryParse を使うのが基本と覚えておきましょう。

2.5 キーボードから入力を受け取る

ここまでは、値をコードの中に直接書いてきました。実際のプログラムでは、ユーザーがキーボードから入力した値を受け取って処理したい場面が多くあります。そのために使うのが Console.ReadLine() です。

重要な注意点があります。Console.ReadLine() は、ユーザーが何を入力しても必ず String（文字列）として受け取ります。数字の「20」を入力しても、プログラムからは "20" という文字として扱われます。これを数値として計算に使いたい場合は、2.4 で学んだ変換が必要です。

flowchart LR A["キーボード入力"] --> B["Console.ReadLine()"] B --> C["文字列（String）
として受け取る"] C --> D["Integer.TryParse
で型変換"] D --> E["数値として
計算・利用できる"]

図の説明: Console.ReadLine() はどんな入力も文字列として受け取ります。数値として計算に使うには、必ず変換のステップを挟む必要があります。

それでは、名前と年齢を尋ねて画面に表示する、簡単な対話プログラムを作ってみましょう。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' 名前を入力してもらう（文字列としてそのまま使える）
        Console.Write("お名前を入力してください: ")
        Dim userName As String = Console.ReadLine()

        ' 年齢を入力してもらう（文字列 → 数値へ変換が必要）
        Console.Write("年齢を入力してください: ")
        Dim ageInput As String = Console.ReadLine()
        Dim age As Integer

        If Integer.TryParse(ageInput, age) Then
            Console.WriteLine(userName & "さん（" & age & "歳）、こんにちは！")
        Else
            Console.WriteLine("年齢は数字で入力してください")
        End If
    End Sub
End Module
実行結果 
お名前を入力してください: 田中花子
年齢を入力してください: 30
田中花子さん（30歳）、こんにちは！

注意: TryParseを使わないと落ちる

もし Integer.TryParse の代わりに CInt(ageInput) をそのまま使っていたら、ユーザーが「三十」のような数字以外の文字を入力した瞬間に例外が発生し、プログラムが異常終了してしまいます。ユーザーの入力は何が来るかわからないものとして扱い、必ず TryParse で安全に変換する習慣をつけましょう。

やってみよう 2-1: 自己紹介入力プログラムを作ろう

2.5 の対話プログラムを発展させて、好きな食べ物も入力してもらい、3つの情報をまとめて表示するプログラムを作ってみましょう。

手順

  • 1 名前（String）、年齢（Integer、TryParseで変換）に加えて、好きな食べ物（String）も入力してもらう。
  • 2 10年後の年齢を Const を使わずに age + 10 で計算し、変数に入れる。
  • 3 「〇〇さん（△△歳）の好きな食べ物は□□です。10年後は××歳になります」と1行で表示する。
  • 4 年齢に数字以外を入力してわざとエラーメッセージを出し、TryParseが機能していることを確認する。

解答例

Module Program
    Sub Main()
        Console.Write("お名前を入力してください: ")
        Dim userName As String = Console.ReadLine()

        Console.Write("年齢を入力してください: ")
        Dim age As Integer
        If Not Integer.TryParse(Console.ReadLine(), age) Then
            Console.WriteLine("年齢は数字で入力してください")
            Return
        End If

        Console.Write("好きな食べ物を入力してください: ")
        Dim food As String = Console.ReadLine()
        Dim futureAge As Integer = age + 10

        Console.WriteLine(userName & "さん（" & age & "歳）の好きな食べ物は" & food & "です。10年後は" & futureAge & "歳になります")
    End Sub
End Module

理解度確認クイズ

  • Q1. 変数を「箱」にたとえると、Dim age As Integer と age = 20 は、それぞれどんな操作にあたりますか？

    回答を表示

    Dim age As Integer は「age という名前の、整数専用の箱を用意する（宣言）」操作です。age = 20 は「その箱に20という値を入れる（代入）」操作にあたります。

  • Q2. 商品の金額を扱う変数には、Double ではなく Decimal を使うべきなのはなぜですか？

    回答を表示

    Double は内部的に近似値として計算されるため、わずかな誤差が生じることがあります。Decimal は誤差が出ないよう設計されており、1円のズレも許されない金額計算に適しているためです。

  • Q3. Option Strict On を有効にすると、どのような効果がありますか？

    回答を表示

    型の異なる値（文字列と数値など）を暗黙のうちに変換することを禁止し、そのようなコードをコンパイル時にエラーとして知らせてくれます。これにより、実行時になって初めて発覚するエラーを事前に防げます。

  • Q4. Integer.Parse と Integer.TryParse の違いは何ですか？ ユーザーからの入力を扱うときはどちらを使うべきですか？

    回答を表示

    Integer.Parse は変換に失敗すると例外を発生させてプログラムを止めてしまいます。Integer.TryParse は変換の成功・失敗を True / False で教えてくれるため、プログラムを止めずに対処できます。何が入力されるかわからないユーザー入力には TryParse を使うべきです。
