計算と文字列を操作しよう

第4章では変数とデータ型を学びました。この章では、その値を使って実際に計算したり、画面に見やすく表示したりする方法を身につけます。算術演算子・代入演算子・f文字列・文字列操作という、これから何度も使う基本の道具がそろいます。

この章で学ぶこと

  • 算術演算子（+ - * / // % **）を使い分けられる
  • 代入演算子（+= など）と round() で値を丸められる
  • f文字列を使って変数を含んだ文章をきれいに表示できる
  • 文字列の連結・長さ取得・スライス・代表的なメソッドを使える

5.1 算術演算子

Python では、数値どうしを計算するために算術演算子を使います。足し算・引き算・掛け算はふだん使う記号と同じですが、割り算には3種類あり、それぞれ結果が異なります。

演算子 意味 例 結果
+ 足し算 7 + 3 10
- 引き算 7 - 3 4
* 掛け算 7 * 3 21
/ 割り算（常に float） 7 / 3 2.3333...
// 切り捨て除算（商） 7 // 3 2
% 剰余（あまり） 7 % 3 1
** べき乗 2 ** 3 8
calc.py 
# 3種類の割り算を比べる
people = 7
items = 3

print(items / people)   # 通常の割り算（float）
print(items // people)  # 切り捨て除算（商だけ）
print(items % people)   # 剰余（あまりだけ）
実行結果 
0.42857142857142855
0
3

優先順位は数学と同じで、** → * / // % → + - の順に計算されます。同じ優先順位のものは左から順に計算され、丸かっこ () で囲むと先に計算させられます。3 + 4 * 2 は 3 + 8 で 11、(3 + 4) * 2 は 14 になります。迷ったら丸かっこを付けておくと安全です。

注意: / は必ず float になる

10 / 2 は int どうしの計算でも、結果は 5 ではなく 5.0（float）になります。整数のままの商がほしいときは // を使いましょう。

5.2 代入演算子と round()

「今の値に何かを足して、同じ変数に入れ直す」処理はとてもよく使うため、代入演算子という短い書き方が用意されています。total = total + 100 は total += 100 と書けます。

書き方 意味
total += 100 total = total + 100 と同じ
total -= 100 total = total - 100 と同じ
total *= 2 total = total * 2 と同じ
total /= 2 total = total / 2 と同じ

割り算をすると小数点以下がずらずらと続くことがあります。見やすい桁数に丸めるには組み込み関数 round() を使います。round(値, 丸める桁数) の形で書き、第2引数を省略すると整数に丸められます。

round_sample.py 
# 累計とroundの練習
total = 0
total += 780
total += 1200
print(total)  # 1980

price = 1000 / 3
print(round(price))     # 整数に丸める
print(round(price, 2))  # 小数第2位まで
実行結果 
1980
333
333.33

5.3 f文字列

これまでは print("合計:", total, "円") のようにカンマで区切って表示してきました。この書き方は簡単ですが、値の間に自動でスペースが入るなど、細かい見た目の調整がしにくいという弱点があります。そこで本章からはf文字列を使います。文字列の前に f を付け、{変数名} と書くと、その部分が変数の値に置き換わります。

fstring.py 
name = "田中"
price = 12800

# f文字列で変数を文章に埋め込む
print(f"{name}さんの合計は{price}円です")

# 桁区切りカンマと小数の桁数も指定できる
print(f"金額: {price:,}円")
print(f"税込: {price * 1.1:.1f}円")
実行結果 
田中さんの合計は12800円です
金額: 12,800円
税込: 14080.0円

{変数名:書式} の : の後ろが書式指定です。, は3桁ごとにカンマを入れる、.1f は小数第1位まで表示するという意味です。よく使う書式を表にまとめます。

書式 意味 例
{x} そのまま表示 1980
{x:,} 3桁区切りカンマ 1,980
{x:.1f} 小数第1位まで 1980.0
{x:.2f} 小数第2位まで 1980.00

これから使う表記のルール

本ガイドでは次の章から、画面に値を表示するときは基本的にf文字列を使います。カンマ区切りの print() も引き続き使えるので、状況に応じて使い分けてください。

5.4 文字列の操作

文字列（str）も、数値と同じようにさまざまな操作ができます。まずは連結と繰り返し、そして文字数を数える len() です。

str_basic.py 
sei = "山田"
mei = "太郎"

full_name = sei + mei       # 文字列の連結
line = "-" * 10              # 文字列の繰り返し

print(full_name)
print(line)
print(len(full_name))        # 文字数
実行結果 
山田太郎
----------
4

文字列は1文字ずつ数字（インデックス）で取り出せます。最初の文字は 0 番目です。範囲を指定して取り出すスライスも使えます。

flowchart LR subgraph S["文字列 P y t h o n"] direction LR A0["P
0"] --- A1["y
1"] --- A2["t
2"] --- A3["h
3"] --- A4["o

5"] end S -->|"word[0]"| R1["P"] S -->|"word[1:4]"| R2["yth"] S -->|"word[-1]"| R3["n（末尾）"]
slice.py 
word = "Python"

print(word[0])     # 先頭の1文字
print(word[1:4])   # 1番目から3番目まで（4番目は含まない）
print(word[-1])    # 末尾の1文字（負のインデックス）

文字列には、よく使う便利なメソッド（文字列に対してできる命令）もそろっています。代表的なものを見てみましょう。

メソッド 内容 例 → 結果
.upper() 大文字に変換 "abc".upper() → "ABC"
.replace(旧, 新) 文字列を置き換える "abc".replace("b","X") → "aXc"
.split(区切り) 区切り文字でリストに分割 "a,b,c".split(",") → ["a","b","c"]
.strip() 前後の空白を取り除く " ab ".strip() → "ab"
methods.py 
memo = "  食費, 850円  "

cleaned = memo.strip()          # 前後の空白を除去
parts = cleaned.split(",")      # カンマで分割してリストに

print(cleaned)
print(parts)
print(parts[0].upper())
実行結果 
食費, 850円
['食費', ' 850円']
食費

.split(",") のように「カンマ区切りの文字列をリストに分ける」処理は、第9章・第12章で支出記録（日付・カテゴリ・金額・メモ）を扱うときにも同じ考え方を使います。今のうちに感覚をつかんでおきましょう。

重要ポイント

文字列のメソッドは元の文字列を変更するのではなく、新しい文字列を返します。memo.strip() を実行しても memo 自体は変わらないため、結果を使いたい場合は cleaned = memo.strip() のように別の変数に代入するか、memo = memo.strip() のように上書きする必要があります。

やってみよう 5-2: 割り勘計算

同じ ch05 フォルダに warikan.py を作り、合計金額を人数で割り勘するプログラムを書きましょう。

手順

  1. 1 total（合計金額）と people（人数）を input() と int() で受け取る（第4章の復習）。
  2. 2 // で1人あたりの金額（切り捨て）を、% であまりを求める。
  3. 3 f文字列で「1人あたり ○○円（あまり ○○円は幹事負担）」のように表示する。

合計3000円・人数4人で試すと、1人あたり750円・あまり0円になります。合計2000円・人数3人だとどうなるか、電卓で先に計算してから確認してみましょう。

理解度確認クイズ

  1. Q1. 17 // 5 と 17 % 5 の結果はそれぞれ何ですか。

    回答を表示

    17 // 5 は商の 3、17 % 5 はあまりの 2 です（3 × 5 + 2 = 17）。

  2. Q2. 変数 name = "鈴木" があるとき、「鈴木さん、こんにちは」と表示するf文字列を書いてください。

    回答を表示

    print(f"{name}さん、こんにちは") です。文字列の前に f を付け、変数を {} で囲みます。

  3. Q3. word = "Python" のとき、word[1:4] はどんな文字列になりますか。理由も説明してください。

    回答を表示

    "yth" です。インデックスは 0 番目から始まり、word[1:4] は1番目から3番目まで（4番目の文字は含まない）を取り出すためです。
