同じ処理を繰り返そう（for文・while文）

これまでのプログラムは、上から下へ一度だけ実行していました。この章では「同じ処理を何度も繰り返す」ための2つの文、for 文と while 文を学びます。繰り返しは、たくさんのデータを1つずつ処理したり、条件が満たされるまで作業を続けたりするための、プログラミングの中心的な考え方です。

この章で学ぶこと

  • for 文と range() を使って、決まった回数だけ処理を繰り返せる
  • 文字列やリストを for で1文字・1要素ずつ処理し、合計を求める定番パターンが書ける
  • while 文で「条件が真の間」処理を繰り返せる
  • break・continue とネストしたループの使い方を理解する

7.1 for 文と range()

「こんにちは」を5回表示したいとき、print("こんにちは") を5行書くのは大変ですし、10回・100回になったら現実的ではありません。for 文を使えば、同じ処理を指定した回数だけ繰り返せます。回数を指定するときによく使うのが range() です。

for_range.py 
# range(5) は 0, 1, 2, 3, 4 の5回を表す
for i in range(5):
    print("こんにちは")

# range(1, 11) は 1〜10（11は含まない）
for i in range(1, 11):
    print(i, "番目")
実行結果（一部抜粋） 
こんにちは
こんにちは
こんにちは
こんにちは
こんにちは
1 番目
2 番目
...
10 番目

range(開始, 終了) は「終了の数は含まない」という点に注意してください。range(1, 11) は 1 から 10 までの10個です。i は for 文が繰り返すたびに自動で入る変数で、ループ変数と呼びます。名前は自由ですが、慣習として i（index の頭文字）がよく使われます。

書き方 意味 得られる値
range(5) 0から始まり5回 0, 1, 2, 3, 4
range(1, 11) 1から10まで 1, 2, ..., 10
range(0, 10, 2) 0から10未満、2ずつ増える（ステップ） 0, 2, 4, 6, 8
flowchart TD A["range(1, 11) を用意"] --> B{"まだ値が残っている？"} B -->|Yes| C["iに次の値を代入"] C --> D["ブロックを実行"] D --> B B -->|No| E["ループを終了"]

用語: イテラブル

for 変数 in 何か: の「何か」の部分には、range() のほか、文字列やリストなど「1つずつ取り出せるもの」を置けます。これをイテラブルと呼びます。リストでの使い方は第8章で詳しく学びます。

7.2 文字列を for で回す、合計を求める定番パターン

文字列も for で1文字ずつ取り出せます。また、繰り返しの中でよく使うのが、ループの外で用意した「累積用の変数」に、繰り返しのたびに値を足していくパターンです。

sum_pattern.py 
# 文字列を1文字ずつ取り出す
for char in "Python":
    print(char)

# 1から10までの合計を求める（累積変数のパターン）
total = 0
for i in range(1, 11):
    total += i  # total = total + i と同じ
print(f"合計: {total}")
実行結果 
P
y
t
h
o
n
合計: 55

この「total = 0 で用意して、ループの中で total += i を足していく」という形は、合計を求めるときの定番パターンです。個数を数える場合も、count = 0 と count += 1 という同じ考え方が使えます。

重要ポイント

累積変数は必ずループの外（前）で初期化します。total = 0 をループの中に書いてしまうと、繰り返すたびにリセットされてしまい、合計が求められません。

7.3 while 文

for 文は「決まった回数」を繰り返すのに向いています。一方、while 文は「条件が真（True）である間、繰り返す」という書き方です。繰り返す回数が事前にわからないときに使います。

while_basic.py 
# countが3未満の間、繰り返す
count = 0
while count < 3:
    print("カウント:", count)
    count += 1  # 必ず変数を更新する

print("終了")
実行結果 
カウント: 0
カウント: 1
カウント: 2
終了

注意: 無限ループ

上の例で count += 1 を書き忘れると、count がずっと 0 のままで条件が真であり続け、プログラムが永遠に終わらなくなります（無限ループ）。もし実行が止まらなくなったら、ターミナルで Ctrl + C（Mac も同じ）を押すと強制的に止められます。while 文を書いたら、条件がいつか偽になるかを必ず確認しましょう。

for 文と while 文は、次のように使い分けます。

文 向いている場面 例
for 繰り返す回数やデータの数が決まっている 1〜10まで表示する、リストの全要素を処理する
while 何回繰り返すか事前にわからず、条件で判断したい 正しい値が入力されるまで聞き直す、ゲームが終わるまで続ける

7.4 break と continue、ネストしたループ

繰り返しの途中で処理を制御したいことがあります。break は「ループをそこで打ち切る」、continue は「その回だけスキップして次に進む」ための命令です。

break_continue.py 
for i in range(1, 11):
    if i == 5:
        break  # 5になったらループを終了する
    print(i)

print("---")

for i in range(1, 11):
    if i % 2 == 0:
        continue  # 偶数のときはこの回をスキップ
    print(i)
実行結果 
1
2
3
4
---
1
3
5
7
9

for 文や while 文は、内側にさらに別のループを入れて入れ子（ネスト）にできます。代表例が「九九の表」です。外側のループが「段」、内側のループが「その段の1〜9」を表します。

multiplication_table.py 
# 九九の表（2の段〜4の段だけ表示）
for dan in range(2, 5):
    for i in range(1, 10):
        # end=" " で改行せず半角スペースで区切る
        print(dan * i, end=" ")
    print()  # 段が変わるところで改行する
実行結果 
2 4 6 8 10 12 14 16 18
3 6 9 12 15 18 21 24 27
4 8 12 16 20 24 28 32 36

ネストのインデントに注意

内側のループは、外側のループよりさらに1段深くインデントします。break や continue は、それが書かれている一番内側のループだけに効きます。外側と内側を混同しないよう、インデントの深さを常に意識しましょう。

やってみよう 7-1: 数当てゲーム

while 文と break を使って、コンピュータが決めた数字を当てるゲームを作りましょう。乱数を扱う random モジュールは第13章で詳しく学びますが、ここでは「おまじない」として使います。

手順

  1. 1 python-study/ch07/guess_game.py を作成し、先頭に import random と書く。
  2. 2 answer = random.randint(1, 10) で 1〜10 の正解の数字を決める。
  3. 3 while True: でループし、int(input("数字を入力: ")) で予想を受け取る。
  4. 4 予想が正解と一致したら「正解！」と表示して break。一致しなければ「もっと大きい／小さい」とヒントを表示する。

ヒント: while True: は「ずっと真」なので、そのままだと無限ループです。正解したときの break が、ループを抜ける唯一の出口になります。

理解度確認クイズ

  1. Q1. range(1, 6) で得られる値をすべて書いてください。

    回答を表示

    1, 2, 3, 4, 5 です。range(開始, 終了) は終了の数を含まないため、6 は含まれません。

  2. Q2. for 文と while 文は、それぞれどんな場面で使うのが向いていますか？

    回答を表示

    for 文は繰り返す回数やデータの数があらかじめ決まっている場合に向いています。while 文は、何回繰り返すか事前にわからず、条件が満たされるまで続けたい場合に向いています。

  3. Q3. break と continue の違いを説明してください。

    回答を表示

    break はループそのものをそこで打ち切って抜け出します。continue はループ全体は続けたまま、その回の残りの処理だけをスキップして次の繰り返しに進みます。
