ホーム Python 第2章
第2章 所要時間: 約90分

開発環境を準備しよう

この章では、実際に手を動かしてコードを書くための環境を用意します。Python 本体のインストール、コードを書くエディタ（VS Code）の導入、そしてコンピュータに指示を出す「ターミナル」の基本操作を身につけます。ここまでの準備が整えば、次章からいよいよプログラムを書き始められます。

この章で学ぶこと

  • 「Python本体」「エディタ」「ターミナル」がそれぞれ何をする道具かを説明できる
  • 自分のパソコンに Python をインストールし（Windows は Python install manager を使う）、バージョンを確認できる
  • VS Code に Python 拡張機能を入れ、作業用フォルダを開ける
  • ターミナルの基本コマンド（移動・一覧表示）を使え、python が見つからないときの確認手順が分かる

2.1 開発に必要な道具

Python でプログラムを書いて動かすには、役割の異なる3つの道具が必要です。それぞれが何をするのかを最初に整理しておくと、この先インストール作業でつまずいたときに「今どこがうまくいっていないのか」を切り分けやすくなります。

エディタ（VS Code）

Python のコードを書き、ファイル（.py）として保存するためのソフト。文章を書くメモ帳の高機能版です。

ターミナル

文字でコンピュータに命令を出す画面。「このファイルを Python で実行して」と指示を出す窓口です。

Python本体

第1章で学んだインタプリタそのもの。ターミナルから呼び出されて、コードを実際に実行します。

3つの道具は、下の図のような順番で連携します。エディタはコードを書くだけで実行はできません。実行を担当するのはあくまで Python本体で、その橋渡しをターミナルが行います。

flowchart LR A["エディタ（VS Code）
コードを書いて保存"] --> B["ファイル
hello.py"] B --> C["ターミナル
実行コマンドを入力"] C --> D["Python本体
インタプリタ"] D --> E["実行結果を表示"]

VS Code の中でも完結できます

VS Code にはターミナルが内蔵されているため、実際にはエディタとターミナルを1つの画面で行き来しながら作業します。「役割が別物」という点だけ押さえておけば十分です。

2.2 Python のインストール

Python 本体は、Python 公式サイト（python.org）が配布しているものを使います。本ガイドは Python 3.12 以降を前提としていますが、これからインストールする場合は、その時点の最新版を入れれば問題ありません（本章の画面例は Python 3.14 系のものです）。インストールの方法は OS によって異なります。

Windows

公式の管理ツール Python install manager をインストールし、それを使って Python 本体を入れます。手順はこのすぐ下で説明します。

macOS

python.org のダウンロードページから macOS 用のインストーラ（.pkg ファイル）をダウンロードして開き、案内に従ってインストールを進めます。macOS には別バージョンの Python があらかじめ入っていることがありますが、新しくインストールしたものを使うので気にする必要はありません。

Windows: Python install manager を使う

Python install manager（Python インストールマネージャー）は、Python 本体のインストールや更新、複数バージョンの切り替えを行うための公式ツールです。Python 3.14 から、Windows ではこのツールを使う方法が公式に推奨されています。次の手順で進めましょう。

  1. 1 Microsoft Store アプリで「Python install manager」を検索し、「入手」（または「インストール」）を押します。Microsoft Store を使えない場合は、python.org のダウンロードページで「Download Python install manager」を選び、ダウンロードしたファイルをダブルクリックして「インストール」を押します（どちらから入れても中身は同じです）。
  2. 2 インストールが終わったら、ターミナルを新しく開き（スタートメニューで「ターミナル」または「PowerShell」と検索して起動します）、python と入力して Enter を押します。
  3. 3 Python 本体がまだ入っていない場合は、最新版が自動でダウンロード・インストールされます。準備ができると >>> という記号が表示されます（対話モードといいます。第3章で詳しく学びます）。exit() と入力して Enter を押し、元の画面に戻ります。

英語の質問が表示されたら

Microsoft Store の「開く」ボタンや、スタートメニューの「Python install manager」から起動すると、設定を確認する画面が英語で表示されます。Install CPython now? [Y/n] と聞かれたら、そのまま Enter を押すと最新の Python がインストールされます（CPython は python.org が配布している Python 本体の正式名称です）。そのほかの [y/N] で終わる質問（長いパス名の許可や PATH への追加など）は、よく分からなければ何も入力せずに Enter を押して構いません。python・py コマンドはそのまま使えます。

注意: 「Add python.exe to PATH」は従来の手順です

インターネット上の解説記事には、「インストーラの最初の画面で Add python.exe to PATH にチェックを入れる」という手順がよく載っています。これは従来のインストーラの手順です。従来のインストーラは Python 3.14 で非推奨となり、Python 3.16 以降は提供されない予定です。本ガイドでは Python install manager を使うため、この操作は必要ありません。以前に従来のインストーラで Python を入れたことがある場合は、2.4 のトラブル対処も確認してください。

インストールを確認する（Windows・macOS 共通）

インストールが終わったら、ターミナルを開いて正しく入ったか確認します。Windows と macOS/Linux では実行コマンドの名前が少し異なります。

ターミナル（Windows） 
python --version
py --version

Windows では python と py のどちらのコマンドも使えます。まず python --version を試し、うまくいかない場合は py --version も試してください（どちらか一方でバージョンが表示されれば大丈夫です）。

ターミナル（macOS / Linux） 
python3 --version
実行結果 
Python 3.14.7

このように「Python 3.14.7」のようなバージョン番号が表示されれば成功です（数字はインストールした時期によって異なります。3.12 以降であれば、本ガイドの内容をそのまま試せます）。本ガイドでは以降、python（macOS は python3）と表記します。実行するときは自分の OS に合わせて読み替えてください。

2.3 VS Code と Python 拡張機能の導入

VS Code 公式サイトからインストーラをダウンロードし、案内に従ってインストールします。VS Code 自体はどんな言語でも使える汎用エディタなので、Python 用の機能を追加する必要があります。

  1. VS Code を起動し、左側の縦アイコン一覧から「拡張機能」（四角が4つ並んだアイコン）を開く
  2. 検索欄に「Python」と入力し、Microsoft 製の「Python」拡張機能をインストールする
  3. ホームフォルダに python-study という作業用フォルダを作成し、VS Code の「フォルダーを開く」でそのフォルダを開く
  4. 画面右下（または左下）に表示される Python のバージョン表示をクリックし、先ほどインストールした Python が選ばれているか確認する（インタプリタの選択）

python-study フォルダは、この先の章で作るプログラムをすべて保存する場所です。章ごとに ch03・ch04 のようなサブフォルダを作り、その中にファイルを置いていきます（例: python-study/ch03/hello.py）。

「インタプリタの選択」って何？

パソコンに Python が複数入っていることがあり、VS Code は「どの Python を使ってコードを実行するか」を選べるようになっています。2.2 でインストールしたものが選ばれていれば問題ありません。表示がおかしいときは、コマンドパレット（Ctrl+Shift+P / Cmd+Shift+P）で「Python: Select Interpreter」を検索すると選び直せます。

2.4 ターミナルの基本

ターミナルは「今どこのフォルダにいるか」を意識しながら操作します。よく使う3つのコマンドを覚えておきましょう。

やりたいこと Windows macOS / Linux
今いる場所を表示する pwd（PowerShell）／cd（コマンドプロンプト、引数なし） pwd
フォルダを移動する cd python-study cd python-study
中身の一覧を表示する dir ls

よくあるつまずきを2つ紹介します。あらかじめ知っておくと、実際に遭遇したときに落ち着いて対処できます。

「python は認識されていません」と出る／Microsoft Store が開く（Windows）

ターミナルは、入力されたコマンド名に対応するプログラムを、PATH（コマンドを探しに行く場所のリスト）に登録された場所から探します。Python install manager を入れると、python・py コマンドは Windows の「アプリ実行エイリアス」という仕組みで、PATH に最初から含まれている場所へ自動的に登録されます。そのため、自分で PATH を設定する必要はありません。このエラーが出たり Microsoft Store が開いたりするのは、多くの場合、Python install manager がまだ入っていないか、インストール直後で反映されていないときです。次の順に確認しましょう。

  1. 2.2 の手順で Python install manager をインストールしたか確認する（Microsoft Store が開いた場合は、そこで「Python install manager」を検索してインストールしても構いません）。
  2. ターミナル（VS Code の中のターミナルも含む）をいったん閉じて、開き直す。
  3. py --version でバージョンが表示されるか試す。
  4. スタートメニューで「アプリ実行エイリアス」と検索して「アプリ実行エイリアスの管理」を開き、「Python (default)」と「Python install manager」の項目がオンになっているか確認する（すでにオンなら、一度オフにしてからオンに戻す）。

以前に従来のインストーラで Python を入れていた（Windows）

古い Python や「Python Launcher」が残っていると、python と py で別のバージョンが起動したり、py を実行すると「can't open file」というエラーが出たりすることがあります。設定アプリの「インストールされているアプリ」で「Python」を検索し、不要になった古い Python や「Python Launcher」をアンインストールしてから、ターミナルを開き直してください。それでも解決しない場合は、公式ドキュメントのトラブルシューティング（英語）を参照してください。

やってみよう 2-1: バージョン確認と作業フォルダ作成

実際に環境を整えて、この先の章で使う土台を作ります。

手順

  1. 1 ターミナルを開き、python --version（macOS は python3 --version）でバージョンが表示されることを確認する。
  2. 2 ホームフォルダに python-study フォルダを作成する（エクスプローラー／Finder で作ってもよい）。
  3. 3 VS Code で python-study フォルダを開き、Python 拡張機能が有効になっていること（右下のバージョン表示）を確認する。

ここまで確認できれば、次章からすぐにコードを書き始められます。うまくいかない場合は 2.4 のトラブル対処を見直してみましょう。

理解度確認クイズ

  1. Q1. エディタ・ターミナル・Python本体の役割の違いを説明してください。

    回答を表示

    エディタ（VS Code）はコードを書いて保存する道具、ターミナルはコンピュータに命令を出す窓口、Python本体（インタプリタ）はコードを実際に実行するソフトウェアです。エディタで書いたファイルを、ターミナル経由でPython本体に渡して実行します。

  2. Q2. Windows で Python をインストールするとき、本ガイドではどの方法を使いますか？また、従来の手順にある「Add python.exe to PATH」のチェックは必要ですか？

    回答を表示

    公式に推奨されている Python install manager を使います。Microsoft Store または python.org から Python install manager をインストールし、ターミナルで python と入力すると、最新の Python が自動でインストールされます。python・py コマンドは自動で使えるようになるため、「Add python.exe to PATH」のチェック（従来のインストーラの手順）は必要ありません。

  3. Q3. macOS でフォルダの中身を一覧表示するコマンドは何ですか？

    回答を表示

    ls です。Windows では dir を使います。現在地を確認する pwd（Windows のコマンドプロンプトでは cd のみ入力）や、移動する cd フォルダ名 とあわせて覚えておきましょう。
