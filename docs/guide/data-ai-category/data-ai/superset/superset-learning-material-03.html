ホーム Apache Superset 第3章
第3章 所要時間: 約45分

画面ツアーと基本操作

前章で起動した Superset に、あらためてログインするところから始めます。この章ではまだ何も「作らず」、ナビゲーションバーの構成、サンプルダッシュボードの見る側の操作、一覧画面の使い方、Settings メニューの中身を一通り確認します。第1章で学んだ「接続・データセット・チャート・ダッシュボード」の4つの要素が、実際の画面のどこに現れるのかをつかむことがこの章のゴールです。

この章で学ぶこと

  • ナビゲーションバーの Dashboards / Charts / Datasets / SQL / Settings がそれぞれ何を扱う場所か説明できる
  • サンプルダッシュボードを編集せずに、フィルタ・ホバー・タブ切り替えなど「見る側」の操作ができる
  • チャート一覧・データセット一覧の見方を理解し、目的の画面へ迷わず移動できる
  • ダッシュボード → チャート → データセット → データベース接続の関係を、画面を操作しながら確認できる

3.1 ナビゲーションバーの構成

Superset にログインすると、画面上部に横並びのナビゲーションバーが表示されます。項目数は多くありませんが、どこに何があるかを先に地図として持っておくと、以降の章で「今どの画面を触っているか」を見失いにくくなります。

メニュー 開く画面 主な用途
Dashboards 保存済みダッシュボードの一覧 複数チャートをまとめた画面を開く・新規作成する（第10章）
Charts 保存済みチャートの一覧 個々のグラフを開く・新規作成する（第8章）
Datasets データセットの一覧 分析対象のテーブル／SQL定義を確認し、新規チャート作成の起点にする（第6章）
SQL > SQL Lab SQLエディタ 自由にSQLを書いて実行し、結果を確認する（第5章）
SQL > Saved Queries 保存したクエリの一覧 過去に保存したSQLを呼び出して再実行する（第5章）
SQL > Query History クエリの実行履歴 過去に実行したSQLと結果を振り返る（第5章）
Settings 管理系メニューの一覧 接続・ユーザー・権限など管理者向けの設定（3.4 で詳しく）

右側にあるアイコン類

ナビゲーションバーの右側には、新規作成用の「＋」アイコンや検索アイコン、ユーザーメニュー（3.6 で扱います）が並びます。配置やアイコンの種類はバージョンによって多少異なる場合があります。迷ったら、まずは今回のように文字が書かれたメニュー項目（Dashboards / Charts / Datasets / SQL / Settings）を基準にすると迷いにくくなります。

3.2 サンプルダッシュボードを開く

ナビゲーションバーの Dashboards をクリックすると、第2章で読み込んだサンプルデータのダッシュボード一覧が表示されます。一覧に並ぶ名前は読み込んだサンプルデータの内容やバージョンによって異なりますが、どれか1つのタイトル文字列をクリックして開いてみましょう。タイトル横の鉛筆アイコンではなく、タイトルの文字自体をクリックするのがポイントです。

この章では「編集モード」に入らない

ダッシュボード右上には Edit dashboard（編集）ボタンがありますが、この章ではまだクリックしません。編集モードはチャートの配置やサイズを変更するためのモードで、第10章で扱います。もし誤って入ってしまった場合は、変更を加えずに右上の Discard（破棄）を選べば、見る側の画面に戻れます。

まずは見る側の操作だけで、ダッシュボードがどのくらい「触れる」ものかを体感してください。

操作 場所 できること
フィルタバーの操作 画面上部または左側のフィルタパネル 期間や属性の値を変更して表示を絞り込む。変更は自分の画面だけに反映され、保存はされない
チャートにカーソルを合わせる 各チャートの上・右上 数値の詳細がツールチップで表示され、「...」メニューが右上に現れる
タブの切り替え ダッシュボード上部のタブ（設定されている場合） カテゴリ別に分かれたチャート群を切り替える
更新（Force refresh） 右上の「...」メニュー キャッシュを使わず最新データを取得し直して再描画する
全画面表示 右上の「...」メニュー ナビゲーションバーを隠し、ダッシュボードだけを大きく表示する（Escキーなどで解除）

アイコンの正確な位置は毎回確認する

「...」メニューの位置やアイコンの見た目は、Superset のバージョンや画面幅によって変わることがあります。名前で覚えるより、「カーソルを合わせると出てくるメニューを探す」という探し方のほうが、バージョンが変わっても通用します。

3.3 チャート一覧・データセット一覧の見方

ナビゲーションバーの Charts と Datasets は、見た目も操作方法もよく似た一覧画面です。どちらも上部に検索ボックスがあり、列見出し（名前・種類・所有者・更新日時など）をクリックすると並び替えができます。片方の使い方を覚えれば、もう一方も同じ要領で使えます。

検索・並び替え・所有者・更新日時

検索ボックスで名前を絞り込み、列見出しで並び替えられます。Owner（所有者）や Modified（更新日時）の列で、「誰が」「いつ」作ったものかが一目で分かります。

行末のアイコン

各行にカーソルを合わせると右端にアイコンが現れます。Edit（編集）・Export（書き出し）・Delete（削除）が代表的な操作です。

混同しやすいのが、「名前をクリックしたとき」の挙動です。Charts と Datasets とで、実は行き先が違います。

一覧画面 名前をクリックすると 行末メニューでできること
Charts 一覧 その既存チャートの Explore 画面（編集画面）が開く Edit ／ Export ／ Delete
Datasets 一覧 そのデータセットを使った新規チャート作成画面（Explore）が開く Edit ／ Export ／ Delete

重要ポイント

Datasets一覧での「名前クリック＝新規チャート作成」は、第1章で見た「Dataset → Chart」という積み上げの関係がそのまま画面の動線になっている一例です。データセットを整備しておくほど、ここから始まるチャート作成がスムーズになります。

3.4 Settings メニューにあるもの

ナビゲーションバー右側の歯車アイコン（Settings）を開くと、これまでの Dashboards / Charts / Datasets とは毛色の違う、管理者向けの項目が並びます。今の時点で全部を使いこなす必要はありません。「どこで何ができるか」と「本教材のどの章で扱うか」を一覧にしておくので、迷ったらここに戻ってきてください。

項目 できること 扱う章
Database Connections データベース接続の追加・編集・削除 第4章
List Users ユーザーアカウントの一覧・追加 第13章
List Roles ロール（権限のまとまり）の一覧・編集 第13章
Row Level Security 行単位でデータを絞り込むアクセス制御ルールの設定 第13章
Alerts & Reports 条件監視の通知や、定期的なレポート配信の設定 第14章
Annotation Layers 時系列チャートに注記（イベントなど）を重ねるための定義 本教材では扱いません（応用）
CSS Templates ダッシュボードの見た目を調整するCSSのひな形管理 本教材では扱いません（応用）
Action Log 誰が・いつ・何をしたかの操作履歴 必要に応じて参照（本教材では詳しく扱いません）

「管理者だけが触る場所」という感覚を持つ

Settings 配下の項目の多くは、接続情報やユーザー権限などシステム全体に影響する設定です。そのため一般利用者のロール（Gamma など）ではメニュー自体が表示されない、または一部しか表示されないのが一般的です。表示される項目や並び順はバージョンや権限設定によって異なる場合があります。ロールの違いは第13章で詳しく学びます。

3.5 4つの要素を画面で辿る

第1章では「Database 接続 → Dataset → Chart → Dashboard」という積み上がる順番で4つの要素を紹介しました。実際の画面操作では、多くの場合その逆順、つまり「ダッシュボードを見ていて、気になったチャートから元のデータセット・接続へさかのぼる」という辿り方をします。この節では、その辿り方を実際の操作手順で確認します。

flowchart TD A["ダッシュボードを開く"] --> B["チャートの「...」メニューから
Edit chart を選ぶ"] B --> C["Explore画面の左上で
データセット名を確認する"] C --> D["Datasets一覧でそのデータセットを開き
「Database」欄の接続名を確認する"] D --> E["Settings ＞ Database Connectionsで
その接続の詳細を見る（第4章）"]

矢印の順に、自分の環境でも実際にクリックしてみましょう。合言葉は「チャートは必ずどこかのデータセットに属し、データセットは必ずどこかの接続に属する」です。この1本の道筋が頭に入っていれば、規模の大きいダッシュボードに出会っても「このチャート、元データは何だろう」と迷わず調べられるようになります。

Explore画面はまだ「編集」しなくてよい

Edit chart で開いた Explore 画面は、そのままチャートの中身を編集できる画面でもあります。この章では左上のデータセット名を確認するだけで十分です。軸や集計方法を変える操作は第8章でじっくり扱います。保存さえしなければ、多少触っても元のチャートは変わりません。

3.6 知っておくと便利な操作

最後に、この先の章でも繰り返し使う、細かいけれど知っておくと迷わない操作をまとめます。

画面右上のユーザーアイコン（アバター）をクリックすると、ユーザーメニューが開きます。代表的な項目は次のとおりです。

  • Profile — 自分のユーザー情報（作成したチャートやダッシュボードの一覧を含む）を確認する
  • Info — 動作中の Superset のバージョンなどの情報を確認する
  • Logout — ログアウトする

データベース認証（ユーザー名とパスワードでのログイン）を使っている場合、パスワードの変更もこのユーザーメニューから行えます。社内の SSO（シングルサインオン）と連携している環境では、パスワードは Superset 側ではなく連携元のシステムで管理されるため、この項目自体が表示されないこともあります。

ダークモード・言語設定の有無

ダークモードの切り替えや表示言語の設定は、Superset のバージョンやサーバ側の設定（superset_config.py）によって用意されているかどうかが変わります。見当たらない場合は、その環境では無効化されているだけの可能性が高く、故障ではありません。

最後にもう1つ。一覧画面（Dashboards・Charts・Datasets）や Explore 画面では、ブラウザの「戻る」ボタンも問題なく機能します。ただしダッシュボードの編集モード中やフィルタを適用している最中は話が別です。Superset は1つのページの中で画面を切り替える作り（SPA）になっており、この状態でブラウザの「戻る」を使うと画面の状態管理と噛み合わず、フィルタの選択や編集中の内容が中途半端な状態で表示されてしまうことがあるため避けてください。そうした場面では、パンくずやナビゲーションバー・「Discard」ボタンなど画面内に用意された移動手段を使うほうが安全です。

やってみよう 3-1: チャートからデータベース接続まで逆算する

3.5 で確認した辿り方を、今度は自分の手だけで実行してみましょう。サンプルダッシュボードから出発し、任意のチャート1枚について「どのデータセットを使っているか」「そのデータセットはどのデータベース接続に属するか」を特定します。

手順

  1. 1 3.2 で開いたサンプルダッシュボードに戻り、チャートを1枚選ぶ。
  2. 2 選んだチャートにカーソルを合わせ、右上に出てくる「...」メニューから Edit chart を開く。
  3. 3 開いた Explore 画面の左上に表示されているデータセット名をメモする。
  4. 4 ナビゲーションバーの Datasets からそのデータセット名を検索し、行末の編集アイコンを開いて「Database」欄に表示されている接続名を確認する。

解答の目安

チャートの「...」メニューから Edit chart（Explore）を開くと、左上にそのチャートが使っているデータセット名が表示されます。次に Datasets 一覧でそのデータセット名を探し、行末の編集アイコンから開くと「Database」欄に接続名が表示されます。この接続名は Settings ＞ Database Connections の一覧にも同じ名前で登場します（詳しい設定内容は第4章）。チャート → データセット → データベース接続の3階層を、実際に自分の画面上でクリックしながら特定できれば成功です。

理解度確認クイズ

  1. Q1. ナビゲーションバーの「SQL」メニューを開くと、何が並んでいますか？

    回答を表示

    SQL Lab（クエリエディタ）・Saved Queries（保存したクエリの一覧）・Query History（実行履歴）の3つです。いずれもSQLを実行・確認するための画面で、詳しくは第5章で扱います。

  2. Q2. サンプルダッシュボードを開くとき、この章ではまだ何をしない方がよいと説明されましたか？その理由もあわせて答えてください。

    回答を表示

    右上のEdit dashboard（編集モード）に入ることです。編集モードはチャートの配置やサイズを変更するための機能で、第10章で扱います。まずは見る側の操作（フィルタ・ホバー・タブ切り替え・更新・全画面表示）に慣れることが優先です。誤って入ってしまっても、Discardで変更を保存せずに抜けられます。

  3. Q3. Datasets一覧でデータセット名をクリックした場合と、Charts一覧でチャート名をクリックした場合とでは、開く画面はどう違いますか？

    回答を表示

    Datasets一覧で名前をクリックすると、そのデータセットを使った新規チャート作成画面（Explore）が開きます。一方Charts一覧で名前をクリックすると、既存のそのチャートのExplore画面（編集画面）が開きます。「新規作成の起点」か「既存チャートを開く」かという違いです。

  4. Q4. Settingsメニューが「管理者だけが触る場所」と言われるのはなぜですか？

    回答を表示

    Database Connections・List Users・List Roles・Row Level Securityなど、Settings配下の項目の多くが接続情報やユーザー権限などシステム全体に影響する設定だからです。一般利用者のロールではメニュー自体が表示されない、または一部しか表示されないよう権限で制御されるのが一般的です。ロールの違いは第13章で詳しく学びます。
