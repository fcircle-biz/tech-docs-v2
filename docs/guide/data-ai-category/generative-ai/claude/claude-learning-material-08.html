アーティファクトで作成する

Claude は、まとまった量のコードや文章を会話とは別の専用ウィンドウ「アーティファクト（Artifacts）」として作成できます。この章では、アーティファクトが作られる条件・種類・使い方・共有方法を理解し、自分の業務で活用できるようになります。

この章で学ぶこと

  • アーティファクトとは何かを説明し、Claude がそれを自動作成する条件を挙げられる
  • 6種類の主要なアーティファクトを用途に応じて選べる
  • アーティファクトをコピー・ダウンロード・組織内共有・一般公開できる
  • アーティファクトが作成されないときのトラブルシューティングができる

8.1 アーティファクトとは何か

アーティファクトとは、Claude が会話とは別の専用ウィンドウに作成する、独立した対話型の出力のことです。長いコードや文章のかたまりがチャットの中に埋もれてしまう代わりに、動作する Web サイトやインタラクティブなチャート、すぐにダウンロードできるドキュメントなど、レンダリングされてすぐ使えるコンテンツとして表示されます。

Claude はすべての出力をアーティファクトにするわけではありません。次の4つの条件を満たすと判断したときに、自動的にアーティファクトとして作成します。

  • 内容がまとまっており自己完結的で、一般的に15行を超えるもの
  • 編集したり、繰り返し手を加えたり、再利用したくなりそうなもの
  • 会話の前後の文脈がなくても単体で成立する複雑な内容
  • あとで参照したり使ったりしたくなるコンテンツ

用語: アーティファクトとチャット本文の違い

チャット本文の返信は会話の流れの中に残りますが、アーティファクトは会話の右側の専用ウィンドウに独立して表示されます。プレビューを見ながら元のコードを確認したり、そのままコピー・ダウンロードしたりできる点が大きな違いです。

8.2 6種類の主なアーティファクト

Claude が作成できるアーティファクトには、主に次の6種類があります。作りたいものに応じて、Claude が自動的に適切な種類を選びます。

①ドキュメント

Markdown、プレーンテキスト、Word、PDF、PowerPoint、Excel。議事録・レポート・企画書など文章量の多いコンテンツに最適。

②コードスニペット

Python、JavaScript、C++ など、あらゆる言語のコード。閲覧・コピー・ダウンロードができる。

③HTMLページ

HTML・CSS・JavaScript を1ファイルにまとめた完全な Web ページ。ランディングページや簡単なプロトタイプに。

④SVG画像

ロゴ・アイコン・イラストなどのスケーラブルなベクター画像。ウィンドウ内でそのままレンダリングされる。

⑤Mermaid図

フローチャート、シーケンス図、ガントチャート、組織図など。関係性を説明すれば調整可能な図を作成。

⑥Reactコンポーネント

計算ツール・ダッシュボード・ゲーム・データビジュアライゼーションなど、実際に動くインタラクティブな UI。

8.3 アーティファクトウィンドウの操作

Claude がアーティファクトを生成すると、会話の右側にある専用ウィンドウに表示されます。ウィンドウ内では、次の操作ができます。

操作 できること
表示形式の切り替え プレビュー（見た目）と元のコードを切り替えて表示できる
コンテンツのコピー コピーアイコンをクリックすると、内容を他の場所で使うために取得できる
ファイルのダウンロード アーティファクトをファイルとしてパソコンに保存できる
コードの確認 Claude が裏側で実際に生成した内容をそのまま確認できる

トラブルシューティング: アーティファクトが自動作成されないとき

ある程度まとまった内容を依頼したのに、Claude がアーティファクトを作成せずチャット内でそのまま応答することがあります。そのときは「これをアーティファクトとして作成して」「これをアーティファクトで見せて」と明示的に頼めば、あらためて専用ウィンドウに作成してもらえます。

8.4 アーティファクトの共有と公開

役に立つアーティファクトを作成できたら、それを共有する方法がいくつか用意されています。

共有方法 対象プラン 特徴
コピー／ダウンロード — 個人利用や他のチャネルでの共有に使う
組織内で共有 Team・Enterprise 組織内にとどまり、アクセスにはチーム認証が必要
一般公開 Free・Pro・Max 右上の「Share」または「Publish」からリンクを発行

重要ポイント: 一般公開したときに何が起きるか

  • ・選択したバージョンのみが公開され、チャット本体は非公開のまま
  • ・Claude アカウントがなくても、誰でもそのアーティファクトを閲覧・操作できる
  • ・他のユーザーがあなたのアーティファクトを「リミックス」し、自分の会話で開いて修正・発展させられる
  • ・公開されたアーティファクトは検索エンジンにインデックスされないため、Google の検索結果には出ない
  • ・公開はいつでも解除でき、そのアーティファクトに戻って公開アクセスを取りやめれば非公開に戻せる

アーティファクトを最大限活用するコツ

  • 具体的に伝える。「予算管理ツールを作って」よりも「カテゴリごとに支出を入力でき、円グラフで内訳が見られ、予算オーバー時に警告が出る月次予算管理ツールを作って」のほうが良い結果になる
  • 利用者像を伝える。「新入社員向け」なのか「エンジニアリングチーム向け」なのかで、適切なデザインの選択が変わる
  • 一度に1つの変更で反復する。機能追加や修正は1点ずつ依頼すると、うまくいっている部分を見極めやすく、問題も早く見つかる

メモ: Imagine による図表生成

Claude はコードベースのアーティファクトに加えて、Imagine を使ってフローチャートのような視覚的な図を HTML として生成できる場合があります。

やってみよう 8-1: 業務プロセスをフローチャートのアーティファクトにする

自分の業務プロセスを1つ選び、アーティファクトとして作成・改善・ダウンロードするところまで体験してみましょう。

手順

  1. 1 自分の業務の中にある一連の手順（例: 経費精算、問い合わせ対応など）を1つ選ぶ。
  2. 2 「新入社員向けに、〇〇プロセスを示すフローチャートをアーティファクトとして作成して」と、利用者像を明示して依頼する。
  3. 3 アーティファクトウィンドウでプレビューを確認する。もし作成されなければ「これをアーティファクトとして作成して」と明示的に依頼する。
  4. 4 「判断が分岐する箇所を1つ追加して」と1点だけ改善を依頼し、変化を確認する。
  5. 5 満足のいく内容になったら、ダウンロードボタンでファイルとして保存する。

ヒント: 一度に複数の変更を依頼すると、どの指示がどの結果に効いたのか分かりにくくなります。改善は1つずつ、が鉄則です。

理解度確認クイズ

  1. Q1. Claude がアーティファクトを自動的に作成する4つの条件を挙げてください。

    回答を表示

    「内容がまとまっており自己完結的で一般的に15行を超える」「編集・再利用したくなりそう」「文脈がなくても単体で成立する複雑な内容」「あとで参照・利用したくなる」の4条件です。

  2. Q2. アーティファクトを一般公開すると、どのようなことが起きますか。

    回答を表示

    選択したバージョンのみが公開され、チャット本体は非公開のままです。Claude アカウントがなくても誰でも閲覧・操作でき、他ユーザーが「リミックス」して自分の会話で発展させられます。また検索エンジンにインデックスされないため Google 検索結果には出ません。公開はいつでも解除できます。

  3. Q3. 期待していたのにアーティファクトが自動作成されなかった場合、どうすればよいですか。また組織内共有と一般公開の対象プランの違いは何ですか。

    回答を表示

    「これをアーティファクトとして作成して」のように明示的に依頼すれば、あらためて専用ウィンドウに作成してもらえます。組織内共有は Team・Enterprise 向けで組織内にとどまりチーム認証が必要ですが、一般公開は Free・Pro・Max 向けでリンクを知っている誰でもアクセスできます。
