# Claude 入門 学習ガイドライン

このガイドラインでは、Anthropic の AI アシスタント **Claude** を業務で使いこなすための基礎を、入門者向けに段階的に学習するカリキュラムを提供しています。プログラミングの知識は不要です。営業・マーケティング・財務・人事・法務・研究など、あらゆる職種の方が対象です。

## 前提条件

### 必要な環境

- Web ブラウザ（Chrome・Edge・Safari 等）
- Claude アカウント（Free プランでも大半の章を追体験できます）
- 一部の章では有料プランが必要です（第9章 Skills は Pro 以上、第11章 Enterprise Search は Team／Enterprise）

### 参考リソース

- [Claude（claude.ai）](https://claude.ai/)
- [Anthropic ヘルプセンター](https://support.anthropic.com/)
- [AI Fluency コース（無料）](https://www.anthropic.com/ai-fluency)
- [コネクタディレクトリ](https://claude.ai/directory)

### 前提知識

- **必須**: Web ブラウザとクラウドサービス（Google Drive・Slack 等）の一般的な利用経験
- **推奨**: 生成 AI を一度でも触ったことがあると理解が早まります（未経験でも問題ありません）

## 学習コンテンツ

### [1. Claudeとは](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-01.html)
Claude の設計思想（Constitutional AI、helpful・harmless・honest）と5つの能力領域を学び、Claude.ai・Claude Code・@Claude といった複数の利用経路の違いをつかみます。

### [2. Claudeとの最初の会話](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-02.html)
Claude.ai の基本操作と、プロンプトの3要素「状況を設定する・タスクを定義する・ルールを指定する」を学び、伝わる依頼文を書けるようになります。

### [3. コンテキストを与える](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-03.html)
ファイルや画像のアップロード、回答を改善する4つの手段、Memory・Styles・個人設定によるパーソナライズを学びます。

### [4. より良い結果を得るために](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-04.html)
「回答が一般的すぎる」「事実が誤っている」など初心者がつまずく5つの課題と、その具体的な対処法・反復改善の進め方を学びます。

### [5. AI Fluency と evals](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-05.html)
4D Framework（Delegation・Description・Discernment・Diligence）と、自分の業務で Claude の出力品質を検証する eval の4ステップを学びます。

### [6. デスクトップアプリの3モード](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-06.html)
デスクトップアプリの Chat・Cowork・Code という3つのモードの違いと、作業内容に応じた使い分けを学びます。

### [7. プロジェクトを使いこなす](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-07.html)
専用ワークスペースであるプロジェクトの作り方、プロジェクト指示とナレッジベースの設計、チーム共有と権限管理を学びます。

### [8. アーティファクトで作成する](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-08.html)
独立した成果物「アーティファクト」の生成条件と6つの種類、ダウンロード・組織内共有・一般公開の使い分けを学びます。

### [9. スキルを活用する](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-09.html)
Claude に専門知識と手順を教える Skills の仕組み、Anthropic 製スキルの有効化、会話ベースでのカスタムスキル作成を学びます。

### [10. コネクタと MCP](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-10.html)
Google Drive・Slack・Notion などの業務ツールと Claude をつなぐコネクタと、その基盤となる Model Context Protocol（MCP）、権限とセキュリティを学びます。

### [11. エンタープライズ検索とリサーチ](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-11.html)
社内ナレッジを横断検索する Enterprise Search と、引用付きの網羅的レポートを自動生成する Research モード、そして4つの「調べる」機能の使い分けを学びます。

### [12. 実践への展開と次のステップ](https://fcircle-biz.github.io/tech-docs-v2/guide/data-ai-category/generative-ai/claude/claude-learning-material-12.html)
職種別のユースケース、Claude Code・@Claude・Claude Design・Claude for Microsoft 365 などの周辺製品、学習を続けるための公式リソースを学びます。

## 学習目標

このガイドを完了すると、以下のスキルを身につけることができます：

- Claude の設計思想と能力範囲を理解し、任せられる業務を自分で判断できる
- 状況・タスク・ルールの3要素を含む、意図が伝わるプロンプトを書ける
- ファイル添付・Memory・Styles を使って、自分専用の作業環境に育てられる
- 期待と違う出力が返ったとき、症状に応じた対処法を選んで改善できる
- プロジェクトで文脈を持続させ、チームと共有できる
- アーティファクトで再利用可能な成果物を作り、適切な範囲で共有できる
- スキルとコネクタで、Claude を自分の業務ツールと手順に接続できる
- Research・Web検索・Extended thinking・Enterprise Search を目的別に使い分けられる
- 学んだ機能を組み合わせて、自分の繰り返し業務を効率化するワークフローを設計できる
