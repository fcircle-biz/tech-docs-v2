スキルを活用する

Skills（スキル）は、Claude が専門的なタスクを毎回同じ手順で再現性高くこなすための「専門知識のパッケージ」です。この章では Skills の仕組み・有効化の方法・カスタム Skill の作り方、そして混同しやすい Projects との使い分けを学びます。

この章で学ぶこと

  • Skills（スキル）とは何か、Claude がそれをどう使うかを説明できる
  • Anthropic 製の組み込み Skills を挙げ、ドキュメント作成機能との関係を説明できる
  • Settings から Skills を有効化・管理できる
  • 会話を通じてカスタム Skill を作成でき、Projects との使い分けを説明できる

プランでの利用可否

Skills は現在、Pro・Max・Team・Enterprise プラン向けのプレビュー機能です。Free プランでは利用できません。Free プランの方は、実際の操作手順は読み飛ばし、この章では考え方の理解を優先してください。

9.1 Skills とは何か

Skills（スキル）とは、Claude が専門的なタスクのパフォーマンスを高めるために動的に読み込む、指示・スクリプト・リソースをまとめたフォルダのことです。特定のタスクを毎回同じように再現性高くこなす方法を、あらかじめ Claude に教えておくものだとイメージしてください。

たとえるなら「業務マニュアル一式」

Skills は、新人に渡す「業務マニュアル一式」に似ています。マニュアルには「何をすべきか」「どんな成果物が合格ラインか」「どんな手順で進めるか」がまとめられていますよね。Skills も同じように、Claude に対して特定タスクの進め方一式を渡しておくイメージです。

すでに Claude を使って Excel スプレッドシート、PowerPoint プレゼンテーション、Word ドキュメント、PDF などを作成したことがある方は、実はもう Skills の働きを目にしています。こうしたファイル作成機能は、裏側で動いている Skills によって実現されているのです。

ただし Skills はドキュメント作成にとどまりません。カスタム Skills を使えば、四半期の差異分析の手法、ブランドボイスのレビュープロセス、コンプライアンスチェックリストといった、再現性のある業務フロー全体をコード化でき、Claude は毎回同じ厳密な手順に従って作業を進められるようになります。

9.2 2つのカテゴリー

Skills には、大きく分けて2つのカテゴリーがあります。

カテゴリー 内容
Anthropic Skills Anthropic が作成・保守。Excel・Word・PowerPoint・PDF ファイルの作成機能を強化する。全有料ユーザーが利用可能で、関連性がある場合に Claude が自動的に呼び出すため、特別な操作は不要
カスタム Skills 専門的な業務フローや特定分野のタスクのために、自分や組織が作成する Skills。ブランドガイドラインの適用、議事録の書式統一、組織独自のデータ分析フローなど

プロンプトを送ると、Claude は内容に関連する Skill があるかを自動判断し、あれば読み込んで実行します。呼び出しの流れは次のとおりです。

重要ポイント

どの Skill を使うかは常に Claude が自動判断します。使う側が「このSkillを使って」と毎回指定する必要はありません。

9.3 Skills を有効にする

Skills を利用するには、Code execution and file creation（コード実行とファイル作成）を有効にしておく必要があります。Skills の動作には、Claude の安全なサンドボックス環境が必要になるためです。

有効化の手順

  1. 1Settings > Capabilities（設定 > 機能）に移動する
  2. 2Code execution and file creation がオンになっていることを確認する
  3. 3Skills セクションまでスクロールする
  4. 4必要に応じて、個々のスキルのオン・オフを切り替える

有効化すると、設定画面に Anthropic の組み込み Skills と、アップロード済みのカスタム Skills を含む、利用可能な Skills の一覧が表示されます。

組織で使う場合の要件

プラン 要件
Enterprise 各メンバーが Skills にアクセスできるようになる前に、組織の Owner が Admin 設定で Code execution と Skills の両方を先に有効化する必要がある
Team この機能は組織レベルでデフォルトで有効

9.4 呼び出しの実際とファイル操作

Skills の良いところは、基本的に意識する必要がないという点です。どのスキルを使うかは Claude がリクエスト内容に応じて自動的に判断します。以下は、Skills が呼び出されるプロンプトの例です。

プロンプト例 
月次経費を管理するExcelスプレッドシートを、合計を計算する数式付きで作成して
この議事録のドキュメントをPowerPointプレゼンテーションに変換して
このデータをまとめたPDFレポートを作成して
シナリオ分析付きの財務モデルをExcelで作って

Claude がスキルを使用すると、作業中の思考の過程（chain of thought）にその旨が表示されます。出力結果はダウンロード可能なファイルとして提供され、パソコンに保存するか、Google Drive へ直接保存できます。

File execution（ファイル操作）

この機能により、Claude は隔離された環境の中で実際のあなたのファイルを扱い、更新版を作成できます。スライド・スプレッドシート・契約書（.xlsx・.pptx・.docx・.pdf など任意のファイル）をアップロードすると、Claude がスライドを作成したり、分析を行ったり、編集の提案を加えたりする様子を確認できます。作業が終わったら、これらのファイルをダウンロードするか、Drive で開くことができます。

つまずきやすいポイント

Chat では、Claude は元のファイルをその場で編集するのではなく、ドキュメントの新しいバージョンを作成します。アップロードした元ファイルが自動的に上書きされるわけではないので、更新版として出力されたファイルを別途保存・活用してください。

これらの機能を使うには、Claude に外部データソースへのアクセスを許可する必要があります。表示されたら、Allow limited network access（限定的なネットワークアクセスを許可する）をオンにしてください。

セキュリティ上の注意点

Skills には実行可能なコードが含まれる場合があるため、慎重に扱うことが重要です。

  • 信頼できる提供元のカスタム Skills のみをインストールする
  • Anthropic の組み込み Skills は Anthropic によってテスト・保守されている
  • アップロードしたカスタム Skills は、自分個人のアカウント内でのみ非公開に保たれる
  • 外部の提供元からカスタム Skill をインストールする場合は、使用前にその中身を確認し、何を行うものかを理解しておく

9.5 カスタム Skill の作成と Projects との使い分け

Anthropic の組み込み Skills は一般的なドキュメント作成タスクをカバーしていますが、Skills の真価が発揮されるのは自分専用の Skill を作成したときです。カスタム Skill を作成する最も簡単な方法は、Claude との会話を通じて行うことです。コードを書いたり、手作業でファイルを作成したりする必要はありません。

会話を通じてカスタム Skill を作る手順

  1. 1新しいチャットを開始し、作成したい内容を Claude に伝える（例:「四半期ビジネスレビューを作成するためのスキルを作りたい」）
  2. 2Claude からの質問に答える。「このスキルは何をすべきか」「どのような成果物が良い出力か」「いつ使うか、具体例」などをヒアリングされる
  3. 3お持ちであれば参考資料をアップロードする（テンプレート・スタイルガイド・ブランド素材・自信のある成果物の実例など）
  4. 4スキルを保存する。完了すると Claude が適切に構造化された Skill を含むファイルを生成し、保存すればすぐ使える状態になる

自分の Skills を確認・管理する

左サイドバーの Customize タブを開くと、自分が利用できるすべての Skills を確認できるほか、手動で編集したり、Claude とチャットしながら編集したりできます。作成後は関連するタスクに取り組むたびに Claude が自動的にそのスキルを呼び出すため、手動での起動は不要です。

Projects との使い分け

「Projects と Skills のどちらも Claude に追加のコンテキストを与えられるなら、それぞれどう使い分ければいいのか」と疑問に思うかもしれません。次のように考えてください。Projects は知識を蓄積し、Skills はタスクを実行します。Projects が「何を」（情報）を提供し、Skills が「どのように」（プロセス）を提供します。この2つは互いに補い合う関係にあり、Skills は Projects に保存された知識を参照できます。

やってみよう 9-1: Skills の自動呼び出しを確認する

Anthropic Skills が実際にどう呼び出されるかを、chain of thought（思考の過程）で確認してみましょう。Pro・Max・Team・Enterprise プランをお使いの方が対象です。

手順

  1. 1 Settings > Capabilities に移動し、Code execution and file creation がオンになっていることを確認する（オフなら オンにする）。
  2. 2 Skills セクションまでスクロールし、Anthropic Skills とアップロード済みのカスタム Skills の一覧を眺めてみる。
  3. 3 新しいチャットで「月次経費を管理するExcelスプレッドシートを、合計を計算する数式付きで作成して」と依頼する。
  4. 4 Claude の思考の過程（chain of thought）に Skill が呼び出された旨が表示されるか確認し、出力された Excel ファイルをダウンロードするか Google Drive へ保存してみる。

ヒント: Free プランの方は実際の操作はできませんが、周囲の Pro・Max ユーザーの画面を見せてもらったり、9.4 のプロンプト例を読み返したりして、呼び出しの流れをイメージしておきましょう。

理解度確認クイズ

  1. Q1. Skills とは何ですか。一言で説明してください。

    回答を表示

    Claude が専門的なタスクのパフォーマンスを高めるために動的に読み込む、指示・スクリプト・リソースをまとめたフォルダです。「専門知識のパッケージ」であり、特定タスクを毎回同じように再現性高くこなす方法を Claude に教えるものです。

  2. Q2. Skills を使うにはどのプランが必要ですか。また有効化のために最初に何をオンにする必要がありますか。

    回答を表示

    Pro・Max・Team・Enterprise プラン向けのプレビュー機能で、Free プランでは利用できません。利用には Settings > Capabilities で Code execution and file creation をオンにしておく必要があります。

  3. Q3. 「Projects は知識を蓄積し、Skills はタスクを実行する」とは、どういう意味ですか。

    回答を表示

    Projects は仕様書や議事録などの参考資料を蓄積し、Claude が業務を理解するための「何を（情報）」を提供します。Skills は具体的な手順・実行順序・方法論をコード化し、「どのように（プロセス）」を提供します。両者は補い合う関係で、Skills は Projects に保存された知識を参照できます。
