ホーム Claude Code 第3章
第3章 所要時間: 約50分

インストールとセットアップ

この章では、Claude Code を実際に自分の環境へインストールし、起動から初期設定までを完了させます。ターミナル版の導入手順に加えて、VS Code・JetBrains・デスクトップアプリ・Web版という4つの導入方法も押さえ、状況に応じて使い分けられるようになりましょう。あわせて、claude を起動するときに必ず知っておくべき「アクセス範囲」の重要な注意点も学びます。

この章で学ぶこと

  • 自分のOS（macOS／Linux／WSL／Windows）に合ったインストール方法を理解し、実際にインストールできる
  • claude の起動から初期設定（カラーテーマ・サインイン）までの流れを説明できる
  • claude のアクセス範囲の重要な性質を理解し、安全なディレクトリで起動できる
  • VS Code・JetBrains・デスクトップアプリ・Web版、それぞれの導入方法と特徴を理解する
  • インストール後に動作確認のコマンドを使って、正しくセットアップできたかを確認できる

3.1 OS別インストール（ターミナル版）

Claude Code は、ターミナル・Web・IDE のいずれからでも簡単にインストールできます。まずは第1章の 1.5 でも触れた、本ガイドの中心であるターミナル版から見ていきましょう。インストール方法は OS によって異なります。

flowchart TD A["claude コマンドの導入"] --> B{"使用しているOS"} B -->|macOS・Linux・WSL| C["ターミナルで curl コマンドを実行"] B -->|Windows| D{"PowerShell か CMD か"} D -->|PowerShell| E["irm コマンドを実行"] D -->|CMD| F["curl コマンドを実行"] C --> G["claude コマンドが使えるようになる"] E --> G F --> G G --> H["プロジェクトのディレクトリで claude を実行"]

macOS・Linux・WSL では、curl コマンドを使えば一度にインストールできます。

terminal — macOS ／ Linux ／ WSL 
# Claude Code を一括インストール（自動アップデートに対応）
curl -fsSL https://claude.ai/install.sh | bash

# インストールされたバージョンを確認する
claude --version

Windows では、PowerShell か CMD のいずれかを使います。PowerShell では Invoke-RestMethod（省略形 irm）コマンドを使います。

PowerShell — Windows 
# Claude Code を一括インストール（PowerShell）
irm https://claude.ai/install.ps1 | iex

# インストールされたバージョンを確認する
claude --version

すでに Node.js 環境がある場合は、npm 経由でもインストールできます。

terminal — npm（Node.js 環境） 
# npm がすでに使える環境ならこちらでも導入できる
npm install -g @anthropic-ai/claude-code

macOS・Linux では Homebrew（brew install）、Windows では winget（winget install）も利用できますが、どちらも自動アップデートには対応していません。更新のたびに手動でコマンドを実行し直す必要がある点に注意してください。

インストール方法は変わることがあります

上記のコマンドは執筆時点のものです。Claude Code は活発に開発が続いており、インストール方法が変更される可能性があります。実行する前に、必ず公式ドキュメント（docs.claude.com）で最新の手順を確認する習慣をつけましょう。

3.2 起動と初期設定

インストールが終わったら、対象のプロジェクトのディレクトリに移動してから claude を実行します。もし claude コマンドが認識されない場合は、ターミナルを再起動してから試してください（PATH の反映にはターミナルの再起動が必要なことがあります）。

初回起動時は、次のような初期セットアップの手順が続きます。

terminal — 初回起動の流れ（イメージ） 
$ cd ~/projects/my-app
$ claude

Claude Code へようこそ
? カラーテーマを選択してください   Dark mode
? サインイン方法を選択してください
    Claude アカウントでログイン（Pro／Max／Enterprise）
    APIキーを使用する
    サードパーティ・プラットフォームを使用する

設定する項目は主に2つです。①カラーテーマの選択と②サインイン方法の選択です。サインインは、Claude のPro／Max／Enterprise サブスクリプションでのログイン、APIキーの入力、またはサードパーティ・プラットフォーム（Amazon Bedrock や Google Vertex AI など）の利用から選べます。

組織のEnterpriseアカウントがある場合

所属する組織で Claude Enterprise アカウントを契約している場合は、サインインの選択肢で必ずそのオプションを選んでください。個人アカウントでサインインしてしまうと、組織の設定や利用枠が反映されません。

3.3 アクセス範囲の重要な性質

Claude Code を起動する前に、必ず理解しておくべき重要な性質があります。それはclaude を実行したディレクトリと、そのすべてのサブフォルダに対してアクセス権が与えられるということです。

アクセス範囲のイメージ 

~/projects/
├── my-app/              ← ここで claude を実行した
│   ├── src/               読み書き可能
│   ├── tests/              読み書き可能
│   └── .env                読み書き可能（機密ファイルも例外ではない）
└── other-app/            × アクセス不可（別ディレクトリのため）

重要: 広い階層で claude を起動しない

ホームディレクトリ直下（~）や、ファイルシステムのルートのような広い階層で claude を起動すると、意図しない範囲の大量のファイルにアクセスできる状態になってしまいます。必ず対象プロジェクトのディレクトリまで cd してから起動するようにしましょう。.env のような機密情報を含むファイルも、アクセス範囲に含まれる点を忘れないでください。

なお、このアクセス範囲はあくまで「Claude Code がファイルを見に行ける・調べられる範囲」です。実際にファイルを変更したりコマンドを実行したりする際には、第2章で学んだとおり許可モードにもとづく確認が別途入ります。アクセス範囲と許可モードは、Claude Code を安全に使うための2つの独立した仕組みとして覚えておきましょう。

3.4 IDE・デスクトップ・Web版でのインストール

第1章の 1.5 で紹介したとおり、Claude Code はターミナル以外にも4つの形態で利用できます。それぞれの導入方法を見ていきましょう。どれを選んでも中身の Claude Code は同じで、操作する画面が違うだけです。

Visual Studio Code

Extensions（拡張機能）パネルで「Claude Code」を検索します。青い認証マークが付いたAnthropic 製の拡張機能を選び、Install をクリックしてください。インストール後は VS Code の再起動が必要になる場合があります。起動後は Ctrl/Cmd + Shift + P でコマンドパレットを開き「Claude Code Open in New Tab」を実行するか、サイドバーの Claude ロゴをクリックします。

JetBrains系IDE

IntelliJ IDEA などの JetBrains 系 IDE では、JetBrains Marketplace から Claude Code プラグインをインストールします。インストール後に IDE を再起動すると Claude のロゴが表示され、クリックするとエディタと並行して使えるターミナル形式のペインが開きます。

デスクトップアプリ

Claude デスクトップアプリをインストールしてサインインすると、上部に「Code」というトグルが表示されます。見た目や操作感はチャット側とよく似ていますが、特定のフォルダを指定して作業したり、権限を変更したり、クラウド環境で作業したりすることもできます。

Web版

ブラウザで claude.ai/code にアクセスするか、チャットアプリのサイドバーにある「Code」ラベルをクリックします。デスクトップアプリと似た使い方ができますが、対象は GitHub リポジトリに限られます。

3.5 どれを使う？5つの形態の比較

5つの提供形態はどれも中身が同じ Claude Code です。目的に応じて選ぶための目安を、次の表にまとめました。

形態 こんな時におすすめ 特徴
ターミナル 最新機能をいち早く試したい 新機能はまずここからリリースされる。本ガイドが中心的に扱う形態
VS Code エディタと一体化させて使いたい 拡張機能として導入。ターミナル版とほぼ同じ体験
JetBrains系IDE IntelliJ 等のIDEで完結させたい プラグイン導入。ターミナル形式のペインで操作
デスクトップアプリ バックグラウンドで動かしながら他の作業もしたい 「Code」トグルで切替。クラウド環境での作業も可能
Web版 GitHubリポジトリにリモートで取り組みたい ブラウザから利用。対象はGitHubリポジトリに限定

どの形態を使うかは自由に選べますし、プロジェクトによって使い分けてもかまいません。迷ったら、まずはターミナル版から始めるのがおすすめです。新機能が最初に届くうえ、Claude Code の動きがもっとも素直に見えるためです。

3.6 動作確認

インストールと初期設定が終わったら、正しくセットアップできているかを確認しましょう。よく使う確認コマンドは3つです。

terminal — バージョン確認 
# インストール済みのバージョンを確認する（通常のターミナルで実行）
claude --version

セッションを開始したら、スラッシュコマンドでも状態を確認できます。

terminal — Claude Code セッション内 
$ claude
> /status
> /help
コマンド 実行場所 確認できること
claude --version 通常のターミナル インストールされているバージョン番号
/status claude セッション内 サインイン中のアカウントや現在の設定
/help claude セッション内 利用できるスラッシュコマンドの一覧

ここまでできればセットアップ完了

claude --version でバージョンが表示され、claude の起動後に /status で自分のアカウント情報が確認できれば、インストールと初期設定は正しく完了しています。次の第4章から、実際に Claude Code へ話しかけていきます。

やってみよう 3-1: Claude Code を実際にインストールする

ここまで読んだら、実際に手を動かして Claude Code をインストールしてみましょう。

手順

  1. 1 自分のOS（macOS／Linux／WSL／Windows）を確認し、3.1 の中から自分に合ったインストール方法を選ぶ。
  2. 2 ターミナルでインストールコマンドを実行し、claude --version でインストールが成功したことを確認する。
  3. 3 学習用に新しく空のフォルダを作成し、そこへ cd してから claude を実行して、カラーテーマの選択とサインインまで済ませる（3.3 のアクセス範囲の注意を思い出しましょう）。
  4. 4 セッション内で /status を実行し、自分のアカウント情報が正しく表示されることを確認する。

理解度確認クイズ

  1. Q1. macOS・Linux・WSL でインストールする際の基本コマンドは何ですか。また、Homebrew や winget での代替インストールにはどんな注意点がありますか。

    回答を表示

    基本コマンドは curl -fsSL https://claude.ai/install.sh | bash（Windows の PowerShell では irm https://claude.ai/install.ps1 | iex）です。Homebrew や winget での代替インストールは自動アップデートに対応していないため、更新のたびに手動でコマンドを実行し直す必要があります。なお、インストール方法は変更される可能性があるため、実行前に公式ドキュメントで最新の手順を確認しましょう。

  2. Q2. claude を実行したときのアクセス範囲について、正しく説明してください。

    回答を表示

    claude を実行したディレクトリと、そのすべてのサブフォルダに対してアクセス権が与えられます。.env のような機密ファイルも例外ではありません。そのため、ホームディレクトリ直下やファイルシステムのルートのような広い階層では起動せず、必ず対象プロジェクトのディレクトリまで移動してから起動する必要があります。

  3. Q3. 「最新機能をいち早く試したい」場合と「GitHubリポジトリにリモートで取り組みたい」場合、それぞれどの提供形態が向いていますか。

    回答を表示

    最新機能をいち早く試したい場合はターミナルが向いています（新機能はまずターミナルからリリースされるため）。GitHubリポジトリにリモートで取り組みたい場合はWeb版（claude.ai/code）が向いています。対象はGitHubリポジトリに限定されますが、ブラウザだけで作業できます。
