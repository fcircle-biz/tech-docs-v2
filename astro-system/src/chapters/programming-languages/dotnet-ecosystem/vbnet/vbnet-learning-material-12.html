ホーム VB.NET入門 第12章
第12章 所要時間: 約90分

ファイルを読み書きする - 入出力の基本

プログラムを終了すると、変数に入れていたデータはすべて消えてしまいます。データを次回も使えるようにするには「ファイル」に保存しておく必要があります。この章では、System.IO を使ったファイルの読み書き、大きなファイルを扱う StreamWriter / StreamReader、パスとフォルダの操作、そして業務でよく使う CSV ファイルの読み書きまでを学びます。

この章で学ぶこと

  • なぜファイルへの保存（永続化）が必要なのかを説明できる
  • File クラスや StreamWriter / StreamReader でテキストファイルを読み書きできる
  • Path や Directory を使ってパス・フォルダを安全に操作できる
  • CSV ファイルを読み込んで、クラスのオブジェクトのリストに変換できる

12.1 なぜファイルに保存するのか

これまでの章で扱ってきた変数やオブジェクトは、すべてメモリ（RAM）の上に置かれていました。メモリはとても高速に読み書きできますが、プログラムを終了したり、パソコンの電源を切ったりすると、中身はすべて消えてしまいます。せっかく入力してもらった名簿や、計算した結果を、次にプログラムを起動したときにも使いたい場合はどうすればよいでしょうか。

その答えがファイルです。ハードディスクや SSD 上のファイルにデータを書き出しておけば、プログラムを終了しても、パソコンを再起動しても、データは消えずに残り続けます。この「データを消えない場所に残す」ことを永続化（えいぞくか）と呼びます。

設定ファイル

前回の画面サイズや接続先など、アプリの設定を次回起動時にも覚えておくために使います。

ログファイル

いつ・何が起きたかを記録しておき、トラブルが起きたときの原因調査に役立てます。

CSVによるデータ受け渡し

Excelや他システムとの間で、表形式のデータをファイル経由でやり取りします（12.5で学びます）。

VB.NET でファイルを扱う機能は、System.IO という名前空間にまとまっています。「名前空間」とは、関連するクラスをグループ分けして整理する仕組みのことです。ファイルの入出力（Input/Output）に関するクラスは System.IO にまとめられているため、ファイルの先頭で次のように書いておくと、以降は短い名前でクラスを呼び出せるようになります。

Imports宣言 ファイルの先頭に記述 
' System.IOの機能を短い名前で使えるようにする
Imports System.IO

Module Program
    Sub Main()
        ' これ以降 File.WriteAllText のように書ける
    End Sub
End Module

用語: Importsは省略できる

Imports System.IO を書かなくても、System.IO.File.WriteAllText(...) のようにフルネームで書けば動作します。Imports は「毎回 System.IO. と書くのは面倒なので省略できるようにする」ための宣言だと考えてください。

12.2 手軽な読み書き（Fileクラス）

少量のデータをさっと読み書きしたいだけなら、File クラスの共有メソッド（Shared メソッド）が便利です。第9章で学んだ Shared メンバーと同じで、New でインスタンスを作らずに、いきなり File.〇〇(...) の形で呼び出せます。

メソッド 役割
File.WriteAllText(path, text) ファイルに文字列を書き込む。既存の内容は上書きで消える。
File.AppendAllText(path, text) ファイルの末尾に文字列を追記する。既存の内容は消えない。
File.ReadAllText(path) ファイルの中身をまとめて1つの文字列として読み込む。
File.ReadAllLines(path) ファイルを1行ごとに読み込み、String()（文字列の配列）として返す。
File.Exists(path) 指定したパスにファイルが存在するかを Boolean で返す。

次の例は、メモに1行書き込んだ後、そのファイルを1行ずつ読み込んで画面に表示するプログラムです。第5章で学んだ For Each を使って、配列の各行を順番に処理しています。

Program.vb 完全なプログラム 
Imports System.IO

Module Program
    Sub Main()
        Dim path As String = "memo.txt"

        ' 1行書き込む（既存の内容は消える）
        File.WriteAllText(path, "1行目のメモです" & Environment.NewLine)
        ' 末尾に1行追記する
        File.AppendAllText(path, "2行目のメモです" & Environment.NewLine)

        ' ファイルを1行ずつ読み込んで表示する
        Dim lines As String() = File.ReadAllLines(path)
        For Each line As String In lines
            Console.WriteLine(line)
        Next
    End Sub
End Module
実行結果 
1行目のメモです
2行目のメモです

File クラスは1行で書けて手軽ですが、内部では「ファイルを開く → 全部読む（または書く）→ 閉じる」を毎回まとめて行っています。数万行あるような大きなファイルを1行ずつ処理したい場合には、次に学ぶ StreamWriter / StreamReader の方が向いています。

注意: WriteAllTextは既存の内容を消す

File.WriteAllText を同じファイルに対して繰り返し呼ぶと、そのたびに前の内容が消えて上書きされます。データを積み重ねたい場合は File.AppendAllText（追記）を使いましょう。また、存在しないファイルを File.ReadAllText で読もうとすると、第11章で学んだ FileNotFoundException が発生します。読み込み前に File.Exists で確認するか、Try ... Catch で備えましょう。

12.3 StreamWriter / StreamReader と Using

大きなファイルを扱うときや、1行ずつ順番に書き込み・読み込みをしたいときは、StreamWriter（書き込み用）とStreamReader（読み込み用）を使います。これらは「ファイルへの通り道（ストリーム）」を表すオブジェクトで、開いたら必ず閉じる必要があります。

ファイルを開いたまま閉じ忘れると、そのファイルは他のプログラム（Excelなど）から開けなくなったり、書き込んだ内容が正しく保存されなかったりします。第11章で「Finally で必ず後片付けをする」という話をしましたが、ファイルを閉じる処理はまさにその代表例です。VB.NET には、この後片付けを自動でやってくれるUsingステートメントが用意されています。

Program.vb Sub Main内に記述 
Dim path As String = "log.txt"

' Usingブロックを抜けると自動的にファイルが閉じられる
Using writer As New StreamWriter(path)
    writer.WriteLine("処理を開始しました")
    writer.WriteLine("処理が完了しました")
End Using ' ← ここで確実にClose()が呼ばれる

' ファイルを1行ずつ読み込む
Using reader As New StreamReader(path)
    Dim line As String = reader.ReadLine()
    Do While line IsNot Nothing
        Console.WriteLine(line)
        line = reader.ReadLine()
    Loop
End Using

Using 変数名 As New クラス名(...) ... End Using という形は、内部的には Try ... Finally と同じ仕組みで動いています。ブロックの中で例外が発生してエラーで抜け出した場合でも、End Using に到達した扱いとなり、必ず後片付け（ファイルを閉じる処理）が実行されます。これにより、閉じ忘れによる事故を防げます。

flowchart TD A["Usingでファイルを開く"] --> B["ブロック内で読み書き"] B --> C{"例外は発生した？"} C -->|発生した| D["エラーとして中断"] C -->|発生しなかった| E["処理が正常終了"] D --> F["End Usingで確実に閉じる"] E --> F F --> G["ファイルが安全に解放される"]

図の説明: Usingブロックは、途中でエラーが起きても正常に終わっても、End Usingの時点で必ずファイルを閉じます。これにより閉じ忘れを防ぎ、ファイルが他のプログラムから使えなくなる事故を回避できます。

追記モードと文字コードの指定

StreamWriter は初期状態だと上書きモードですが、コンストラクタの第2引数に True を渡すと追記モードになります。また、日本語を含むファイルで文字化けを防ぐために、文字コード（エンコーディング）を明示的に指定するのが安全です。文字コードの指定に使う UTF8Encoding クラスは System.Text 名前空間にあるため、ファイルの先頭に Imports System.IO だけでなく Imports System.Text も書いておく必要があります。

Program.vb Sub Main内に記述 
' ファイルの先頭でImports System.IOとImports System.Textの両方が必要
' 第2引数Trueで追記モード、文字コードにUTF-8を指定
Using writer As New StreamWriter("log.txt", True, New UTF8Encoding(False))
    writer.WriteLine("追記された1行です")
End Using

用語: 文字コードと文字化け

文字コードとは、文字をコンピュータ内部でどんな数値として扱うかの取り決めです。書き込んだときと読み込んだときで文字コードが食い違うと、いわゆる文字化けが起こります。現在の主流は UTF-8 です。New UTF8Encoding(False) の False は「BOM（ファイルの先頭に付く目印）を付けない」という意味で、多くの一般的なテキストエディタやツールと相性の良い形式になります。UTF8Encoding は System.Text 名前空間のクラスなので、忘れずに Imports System.Text を追加してください。

12.4 パスとフォルダの操作

ファイルの場所を示す文字列をパスと呼びます。パスには2種類あります。C:\data\members.txt のように場所を完全に指定する絶対パスと、現在のフォルダを基準にした data\members.txt のような相対パスです。

Path.Combineでパスを組み立てる

フォルダ名とファイル名を & でつなげてパスを作ることもできますが、区切り文字の \ を付け忘れるミスが起こりがちです。Path.Combine を使えば、区切り文字を自動的に補ってくれるため、より安全にパスを組み立てられます。

Program.vb Sub Main内に記述 
Dim folder As String = "C:\data"
Dim fileName As String = "members.txt"

' 区切り文字\を自動的に補って結合する
Dim fullPath As String = Path.Combine(folder, fileName)
Console.WriteLine(fullPath) ' C:\data\members.txt

' ファイル名や拡張子だけを取り出す
Console.WriteLine(Path.GetFileName(fullPath))  ' members.txt
Console.WriteLine(Path.GetExtension(fullPath)) ' .txt

Directoryクラスによるフォルダ操作

フォルダ（ディレクトリ）を扱うには Directory クラスを使います。File クラスと同じく共有メソッドとして呼び出せます。

メソッド 役割
Directory.Exists(path) フォルダが存在するかを確認する。
Directory.CreateDirectory(path) フォルダを新しく作成する（既にある場合は何もしない）。
Directory.GetFiles(path) フォルダ内のファイル一覧を String() で取得する。
Program.vb Sub Main内に記述 
Dim folder As String = "C:\data\output"

' フォルダが無ければ作成する
If Not Directory.Exists(folder) Then
    Directory.CreateDirectory(folder)
End If

' フォルダ内の全ファイルを一覧表示する
For Each filePath As String In Directory.GetFiles(folder)
    Console.WriteLine(Path.GetFileName(filePath))
Next

Windows Formsアプリ（第13章）などでは、実行中のプログラム自身のフォルダやデスクトップのパスをよく使います。こうした「特別なフォルダ」の場所は、パソコンによって異なるため、直接文字列で書かずに Environment.GetFolderPath で取得するのが安全です。

Program.vb Sub Main内に記述 
' 実行中のパソコンのデスクトップのパスを取得する
Dim desktop As String = Environment.GetFolderPath(Environment.SpecialFolder.Desktop)
Dim savePath As String = Path.Combine(desktop, "result.txt")
Console.WriteLine(savePath)

注意: パスの中の\とバックスラッシュ

Windowsのパス区切り文字 \ は、VB.NETの文字列の中では特別な意味を持たない普通の文字として扱えるため、そのまま "C:\data\file.txt" と書けます（C#の \n のようなエスケープの心配はありません）。ただし、パスに全角文字やスペースを含めると環境によって動かないことがあるため、業務システムでは半角英数字中心のフォルダ構成にするのが安全です。

12.5 CSVファイルを扱う

CSV（Comma-Separated Values）とは、値をカンマ（,）で区切って並べた表形式のテキストファイルです。1行が表の1行に対応し、Excelでそのまま開けるため、業務システムとExcelの間でデータをやり取りする定番の形式として広く使われています。

products.csv 
商品名,単価,在庫数
ノート,150,200
ボールペン,100,350
消しゴム,80,180

1行目は列の意味を表すヘッダー行で、多くの場合はデータとしては使わず読み飛ばします。CSVを読み込むときは、1行を Split(","c) でカンマ区切りに分解し、文字列の配列として受け取ります。","c の c は「これは1文字（Char型）ですよ」という印です。

第8章で学んだクラスと組み合わせると、CSVの各行を商品オブジェクトに変換して List(Of Product)（第6章）にまとめることができます。業務データをプログラムで扱いやすい形にする、よくあるパターンです。

Product.vb クラスの定義 
' 商品1件分のデータを表すクラス
Public Class Product
    Public Property Name As String
    Public Property Price As Integer
    Public Property Stock As Integer
End Class
Program.vb Sub Main内に記述 
Dim products As New List(Of Product)()
Dim lines As String() = File.ReadAllLines("products.csv")

' 1行目（ヘッダー）は読み飛ばし、2行目以降を変換する
For i As Integer = 1 To lines.Length - 1
    Dim columns As String() = lines(i).Split(","c)
    Dim p As New Product() With {
        .Name = columns(0),
        .Price = Integer.Parse(columns(1)),
        .Stock = Integer.Parse(columns(2))
    }
    products.Add(p)
Next

' 在庫金額の合計を計算する
Dim total As Integer = 0
For Each p As Product In products
    total += p.Price * p.Stock
Next
Console.WriteLine($"在庫金額の合計: {total}円")

書き出すときは逆に、String.Join(",", ...) で配列やリストの値をカンマでつなげます。

Program.vb Sub Main内に記述 
Dim values As String() = {"ノート", "150", "200"}

' 配列の各要素をカンマでつなげて1行の文字列にする
Dim csvLine As String = String.Join(",", values)
File.AppendAllText("products.csv", csvLine & Environment.NewLine)

products.csv"] --> B["File.ReadAllLinesで
行の配列を取得"] B --> C["各行をSplitで
カンマ区切りに分解"] C --> D["Productオブジェクトを生成"] D --> E["List(Of Product)に追加"]

図の説明: CSVファイルを行ごとの配列として読み込み、各行をカンマで分解してからProductオブジェクトを作り、最終的にList(Of Product)へまとめる流れです。

用語: 本格的なCSV処理には専用ライブラリも

ここで紹介した Split(","c) による方法は、値そのものにカンマやダブルクォート、改行が含まれるデータ（例: "東京都,新宿区" のような住所）にはそのままでは対応できません。実務でそうしたデータを扱う場合は、CsvHelper のような専用ライブラリを使うのが一般的です。まずは基本の仕組みを理解しておきましょう。

重要ポイント

少量のデータは File クラスで手軽に、大きなファイルや細かい制御が必要な場合は Using と StreamWriter / StreamReader で確実に。Usingを使えば閉じ忘れの心配がないことを覚えておきましょう。ファイル入出力は、次章のWindows Formsアプリや第14章のデータベース接続でも土台となる重要な技術です。

やってみよう 12-1: 簡単な名簿プログラムを作ろう

キーボードから入力した名前を members.txt に追記し、保存済みの一覧をすべて読み込んで表示するプログラムを作ってみましょう。

手順

  • 1 Console.ReadLine()（第2章）で名前を1件入力してもらう。
  • 2 File.AppendAllText で members.txt に追記する（末尾に改行を付ける）。
  • 3 File.Exists でファイルの有無を確認してから File.ReadAllLines で一覧を読み込む。
  • 4 For Each で全員の名前を「〇〇さん」の形で表示する。

解答例

Imports System.IO

Module Program
    Sub Main()
        Dim path As String = "members.txt"

        Console.Write("名前を入力してください: ")
        Dim name As String = Console.ReadLine()
        File.AppendAllText(path, name & Environment.NewLine)

        Console.WriteLine("--- 現在の名簿 ---")
        If File.Exists(path) Then
            Dim members As String() = File.ReadAllLines(path)
            For Each m As String In members
                Console.WriteLine($"{m}さん")
            Next
        End If
    End Sub
End Module

理解度確認クイズ

  • Q1. プログラムで扱ったデータをファイルに保存する必要があるのはなぜですか？

    回答を表示

    変数に入れたデータはメモリ上にあり、プログラムを終了すると消えてしまうためです。次回起動時にも使えるようにするには、ファイルに書き出して残しておく「永続化」が必要です。

  • Q2. File.WriteAllText と File.AppendAllText の違いは何ですか？

    回答を表示

    File.WriteAllText は既存の内容を消して新しい内容で上書きします。File.AppendAllText は既存の内容を消さず、末尾に追記します。

  • Q3. StreamWriterをUsingブロックで使うと、なぜ安全なのですか？

    回答を表示

    Usingブロックは、途中で例外が発生しても正常終了しても、End Usingの時点で必ずファイルを閉じてくれるためです。閉じ忘れによって他のプログラムがファイルを開けなくなる事故を防げます。

  • Q4. CSVの1行をカンマ区切りで配列に分解するには、どのメソッドを使いますか？

    回答を表示

    Split(","c) です。文字列に対して呼び出すと、カンマを区切りとして分割されたString()（文字列の配列）が得られます。
