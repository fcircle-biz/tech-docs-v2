同じ処理を繰り返す - ループ

前章では「もし〜なら」で処理を切り替える分岐を学びました。この章では、同じ処理を何度も実行する「ループ（繰り返し）」を学びます。For ... Next・Do ... Loop・While・For Each という4種類の繰り返し文と、それらを安全に使いこなすための制御方法を身につけます。

この章で学ぶこと

  • 繰り返し処理がなぜ必要かを理解し、ループの構成要素（初期値・条件・更新）を説明できる
  • For ... Next を使って、回数が決まった繰り返し処理を書ける
  • Do While / Do Until / While を使い分け、前判定と後判定の違いを理解している
  • Exit / Continue によるループ制御と、入れ子ループの書き方が分かる

5.1 繰り返し処理とは

たとえば「1から100までの数を画面に表示する」というプログラムを考えてみましょう。Console.WriteLine(1) から Console.WriteLine(100) まで100行を手で書くのは非効率ですし、「1から1000まで」に変わったら書き直しも大変です。こうした「同じような処理を、条件が満たされるまで何度も実行する」場面で使うのが繰り返し（ループ）です。

第1章で紹介した3つの制御構造（順次・分岐・繰り返し）のうち、最後の1つがこのループです。ループを使えば、100件のデータ処理も、1万件のデータ処理も、ほとんど同じ数行のコードで書けます。ループは次の3つの要素で構成されています。

初期値

繰り返しを始める前に、カウンタ（回数を数える変数）へ最初の値を設定します。

継続条件

この条件が真である間だけ、処理を繰り返します。条件が偽になった時点でループを抜けます。

変化（更新）

1回処理するたびにカウンタを増減させます。これを忘れると条件が変化せず終わりません。

flowchart TD A["初期値の設定
（例：i = 1）"] --> B{"継続条件を確認
（例：i は10以下か？）"} B -->|真| C["処理を実行"] C --> D["変化（更新）
（例：iを1増やす）"] D --> B B -->|偽| E["ループを終了"]

図の説明: ループは「初期値の設定 → 継続条件の確認 → 処理の実行 → 変化（更新）」を繰り返し、継続条件が偽になった時点で終了します。この4つの要素はどのループ文でも共通の考え方です。

用語: カウンタ変数

ループの中で「今何回目か」「今いくつ目か」を覚えておく変数をカウンタ変数と呼びます。慣習的に i（index の頭文字）という名前がよく使われます。二重ループでは内側に j を使うのが定番です。

5.2 For ... Next

「繰り返す回数があらかじめ決まっている」場面でもっともよく使うのが For ... Next 文です。カウンタ変数の初期値・上限値を1行で書くだけで、初期値の設定・継続条件の確認・変化（更新）をすべて自動で行ってくれます。

For文の基本形 Sub Main内に記述 
' iを1から10まで1ずつ増やしながら繰り返す
For i As Integer = 1 To 10
    Console.WriteLine("カウント: " & i)
Next

For i As Integer = 1 To 10 の1行だけで「iを1から始め、10になるまで1ずつ増やしながら繰り返す」という意味になります。Next まで来ると自動的にiが1増え、再び10以下かどうかが確認されます。11になった時点でループが終わり、Next の次の行へ処理が進みます。

Stepで増減の幅を変える

既定では1ずつ増えますが、Step を付けると増減の幅を変更できます。正の数なら増加、負の数なら減少（カウントダウン）になります。

Stepの使用例 Sub Main内に記述 
' 0から10まで2ずつ増やす（偶数のみ表示）
For i As Integer = 0 To 10 Step 2
    Console.WriteLine(i)
Next

' 5から1まで1ずつ減らす（カウントダウン）
For i As Integer = 5 To 1 Step -1
    Console.WriteLine(i)
Next

For文の代表的な使い道として、合計を求める処理があります。ループの外で合計用の変数を0で用意し、1回処理するたびに足し込んでいくのが基本パターンです。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' 合計を入れる変数は必ずループの外で0に初期化する
        Dim sum As Integer = 0

        For i As Integer = 1 To 10
            sum += i  ' sum = sum + i と同じ意味
        Next

        Console.WriteLine("1から10までの合計: " & sum)
    End Sub
End Module
実行結果 
1から10までの合計: 55

用語: 複合代入演算子

sum += i は sum = sum + i を短く書いたものです（第3章で扱った演算子の応用）。同様に -=・*=・/= もあり、ループの中で頻繁に使われます。

5.3 Doループと While

For文は「繰り返す回数が決まっている」場合に向いていますが、「利用者が正しい値を入力するまで」のように繰り返す回数が事前に分からない場合もあります。そうした場面では Do ... Loop や While ... End While を使います。

Do While ... Loop（前判定）

Do While 条件 は、条件を先に確認してから処理を実行します。最初から条件が偽であれば、処理は一度も実行されません。

Do While の例 Sub Main内に記述 
' countが5未満の間だけ繰り返す
Dim count As Integer = 0
Do While count < 5
    Console.WriteLine("count = " & count)
    count += 1  ' 更新を忘れると無限ループになる
Loop

Do ... Loop Until（後判定）

Do ... Loop Until 条件 は、処理を先に実行してから条件を確認します。そのため条件がどうであれ、最低1回は必ず実行されるのが特徴です。「まず1回試してみて、それが正しくなければやり直す」入力チェックなどに向いています。

Do Loop Until の例 Sub Main内に記述 
' 正しい数値が入力されるまで、少なくとも1回は必ず尋ねる
Dim input As String
Dim number As Integer
Do
    Console.Write("1〜10の数値を入力してください: ")
    input = Console.ReadLine()
Loop Until Integer.TryParse(input, number) AndAlso number >= 1 AndAlso number <= 10

While ... End While

While ... End While は Do While ... Loop と同じ「前判定」の繰り返しを、別の書き方で表したものです。動作はまったく同じで、どちらを使うかは好みやチームの慣習によります。

While の例 Sub Main内に記述 
' Do While と同じ意味を While で書く
Dim count As Integer = 0
While count < 5
    Console.WriteLine("count = " & count)
    count += 1
End While

前判定と後判定の違いを表と図で整理しておきましょう。

種類 書き方 条件確認のタイミング 最低実行回数
前判定 Do While / While 処理の前 0回（条件が最初から偽なら実行されない）
後判定 Do ... Loop Until 処理の後 1回（必ず1回は実行される）

注意: Do Until と Do While は条件の向きが逆

Do While 条件 は「条件が真の間」繰り返すのに対し、Do Until 条件 は「条件が偽の間（真になるまで）」繰り返します。Do While count < 5 と Do Until count >= 5 は同じ動きになりますが、条件の書き方が逆になる点に注意してください。

5.4 For Each

配列やコレクション（複数のデータをまとめて持つ入れ物。第6章で詳しく学びます）に入っているデータを、先頭から順番に1つずつ取り出して処理したいことがよくあります。そのようなときに便利なのが For Each 文です。

For Each の例 Sub Main内に記述 
' 名前の一覧を1件ずつ取り出して表示する
Dim names() As String = {"佐藤", "鈴木", "高橋"}

For Each item As String In names
    Console.WriteLine(item & "さん、こんにちは")
Next

For i As Integer = 0 To names.Length - 1 のように要素数を数えて回す代わりに、For Each item As String In names と書くだけで、要素の個数を一切気にせず全件を処理できます。名前が3件でも300件でも、コードは変わりません。配列やコレクションの中身をひととおり処理したいときの定番の書き方です。詳しい配列の作り方や便利なコレクションについては、次の第6章でじっくり学びます。

For と For Each の使い分け

「何番目の要素か」という番号（インデックス）そのものが必要なら For、番号は不要で「中身を順番に処理したいだけ」なら For Each が向いています。迷ったらまず For Each を検討するとコードがすっきりします。

5.5 ループの制御と入れ子

ループの中で「ある条件が成立したら、途中で繰り返しをやめたい」「今回だけスキップして次の回に進みたい」という場面があります。VB.NET では次のキーワードでループの流れを制御できます。

キーワード 対象 動作
Exit For For文 ループを即座に抜け、Nextの次の行に進む
Exit Do Doループ ループを即座に抜け、Loopの次の行に進む
Continue For For文 今回の残りの処理をスキップし、次の回へ進む
Exit For と Continue For の例 Sub Main内に記述 
For i As Integer = 1 To 10
    If i = 7 Then
        Exit For  ' iが7になったらループ全体を終了する
    End If

    If i Mod 2 = 0 Then
        Continue For  ' 偶数のときは表示せず次の回へ
    End If

    Console.WriteLine(i)  ' 1, 3, 5 のみ表示される
Next

ループの入れ子（二重ループ）

ループの中にさらにループを書くことを入れ子（ネスト）と呼びます。「表」のように縦横2方向にデータを扱いたいときによく使う形で、代表例が九九の表です。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' 外側のiが「段」、内側のjが「かける数」を表す
        For i As Integer = 1 To 9
            For j As Integer = 1 To 9
                Console.Write(i * j & vbTab)  ' vbTabでタブ区切りにする
            Next
            Console.WriteLine()  ' 1段終わるごとに改行する
        Next
    End Sub
End Module

外側のループが1回まわる間に、内側のループは9回すべてまわります。そのため外側が9回、内側がそのたびに9回で、合計81回の処理が行われます。二重ループの回数は「外側の回数 × 内側の回数」になると覚えておきましょう。

注意: 無限ループに気をつけて

Do While や While でカウンタ変数を更新し忘れると、条件が永遠に真のままになり無限ループに陥ります。プログラムが固まったように見えたら、Visual Studio 上部の停止ボタン（□）をクリックするか、Shift + F5 キーで強制終了できます。実行前に「更新は書いたか」を必ず確認する習慣をつけましょう。

重要ポイント

回数が決まっているなら For、決まっていないなら Do While / Do Until、コレクションの全件処理なら For Each。この使い分けを押さえておけば、ほとんどの繰り返し処理は迷わず書けるようになります。

やってみよう 5-1: 入力チェック付き合計プログラムを作ろう

利用者に数値を入力させ、「1から入力された数まで」の合計を求めるプログラムを作りましょう。正しい数値が入力されるまで尋ね直す入力チェックも組み合わせます。

手順

  • 1 Do ... Loop Until を使い、正しい整数が入力されるまで Console.ReadLine で尋ね続ける。
  • 2 入力された数を上限として、For ループで1からその数までを合計する。
  • 3 合計結果を Console.WriteLine で表示する。
  • 4 余裕があれば、合計だけでなく「入力された数までの偶数だけの合計」も同時に求めてみる（Mod を使う）。

解答例

Module Program
    Sub Main()
        Dim input As String
        Dim maxValue As Integer

        ' 正しい正の整数が入力されるまで尋ね続ける
        Do
            Console.Write("いくつまで合計しますか？（1以上の整数）: ")
            input = Console.ReadLine()
        Loop Until Integer.TryParse(input, maxValue) AndAlso maxValue >= 1

        Dim sum As Integer = 0
        For i As Integer = 1 To maxValue
            sum += i
        Next

        Console.WriteLine("1から" & maxValue & "までの合計: " & sum)
    End Sub
End Module

理解度確認クイズ

  • Q1. ループを構成する3つの要素は何ですか？

    回答を表示

    初期値（最初の値の設定）・継続条件（繰り返しを続けるかどうかの判定）・変化（更新）（カウンタ変数を増減させる処理）の3つです。この3つがそろって初めてループは正しく動作します。

  • Q2. Do While（前判定）と Do ... Loop Until（後判定）の、最低実行回数の違いは何ですか？

    回答を表示

    Do While は条件を先に確認するため、条件が最初から偽なら0回も実行されないことがあります。一方 Do ... Loop Until は処理を先に実行してから条件を確認するため、必ず1回以上実行されます。

  • Q3. 配列の要素数を気にせず、全件を1つずつ処理したいときに使う繰り返し文は何ですか？

    回答を表示

    For Each です。For Each item As 型 In 配列名 と書くだけで、要素数を数えなくても先頭から順に全件を処理できます。

  • Q4. For文の中でループを完全に途中終了させる命令と、今回の処理だけをスキップして次の回に進む命令は、それぞれ何ですか？

    回答を表示

    完全に終了するのは Exit For、今回だけスキップして次へ進むのは Continue For です。Doループの場合は Exit Do を使います。
