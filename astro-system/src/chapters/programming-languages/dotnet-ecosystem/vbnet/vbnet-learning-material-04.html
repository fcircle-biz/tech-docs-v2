ホーム VB.NET入門 第4章
第4章 所要時間: 約90分

プログラムに判断させる - 条件分岐

これまでのプログラムは、書いた順番どおりに上から下へ処理が進むだけでした。この章では「もし〜なら〜する」という日常の判断をプログラムで表現する条件分岐を学びます。If 文と Select Case 文を使い分けながら、点数による合否判定や成績判定ができるようになります。

この章で学ぶこと

  • If ... Then ... Else ... End If を使って条件によって処理を切り替えられる
  • ElseIf を使った多分岐を、評価される順序に注意しながら書ける
  • Select Case を使って値による分岐を読みやすく書ける
  • AndAlso / OrElse で複合条件を作り、入れ子（ネスト）の If も書ける

4.1 条件分岐とは

私たちは日常生活で無意識に「もし〜なら〜する」という判断をしています。「もし雨が降っていたら傘を持って出かける」「もし80点以上なら合格」といった具合です。条件分岐とは、このような判断の仕組みをプログラムで表現するものです。第1章で紹介した3つの制御構造（順次・分岐・繰り返し）のうち、2つ目にあたります。

条件分岐がなければ、プログラムはいつも同じ結果しか出せません。条件によって処理を切り替えられるようになると、入力された値に応じて挙動を変える、実用的なプログラムが作れるようになります。まずは「点数が80点以上なら合格、そうでなければ不合格」という単純な判定を、図で確認してみましょう。

flowchart TD A["点数を入力"] --> B{"80点以上か？"} B -->|はい| C["合格と表示"] B -->|いいえ| D["不合格と表示"] C --> E["終了"] D --> E

図の説明: 「80点以上か？」という条件を判定し、結果が「はい（真）」なら合格、「いいえ（偽）」なら不合格の処理に分かれます。分岐後、どちらのルートを通っても最終的には同じ場所（終了）に合流します。

VB.NET でこの「もし〜なら」を表す条件式は、必ず真偽値（Boolean）、つまり True（真）か False（偽）のどちらかになります。第3章で学んだ比較演算子（> >= = など）は、まさにこの真偽値を作り出すための道具でした。

用語: 条件式・分岐先

「点数 >= 80」のように、真偽を判定できる式を条件式と呼びます。条件式の結果（True / False）によってどちらの処理へ進むかが決まり、この分かれ道のことを分岐、それぞれの行き先を分岐先と呼びます。

4.2 If ... Then ... End If

VB.NET で条件分岐を書く基本の形が If ... Then ... End If です。もっとも単純な形は、条件が成り立つときだけ処理を実行するものです。

If文の基本形 Sub Main内に記述 
Dim score As Integer = 85

' 条件が成り立つときだけ中の処理が実行される
If score >= 80 Then
    Console.WriteLine("合格です")
End If

Console.WriteLine("判定を終了しました")

「不合格」の場合の処理も書きたいときは、Else を使って二者択一にします。条件が True なら Else より前、False なら Else より後ろが実行されます。

If ... Else ... End If Sub Main内に記述 
Dim score As Integer = 65

If score >= 80 Then
    Console.WriteLine("合格です")
Else
    ' 条件が成り立たないときはこちらが実行される
    Console.WriteLine("不合格です")
End If
実行結果 
不合格です

なお、処理が1行だけの場合は、End If を省略した1行形式で書くこともできます。

1行形式のIf文 Sub Main内に記述 
Dim x As Integer = 5

' End If を省略した1行形式
If x > 0 Then Console.WriteLine("正の数です")

注意: 1行形式は使いどころを絞る

1行形式は短く書けますが、処理を追加したくなったときに書き換えを忘れがちで、複数条件が絡むと読みにくくなります。本ガイドでは複数行形式（Then の後で改行し End If で閉じる）を基本の書き方として推奨します。

4.3 ElseIf による多分岐

「合格・不合格」の2択ではなく、「90点以上はA、80点以上はB、70点以上はC、それ以外はD」のように3つ以上に分けたいときは ElseIf を使います。上から順に条件を並べ、最後の Else で「どれにも当てはまらない場合」を受け止めます。

成績判定 Sub Main内に記述 
Dim score As Integer = 85

If score >= 90 Then
    Console.WriteLine("評価: A")
ElseIf score >= 80 Then
    Console.WriteLine("評価: B")
ElseIf score >= 70 Then
    Console.WriteLine("評価: C")
Else
    Console.WriteLine("評価: D")
End If
実行結果 
評価: B
flowchart TD A["score = 85"] --> B{"90点以上か？"} B -->|はい| C["評価: A"] B -->|いいえ| D{"80点以上か？"} D -->|はい| E["評価: B"] D -->|いいえ| F{"70点以上か？"} F -->|はい| G["評価: C"] F -->|いいえ| H["評価: D"]

図の説明: 条件は必ず上から順に評価されます。85点の場合、まず「90点以上か？」が「いいえ」と判定されて次の条件に進み、「80点以上か？」が「はい」と判定された時点でそこから下の条件は一切確認されずに「評価: B」が実行されます。

重要ポイント: 最初に一致した分岐だけが実行される

If / ElseIf は上から順に評価され、条件が True になった時点でその処理だけが実行され、残りの ElseIf や Else は確認すらされません（これを「ショートサーキット」と呼びます）。したがって条件を並べる順序がとても重要です。

この順序を間違えると、意図しない結果になります。次の例を見てください。条件の並び順を「小さいほうから」にしてしまった悪い例です。

悪い例: 条件の順序ミス Sub Main内に記述 
Dim score As Integer = 95

' 誤り: 70点以上を先に判定してしまっている
If score >= 70 Then
    Console.WriteLine("評価: C")
ElseIf score >= 80 Then
    Console.WriteLine("評価: B")
ElseIf score >= 90 Then
    Console.WriteLine("評価: A")
End If
' 結果: 95点でも最初の条件(70点以上)に一致し「評価: C」になってしまう

95点は本来「評価: A」になるべきですが、最初の条件 score >= 70 がすでに True になってしまうため、そこで処理が止まり「評価: C」と表示されてしまいます。範囲を絞り込む条件は、必ず狭い範囲（数値が大きいほう）から先に書くのが鉄則です。

4.4 Select Case

1つの値に対して分岐先がたくさんある場合、If ... ElseIf を何度も繰り返すとコードが縦に長くなり読みにくくなります。そのようなときは Select Case を使うと、値による分岐をすっきり書けます。

Select Caseの基本形 Sub Main内に記述 
Dim dayNumber As Integer = 3

Select Case dayNumber
    Case 1
        Console.WriteLine("月曜日")
    Case 2, 3
        ' カンマ区切りで複数の値をまとめて指定できる
        Console.WriteLine("火曜日か水曜日")
    Case 4 To 6
        ' Toで範囲を指定できる
        Console.WriteLine("木曜日から土曜日")
    Case Else
        Console.WriteLine("日曜日")
End Select
実行結果 
火曜日か水曜日

比較演算子を使いたい場合は Case Is を使います。先ほどの成績判定を Select Case で書き直すと次のようになります。

Case Isで成績判定 Sub Main内に記述 
Dim score As Integer = 85

Select Case score
    Case Is >= 90
        Console.WriteLine("評価: A")
    Case Is >= 80
        Console.WriteLine("評価: B")
    Case Is >= 70
        Console.WriteLine("評価: C")
    Case Else
        Console.WriteLine("評価: D")
End Select

Select Case も If と同じく上から順に評価され、最初に一致した Case だけが実行されます（他言語の switch 文と違い、次の Case に処理が流れ落ちる心配はありません）。If と Select Case のどちらを使うべきか、目安を表にまとめます。

状況 おすすめ 理由
1つの変数の値で3パターン以上に分ける Select Case 値の一覧が縦に並び、条件と処理の対応が読み取りやすい
複数の異なる変数を組み合わせて判定する If ... ElseIf Select Case は1つの値を軸にする分岐しか書けない
条件がTrue/False1つだけの単純な判定 If ... Else Select Case にするとかえって大げさになる

4.5 条件を組み合わせる／入れ子

「年齢が18歳以上、かつ 会員である」のように、複数の条件をまとめて1つの判定にしたい場合があります。第3章で学んだ論理演算子のうち AndAlso（かつ）と OrElse（または）を条件式の中で使います。

複合条件 Sub Main内に記述 
Dim age As Integer = 20
Dim isMember As Boolean = True

' AndAlso: 両方ともTrueのときだけ全体がTrue
If age >= 18 AndAlso isMember Then
    Console.WriteLine("会員割引を適用します")
Else
    Console.WriteLine("割引の対象外です")
End If

用語: AndAlsoとOrElseを使う理由

VB.NET には And / Or という演算子もありますが、これらは左右両方の条件式を必ず評価します。一方 AndAlso / OrElse は、左側だけで結果が確定すれば右側を評価しません（短絡評価）。無駄な評価を避けられ、動作も直感的なため、通常はこちらを使います。

条件分岐の中に、さらに別の条件分岐を書くこともできます。これを入れ子（ネスト）と呼びます。たとえば「合格かどうか」を判定したあと、合格者の中でさらに「優秀者かどうか」を判定する場合です。

Ifの入れ子 Sub Main内に記述 
Dim score As Integer = 95

If score >= 80 Then
    Console.WriteLine("合格です")

    ' 合格者の中でだけ、さらに条件を判定する（入れ子）
    If score >= 90 Then
        Console.WriteLine("優秀者として表彰されます")
    End If
Else
    Console.WriteLine("不合格です")
End If

注意: 入れ子を深くしすぎない

入れ子は便利ですが、3段・4段と深くなるほどコードが右へ右へとずれていき、どの End If がどの If に対応するのか読み取りづらくなります。AndAlso で条件をまとめられないかをまず検討し、それでも入れ子が必要な場合は2段まで、を1つの目安にしましょう。

最後に、単純な二者択一の値を1行で決めたいときに使える If() 演算子（他言語の三項演算子に近いもの）を紹介します。If(条件式, Trueのときの値, Falseのときの値) という形で書きます。

If()演算子 Sub Main内に記述 
Dim score As Integer = 85

' If()演算子: 条件式, Trueのときの値, Falseのときの値
Dim result As String = If(score >= 80, "合格", "不合格")
Console.WriteLine(result)

変数に代入する値を1行で切り替えたいだけのときに便利ですが、条件や処理が複雑になる場合は素直に If ... Else ... End If を使うほうが読みやすいコードになります。

やってみよう 4-1: 数値判定とBMI判定プログラムを作ろう

条件分岐を実際に手を動かして体験してみましょう。2つのプログラムに挑戦します。

手順

  • 1 Console.ReadLine と Integer.Parse を使い、キーボードから整数を入力してもらう。
  • 2 入力された数値が「正の数」「負の数」「ゼロ」のどれかを If ... ElseIf ... Else で判定し表示する。
  • 3 続けて体重(kg)と身長(m)を入力してもらい、BMI（体重 ÷ 身長 ÷ 身長）を計算する。
  • 4 BMIの値を「18.5未満: 低体重」「18.5〜25未満: 標準」「25以上: 肥満」の3段階で Select Case または If ... ElseIf で判定して表示する。条件の順序に注意すること。

解答例

Module Program
    Sub Main()
        Console.Write("整数を入力してください: ")
        Dim num As Integer = Integer.Parse(Console.ReadLine())

        If num > 0 Then
            Console.WriteLine("正の数です")
        ElseIf num < 0 Then
            Console.WriteLine("負の数です")
        Else
            Console.WriteLine("ゼロです")
        End If

        Console.Write("体重(kg)を入力してください: ")
        Dim weight As Double = Double.Parse(Console.ReadLine())
        Console.Write("身長(m)を入力してください: ")
        Dim height As Double = Double.Parse(Console.ReadLine())
        Dim bmi As Double = weight / (height * height)

        ' 範囲が狭いほう(数値が大きいほう)から先に判定する
        If bmi >= 25 Then
            Console.WriteLine("BMI判定: 肥満")
        ElseIf bmi >= 18.5 Then
            Console.WriteLine("BMI判定: 標準")
        Else
            Console.WriteLine("BMI判定: 低体重")
        End If
    End Sub
End Module

理解度確認クイズ

  • Q1. 次のコードを score = 95 で実行すると、何が表示されますか。理由も説明してください。
    If score >= 70 Then Console.WriteLine("C") ElseIf score >= 90 Then Console.WriteLine("A") End If

    回答を表示

    「C」が表示されます。If / ElseIf は上から順に評価され、最初に True になった分岐だけが実行されるためです。95点は最初の条件 score >= 70 ですでに True になるので、そこで処理が終わり「A」の条件は確認されません。範囲を絞る条件は数値が大きいほうから先に書く必要があります。

  • Q2. Select Case で「Case 4 To 6」や「Case 2, 3」のように書けるのは、それぞれどのような指定方法ですか。

    回答を表示

    Case 4 To 6 は4から6までの範囲を、Case 2, 3 はカンマ区切りで複数の値をまとめて指定する書き方です。どちらもいずれかに一致すればその Case の処理が実行されます。

  • Q3. 「年齢が18歳以上、かつ会員である」場合だけ割引したいとき、条件式はどのように書きますか。

    回答を表示

    If age >= 18 AndAlso isMember Then のように書きます。AndAlso は左右の条件式が両方とも True のときだけ全体が True になります。

  • Q4. VB.NETのコードの中で「=」という記号は、条件式の中と代入文の中でそれぞれどんな意味になりますか。

    回答を表示

    Dim x As Integer = 5 のような代入文では「右辺の値を左辺の変数に代入する」意味になり、If x = 5 Then のような条件式では「値が等しいかどうかを比較する」意味になります。同じ記号でも文脈によって役割が変わる点に注意しましょう。
