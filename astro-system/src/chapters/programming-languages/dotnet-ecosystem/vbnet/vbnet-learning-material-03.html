ホーム VB.NET入門 第3章

計算と文字列を扱う - 演算子と文字列操作

第2章で変数とデータ型を学びました。この章では、その変数を使って実際に「計算する」「文字列を組み立てる」方法を学びます。四則演算や比較・論理演算子の使い方、文字列を連結・加工する代表的なメソッド、そして数値を見やすく整形する方法まで、日常の業務プログラムでよく使う操作をひととおり身につけます。

この章で学ぶこと

  • 算術演算子・比較演算子・論理演算子の種類と使い分けを説明できる
  • 実数除算 / と整数除算 \ の違いを理解し、正しく使い分けられる
  • 文字列の連結・検索・置換など、代表的な文字列操作ができる
  • String.Format や補間文字列を使って、数値や文字列を見やすい形式で表示できる

3.1 算術演算子

VB.NET には、数値を計算するための算術演算子が7種類あります。足し算・引き算・掛け算はほかの言語と同じですが、割り算だけは2種類ある点がVB.NETの特徴です。まずは一覧で確認しましょう。

演算子 意味 例 結果
+ 加算（足し算） 3 + 2 5
- 減算（引き算） 3 - 2 1
* 乗算（掛け算） 3 * 2 6
/ 実数除算（小数まで求める） 7 / 2 3.5
\ 整数除算（商だけを求め、小数は切り捨て） 7 \ 2 3
Mod 剰余（割り算のあまりを求める） 7 Mod 2 1
^ べき乗（累乗） 2 ^ 3 8

/ と \ の違い

この2つの割り算は、初学者がもっとも混同しやすいポイントです。/（実数除算）は割り切れない場合も小数まできちんと計算しますが、\（整数除算）は「何回ぴったり入るか」という商だけを求め、あまりは切り捨てます。同じ 7 と 2 でも結果がまったく違うことを、実際に動かして確認しましょう。

Program.vb 完全なプログラム 
Module Program
    Sub Main()
        ' 実数除算：小数まで計算する
        Console.WriteLine(7 / 2)

        ' 整数除算：商だけを求める（あまりは切り捨て）
        Console.WriteLine(7 \ 2)

        ' 剰余：あまりだけを求める
        Console.WriteLine(7 Mod 2)
    End Sub
End Module
実行結果 
3.5
3
1

注意: 整数同士の割り算と0での割り算

Integer 同士を / で割っても、VB.NETでは自動的に Double（実数）に変換されて計算されるため、小数の結果が得られます（例: 7 / 2 は 3.5）。また、Integer を 0 で割ると実行時エラー（例外）になりますが、Double を 0 で割るとエラーにはならず「無限大」を表す特別な値になります。例外については第11章で詳しく学びます。

演算子の優先順位

1つの式に複数の演算子が含まれる場合、VB.NETは決まった順番で計算します。算数の「掛け算・割り算は足し算・引き算より先」というルールと似ていますが、VB.NETには \（整数除算）や Mod（剰余）も加わるため、順番を図で確認しておきましょう。

flowchart TD A["1. べき乗（累乗）"] --> B["2. 符号（プラス・マイナス）"] B --> C["3. かけ算・実数のわり算"] C --> D["4. 整数のわり算"] D --> E["5. あまり（Mod）"] E --> F["6. たし算・ひき算"] F --> G["7. 文字列連結"] G --> H["8. 比較演算子"] H --> I["9. 論理演算子"]

図の説明: 上にあるものほど先に計算されます。べき乗がもっとも優先度が高く、論理演算子がもっとも低くなります。順番に迷ったときや、意図をはっきりさせたいときは、丸括弧 () で囲んで計算順序を明示しましょう。丸括弧の中は常に最優先で計算されます。

たとえば 2 + 3 * 4 は「掛け算が先」なので 14 になりますが、(2 + 3) * 4 と丸括弧を付ければ 20 になります。優先順位を暗記しきれなくても、丸括弧を使えば常に自分の意図どおりの順番で計算させることができます。迷ったら丸括弧を使う、と覚えておきましょう。

複合代入演算子

「変数に今の値を使って計算し、その結果をまた同じ変数に戻す」という処理はとてもよく使うため、VB.NETには短く書ける複合代入演算子が用意されています。

複合代入 意味 同じ意味の書き方
x += 1 xに1を足して代入 x = x + 1
x -= 1 xから1を引いて代入 x = x - 1
x *= 2 xを2倍して代入 x = x * 2

3.2 比較演算子

比較演算子は、2つの値を比べて「正しいか（True）・正しくないか（False）」を判定するための演算子です。判定結果は必ず Boolean 型（第2章参照）の値になります。第4章の条件分岐では、この比較演算子が判定の中心的な役割を果たします。

演算子 意味 例 結果
= 等しい 3 = 3 True
<> 等しくない 3 <> 2 True
< より小さい 3 < 5 True
> より大きい 3 > 5 False
<= 以下 3 <= 3 True
>= 以上 3 >= 5 False

用語: 同じ「=」でも意味が違う

VB.NETでは 代入（値を入れる） と 比較（等しいか調べる） の両方に同じ = という記号を使います。Dim x = 5 は「xに5を代入する」ですが、If x = 5 Then は「xが5と等しいか比較する」という意味です。どちらの意味になるかは書く場所（文の形）で決まるので、慣れるまでは意識して読み分けましょう。C#など他の言語では代入に =、比較に == と記号を使い分けることが多く、VB.NETの特徴的な点です。

比較の結果を変数に入れて確認してみましょう。Boolean 型の変数には、比較演算子の結果をそのまま代入できます。

Program.vb Sub Main内に記述 
Dim score As Integer = 75

' 比較演算子の結果はBoolean（True/False）
Dim isPassed As Boolean = score >= 60

Console.WriteLine(isPassed)          ' True
Console.WriteLine(score <> 100)      ' True（100ではないので）

3.3 論理演算子

論理演算子は、複数の Boolean 値（True/False）を組み合わせて、1つの判定結果を作るための演算子です。「AかつB」「AまたはB」といった複合条件を作るときに使います。

演算子 意味 例
And 両方True（かつ）のときTrue True And False → False
Or どちらかTrue（または）のときTrue True Or False → True
Not 結果を反転させる Not True → False
Xor どちらか一方だけTrueのときTrue True Xor False → True

真理値表で確認する

And と Or の組み合わせパターンをすべて表にまとめました。よく見比べておきましょう。

A B A And B A Or B
True True True True
True False False True
False True False True
False False False False

短絡評価する AndAlso・OrElse

VB.NETには And／Or のほかに、AndAlso／OrElse という似た演算子があります。違いは「両方の条件を必ず評価するかどうか」です。AndAlso は左側がFalseだった時点で右側を評価せずに結果を確定させます（これを短絡評価と呼びます）。OrElse も同様に、左側がTrueだった時点で右側を評価しません。

Program.vb Sub Main内に記述 
Dim age As Integer = 25

' 20歳以上 かつ 30歳未満 のとき True
Dim isTwenties As Boolean = age >= 20 AndAlso age < 30

Console.WriteLine(isTwenties)   ' True

重要ポイント: 実務では AndAlso・OrElse が基本

実務のVB.NETコードでは、And／Or よりも AndAlso／OrElse を使うのが基本です。短絡評価は無駄な処理を省いて速いだけでなく、「左側の条件がFalseなら右側は評価しない」という性質を使って、obj IsNot Nothing AndAlso obj.Name = "A" のように「オブジェクトが存在するときだけ中身を調べる」という安全な書き方ができます。特別な理由がない限り、AndAlso／OrElse を使うようにしましょう。

3.4 文字列の操作

業務プログラムでは、数値の計算と同じくらい文字列（String）の操作が重要です。氏名を組み立てたり、住所から一部を取り出したり、CSVデータを分割したりと、文字列を扱う場面は数多くあります。まずは文字列同士をつなげる「連結」から見ていきましょう。

文字列の連結演算子 &

VB.NETで文字列同士をつなげるには、&（アンパサンド）演算子を使います。+ でも文字列同士なら連結できますが、+ は本来「足し算」の演算子であり、数値と文字列が混ざったときに「計算」と「連結」のどちらの意図なのか分かりにくくなります。& は常に「文字列として連結する」という意味になるため、意図がはっきりして安全です。

Program.vb Sub Main内に記述 
Dim sei As String = "山田"
Dim mei As String = "太郎"

' & で文字列を連結する（前後に半角スペースを入れる）
Dim fullName As String = sei & " " & mei
Console.WriteLine(fullName)     ' 山田 太郎

' "10" & 5 は文字列連結なので "105" になる
Console.WriteLine("10" & 5)     ' 105
' 10 + 5 は数値の足し算なので 15 になる
Console.WriteLine(10 + 5)       ' 15

注意: & の前後には半角スペースを入れる

& の直後に数値をスペースなしで書く（例: "合計:" &5）と、&5 の部分が数値の型を表す特殊な記号として解釈され、意図と違う動作やエラーの原因になることがあります。& の前後には必ず半角スペースを入れるクセをつけましょう。（例: "合計:" & 5）

代表的な文字列メソッド

String 型の変数には、文字列を調べたり加工したりするための便利な機能（メソッド）が最初から備わっています。よく使うものを一覧にしました。

メソッド／プロパティ 役割 例
.Length 文字数を取得 "VBNET".Length → 5
.Substring(開始, 長さ) 指定位置から一部を取り出す "VBNET".Substring(0, 2) → "VB"
.IndexOf(文字) 文字が最初に現れる位置を調べる "VBNET".IndexOf("N") → 2
.Replace(旧, 新) 文字を置き換える "VB6".Replace("6", ".NET") → "VB.NET"
.Trim() 前後の空白を取り除く " VB ".Trim() → "VB"
.ToUpper() / .ToLower() 大文字／小文字に変換 "vb".ToUpper() → "VB"
.Contains(文字) 指定した文字を含むか調べる "VBNET".Contains("NET") → True
.StartsWith(文字) 指定した文字で始まるか調べる "VBNET".StartsWith("VB") → True
.Split(区切り文字) 区切り文字で分割し配列にする "a,b,c".Split(","c) → ["a","b","c"]

用語: 文字列は0から数える（インデックス）

文字列の中の位置を指すとき、VB.NETでは先頭の文字を0番目として数えます。これをインデックスと呼びます。たとえば "VBNET" なら、Vが0番目、Bが1番目、Nが2番目です。だから "VBNET".Substring(0, 2) は「0番目から2文字分」を意味し、"VB" が得られます。この「0から数える」考え方は配列（第6章）でも共通するので、ここでしっかり慣れておきましょう。

Program.vb Sub Main内に記述 
Dim message As String = "  Hello, VB.NET  "

' 前後の空白を除去してから大文字に変換
Dim cleaned As String = message.Trim().ToUpper()
Console.WriteLine(cleaned)                  ' HELLO, VB.NET

' カンマ区切りの文字列を配列に分割する
Dim csv As String = "山田,佐藤,鈴木"
Dim names As String() = csv.Split(","c)
Console.WriteLine(names(1))                 ' 佐藤（0番目=山田, 1番目=佐藤）

3.5 書式を整える

画面に数値や文字列を表示するとき、そのまま並べるだけでなく「金額はカンマ区切りで」「小数は2桁まで」のように見やすい形式に整えることがよくあります。VB.NETには、そのための方法がいくつか用意されています。

補間文字列（String Interpolation）

もっとも読みやすいのは補間文字列です。文字列の前に $ を付け、変数を { }（波かっこ）で囲むと、その部分が変数の値に置き換わります。& で何個もつなげるより、文章の形がそのまま見えるため直感的です。

Program.vb Sub Main内に記述 
Dim name As String = "田中"
Dim age As Integer = 28

' $ を付けて { } に変数を埋め込む（補間文字列）
Console.WriteLine($"こんにちは、{name}さん（{age}歳）")
' 出力: こんにちは、田中さん（28歳）

数値の書式指定

金額や数量を表示するときは、ToString() に書式指定文字列を渡すことで、桁区切りや通貨記号を付けた表示に変換できます。String.Format を使う方法もあり、複数の値を一度に整形したいときに便利です。

書式指定 意味 例
"C" 通貨（円マークとカンマ区切り） 1000.ToString("C") → ￥1,000
"N0" 桁区切り（小数なし） 1234567.ToString("N0") → 1,234,567
"0.00" 小数点以下を2桁でそろえる 3.5.ToString("0.00") → 3.50
Program.vb Sub Main内に記述 
Dim price As Integer = 1980
Dim total As Integer = 1234567

' 書式指定文字列でカンマ区切り・通貨表示にする
Console.WriteLine(price.ToString("C"))     ' ￥1,980
Console.WriteLine(total.ToString("N0"))    ' 1,234,567

' String.Format で複数の値をまとめて整形
Console.WriteLine(String.Format("合計金額: {0} 円", total.ToString("N0")))
' 出力: 合計金額: 1,234,567 円

補間文字列の { } の中では、変数のあとに :書式 を続けて書くと、書式指定をそのまま適用できます。$"{total:N0} 円" と書けば、total.ToString("N0") と組み合わせるより短く、桁区切りされた文字列を埋め込めます。

改行を入れる

1つの文字列の中で改行したいときは、vbCrLf（VB.NET独自のキーワード）または Environment.NewLine（.NET共通の書き方）を使います。どちらも「改行」を表す特別な文字列です。

Program.vb Sub Main内に記述 
' vbCrLf で改行を挟んで1つの文字列にする
Dim report As String = "商品名: ノート" & vbCrLf & "価格: ￥150"
Console.WriteLine(report)

やってみよう 3-1: 消費税込み価格を計算しよう

単価と個数をキーボードから入力し、小計・消費税（10%）・合計金額を桁区切りで表示するプログラムを作りましょう。第2章で学んだ入力と型変換、この章で学んだ計算と書式指定を組み合わせます。

手順

  • 1 Console.ReadLine で単価と個数を入力し、Integer.Parse で数値に変換する。
  • 2 小計 = 単価 * 個数 を計算する。
  • 3 消費税 = 小計 * 0.1 を計算し、CInt で整数に変換する。
  • 4 合計 = 小計 + 消費税 を計算し、ToString("N0") で桁区切り表示する。

解答例

Module Program
    Sub Main()
        Console.Write("単価を入力してください: ")
        Dim price As Integer = Integer.Parse(Console.ReadLine())
        Console.Write("個数を入力してください: ")
        Dim qty As Integer = Integer.Parse(Console.ReadLine())

        Dim subtotal As Integer = price * qty
        Dim tax As Integer = CInt(subtotal * 0.1)
        Dim total As Integer = subtotal + tax

        Console.WriteLine($"小計: {subtotal:N0} 円")
        Console.WriteLine($"消費税: {tax:N0} 円")
        Console.WriteLine($"合計: {total:N0} 円")
    End Sub
End Module

理解度確認クイズ

  • Q1. 7 \ 2 の結果はいくつですか。また 7 / 2 の結果と何が違いますか。

    回答を表示

    7 \ 2 は整数除算なので 3 になります（商だけを求め、あまりは切り捨てます）。一方 7 / 2 は実数除算なので、小数まで計算して 3.5 になります。

  • Q2. VB.NETで文字列を連結する演算子は何ですか。なぜ + ではなくそちらを使うことが推奨されますか。

    回答を表示

    &（アンパサンド）です。+ は本来「足し算」の演算子であり、数値と文字列が混ざったときに計算なのか連結なのか意図があいまいになります。& は常に「文字列として連結する」という意味になるため、意図がはっきりして安全です。

  • Q3. AndAlso と And の違いを説明してください。実務ではどちらを使うのが基本ですか。

    回答を表示

    And は左右両方の条件を必ず評価しますが、AndAlso は左側がFalseだった時点で右側を評価しません（短絡評価）。実務では、無駄な評価を省け、obj IsNot Nothing AndAlso obj.Name = "A" のような安全な書き方ができる AndAlso（と OrElse）を使うのが基本です。

  • Q4. 整数を「1,234,567」のように桁区切りで表示するには、ToString() にどのような書式指定文字列を渡しますか。

    回答を表示

    "N0" です。1234567.ToString("N0") のように使うと 1,234,567 という桁区切りの文字列が得られます。通貨記号も付けたい場合は "C" を使います。
