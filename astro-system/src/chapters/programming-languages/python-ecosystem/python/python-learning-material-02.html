ホーム Python 第2章
第2章 所要時間: 約90分

開発環境を準備しよう

この章では、実際に手を動かしてコードを書くための環境を用意します。Python 本体のインストール、コードを書くエディタ（VS Code）の導入、そしてコンピュータに指示を出す「ターミナル」の基本操作を身につけます。ここまでの準備が整えば、次章からいよいよプログラムを書き始められます。

この章で学ぶこと

  • 「Python本体」「エディタ」「ターミナル」がそれぞれ何をする道具かを説明できる
  • 自分のパソコンに Python をインストールし、バージョンを確認できる
  • VS Code に Python 拡張機能を入れ、作業用フォルダを開ける
  • ターミナルの基本コマンド（移動・一覧表示）を使え、PATH の問題に気づける

2.1 開発に必要な道具

Python でプログラムを書いて動かすには、役割の異なる3つの道具が必要です。それぞれが何をするのかを最初に整理しておくと、この先インストール作業でつまずいたときに「今どこがうまくいっていないのか」を切り分けやすくなります。

エディタ（VS Code）

Python のコードを書き、ファイル（.py）として保存するためのソフト。文章を書くメモ帳の高機能版です。

ターミナル

文字でコンピュータに命令を出す画面。「このファイルを Python で実行して」と指示を出す窓口です。

Python本体

第1章で学んだインタプリタそのもの。ターミナルから呼び出されて、コードを実際に実行します。

3つの道具は、下の図のような順番で連携します。エディタはコードを書くだけで実行はできません。実行を担当するのはあくまで Python本体で、その橋渡しをターミナルが行います。

flowchart LR A["エディタ（VS Code）
コードを書いて保存"] --> B["ファイル
hello.py"] B --> C["ターミナル
実行コマンドを入力"] C --> D["Python本体
インタプリタ"] D --> E["実行結果を表示"]

VS Code の中でも完結できます

VS Code にはターミナルが内蔵されているため、実際にはエディタとターミナルを1つの画面で行き来しながら作業します。「役割が別物」という点だけ押さえておけば十分です。

2.2 Python のインストール

Python 公式サイトから、Windows・macOS 共通のインストーラをダウンロードして実行します。本ガイドは Python 3.12 以降を前提とするので、公式サイトのトップにある最新の Python 3 系をダウンロードしてください。

Windows

ダウンロードしたインストーラを起動したら、最初の画面で「Add python.exe to PATH」に必ずチェックを入れてから「Install Now」を選びます。これを忘れると、ターミナルから python が見つからないエラーになります。

macOS

ダウンロードした .pkg ファイルを開き、案内に従ってインストールを進めます。macOS には別バージョンの Python があらかじめ入っていることがありますが、新しくインストールしたものを使うので気にする必要はありません。

インストールが終わったら、ターミナルを開いて正しく入ったか確認します。Windows と macOS/Linux では実行コマンドの名前が少し異なります。

ターミナル（Windows） 
python --version
py --version

Windows では、まず python --version を試し、うまくいかない場合は py --version も試してください（どちらか一方でバージョンが表示されれば大丈夫です）。

ターミナル（macOS / Linux） 
python3 --version
実行結果 
Python 3.12.4

このように「Python 3.12.4」のようなバージョン番号が表示されれば成功です。本ガイドでは以降、python（macOS は python3）と表記します。実行するときは自分の OS に合わせて読み替えてください。

2.3 VS Code と Python 拡張機能の導入

VS Code 公式サイトからインストーラをダウンロードし、案内に従ってインストールします。VS Code 自体はどんな言語でも使える汎用エディタなので、Python 用の機能を追加する必要があります。

  1. VS Code を起動し、左側の縦アイコン一覧から「拡張機能」（四角が4つ並んだアイコン）を開く
  2. 検索欄に「Python」と入力し、Microsoft 製の「Python」拡張機能をインストールする
  3. ホームフォルダに python-study という作業用フォルダを作成し、VS Code の「フォルダーを開く」でそのフォルダを開く
  4. 画面右下（または左下）に表示される Python のバージョン表示をクリックし、先ほどインストールした Python が選ばれているか確認する（インタプリタの選択）

python-study フォルダは、この先の章で作るプログラムをすべて保存する場所です。章ごとに ch03・ch04 のようなサブフォルダを作り、その中にファイルを置いていきます（例: python-study/ch03/hello.py）。

「インタプリタの選択」って何？

パソコンに Python が複数入っていることがあり、VS Code は「どの Python を使ってコードを実行するか」を選べるようになっています。2.2 でインストールしたものが選ばれていれば問題ありません。表示がおかしいときは、コマンドパレット（Ctrl+Shift+P / Cmd+Shift+P）で「Python: Select Interpreter」を検索すると選び直せます。

2.4 ターミナルの基本

ターミナルは「今どこのフォルダにいるか」を意識しながら操作します。よく使う3つのコマンドを覚えておきましょう。

やりたいこと Windows macOS / Linux
今いる場所を表示する pwd（PowerShell）／cd（コマンドプロンプト、引数なし） pwd
フォルダを移動する cd python-study cd python-study
中身の一覧を表示する dir ls

よくあるつまずきを2つ紹介します。あらかじめ知っておくと、実際に遭遇したときに落ち着いて対処できます。

「python は認識されていません」と出る（PATH の問題）

Windows で「Add python.exe to PATH」にチェックを入れずにインストールした場合に起きます。PATH とは「コマンド名だけでプログラムを探せる場所のリスト」のことで、ここに Python の場所が登録されていないと、ターミナルが python を見つけられません。インストーラを再実行し、チェックを入れ直して修復インストールしてください。

Windows で python と打つと Microsoft Store が開く

Windows の設定で、未インストールのアプリ名を打つとストアへ誘導される機能が働いています。py --version を代わりに試すか、設定アプリの「アプリ実行エイリアス」で python.exe の項目をオフにしてから、公式インストーラで入れ直した Python を使ってください。

やってみよう 2-1: バージョン確認と作業フォルダ作成

実際に環境を整えて、この先の章で使う土台を作ります。

手順

  1. 1 ターミナルを開き、python --version（macOS は python3 --version）でバージョンが表示されることを確認する。
  2. 2 ホームフォルダに python-study フォルダを作成する（エクスプローラー／Finder で作ってもよい）。
  3. 3 VS Code で python-study フォルダを開き、Python 拡張機能が有効になっていること（右下のバージョン表示）を確認する。

ここまで確認できれば、次章からすぐにコードを書き始められます。うまくいかない場合は 2.4 のトラブル対処を見直してみましょう。

理解度確認クイズ

  1. Q1. エディタ・ターミナル・Python本体の役割の違いを説明してください。

    回答を表示

    エディタ（VS Code）はコードを書いて保存する道具、ターミナルはコンピュータに命令を出す窓口、Python本体（インタプリタ）はコードを実際に実行するソフトウェアです。エディタで書いたファイルを、ターミナル経由でPython本体に渡して実行します。

  2. Q2. Windows で Python をインストールするときに必ずチェックすべき項目は何ですか？

    回答を表示

    「Add python.exe to PATH」です。これにチェックを入れないと、ターミナルが python コマンドの場所を見つけられず、「python は認識されていません」というエラーになります。

  3. Q3. macOS でフォルダの中身を一覧表示するコマンドは何ですか？

    回答を表示

    ls です。Windows では dir を使います。現在地を確認する pwd（Windows のコマンドプロンプトでは cd のみ入力）や、移動する cd フォルダ名 とあわせて覚えておきましょう。
