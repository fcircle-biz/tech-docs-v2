処理をまとめよう（関数）

ここまでの章では、同じような処理を何度も書き写すことがありました。この章では、処理に名前を付けてひとまとめにする関数を学びます。関数を使うと、プログラムが読みやすくなり、修正も1か所で済むようになります。print() や len() のようにこれまで使ってきた関数を、今度は自分の手で作ってみましょう。

この章で学ぶこと

  • def を使って自分だけの関数を定義し、呼び出せる
  • return で結果を関数の外へ持ち帰る仕組みを理解する
  • デフォルト引数・キーワード引数を使って呼び出し方を柔軟にできる
  • ローカル変数とグローバル変数の違い（スコープ）を説明できる

10.1 関数とは

実は、ここまでの章ですでに関数を何度も使っています。print()・len()・sum()・int() はすべて Python が最初から用意している組み込み関数です。「名前」で呼び出すと「決まった処理」を実行し、必要に応じて「結果」を返してくれる部品、それが関数です。

支出記録の合計を求める処理のように、同じ計算はプログラムのあちこちで必要になります。同じ処理をコピー＆ペーストで増やしていくと、計算方法を1つ直したいときに、あちこちを修正しなければなりません。処理を関数として1か所にまとめておけば、直すのは関数の中身だけで済みます。

同じコードを書かない

1度定義すれば、何度でも呼び出して使い回せます。

読みやすくなる

処理に名前が付くので「何をしているか」が一目で分かります。

修正が1か所で済む

処理を直したいとき、関数の中身を直すだけで全体に反映されます。

用語: 引数と戻り値

関数に渡す値を引数（ひきすう）、関数が返す値を戻り値（もどりち）と呼びます。len("abc") では "abc" が引数、返ってくる 3 が戻り値です。

10.2 def で関数を定義する

自分で関数を作るには def（define＝定義するの略）を使います。if や for と同じように、行末にコロン : を書き、処理内容はインデントして書きます。

greet.py 
# あいさつを表示する関数を定義する
def greet(name):
    print(f"こんにちは、{name}さん！")

# 定義した関数を呼び出す（何度でも使える）
greet("田中")
greet("鈴木")
実行結果 
こんにちは、田中さん！
こんにちは、鈴木さん！

name の部分を引数（パラメータ）と呼びます。呼び出すときに渡した値（"田中" や "鈴木"）が name に入り、関数の中で使えます。呼び出す順番どおりに値が渡されるので、これを位置引数と呼びます。関数は必ず先に定義してから呼び出す必要がある点に注意しましょう。

flowchart LR A["呼び出し側
greet（田中）"] -->|引数を渡す| B["関数 greet
name に田中が入る"] B -->|print で表示| C["こんにちは、田中さん！"]

引数は複数持たせることもできます。カンマ , で区切って並べます。

show_price.py 
# 商品名と金額を受け取って表示する関数
def show_price(item, price):
    print(f"{item}: {price:,}円")

show_price("ノート", 150)
show_price("ボールペン", 120)

10.3 戻り値 return

10.2 の greet() は「表示するだけ」の関数でした。しかし多くの場面では、関数の中で計算した結果を呼び出し元に持ち帰りたいことがあります。そのために使うのが return です。

tax.py 
# 税込価格を計算して返す関数（学習用に簡略化した計算例）
def calc_tax_included(price):
    return int(price * 1.1)  # int() は小数点以下を切り捨てる

# 戻り値を変数で受け取る
result = calc_tax_included(1000)
print(f"税込価格: {result}円")
実行結果 
税込価格: 1100円

補足: この税込計算は学習用の簡略版です

int() は四捨五入ではなく、小数点以下を切り捨てます（int(109.9) は 109）。ここでは関数の書き方に集中するため、計算を簡略化しています。実際の業務で金額を扱うときは、端数を切り捨てるのか四捨五入するのかといったルールを先に決め、必要に応じて標準ライブラリの decimal モジュールで正確に計算します（第5章 5.2 の round() の注意もあわせて確認しましょう）。

print() は画面に文字を表示するだけで、その結果をあとで使うことはできません。一方 return は値を呼び出し元に渡すので、result のように変数へ代入したり、別の計算に使ったりできます。return が実行されると、その時点で関数の処理は終了します。

項目 print() return
すること 画面に文字を表示する 呼び出し元に値を渡す
結果の再利用 できない（表示して終わり） 変数に受け取って再利用できる
関数の実行 続けて次の行を実行する その時点で関数を終了する

return にはカンマ区切りで複数の値を並べることもでき、呼び出し側はタプルのアンパック代入（第8章）で受け取れます。

min_max.py 
# 最小値と最大値を同時に返す関数
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([80, 45, 92, 60])
print(f"最小: {low}, 最大: {high}")

補足: return を省略すると

return を書かなかった関数は、自動的に特別な値 None（「値が無い」を表す）を返します。greet() の戻り値を print() すると None と表示されるのはこのためです。

10.4 デフォルト引数とキーワード引数

引数にあらかじめ既定値を設定しておくと、呼び出すときにその引数を省略できます。これをデフォルト引数と呼びます。

discount.py 
# rate に既定値0.1（10％引き）を設定する
def apply_discount(price, rate=0.1):
    return int(price * (1 - rate))  # 小数点以下は切り捨て

print(apply_discount(1000))        # rate 省略 → 10％引き
print(apply_discount(1000, 0.2))   # rate を指定 → 20％引き

呼び出すとき、引数名を指定して値を渡す方法をキーワード引数と呼びます。引数が多い関数でも「どの値が何を表すか」が分かりやすくなり、渡す順番を入れ替えることもできます。

record.py 
# 支出記録を1件分表示する関数（memoは省略可）
def show_record(date, category, amount, memo=""):
    print(f"{date} [{category}] {amount:,}円 {memo}")

# キーワード引数なら順番を気にせず渡せる
show_record(amount=850, category="食費", date="2026-04-01", memo="昼食")

注意: デフォルト引数は後ろに置く

既定値のある引数は、既定値のない引数よりあとに並べる必要があります。def f(a=1, b): のように既定値のある引数を先に書くと SyntaxError になります。

10.5 変数の見える範囲（スコープ）とdocstring

関数の中で作った変数は、関数の外からは見えません。この「変数が有効な範囲」をスコープと呼びます。関数の中だけで使える変数をローカル変数、関数の外（プログラム全体）で使える変数をグローバル変数と言います。

scope.py 
budget = 5000  # グローバル変数

def spend(amount):
    remaining = budget - amount  # remaining はローカル変数
    print(f"残り予算: {remaining}円")

spend(1200)
print(remaining)  # ここでは見えないのでエラーになる
実行結果 
残り予算: 3800円
Traceback (most recent call last):
  File "scope.py", line 8, in <module>
    print(remaining)  # ここでは見えないのでエラーになる
          ^^^^^^^^^
NameError: name 'remaining' is not defined

budget のようなグローバル変数は関数の中から読み取ることはできますが、関数の中で budget = ... と書くと、それは新しいローカル変数の作成になり、外側の budget は変わりません（書き換えたい場合は global 文が必要ですが、初心者のうちは関数の引数と戻り値でやり取りする書き方をおすすめします）。

最後に、関数の説明を書くdocstring（ドックストリング）を紹介します。def の直後に文字列（"""..."""）を書くと、その関数が何をするかの説明になります。他の人（未来の自分も含む）がコードを読むときの助けになります。

docstring.py 
def calc_total(records):
    """支出記録のリストから金額の合計を計算して返す"""
    total = 0
    for record in records:
        total += record["amount"]
    return total

重要ポイント

関数は「入力（引数）を受け取り、処理をして、出力（戻り値）を返す部品」です。処理のまとまりを関数に分けておくほど、プログラムは読みやすく、直しやすくなります。次の第11章では、この関数の中でエラーが起きたときにどう対応するかを学びます。

理解度確認クイズ

  1. Q1. print() と return の違いを説明してください。

    回答を表示

    print() は値を画面に表示するだけで、その結果をあとで再利用することはできません。return は値を呼び出し元に返すので、変数に代入して別の処理に使うことができます。

  2. Q2. 次の関数を apply_discount(1000) のように rate を省略して呼び出せるのはなぜですか。
    def apply_discount(price, rate=0.1): ...

    回答を表示

    rate=0.1 のように既定値（デフォルト値）を設定したデフォルト引数だからです。呼び出すときに rate を省略すると、自動的に 0.1 が使われます。

  3. Q3. 関数の中で作った変数を、関数の外からそのまま参照するとどうなりますか。

    回答を表示

    NameError になります。関数の中で作られた変数はローカル変数で、その関数の中でしか有効ではないためです（スコープが関数の中に限られる）。値を外へ渡したい場合は return を使います。
