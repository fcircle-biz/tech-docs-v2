条件によって処理を変えよう（if文）

ここまでのプログラムは、上から下へ順番に実行するだけでした。この章では、「もし〜なら」という条件に応じて実行する処理を切り替える if 文を学びます。比較演算子・論理演算子と組み合わせることで、状況に応じて動きの変わるプログラムが書けるようになります。

この章で学ぶこと

  • if 文の基本構文と、Python でブロックを表す「インデント」の役割を理解する
  • 比較演算子で真偽値（True／False）を作れるようになる
  • if・elif・else を使って3つ以上の分岐を書ける
  • 論理演算子（and・or・not）と in 演算子で条件を組み合わせられる

6.1 if 文の基本とインデント

if 文は「もし条件が成り立つなら、この処理を実行する」という分岐を作ります。基本の形は次のとおりです。条件の末尾にコロン（:）を書き、実行したい処理は次の行からインデント（スペース4つ）して書きます。

if_basic.py 
score = 85

# 条件が成り立つときだけ、次の行が実行される
if score >= 60:
    print("合格です")
    print("おめでとうございます")

print("判定を終了しました")
実行結果 
合格です
おめでとうございます
判定を終了しました

インデントされた2行（print("合格です") と print("おめでとうございます")）が、if の「かたまり（ブロック）」です。インデントされていない print("判定を終了しました") は if の外側なので、条件に関係なく常に実行されます。第3章で「インデントに意味がある（第6章から本格的に使う）」と予告していましたが、これが正体です。

注意: コロンとインデント忘れ

if score >= 60 のようにコロンを忘れると SyntaxError になります。また、if の次の行でインデントを忘れると IndentationError になります。VS Code は : の後で改行すると自動でインデントしてくれるので、活用しましょう。

6.2 比較演算子と真偽値

if の条件部分には、結果が True（真）か False（偽）になる式を書きます。この2つの値を持つデータ型が、第4章で紹介した bool型です。2つの値を比べて真偽値を作るのが比較演算子です。

演算子 意味 例 結果
== 等しい 5 == 5 True
!= 等しくない 5 != 3 True
< より小さい 3 < 5 True
> より大きい 3 > 5 False
<= 以下 5 <= 5 True
>= 以上 3 >= 5 False

最重要の注意: = と == の違い

= は第4章で学んだ「代入」（変数に値を入れる）です。一方 == は「等しいかどうかを比べる」比較演算子です。if score = 60: のように書くと SyntaxError になります。初心者が最も間違えやすいポイントなので、条件式を書くときは == になっているか毎回確認しましょう。

対話モードで確かめてみましょう。比較の結果はすべて bool 型の値です。

対話モード 
>>> age = 20
>>> age >= 18
True
>>> type(age >= 18)
<class 'bool'>

6.3 if・elif・else で複数分岐

分岐が2つだけなら else（それ以外の場合）を、3つ以上なら elif（else if の略。「そうではなく、もし〜なら」）を使います。点数から評価（A〜D）を判定する例で見てみましょう。

grade.py 
score = 72

# 上から順に条件を調べ、最初に成り立った1つだけが実行される
if score >= 90:
    print("評価: A")
elif score >= 70:
    print("評価: B")
elif score >= 50:
    print("評価: C")
else:
    print("評価: D")
実行結果 
評価: B

ポイントは、elif は上から順に調べて、最初に条件が成り立った1つのブロックだけが実行されることです。score = 72 は score >= 90 は成り立ちませんが、次の score >= 70 で成り立つため「評価: B」が表示され、以降の elif・else は調べられません。流れを図にすると次のようになります。

flowchart TD A["score = 72"] --> B{"score が 90 以上？"} B -->|Yes| C["評価: A"] B -->|No| D{"score が 70 以上？"} D -->|Yes| E["評価: B"] D -->|No| F{"score が 50 以上？"} F -->|Yes| G["評価: C"] F -->|No| H["評価: D"]

用語: 条件の順番が結果を左右する

もし条件を score >= 50 → score >= 70 → score >= 90 の順に書いてしまうと、score = 95 でも最初の score >= 50 で止まり「評価: C」になってしまいます。elif を並べるときは、条件の厳しい（範囲の狭い）ものから先に書くのが基本です。

6.4 論理演算子と in 演算子、ネストの注意

複数の条件を組み合わせたいときは論理演算子を使います。and（かつ／両方が True）・or（または／どちらかが True）・not（否定／True と False を入れ替える）の3つです。

logical.py 
age = 25
has_ticket = True

# and: 両方の条件が成り立つときだけ True
if age >= 18 and has_ticket:
    print("入場できます")

# in: 値がリストや文字列に含まれるか調べる
weekday = "土"
if weekday in ["土", "日"]:
    print("週末料金が適用されます")
実行結果 
入場できます
週末料金が適用されます

in 演算子は「左の値が、右のリストや文字列に含まれているか」を調べ、真偽値を返します。第8章で学ぶリストや第5章の文字列とあわせて使うと、weekday == "土" or weekday == "日" より短く書けて読みやすくなります。

演算子 意味 例
and 両方が True のとき True age >= 18 and has_ticket
or どちらかが True のとき True weekday == "土" or weekday == "日"
not True と False を入れ替える not has_ticket

if の中にさらに if を書く「ネスト（入れ子）」もできます。ただし、インデントが深くなるほど読みにくくなるため、and で1つの条件にまとめられないかをまず検討しましょう。

nest.py 
# ネスト（インデントがさらに1段深くなる）
if age >= 18:
    if has_ticket:
        print("入場できます")

# and でまとめると1段で書ける（おすすめ）
if age >= 18 and has_ticket:
    print("入場できます")

重要ポイント

Python では、インデントの深さがそのまま「どの条件の内側の処理か」を表します。ネストが2〜3段を超えると読みにくくなるサインです。and・or でまとめられないか、第10章で学ぶ関数に処理を分けられないかを考える習慣をつけましょう。

やってみよう 6-1: 入場料金を判定するプログラム

python-study フォルダの ch06 フォルダに ticket.py を作成し、入力した年齢に応じて入場料金を表示するプログラムを作りましょう。

手順

  1. 1 input() と int()（第4章）を使って、年齢をキーボードから整数で受け取る。
  2. 2 if・elif・else で、「6歳未満は無料」「6〜17歳は500円」「18〜64歳は1000円」「65歳以上は700円」の4つに分岐する。
  3. 3 f文字列（第5章）を使い、「料金: 1,000円です」のように料金を表示する。
  4. 4 0歳・6歳・17歳・65歳など、区切りの値（境界値）を入力して、想定どおりの料金になるか確認する。

余裕があれば、and を使って「土日は全年齢+100円」の条件を追加してみましょう。

理解度確認クイズ

  1. Q1. 次のコードで SyntaxError になる理由を説明してください。
    if score = 60:

    回答を表示

    = は変数へ値を代入するための記号で、「等しいかどうか」を比べる比較演算子ではありません。if の条件式では比較演算子の == を使う必要があるため、正しくは if score == 60: と書きます。

  2. Q2. 次のコードを実行すると何が表示されますか。
    score = 95
    if score >= 50:　→　print("C")
    elif score >= 90:　→　print("A")

    回答を表示

    「C」が表示されます。elif は上から順に調べ、最初に成り立った条件のブロックだけを実行します。score = 95 は最初の条件 score >= 50 ですでに成り立つため、そこで判定が終わり、下の score >= 90 は調べられません。厳しい条件を先に書く必要があるのはこのためです。

  3. Q3. if age >= 18: if has_ticket: ... というネストしたif文は、論理演算子を使って1段の if にまとめられます。どう書き換えられますか。

    回答を表示

    if age >= 18 and has_ticket: のように and でつなげば、両方の条件が True のときだけ実行される1段の if にまとめられます。ネストが浅くなり読みやすくなります。
