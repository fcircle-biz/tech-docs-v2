変数とデータ型を理解しよう

前章では print() でメッセージを表示しました。この章では、値に名前を付けて覚えておける「変数」の仕組みと、Python が扱う代表的なデータ型（整数・小数・文字列・真偽値）を学びます。さらに、型を変換する方法と、キーボードから入力を受け取る方法も身につけます。

この章で学ぶこと

  • 変数の役割と、値を代入・再代入する書き方を理解する
  • int・float・str・bool の4つの基本データ型を type() で確認できる
  • int()・float()・str() による型変換ができる
  • input() でキーボードからの入力を受け取り、計算に使える

4.1 変数とは

変数とは、値に付ける「名札」のようなものです。荷物に名前を書いた札を付けておくと、あとで中身を思い出さなくても札を見れば分かります。プログラムでも同じように、計算結果や入力された値に名前を付けておくと、あとから何度でもその名前で呼び出せます。

変数を作るには、イコール記号 = を使います。数学の「等しい」とは意味が違い、Python の = は「右側の値を、左側の名前に代入する（入れる）」という意味です。

variables.py 
# name という名札に文字列を代入する
name = "田中"
print(name)

# 同じ変数に別の値を入れ直す（再代入）
name = "佐藤"
print(name)
実行結果 
田中
佐藤

名札を付け替えるように、name という同じ名前のまま、中身だけを「田中」から「佐藤」へ入れ替えられます。これを再代入と呼びます。中身の様子を図にすると、次のようになります。

flowchart LR subgraph before["再代入前"] direction LR N1["変数名
name"] --> V1["値
田中"] end subgraph after["再代入後"] direction LR N2["変数名
name"] --> V2["値
佐藤"] end before -->|"name = 佐藤 を実行"| after

変数名は自由に決められますが、いくつかのルールがあります。守らないとエラーになったり、あとで読みにくいコードになったりします。

ルール 内容 例
使える文字 英字・数字・アンダースコア（_）。1文字目は数字不可 total_price は OK、1total は NG
大文字・小文字を区別 Age と age は別の変数 綴りだけでなく大小文字も揃える
予約語は使えない Python が文法として使う単語（if・for・while・True など）は変数名にできない。print などの組み込み関数名は予約語ではないが、上書きしてしまうので使わない if = 1 は NG
命名の習慣（スネークケース） 複数単語は英語の小文字＋アンダースコアでつなぐ total_price（TotalPrice は避ける）

意味の分かる名前を付けよう

a や x のような短い名前は、あとで見返したときに何のための変数か分かりません。total_price（合計金額）や user_age（利用者の年齢）のように、値の意味が伝わる名前を付ける習慣をつけましょう。

4.2 基本のデータ型

変数に入れる値には「種類」があります。これをデータ型（型）と呼びます。Python にはたくさんの型がありますが、まずは最もよく使う4つを覚えましょう。

int（整数）

小数点のない整数。age = 20 のように書く。マイナスの値も扱える。

float（浮動小数点数）

小数点を含む数値。height = 172.5 のように書く。

str（文字列）

文字の並び。"..." または '...' で囲んで書く。

bool（真偽値）

True（真）か False（偽）の2つだけを表す型。条件分岐で活躍（第6章）。

変数がどの型を持っているかは、組み込み関数 type() で確認できます。

data_types.py 
age = 20            # int（整数）
height = 172.5      # float（浮動小数点数）
name = "田中"        # str（文字列）
is_student = True   # bool（真偽値）

print(type(age))
print(type(height))
print(type(name))
print(type(is_student))
実行結果 
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

Python は変数を作るときに int name = 20 のように型を書く必要がありません。= 20 と書けば、値を見て自動的に int だと判断してくれます。これは Python の大きな特徴の1つです。

4.3 型変換

型が違う値どうしを組み合わせると、Python はエラーを出すことがあります。次のコードを見てください。

error_sample.py 
# 文字列の "10" と整数の 5 を足そうとする
total = "10" + 5
print(total)
実行結果 
Traceback (most recent call last):
  File "error_sample.py", line 2, in <module>
    total = "10" + 5
            ~~~~~^~~
TypeError: can only concatenate str (not "int") to str

"10" は文字列、5 は整数なので、型が違って足し算できません（str どうしなら + は文字列の連結になり、int どうしなら足し算になります。異なる型を混ぜると Python はどちらの意味か判断できずエラーになります）。このようなときに使うのが型変換の関数です。

関数 変換先 例
int() 整数へ変換 int("10") → 10
float() 浮動小数点数へ変換 float("3.5") → 3.5
str() 文字列へ変換 str(10) → "10"
convert.py 
# "10" を int() で整数に変換してから足す
total = int("10") + 5
print(total)

# 数値を str() で文字列に変換してから連結する
message = "合計は" + str(total) + "円"
print(message)
実行結果 
15
合計は15円

注意: 変換できない文字列

int("こんにちは") のように、数字として読めない文字列を int() に渡すと ValueError になります。次の 4.4 で扱う input() の結果を変換するときによく起こるので、覚えておきましょう（正しい入力になるまで聞き直す方法は第11章で学びます）。

4.4 キーボードから入力する

ここまでのコードは、値をあらかじめプログラムの中に書いていました。実際のプログラムでは、実行するたびに利用者が入力した値を受け取りたい場面がよくあります。そのための組み込み関数が input() です。

ask_name.py 
# 括弧の中の文字列は、入力を促すメッセージ
name = input("名前を入力してください: ")
print("こんにちは、" + name + "さん")
実行結果 
名前を入力してください: 田中
こんにちは、田中さん

ここで重要な注意点があります。input() は、利用者が何を入力しても必ず文字列（str）として受け取ります。数字を入力しても、Python にとっては「数字が書かれた文字列」でしかありません。そのため、入力値を計算に使いたいときは、int() や float() で明示的に変換する必要があります。

flowchart TD A["input（）で入力待ち"] --> B["利用者がキーボードで
20 と入力"] B --> C["input（）の戻り値
文字列20（str）"] C --> D{"計算に使いたい？"} D -->|そのまま使う| E["文字列として扱われる
連結はできるが足し算はできない"] D -->|int（）で変換| F["整数 20（int）
足し算などの計算に使える"]
ask_age.py 
# input() の戻り値をそのまま int() に渡し、整数へ変換する
age = int(input("年齢を入力してください: "))

# age はすでに int なので、そのまま計算できる
next_year_age = age + 1
print("来年のあなたは" + str(next_year_age) + "歳です")
実行結果 
年齢を入力してください: 24
来年のあなたは25歳です

重要ポイント

input() の結果は常に str。計算に使うなら int(input(...)) や float(input(...)) のように、入力を受け取ると同時に変換するのが定番の書き方です。この組み合わせは今後の章でも頻繁に登場します。

やってみよう 4-1: 名前と年齢を入力して10年後の年齢を表示する

理解度確認クイズ

  1. Q1. score = 80 のあと score = 90 を実行すると、score の値はどうなりますか。

    回答を表示

    90 になります。同じ変数名に別の値を代入する「再代入」を行うと、名札の中身が新しい値に入れ替わり、古い値（80）は失われます。

  2. Q2. x = 5、y = "5" のとき、type(x) と type(y) はそれぞれ何になりますか。

    回答を表示

    type(x) は <class 'int'>、type(y) は <class 'str'> です。5 はクォートで囲んでいないので整数、"5" はダブルクォートで囲んでいるので、数字に見えても文字列として扱われます。

  3. Q3. age = input("年齢: ") のあと、そのまま age + 1 を計算するとエラーになります。なぜですか。どう直せばよいですか。

    回答を表示

    input() は入力内容を常に文字列（str）として返すため、age は数字に見えても文字列です。文字列と整数は足し算できないため TypeError になります。age = int(input("年齢: ")) のように int() で整数へ変換してから使えば計算できます。
