これまでのプログラムは、実行結果を画面に表示するだけで、プログラムを終了すればデータは消えてしまいました。この章では、テキストファイルや CSV ファイルにデータを保存し、あとから読み込む方法を学びます。この技術は、第15〜16章で作る家計簿アプリの「記録を残す」機能の土台になります。

この章で学ぶこと

  • csv モジュールで CSV ファイルを読み書きできる

12.1 ファイル操作の流れ

Python でファイルを扱うときは、「開く → 読み書きする → 閉じる」という3つの手順を守ります。ノートに例えると分かりやすいでしょう。ノートを使うときは、まず表紙を開き、文字を書いたり読んだりし、終わったら閉じます。開いたまま放置すると、書いた内容がきちんと保存されなかったり、他のプログラムがそのファイルを使えなくなったりすることがあります。

ファイルを開くには組み込み関数 open() を使います。open() には「どのファイルを」「どんな目的で」開くかを指定します。目的を表すのがモードです。

モード 意味 ファイルが無いとき
"r" 読み込み専用（read） FileNotFoundError
"w" 書き込み専用（write）。既存の内容は消えて上書きされる 新規作成
"a" 追記専用（append）。末尾に書き足す 新規作成

注意: "w" モードは上書き

"w" で既存ファイルを開くと、中身が空になってから書き込まれます。過去の内容を残したい場合は "a"（追記）を使いましょう。第11章で学んだとおり、ファイルが見つからないと FileNotFoundError が発生します。

12.2 with 文でテキストファイルを読み書きする

「開いたら必ず閉じる」を書き忘れないために、Python には with 文があります。with 文の中でファイルを使うと、ブロックを抜けたときに自動でファイルが閉じられます。途中でエラーが起きても確実に閉じられるので、ファイル操作では with 文を使うのが基本です。

write_text.py 
# "w"モードで開いて書き込む（文字コードはUTF-8を指定）
with open("memo.txt", "w", encoding="utf-8") as f:
    f.write("今日はPythonのファイル操作を学んだ\n")
    f.write("with文は自動でファイルを閉じてくれる\n")
# withブロックを抜けた時点でファイルは閉じられている

encoding="utf-8" は文字コードの指定です。OS によって既定の文字コードが異なり、指定を省略すると環境ごとに日本語が文字化けすることがあります。テキストファイルを開くときは、常に encoding="utf-8" を書くと覚えておきましょう。読み込みは read()（全文を1つの文字列として取得）と、for 文で1行ずつ処理する方法があります。

read_text.py 
# "r"モードで開いて全文を1つの文字列として読む
with open("memo.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)

# 1行ずつ読みたいときはforで回す
with open("memo.txt", "r", encoding="utf-8") as f:
    for line in f:
        print("行:", line.strip())
実行結果 
今日はPythonのファイル操作を学んだ
with文は自動でファイルを閉じてくれる

行: 今日はPythonのファイル操作を学んだ
行: with文は自動でファイルを閉じてくれる

用語: strip() がなぜ必要か

1行ずつ読み込むと、行末の改行文字 \n も一緒に取得されます。第5章で学んだ strip() を使うと、前後の空白や改行を取り除けます。print() のときに行が2重に改行されて見えるのは、この \n が原因です。

12.3 CSV ファイルを読み書きする

CSV（Comma-Separated Values）は、表形式のデータをカンマ区切りのテキストで表すファイル形式です。Excel でも開けるため、業務でよく使われます。Python の標準ライブラリ csv モジュールを使うと、自分でカンマを分割する処理を書かずに済みます。コードの先頭に書く import csv は「csv モジュールを使えるようにする」という宣言です（第7章の import random と同じ形で、仕組みは第13章で詳しく学びます）。12.4 の from pathlib import Path も同じ仲間の書き方です。

辞書のリスト（第9章で学んだ「データの表」の形）を CSV に書き出すには csv.DictWriter、読み込むには csv.DictReader が便利です。支出記録のデータで試してみましょう。

write_csv.py 
import csv

# 支出記録（辞書のリスト＝表データ）
records = [
    {"date": "2026-04-01", "category": "食費", "amount": 850},
    {"date": "2026-04-02", "category": "交通費", "amount": 420},
]
fieldnames = ["date", "category", "amount"]

# newline=""はWindowsで空行が入るのを防ぐおまじない
with open("expenses.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(records)
read_csv.py 
import csv

# DictReaderは1行を辞書として読み取ってくれる
with open("expenses.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.DictReader(f)
    total = 0
    for row in reader:
        print(row["date"], row["category"], row["amount"])
        total += int(row["amount"])  # CSVの値は常に文字列なので変換する
print("合計:", total, "円")
実行結果 
2026-04-01 食費 850
2026-04-02 交通費 420
合計: 1270 円

重要ポイント: CSV の値はすべて文字列

csv.DictReader で読み込んだ値は、金額のような数値であっても文字列型です。第4章で学んだとおり、計算する前に int() や float() で変換する必要があります。この処理は第15〜16章の家計簿アプリでもそのまま使います。

12.4 pathlib でパスを扱う

"memo.txt" のようにファイル名だけを書くと、プログラムを実行した場所（カレントディレクトリ）にあるファイルが対象になります。フォルダをまたいだファイルを扱うときはパス（ファイルの場所を表す文字列）を組み立てる必要があります。標準ライブラリ pathlib の Path を使うと、Windows と macOS/Linux でパスの区切り文字（\ と /）が違っても、同じ書き方で扱えます。

use_pathlib.py 
from pathlib import Path

# "/"演算子でフォルダとファイル名をつなげる
data_file = Path("data") / "expenses.csv"

# 存在確認をしてから開く
if data_file.exists():
    print(data_file, "は存在します")
else:
    print(data_file, "はまだありません")

Path オブジェクトは open() にそのまま渡せます。exists() で存在確認をしておけば、第16章で学ぶ「ファイルが無い場合は新規作成する」という分岐にも使えます。ファイル操作の全体像を図で整理しましょう。

flowchart LR A["open()で開く"] --> B{"モード"} B -->|"r"| C["読み込み"] B -->|"w / a"| D["書き込み・追記"] C --> E["withブロックを抜ける"] D --> E E --> F["自動でクローズ"]

やってみよう 12-1: 日記を追記して保存するプログラム

「日記の1行」を入力すると、既存の内容を消さずに diary.txt へ追記していくプログラムを作りましょう。

手順

  1. 1 input() で「今日の出来事」を1行入力してもらう。
  2. 2 open("diary.txt", "a", encoding="utf-8") を with 文で開き、入力内容を1行として書き込む（末尾に \n を付ける）。
  3. 3 プログラムをもう一度実行し、前回書いた内容が消えずに残っていることを確認する。
  4. 4 最後に "r" モードで diary.txt を開き、for 文ですべての行を表示する。

余裕があれば、datetime（第13章で扱います）を使わずに、入力してもらった日付の文字列を行の先頭に付け加えてみましょう。

理解度確認クイズ

  1. Q1. ファイルを扱うときに with 文を使うと、どんな利点がありますか？

    回答を表示

    with ブロックを抜けると、途中でエラーが起きた場合でも自動でファイルが閉じられます。閉じ忘れを防げるので、ファイル操作では with 文を使うのが基本です。

  2. Q2. open() の "w" モードと "a" モードの違いを説明してください。

    回答を表示

    "w" は書き込み専用で、既存の内容を消してから新しく書き込みます（上書き）。"a" は追記専用で、既存の内容を残したまま末尾に書き足します。

  3. Q3. csv.DictReader で読み込んだ金額の値を計算に使う前に、なぜ int() で変換する必要があるのですか？

    回答を表示

    CSV ファイルの中身はすべてテキストであり、csv.DictReader で読み込んだ値はすべて文字列型になるためです。文字列のままでは足し算などの数値計算ができないため、int()（または float()）で数値型に変換してから計算します。
