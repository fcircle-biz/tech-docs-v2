第2章で準備した環境を使って、いよいよ Python のコードを動かします。まずは対話モードで気軽に試し、次にファイルに保存して実行する方法を覚えます。最後に、わざとエラーを起こしてエラーメッセージの読み方の第一歩を学びます。

3.1 対話モード（REPL）で試す

ターミナルで python（macOS は python3）とだけ入力して実行すると、対話モード（REPL: Read-Eval-Print Loop の略）が始まります。>>> というプロンプト（入力待ちの記号）が表示され、1行コードを入力して Enter を押すと、その場ですぐに結果が返ってきます。電卓のように、ちょっとした計算や動作確認をしたいときに便利です。

ターミナル 
# 対話モードを起動する（macOS は python3）
python
実行結果 
Python 3.12.4 (main, Jun  7 2024, 00:00:00)
Type "help", "copyright", "credits" or "license" for more information.
>>> 3 + 5
8
>>> print("こんにちは")
こんにちは
>>> exit()

3 + 5 と入力するとすぐに 8 が返り、print("こんにちは") と入力すればその文字がそのまま表示されます。対話モードを終了するには exit() と入力するか、Windows は Ctrl+Z の後に Enter、macOS/Linux は Ctrl+D を押します。

対話モードの向き・不向き

対話モードは「1行だけ試したい」ときに向いています。ただし、閉じると入力した内容は消えてしまい、複数行の処理をまとめて書くのにも向きません。本格的なプログラムは、次に紹介するスクリプトファイルとして保存します。

3.2 スクリプトファイルを作って実行する

第2章で作った python-study フォルダの中に ch03 フォルダを作り、その中に hello.py というファイルを作成しましょう。VS Code で python-study フォルダを開いた状態なら、サイドバーの「新しいファイル」アイコンから作成できます。

ch03/hello.py 
# はじめてのプログラム
print("Hello, World!")
print("Pythonの学習を始めます")

print() は、かっこの中に書いた内容を画面に表示する関数です（関数については第10章で詳しく学びます。今は「文字を表示する命令」とだけ覚えれば十分です）。文字を表示するときは、前後をダブルクォート "..." で囲みます。

保存したら、実行してみましょう。VS Code 右上の三角形（実行）ボタンを押すか、ターミナルでファイルのあるフォルダに移動して次のコマンドを入力します。

実行結果

対話モードと違い、スクリプトファイルは何度でも同じ内容を保存・再実行できます。行を追加・修正してからもう一度実行する、という繰り返しが、これから先の学習の基本の流れになります。

3.3 コメントと書き方のルール

# から行末まではコメントとして扱われ、実行時には無視されます。コメントは「このコードが何をしているか」を人間向けに書き残すためのメモです。上の hello.py の1行目、# はじめてのプログラム がコメントです。

comment_sample.py 
# この行はコメント（実行されない）
print("この行は実行される")  # 行の途中からもコメントにできる

Python の書き方には、いくつか覚えておきたい基本ルールがあります。

ルール 内容
1行に1命令 基本的に、1つの処理は1行で書く。行末にセミコロン（;）は不要
大文字・小文字を区別する Print と print は別物として扱われる（Print はエラーになる）
文字列はダブルクォートで囲む 本ガイドでは "..." に統一する（シングルクォート '...' でも動くが、書き方をそろえる）
インデント（字下げ）に意味がある スペース4つの字下げで処理のまとまりを表す。第6章の if 文から本格的に使う

重要ポイント

「インデントに意味がある」というのは Python の大きな特徴です。今の段階では覚えるだけで大丈夫ですが、第6章で if 文を学ぶときに、字下げを1文字でもずらすとエラーになる、という体験をします。今のうちに「Python は字下げにうるさい言語だ」と頭の片隅に置いておきましょう。

3.4 エラーメッセージを読んでみる

プログラミングでは、エラーは失敗ではなくごく普通に起こることです。大切なのは、エラーメッセージを読んで「どこが」「なぜ」間違っているのかを見つけることです。ここでは、わざとエラーを起こして、メッセージの読み方に慣れておきましょう。

まず、閉じかっこを忘れてみます。ch03 フォルダに error1.py という名前で、次の内容のファイルを保存して実行してください（1行目はコメントなので、問題があるのは2行目です）。

ch03/error1.py 
# わざと閉じかっこを書き忘れる
print("Hello"
実行結果 
  File "error1.py", line 2
    print("Hello"
         ^
SyntaxError: '(' was never closed

SyntaxError（構文エラー）は、コードの書き方そのものが Python のルールに合っていないときに出ます。「2行目の、この ( が閉じられていない」と教えてくれています。かっこは開いたら必ず閉じる、という習慣をつけましょう。

次に、print をわざと打ち間違えてみます。error2.py として保存してください。

ch03/error2.py 
# わざと print を打ち間違える
prnt("Hello")
実行結果 
Traceback (most recent call last):
  File "error2.py", line 2, in <module>
    prnt("Hello")
    ^^^^
NameError: name 'prnt' is not defined. Did you mean: 'print'?

今度は NameError です。「prnt という名前は定義されていません」という意味で、Python が知らない単語を使ってしまったときに出ます。最後の Did you mean: 'print'? は「print のことですか？」という修正候補の提案で、打ち間違いのときはこれが大きなヒントになります。このように、Python のエラーメッセージは下の行（一番最後の行）にエラーの種類と理由が、その上にファイル名と行番号が書かれています。まずは一番下の行から読む、と覚えておきましょう。エラーの種類は第11章で一覧にして詳しく学びます。

エラーを読む3ステップ

1. 一番下の行で、エラーの種類（SyntaxError など）と理由を確認する。2. 上のほうにある「line 〇」でファイルの何行目かを確認する。3. その行を実際に見て、書き間違いを探す。この3ステップは、この先どんなエラーに出会っても使えます。

やってみよう 3-1: 自己紹介を3行表示するプログラム

ch03 フォルダに profile.py というファイルを作成し、print() を3回使って自己紹介を表示するプログラムを書いてみましょう。

手順

  1. 1 ch03/profile.py を新規作成する。1行目に先頭コメントとして # 自己紹介プログラム と書く。
  2. 2 print() を3回使い、名前・好きなこと・Python を学ぶ目的の3行を、それぞれ別の print() で表示する。
  3. 3 ターミナルで python profile.py（macOS は python3 profile.py）を実行し、3行が表示されることを確認する。
  4. 4 余裕があれば、わざとダブルクォートを1つ消して実行し、どんなエラーメッセージが出るか観察してから直す。

1つの print() に複数行の文字列をまとめて書く必要はありません。「1行1命令」のルールどおり、print() を3回書けば十分です。

理解度確認クイズ

  1. Q1. 対話モード（REPL）とスクリプトファイルの違いは何ですか？

    回答を表示

    対話モードは1行ずつ入力してその場で結果を確認できますが、閉じると内容は消え、複数行の処理には向きません。スクリプトファイル（.py）はコードを保存しておけるため、何度でも同じ内容を再実行でき、まとまったプログラムを書くのに向いています。

  2. Q2. Python のコードで、# から行末までは何として扱われますか？

    回答を表示

    コメントとして扱われ、実行時には無視されます。コードが何をしているかを人間向けにメモしておくために使います。

  3. Q3. Python のエラーメッセージを読むとき、まずどこを確認すればよいですか？

    回答を表示

    一番下の行です。そこにエラーの種類（SyntaxError・NameError など）と理由が書かれています。そのうえで、上のほうにある「line 〇」でファイルの何行目かを確認し、その行を見て書き間違いを探します。
