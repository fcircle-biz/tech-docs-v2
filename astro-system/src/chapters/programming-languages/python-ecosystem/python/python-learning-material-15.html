家計簿アプリを作ろう① 記録と一覧表示

これまで学んだ変数・条件分岐・繰り返し・リスト・辞書・関数・例外・ファイル操作・モジュール・クラスを組み合わせて、総合演習として家計簿アプリ「kakeibo.py」を作ります。この章では、メニューを表示して番号で操作を選ぶ仕組みと、支出を1件ずつ記録する機能、記録を一覧表示する機能を作ります。保存（CSV）と集計は次の第16章で仕上げます。

この章で学ぶこと

  • 家計簿アプリ全体の機能一覧と、支出1件を表す辞書・全記録を持つリストというデータ構造を説明できる

  • 支出を1件入力して records に追加する add_record() を実装できる
  • 記録の一覧を桁を揃えて表示し、合計金額を計算する show_records() を実装できる

15.1 作るアプリの全体像

ここから2章かけて、日々の支出を記録・保存・集計できる家計簿アプリ「kakeibo.py」を作ります。第9章の「辞書のリスト＝表データ」、第10章の関数、第12章のファイル操作を思い出しながら進めましょう。まずは今章で作る範囲の機能を確認します。

第15章（今回）で作る機能

メニュー表示・番号選択の仕組み、支出を1件記録する機能、記録を一覧表示する機能。

第16章で作る機能

CSV への保存・起動時の読み込み、カテゴリ別集計、金額入力の例外処理。

支出1件は、第9章で学んだ辞書で表します。キーは date（日付）・category（カテゴリ）・amount（金額、int型）・memo（メモ）の4つです。すべての支出記録は、この辞書を要素とするリスト records にまとめて保持します。

用語: グローバル変数としての records

第10章で学んだ「関数の中で外側の変数を書き換えるにはグローバル宣言が必要」というルールを思い出してください。今回の records はファイルの先頭で定義するグローバル変数で、add_record() の中では records.append(...) のように中身を変更するだけなので、global 宣言は不要です（records = ... のように丸ごと代入し直す場合だけ必要になります）。

15.2 メニューの表示と選択

まずは新しいフォルダ python-study/ch15 を作り、そこに kakeibo.py を作成します。最初に、グローバル変数 records と、メニューを表示するだけの関数 show_menu() を書きます。

# 家計簿アプリ(第15章版: 記録と一覧表示)

records = []  # 支出記録を保存するリスト(辞書のリスト)


def show_menu():

次に、メニューを繰り返し表示して番号を受け取るメインループを main() 関数として作ります。第7章の while True と、第6章の if・elif・else の組み合わせです。add_record() と show_records() はこのあと15.3・15.4で作るので、ここでは先に呼び出す形だけ書いておきます。

kakeibo.py（2: メインループ） 
def main():  # メニューを表示し、選択に応じて処理を振り分ける
    while True:
        show_menu()
        choice = input("番号を選んでください: ")
        if choice == "1":
            add_record()
        elif choice == "2":
            show_records()
        elif choice == "3":
            print("集計機能は準備中です。(第16章で実装します)")
        elif choice == "0":
            print("終了します。")
            break
        else:
            print("0〜3の番号を入力してください。")

ファイルの最後には、第13章で学んだ if __name__ == "__main__": を書き、直接実行されたときだけ main() を呼び出すようにします。

kakeibo.py（ファイルの末尾） 
# 直接実行されたときだけメインループを開始する
if __name__ == "__main__":
    main()

choice == "1" のように文字列として比較している点に注意してください。input() はキーボードから受け取った内容を常に文字列で返す（第4章）ため、数値に変換せずそのまま比較しています。今の段階で実行すると add_record・show_records が未定義でエラーになります。15.3・15.4で作ってから動作確認しましょう。

注意: 関数はmain()より前に定義する

Python はファイルを上から読みながら実行するため、add_record() や show_records() を main() の中で呼び出すには、main() が実際に呼び出される時点（ファイル末尾の if __name__ == "__main__":）より前に、それらの関数が定義されている必要があります。読みやすさのため、本章では部品となる関数を先に書き、main() をその後ろに置きます。15.3・15.4のコードは show_menu() の下、main() の上に追加していきます。

15.3 支出を記録する関数 add_record

add_record() は、日付・カテゴリ・金額・メモをキーボードから1つずつ受け取り、辞書にまとめて records に追加する関数です。show_menu() の下に追加してください。

kakeibo.py（3: add_record） 
def add_record():
    """支出を1件入力してrecordsに追加する"""
    date = input("日付 (例: 2026-04-01): ")
    category = input("カテゴリ (例: 食費): ")
    amount = int(input("金額: "))  # 例外処理は第16章で追加する
    memo = input("メモ: ")

    record = {"date": date, "category": category, "amount": amount, "memo": memo}
    records.append(record)
    print("記録しました。")

amount = int(input("金額: ")) は、input() が返す文字列を第4章で学んだ int() でそのまま数値に変換しています。「1200円」のように数字以外の文字が混ざっていたり、何も入力せず Enter だけ押したりすると ValueError が発生してプログラムが止まりますが、この単純な変換への対応（try・except）は第16章で追加します。今章では「正しく半角数字だけを入力する」前提で進めましょう。

実行結果（add_record の動作イメージ） 
日付 (例: 2026-04-01): 2026-04-01
カテゴリ (例: 食費): 食費
金額: 850
メモ: 昼食
記録しました。

なぜ辞書1つを変数recordに入れてからappendするのか

records.append({"date": date, ...}) と1行で書くこともできますが、途中で record という名前を付けておくと、行が長くなりすぎず、あとで print(record) して中身を確認しやすくなります。どちらの書き方でも動作は同じです。

15.4 一覧を表示する関数 show_records

show_records() は、records の中身を番号付きで見やすく表示し、最後に合計金額を表示する関数です。第5章で学んだ f文字列の書式指定（{値:,} など）に、新しく幅を揃える指定（{値:>幅}・{値:<幅}）を加え、第8章のリスト操作と組み合わせます。add_record() の下に追加してください。

kakeibo.py（4: show_records） 
def show_records():
    """記録の一覧を番号付きで表示し、合計金額も表示する"""
    if not records:
        print("記録がありません。")
        return

    print("\n===== 支出一覧 =====")
    for i, r in enumerate(records, start=1):
        print(f"{i:>2}. {r['date']} | {r['category']:<6} | {r['amount']:>7,}円 | {r['memo']}")

    total = sum(r["amount"] for r in records)
    print(f"合計: {total:,}円")

書式指定の意味を確認しましょう。{i:>2} は番号を右詰めで2桁分の幅に、{r['category']:<6} はカテゴリ名を左詰めで6文字分の幅に、{r['amount']:>7,} は金額を右詰め7桁＋3桁区切りのカンマ付きで表示します（> は右詰め、< は左詰め、続く数字が幅です）。enumerate(records, start=1) は、リストの要素を「番号」と「要素」の組で1つずつ取り出す組み込み関数で、start=1 を付けると番号が1から始まります。for i, r in ... のように2つの変数で受け取るのは、第9章の items() と同じアンパック代入です。total = sum(r["amount"] for r in records) は、第8章で触れたリスト内包表記に似た書き方で「各記録の amount だけを取り出して合計する」処理です。records が空リストのときは if not records: が真になり（if の条件では、空のリストは False、要素が1つ以上あるリストは True として扱われます）、一覧の代わりにメッセージを出して return で処理を終えます。

実行結果（記録が2件あるとき） 
===== 支出一覧 =====
 1. 2026-04-01 | 食費     |     850円 | 昼食
 2. 2026-04-02 | 交通費    |     480円 | 電車
合計: 1,330円

重要ポイント

桁揃えの数値（>2・<6・>7,）は、あなたが入力するカテゴリ名の長さやデータの件数に応じて調整してかまいません。大切なのは「揃える」という考え方そのものです。なお、幅は「文字数」で数えるため、日本語のような全角文字は画面上で半角2文字分の幅に見え、縦の線が少しずれて表示されることがあります。表示が整うと、一覧が一気に読みやすくなることを体感してください。

理解度確認クイズ

  1. Q1. 支出1件と、すべての支出記録は、それぞれどのようなデータ構造で表しますか？

    回答を表示

    支出1件は date・category・amount・memo をキーに持つ辞書で表します。すべての支出記録は、その辞書を要素とするリスト records にまとめて保持します。

  2. Q2. main() のメインループで、ユーザーが入力した番号 "1" と "2" によって処理が分かれるのはどの仕組みを使っているからですか？

    回答を表示

    if choice == "1": ... elif choice == "2": ... という条件分岐（if・elif・else）です。input() は常に文字列を返すため、数値ではなく文字列 "1"・"2" と比較している点がポイントです。

  3. Q3. show_records() で records が空リストのとき、どのような処理が行われますか？

    回答を表示

    if not records: が真になり、「記録がありません。」と表示したあと return で関数を終了します。if の条件では空リストは False として扱われる（15.4 で説明）ため、一覧表示や合計計算には進みません。
