モジュールとライブラリを使おう

これまでの章では、自分で書いたコードだけでプログラムを作ってきました。しかし Python には、他の人が作った便利な部品（ライブラリ）が無数に公開されています。この章では、それらを取り込む仕組みであるモジュールと、外部ライブラリを安全に使うための仮想環境を学びます。

この章で学ぶこと

  • モジュールとは何かを理解し、import・from import・as を使い分けられる
  • よく使う標準ライブラリ（random・datetime・math・statistics）を使える
  • 自分の関数を別ファイル（自作モジュール）に分け、if __name__ == "__main__": の意味を理解する
  • venv で仮想環境を作り、pip で外部ライブラリをインストールできる

13.1 モジュールとは

モジュールとは、関数や変数をひとまとめにした「部品集」で、実体は拡張子 .py の1つのファイルです。第12章までに使ってきた print() や len() などは、何もしなくても使える組み込み関数でした。それに対し、random（乱数）や csv（第12章で使用）のような機能は、import 文で明示的に「読み込む」必要があります。すべての機能を最初から使えるようにしてしまうと、名前の衝突が増えたりプログラムの起動が遅くなったりするため、Python は必要なモジュールだけを取り込む方式を採っています。

モジュールの取り込み方には、主に3つの書き方があります。

import_patterns.py 
# 1. モジュール全体を読み込む（モジュール名.関数名 で使う）
import math
print(math.sqrt(16))  # 4.0

# 2. モジュールの中の特定の機能だけを読み込む
from math import sqrt
print(sqrt(25))  # 5.0

# 3. 長い名前に別名を付けて読み込む
import statistics as stats
print(stats.mean([10, 20, 30]))  # 20
実行結果 
4.0
5.0
20
書き方 呼び出し方 向いている場面
import math math.sqrt(16) どのモジュールの機能か分かりやすくしたいとき（基本形）
from math import sqrt sqrt(25) 特定の機能だけを何度も使うとき
import statistics as stats stats.mean(...) モジュール名が長い、または慣習的な省略名があるとき

用語: 標準ライブラリ・外部ライブラリ・パッケージ

標準ライブラリは Python 本体に最初から同梱されているモジュール群です（今すぐ使えます）。外部ライブラリはインターネット上で公開されている、標準に含まれないモジュールで、13.4 で学ぶ pip で追加インストールします。複数のモジュールをフォルダにまとめたものをパッケージと呼びますが、初心者のうちは「モジュール＝機能の部品」くらいの理解で十分です。

13.2 よく使う標準ライブラリ

Python には200種類以上の標準ライブラリが同梱されています。ここでは特によく使う4つを紹介します。第7章で「おまじない」として登場した random も、ここでしっかり理解しましょう。

stdlib_sample.py 
import random
import datetime
import math
import statistics

print(random.randint(1, 6))          # 1〜6のランダムな整数（サイコロ）
print(random.choice(["晴れ", "雨"]))  # リストからランダムに1つ選ぶ

today = datetime.date.today()
print(today)                          # 2026-09-23 のような今日の日付

print(math.floor(3.7), math.ceil(3.2))  # 切り捨て3 切り上げ4
print(statistics.mean([80, 90, 70]))    # 平均: 80
モジュール 主な機能 代表的な使い道
random randint()・choice()・shuffle() サイコロ・抽選・おみくじ・テストデータ生成
datetime date.today()・strftime() 今日の日付取得、日付の表示形式の変換、家計簿の記録日
math sqrt()・floor()・ceil()・pi 平方根・切り捨て/切り上げなどの数学計算
statistics mean()・median()・stdev() 平均値・中央値・標準偏差などの統計計算

datetime の日付は、strftime() を使うと好きな形式の文字列に変換できます。家計簿アプリ（第15〜16章）で使う "2026-04-01" のような形式も、この方法で作れます。

date_format.py 
import datetime

today = datetime.date.today()
# %Y-%m-%d は「年-月-日」の2桁ゼロ埋め形式
formatted = today.strftime("%Y-%m-%d")
print(formatted)  # 例: 2026-09-23

重要ポイント

「これをやりたいけれど、自分で書くのは大変そう」と思ったら、まず標準ライブラリに同じ機能がないか探してみましょう。Python 標準ライブラリ（公式・日本語）で検索すると、車輪の再発明をせずに済みます。

13.3 自作モジュール

import できるのは標準ライブラリだけではありません。自分で書いた .py ファイルも、同じフォルダに置けばモジュールとして読み込めます。1つのファイルに全部の処理を書くと長くなって読みにくいので、関数をファイルごとに分けて整理することはとても実用的です。

flowchart LR A["calc_utils.py
関数の定義だけ"] -->|"import calc_utils"| B["main.py
calc_utils.tax_included(...)を呼び出す"] B --> C["実行結果を表示"]

同じフォルダに calc_utils.py（関数を定義するだけのファイル）と main.py（それを使うファイル）を作ってみましょう。

calc_utils.py 
def tax_included(price, rate=0.1):
    """税込価格を計算して返す"""
    return round(price * (1 + rate))

# このファイルを直接実行したときだけ、動作確認コードを動かす
if __name__ == "__main__":
    print(tax_included(1000))
main.py 
import calc_utils

# calc_utils.py の tax_included() を呼び出す
price = calc_utils.tax_included(2000)
print("税込価格:", price, "円")
実行結果（python main.py） 
税込価格: 2200 円

ここで注目してほしいのが if __name__ == "__main__": という書き方です。__name__ は Python が自動的に用意する特別な変数で、そのファイルが「直接実行されたとき」は "__main__" という文字列に、「他のファイルから import されたとき」はモジュール名（"calc_utils"）になります。この違いを利用することで、「モジュールとして使われるときは動かしたくないが、そのファイル単体の動作確認はしたい」処理を安全に書けます。事実、main.py から import calc_utils したときには、calc_utils.py 内の print(tax_included(1000)) は実行されません。

注意: import できる場所

自作モジュールを import できるのは、基本的に実行するファイルと同じフォルダにある場合です。python-study フォルダの中でも章ごとにサブフォルダを分けているときは、import したいファイルを同じサブフォルダにコピーするか、同じ場所に置いて試しましょう。

13.4 venv と pip

標準ライブラリに無い機能を使いたいときは、外部ライブラリをインストールします。ただし、複数のプロジェクトで外部ライブラリを直接インストールしていくと、「プロジェクトAは古いバージョンが必要、プロジェクトBは新しいバージョンが必要」といったバージョンの衝突が起きやすくなります。この問題を避けるのが仮想環境（venv）です。プロジェクトごとに独立した「ライブラリの置き場所」を作り、他のプロジェクトに影響を与えずにライブラリを追加・削除できます。

flowchart TD A["python-study/project1
venv: requests 2.x"] --> C["それぞれ独立
バージョンが衝突しない"] B["python-study/project2
venv: requests 1.x"] --> C

仮想環境は、プロジェクトのフォルダの中で作成します。作成すると .venv という名前のフォルダができます。

ターミナル（仮想環境の作成） 
# python-study フォルダの中で実行する（macOS は python3）
python -m venv .venv

作成しただけではまだ使われません。有効化（activate）して初めて、そのターミナルで使う python や pip が仮想環境のものに切り替わります。有効化のコマンドは OS によって異なります。

ターミナル（Windows） 
.venv\Scripts\activate
ターミナル（macOS / Linux） 
source .venv/bin/activate

有効化に成功すると、プロンプトの先頭に (.venv) と表示されます（Windows の PowerShell で「スクリプトの実行が無効」というエラーが出て有効化できない場合は、VS Code のターミナルの種類をコマンドプロンプトに切り替えて同じコマンドを実行してください）。この状態で pip（Python 標準のパッケージ管理ツール）を使って外部ライブラリをインストールします。

ターミナル（有効化後） 
pip install requests
pip list

requests は Web サイトへアクセスするための代表的な外部ライブラリです。インストールしたライブラリの一覧は、requirements.txt というファイルに書き出しておくと、他のパソコンでも同じ環境を再現できます。

ターミナル（requirements.txt の作成と再現） 
pip freeze > requirements.txt
pip install -r requirements.txt

注意: 仮想環境を使い終えたら

作業を終えるときは deactivate と入力すると、有効化を解除できます。また、本ガイドのこれまでの章（第1〜12章）は標準ライブラリだけで完結しており、仮想環境が無くても動きます。仮想環境が必要になるのは、この章のように pip install で外部ライブラリを使う場合です。

理解度確認クイズ

  1. Q1. import math と from math import sqrt の違いは何ですか？

    回答を表示

    import math はモジュール全体を読み込み、math.sqrt(16) のように「モジュール名.機能名」で呼び出します。from math import sqrt は特定の機能だけを取り出し、sqrt(16) のようにモジュール名を付けずに直接呼び出せます。

  2. Q2. 自作モジュール内の if __name__ == "__main__": は何のためにありますか？

    回答を表示

    そのファイルが「直接実行されたとき」だけ処理を動かし、「他のファイルから import されたとき」は動かさないようにするためです。これにより、動作確認用のコードが、モジュールとして使うときに勝手に実行されるのを防げます。

  3. Q3. 仮想環境（venv）を使う目的は何ですか？

    回答を表示

    プロジェクトごとに独立したライブラリの置き場所を作り、他のプロジェクトと外部ライブラリのバージョンが衝突しないようにするためです。python -m venv .venv で作成し、Windows は .venv\Scripts\activate、macOS は source .venv/bin/activate で有効化してから pip install を実行します。
