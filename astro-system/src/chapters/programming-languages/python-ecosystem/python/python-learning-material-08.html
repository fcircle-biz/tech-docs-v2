複数のデータをまとめよう（リストとタプル）

これまでは1つの変数に1つの値を入れてきました。しかし「クラス全員のテストの点数」のように、たくさんの値をまとめて扱いたい場面は多くあります。この章では、複数のデータをひとまとめにするリストとタプルを学びます。

この章で学ぶこと

  • リストを作成し、インデックスで要素を取り出せる
  • リストへの追加・削除・書き換えができる
  • for 文でリストを処理し、合計・最大値・並べ替えができる
  • リストとタプルの違いを理解し、使い分けの感覚をつかむ

8.1 リストの作成と参照

リストは、複数の値を1つの変数にまとめて入れておける入れ物です。角括弧 [] の中に、値をカンマ区切りで並べて作ります。テストの点数を1つずつ score1・score2…と変数に分けるのではなく、scores という1つのリストにまとめて管理できます。

list_basic.py 
# テストの点数をリストにまとめる
scores = [80, 65, 92, 74, 88]

# 個数を確認する
print("人数:", len(scores))

# インデックス（先頭は0）で要素を取り出す
print("1人目:", scores[0])
print("3人目:", scores[2])

# 負のインデックスは末尾から数える
print("最後:", scores[-1])
実行結果 
人数: 5
1人目: 80
3人目: 92
最後: 88

重要なのは、リストの番号（インデックス）は 0 から始まることです。「1人目」が scores[0]、「3人目」が scores[2] になる点は、初めのうちは間違えやすいので意識しておきましょう。

用語: 要素・インデックス

リストの中に入っている1つ1つの値を要素と呼びます。それぞれの要素の位置を表す番号がインデックスです。範囲外のインデックス（存在しない番号）を指定すると IndexError になります。

8.2 リストの変更

リストは作った後でも中身を自由に変更できます。これは、変更できない文字列（1文字だけ書き換えることはできません）との大きな違いです。よく使うメソッドをまとめて確認しましょう。

list_edit.py 
# 買い物リストを操作する
items = ["米", "卵", "牛乳"]

items.append("パン")        # 末尾に追加
items.insert(1, "パスタ")   # 1番目に挿入
items[0] = "玄米"           # 要素を書き換える
items.remove("卵")          # 値を指定して削除
last_item = items.pop()     # 末尾を取り出して削除

print(items)
print("最後に取り出した物:", last_item)
実行結果 
['玄米', 'パスタ', '牛乳']
最後に取り出した物: パン
メソッド 働き
append(値) リストの末尾に要素を1つ追加する
insert(位置, 値) 指定した位置に要素を挿入する
remove(値) 指定した値を1つ探して削除する（無いと ValueError）
pop() 末尾の要素を取り出して削除する（戻り値を使える）

注意: remove() と pop() の違い

remove(値) は「消したい値そのもの」を指定します。一方 pop(位置) は「消したい位置（インデックス）」を指定し、何も指定しなければ末尾を削除します。似ているので混同しないようにしましょう。

8.3 リストと for 文

第7章で学んだ for 文は、リストの要素を先頭から1つずつ取り出す処理にそのまま使えます。range() を使って番号を回す必要はなく、リストを直接指定するだけです。

list_for.py 
scores = [80, 65, 92, 74, 88]

# リストの要素を1つずつ取り出して表示
for score in scores:
    print(score, "点")

# 便利な組み込み関数
print("合計:", sum(scores))
print("最高点:", max(scores))
print("最低点:", min(scores))
print("小さい順:", sorted(scores))
実行結果 
80 点
65 点
92 点
74 点
88 点
合計: 399
最高点: 92
最低点: 65
小さい順: [65, 74, 80, 88, 92]

sorted(scores) は並べ替えた新しいリストを返すだけで、元の scores は変わりません。一方、scores.sort() は元のリスト自体を並べ替えます。この違いはよく混同されるので注意しましょう。また、一部分だけを取り出すスライスや、値が含まれるか調べる in 演算子も便利です。

list_slice.py 
scores = [80, 65, 92, 74, 88]

# スライス：インデックス1以上3未満を取り出す
print(scores[1:3])

# 先頭3件、末尾2件
print(scores[:3])
print(scores[-2:])

# 92 が含まれているか調べる
print(92 in scores)

スライスの覚え方

scores[開始:終了] は「開始のインデックスから、終了のインデックスの1つ手前まで」を取り出します。scores[1:3] ならインデックス1と2（3は含まない）です。開始や終了を省略すると、それぞれ「先頭から」「末尾まで」になります。

8.4 タプルとリスト内包表記の入口

タプルはリストとよく似ていますが、一度作ったら中身を変更できません。タプルは値をカンマ（,）で区切って作り、読みやすさのために丸括弧 () で囲んで書くのが一般的です。「緯度と経度」「年月日」のように、あとから書き換えたくない・書き換えるべきでない組み合わせを表すのに向いています。

tuple_basic.py 
# タプルはカンマ区切りで作る（丸括弧で囲むのが一般的・変更不可）
point = (35.68, 139.77)
print("緯度:", point[0], "経度:", point[1])

# アンパックして複数の変数へ一度に代入
lat, lon = point
print(f"lat={lat}, lon={lon}")

# 変更しようとするとエラーになる（実行するとTypeError）
# point[0] = 0.0

lat, lon = point のように、タプル（やリスト）の要素をまとめて複数の変数に代入することをアンパック代入と呼びます。値を交換したいときにも a, b = b, a のように使えます（右辺の b, a も、丸括弧を省略したタプルです）。

タプルを作っているのは「カンマ」

point = 35.68, 139.77 のように丸括弧を省略しても、タプルになります。逆に、要素が1つだけのときは注意が必要です。(35.68) はただの数値（float）を丸括弧で囲んだだけなので、タプルにするには (35.68,) のように末尾にカンマを付けます。

最後に、リストを作る少し発展的な書き方も紹介します。リスト内包表記は、for 文で新しいリストを組み立てる処理を1行で書ける記法です。今すぐ使いこなす必要はありませんが、他の人のコードでよく見かけるので、読めるようにしておきましょう。

comprehension.py 
scores = [80, 65, 92, 74, 88]

# 通常のfor文で「10点加算したリスト」を作る場合
bonus_scores = []
for score in scores:
    bonus_scores.append(score + 10)

# リスト内包表記なら1行で書ける（同じ結果）
bonus_scores2 = [score + 10 for score in scores]

print(bonus_scores2)
項目 リスト タプル
作り方 [1, 2, 3] (1, 2, 3)（要素が1つなら (1,)）
変更 できる（追加・削除・書き換え） できない
向いている用途 増減する一覧（買い物リスト、記録の一覧） 意味の決まった組み合わせ（座標、日付）

重要ポイント

迷ったらリストを使えば大丈夫です。要素の追加・削除がある場合や、どちらか分からない場合はリストを選びましょう。タプルは「変更されたら困るデータ」を扱うときに選ぶ、という感覚で覚えておけば十分です。

やってみよう 8-1: テストの点数リストから平均点・最高点を求める

python-study/ch08 フォルダを作り、average.py というファイルを作成しましょう。

手順

  1. 1 5人分のテストの点数をリスト scores に入れる（自分で好きな点数を決めてよい）。
  2. 2 sum() と len() を使って平均点を計算し、f文字列で「平均点: 〇〇点」と表示する。
  3. 3 max() を使って最高点を表示し、for 文で「合格ライン（60点）以上の人数」も数えて表示する。

余裕があれば、sorted(scores, reverse=True) を使って点数の高い順に並べ替えて表示してみましょう（reverse=True で降順になります）。

理解度確認クイズ

  1. Q1. fruits = ["りんご", "みかん", "ぶどう"] のとき、fruits[1] の値は何ですか？

    回答を表示

    "みかん" です。リストのインデックスは0から始まるため、fruits[0] が "りんご"、fruits[1] が "みかん"、fruits[2] が "ぶどう" になります。

  2. Q2. sorted(scores) と scores.sort() の違いを説明してください。

    回答を表示

    sorted(scores) は並べ替えた新しいリストを返すだけで、元の scores は変わりません。一方 scores.sort() は元のリスト自体を並べ替えます（戻り値は None）。

  3. Q3. リストとタプルの一番大きな違いは何ですか。また、それぞれどんな場面で使うと良いですか。

    回答を表示

    リストは作成後も要素の追加・削除・書き換えができますが、タプルはできません。買い物リストや記録の一覧のように増減するデータにはリストを、座標や日付のように変更されては困る決まった組み合わせにはタプルを使います。迷った場合はリストを選べば十分です。
