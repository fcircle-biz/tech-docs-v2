プログラミングとPythonを知ろう

プログラミングとは何か、Python がどんな言語で、どんな場面で活躍しているのかを、身近な例を使って説明します。この章ではまだ環境の準備はしません。コードを書く前に「プログラムとは何をするものなのか」「Python で書いたプログラムはどうやって動くのか」という全体像をつかみましょう。

この章で学ぶこと

  • プログラミングとは何かを、自分の言葉で説明できる
  • Python の特徴（読みやすさ・インデント・豊富なライブラリ）を理解する
  • Python が活躍している分野を具体例とともに知る
  • Python のプログラムが「インタプリタ」によって実行される仕組みをイメージできる

1.1 プログラミングとは何か

プログラミングとは、ひとことで言えば「コンピュータに、やってほしい仕事の手順を順番どおりに教えること」です。コンピュータはとても速く正確に計算できますが、自分で考えて動くことはできません。「何を」「どんな順番で」やればよいかを、人間が細かく指示する必要があります。この指示書をプログラム、指示を書くための言葉をプログラミング言語と呼びます。

料理のレシピを思い浮かべてください。「材料を切る → 炒める → 味付けする」と手順が順番に書かれていて、そのとおりに進めれば誰が作っても同じ料理ができあがります。プログラムもこれと同じで、コンピュータは書かれた手順を上から順番に実行していきます。

手順を書く

「何を、どの順番で」を1つずつ指示します。あいまいな指示ではうまく動きません。

正確で高速

同じ作業を何千回でも、疲れず正確に繰り返してくれます。

書いたとおりに動く

良くも悪くも、書いたとおりに動きます。だから手順を正しく書くことが大切です。

用語: 「コード」と「プログラム」

プログラミング言語で書いた文章をコード（ソースコード）と呼びます。ひとまとまりの仕事をするコードの集まりがプログラムです。「コードを書く＝プログラムを作る」とイメージしておけば大丈夫です。

1.2 Python とはどんな言語か

Python（パイソン）は、1991年にオランダのプログラマー、グイド・ヴァンロッサムが公開したプログラミング言語です。「誰が読んでも分かりやすいコード」を大切にして設計されており、初心者が最初に学ぶ言語として、また現場のプロが毎日使う言語として、世界中で広く使われています。無料で使え、Windows・macOS・Linux のどれでも動きます。

実際のコードを見てみましょう。まだ書き方を覚える必要はありません。「英語の文章に近くて、なんとなく意味が読める」ことを感じてください。

sample.py 
# 買い物の金額リスト
prices = [120, 980, 450]

# 合計を計算して表示する
total = sum(prices)
print("合計:", total, "円")

# 1000円を超えたらメッセージを出す
if total > 1000:
    print("予算オーバーです")
実行結果 
合計: 1550 円
予算オーバーです

sum（合計）、print（表示する）、if（もし〜なら）と、単語の意味から処理の内容がおおよそ想像できます。Python の主な特徴を整理すると、次のようになります。

特徴 内容 初心者にとってのうれしさ
読みやすい文法 記号が少なく、英語に近い書き方 書き方を覚える負担が小さい
インデントで構造を表す 行頭の字下げ（スペース4つ）で処理のまとまりを表す 誰が書いても見た目がそろい、読みやすい
豊富なライブラリ 便利な機能の部品集が大量に公開されている 難しい処理も部品を借りて短く書ける
すぐに試せる 書いたコードを1行ずつその場で実行できる 「動かしながら学ぶ」ことができる

豆知識: 名前の由来と「Python 3」

名前はヘビのニシキヘビではなく、作者が好きだったイギリスのコメディ番組に由来します。また、Python には古い「Python 2」と現在の「Python 3」があり、書き方が一部異なります。Python 2 はすでにサポートが終了しているため、本ガイドでは Python 3（3.12 以降）を使います。インターネットで調べものをするときも、Python 3 向けの情報かどうかを確認しましょう。

1.3 Python でできること

Python は「何でも屋」と言われるほど、幅広い分野で使われています。代表的な使い道を見てみましょう。

  • 業務の自動化 — 毎月のファイル整理、Excel の集計、定型メールの作成などを自動で行う
  • データ分析 — 売上データを集計してグラフにする、アンケート結果の傾向を調べる
  • Web アプリ開発 — Django や Flask を使って Web サービスの裏側（サーバー）を作る
  • AI・機械学習 — 画像認識や需要予測、生成AI を使ったアプリの開発

ほかの言語と比べると、Python の立ち位置がよく分かります。

言語 主な活躍の場 ひとこと
Python 自動化・データ分析・AI・Web サーバー 短いコードで幅広い仕事をこなせる
JavaScript Web ページの動き（ブラウザ） 画面を動かすならこの言語
Java 大規模な業務システム・Android 厳密なルールで大きなシステムを堅く作る

本ガイドの最後（第15〜16章）では、基礎を組み合わせて、支出を記録・保存・集計できる「家計簿アプリ」を作ります。今は難しそうに見えても、1章ずつ積み上げれば必ず作れるようになります。

重要ポイント

どの分野に進む場合でも、土台になるのは変数・条件分岐・繰り返し・関数・データの扱い方といった基礎文法です。本ガイドで学ぶ内容は、データ分析にも Web 開発にも AI にもそのまま通用します。

1.4 Python のプログラムが動く仕組み

コンピュータが直接理解できるのは、0 と 1 の並びでできた機械語だけです。人間が書いた Python のコードをそのまま理解することはできません。そこで間に入るのが、Python インタプリタというソフトウェアです。第2章でインストールする「Python」の正体は、このインタプリタです。

インタプリタは、コードを上から1行ずつ読み取り、その場でコンピュータへの命令に置き換えて実行します。通訳者が話を聞きながら順に訳していく様子に似ています。

flowchart LR A["ソースコード
sample.py"] --> B["Python インタプリタ
1行ずつ読んで解釈"] B --> C["コンピュータが実行"] C --> D["実行結果
合計: 1550 円"] B -.->|書き間違いがあると| E["エラーメッセージ
何行目の何が問題か"]

インタプリタにコードを渡す方法は2つあります。第3章で実際に両方を試します。

対話モード

1行入力するたびに、すぐ結果が返ってきます。電卓のように少しだけ試したいときに便利です。

スクリプトファイル

コードを .py ファイルに保存し、まとめて実行します。何度でも同じ処理を繰り返し実行できます。

学習のコツ

各章には「やってみよう」（実習）と「理解度確認クイズ」があります。読むだけでなく、必ず自分の手でコードを書いて動かしてみましょう。エラーが出ても大丈夫です。上の図のとおり、エラーメッセージは「どこを直せばよいか」を教えてくれるヒントです。

やってみよう 1-1: 自動化したい作業を書き出す

コードを書く前に、「Python で何をしたいか」を考えてみましょう。目的がはっきりしていると、学習の意欲が続きやすくなります。

手順

  1. 1 仕事や生活の中で「毎回同じ手順でやっている作業」を3つ書き出す（例: 毎月の家計の集計、ファイル名の一括変更）。
  2. 2 そのうち1つを選び、作業の手順をレシピのように「1. 〜する、2. 〜する」と箇条書きにする。
  3. 3 手順の中に「もし〜なら」（条件）や「〜の数だけ繰り返す」（繰り返し）が含まれていないか探してみる。

手順3で見つけた「条件」と「繰り返し」は、第6章・第7章で Python の書き方を学びます。書き出したメモは取っておきましょう。

理解度確認クイズ

  1. Q1. プログラミングとは何かを、料理にたとえて説明してください。

    回答を表示

    プログラミングは、料理のレシピのように「やってほしい仕事の手順を、順番どおりにコンピュータへ教えること」です。コンピュータはレシピ（プログラム）のとおりに上から順番に実行します。

  2. Q2. Python で「処理のまとまり」を表すために使うものは何ですか？

    回答を表示

    行頭の字下げ（インデント）です。一般にスペース4つを使います。1.2 のサンプルでは、if の下の print("予算オーバーです") が字下げされていて、「条件に当てはまるときだけ実行する処理」であることを表しています。

  3. Q3. Python インタプリタはどんな役割をするソフトウェアですか？

    回答を表示

    人間が書いた Python のコードを上から1行ずつ読み取り、コンピュータが実行できる命令に置き換えて実行するソフトウェアです。書き間違いがあれば、エラーメッセージで問題の場所を知らせてくれます。
