名前でデータを管理しよう（辞書と集合）

第8章のリストは「順番」でデータを管理しました。この章では「名前（キー）」でデータを管理する辞書と、重複を許さない集合を学びます。辞書はリストと組み合わせることで、支出記録のような「表データ」を表せるようになり、家計簿アプリ（第15〜16章）の土台になります。

この章で学ぶこと

  • 辞書（dict）を作成し、キーで値を参照・追加・更新・削除できる
  • KeyError の原因を理解し、get() で安全に値を取り出せる
  • keys()・values()・items() で辞書を for 文で回せる
  • 集合（set）で重複を取り除き、リストと辞書を組み合わせて表データを扱える

9.1 辞書の基本

リストは「0番目、1番目…」という順番（インデックス）で要素を管理しました。一方、辞書（dict）は「名前」で値を管理するデータ型です。国語辞典で「単語（キー）」から「意味（値）」を引くのと同じ仕組みなので、この名前が付いています。1件の情報を、複数の項目名とセットでまとめたいときに便利です。

dict_basic.py 
# 支出記録を1件、辞書で表す
record = {"date": "2026-04-01", "category": "食費", "amount": 850}

print(record["category"])   # キーで値を参照
record["memo"] = "昼食"     # 新しいキーを追加
record["amount"] = 900      # 既存のキーの値を更新
del record["memo"]          # キーを削除

print(record)
実行結果 
食費
{'date': '2026-04-01', 'category': '食費', 'amount': 900}

辞書は{"キー": 値, "キー": 値, ...}のように波かっこ {} で作ります。キーと値の組み合わせを要素（アイテム）と呼び、キーには文字列や数値、値にはどんなデータ型でも使えます。存在しないキーで参照するとKeyErrorという例外が発生します。

操作 書き方 説明
参照 record["category"] キーが無いと KeyError
安全な参照 record.get("memo") 無ければ None を返す
追加・更新 record["key"] = 値 無ければ追加、あれば上書き
削除 del record["key"] キーごと要素を削除
件数 len(record) 要素（キーの数）を数える

よくあるエラー: KeyError

存在しないキーで record["memo"] のように参照すると KeyError: 'memo' が発生します。「そのキーがあるか分からない」場面では、次の get() を使うと安全です。

get() メソッドを使うと、キーが無くてもエラーにならず、代わりに指定した既定値（省略するとNone）を返します。

dict_get.py 
record = {"date": "2026-04-01", "category": "食費", "amount": 850}

# メモがあれば表示、無ければ「なし」と表示する
memo = record.get("memo", "なし")
print("メモ:", memo)

9.2 辞書のループ

辞書の中身をまとめて処理したいときは、for 文と組み合わせます。目的に応じてkeys()（キーだけ）・values()（値だけ）・items()（キーと値の両方）を使い分けます。

dict_loop.py 
record = {"date": "2026-04-01", "category": "食費", "amount": 850}

for key in record.keys():          # キーだけを順に取り出す
    print(key)

for value in record.values():      # 値だけを順に取り出す
    print(value)

for key, value in record.items():  # キーと値をセットで取り出す
    print(f"{key}: {value}")
実行結果（抜粋） 
date: 2026-04-01
category: 食費
amount: 850

用語: アンパック代入

items() を for 文で回すと、キーと値が (key, value) の組（タプル）として1組ずつ順番に取り出されます。for key, value in record.items(): のように、その1つのタプルを key と value の2つの変数に同時に受け取る書き方を、第8章で学んだアンパック代入と呼びます。なお、items() が返すのはリストではなく、辞書の中身をのぞき見るビューと呼ばれるオブジェクトです（print() すると dict_items([...]) と表示されます）。for 文で回して使う分には、この違いを気にする必要はありません。

なお for key in record: のように keys() を省略しても、キーが1つずつ取り出されます。record.keys()と書いた方が「キーを回している」ことが読み手に伝わりやすいため、本ガイドでは明示的に書きます。

9.3 集合

集合（set）は、重複を許さないデータの集まりです。リストに含まれる「種類」だけを知りたいとき（例: 支出記録に登場したカテゴリの一覧）に向いています。順番は保証されません。

set_basic.py 
# カテゴリのリストから重複を取り除く
categories = ["食費", "交通費", "食費", "娯楽費", "交通費"]
unique_categories = set(categories)
print(unique_categories)

unique_categories.add("光熱費")  # 要素を1つ追加
print(len(unique_categories))
実行結果 
{'食費', '交通費', '娯楽費'}
4

集合は順番を持たないため、1行目の {...} の中の並び順は、実行するたびに変わることがあります（中身の3種類は同じです）。

集合どうしは、数学の集合と同じように和集合（どちらかに含まれる要素）や積集合（両方に共通する要素）を求められます。

set_operation.py 
this_month = {"食費", "交通費", "娯楽費"}
last_month = {"食費", "交通費", "光熱費"}

print(this_month | last_month)  # 和集合（どちらかにある）
print(this_month & last_month)  # 積集合（両方にある）

和集合 |

2つの集合のうち、どちらか一方にでも含まれる要素をすべて集めます。

積集合 &

2つの集合の両方に共通して含まれる要素だけを集めます。

9.4 リストと辞書の組み合わせ

辞書1つは「1件のデータ」を表せます。この辞書をリストに並べると、Excel の表のような「複数件のデータ」を表せます。この形を辞書のリストと呼び、本ガイドの家計簿アプリ（第15〜16章）でも支出記録をこの形で扱います。

辞書"] B["1番目
辞書"] C["2番目
辞書"] end A --> A1["date: 2026-04-01
category: 食費
amount: 850"] B --> B1["date: 2026-04-02

list_of_dict.py 
# 支出記録を「辞書のリスト」で表す
records = [
    {"date": "2026-04-01", "category": "食費", "amount": 850},
    {"date": "2026-04-02", "category": "交通費", "amount": 420},
    {"date": "2026-04-03", "category": "食費", "amount": 1200},
]

# 1件ずつ取り出して表示する
for record in records:
    print(record["date"], record["category"], record["amount"])
実行結果 
2026-04-01 食費 850
2026-04-02 交通費 420
2026-04-03 食費 1200

recordsはリスト、その中身1つ1つ（record）は辞書です。「1件のデータ＝辞書」「複数件＝辞書のリスト」という形は、CSV ファイル（第12章）やカテゴリ別の集計にもそのまま使えます。

重要ポイント

「辞書のキーごとに合計する」処理は、カテゴリ別集計の基本形です。空の辞書 totals = {} を用意し、records を for で回しながら totals[category] = totals.get(category, 0) + amount のように積み上げていく書き方を、第16章のカテゴリ別集計であらためて使います。今はこの「積み上げていく」感覚を覚えておきましょう。

やってみよう 9-1: 単語の出現回数を数える

ch09/word_count.pyを作成し、文章に含まれる単語の出現回数を辞書で数えてみましょう。

手順

  1. 1 words = ["python", "java", "python", "c", "java", "python"] というリストを用意する。
  2. 2 空の辞書 counts = {} を用意し、words を for 文で回す。
  3. 3 各単語について counts[word] = counts.get(word, 0) + 1 で出現回数を積み上げる。
  4. 4 counts.items() を for 文で回し、「単語: 回数」の形で全件表示する。

この「積み上げる」パターンは、9.4 で予告したカテゴリ別集計と同じ仕組みです。

理解度確認クイズ

  1. Q1. 辞書に存在しないキーで record["memo"] のように参照すると何が起きますか。また、エラーにせず安全に取り出すにはどうすればよいですか。

    回答を表示

    KeyErrorが発生します。record.get("memo", "なし")のように get() メソッドを使うと、キーが無い場合はエラーにならず、指定した既定値（省略時は None）が返ります。

  2. Q2. 辞書 record の「キーと値」を両方一度に取り出して for 文で回すには、どのメソッドを使いますか。

    回答を表示

    items()メソッドです。for key, value in record.items():のように書くと、キーと値をタプルとして1組ずつ受け取れます。キーだけなら keys()、値だけなら values() を使います。

  3. Q3. リストとは違い、集合（set）にはどんな特徴がありますか。カテゴリの一覧を求める場合にどう役立つか説明してください。

    回答を表示

    集合は重複を許さず、順番も保証しません。支出記録のカテゴリのリストを set() に渡すだけで、「食費」「食費」のような重複が自動的に取り除かれ、登場したカテゴリの種類だけを簡単に取り出せます。
