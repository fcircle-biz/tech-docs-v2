ホーム HTML 第2章
第2章 所要時間: 約35分

環境の準備と最初のページ

この章では、HTML を書くための環境を実際に整え、はじめての HTML ファイルをブラウザに表示させます。必要なのはエディタとブラウザだけ。難しい設定は一切ありません。手を動かして、「編集して → 保存して → 画面で確認する」という HTML学習の基本サイクルを体に覚え込ませましょう。

この章で学ぶこと

  • HTML学習に何が必要で、何が不要かを説明できる
  • Visual Studio Code をインストールし、日本語化できる
  • 学習用フォルダを作り、正しいファイル名の付け方が分かる
  • index.html を作成し、ブラウザに「Hello HTML」を表示できる

2.1 必要なものはエディタとブラウザだけ

第1章で学んだとおり、HTML の中身はただの文字（テキスト）です。そのため、HTML を書くために高価なソフトや専門的な開発環境は一切必要ありません。用意するものは、たった2つだけです。

① テキストエディタ

HTML を書くためのソフト。Windows の「メモ帳」でも書けますが、この教材では無料で高機能な Visual Studio Code（通称 VS Code）を使います。

② Webブラウザ

書いた HTML を表示して確認するためのソフト。Google Chrome を推奨しますが、Edge・Firefox・Safari でも問題なく学習できます。

逆に言えば、以下のものは学習段階では不要です。混同しやすいので、あらかじめ整理しておきましょう。

誤解されがちなもの 実際のところ
Webサーバー 第1章のとおり、自分の PC でファイルを開くだけで表示を確認できるため不要
有料の開発ソフト VS Code をはじめ、HTML学習に必要なツールはすべて無料で入手できる
インターネット接続（作業中） 作成した HTMLファイルはローカル（PC内）に保存され、オフラインでも表示・編集できる

なぜ VS Code を使うのか

メモ帳でも HTML は書けますが、VS Code にはタグの色分け表示（シンタックスハイライト）や入力補完、あとで紹介する拡張機能など、学習効率を大きく上げる機能が揃っています。Microsoft が無料で提供しており、プロの現場でも広く使われている定番のエディタです。

2.2 Visual Studio Code のインストールと日本語化

それでは実際に VS Code を導入しましょう。手順は Windows・Mac ともにほとんど同じです。

  1. 1 公式サイト code.visualstudio.com にアクセスする。
  2. 2 大きく表示された「Download」ボタンをクリックし、自分の OS（Windows／Mac）向けのインストーラーをダウンロードする。
  3. 3 ダウンロードしたファイルを実行し、表示される案内に沿って「次へ」を選び続けてインストールする（設定はすべて初期値のままでよい）。
  4. 4 インストール後、VS Code を起動する。英語のメニューが表示されれば成功。

起動直後は画面表示が英語です。次に、日本語で使えるように設定します。

用語: 拡張機能（エクステンション）とは

VS Code 本体はシンプルな作りですが、「拡張機能」という追加パーツを入れることで、言語対応や便利な機能をあとから足していけます。スマートフォンにアプリを追加する感覚に近いものだと考えてください。

2.3 便利な拡張機能（Live Server など）

日本語化に続けて、HTML学習をぐっと快適にしてくれる拡張機能を1つ入れておきましょう。特におすすめなのが Live Server です。Live Server は簡易的なWebサーバーを自動で立ち上げてくれる拡張機能で、2.1 で説明したとおり自分でサーバーを構築する必要はありません。

Live Server なしの場合

HTMLファイルを保存するたびに、ブラウザに戻って手動で再読み込み（F5キーなど）する必要があります。

Live Server ありの場合

保存した瞬間にブラウザが自動で再読み込みされます。編集内容をすぐ画面で確認でき、学習のテンポが大きく上がります。

インストール手順

  1. 1 VS Code 左側の拡張機能アイコンをクリックする。
  2. 2 検索欄に「Live Server」と入力する（作者: Ritwick Dey のものを選ぶ）。
  3. 3 Install ボタンを押してインストールする。

使い方は、HTMLファイルを開いた状態でエディタ上を右クリックし「Open with Live Server」を選ぶだけです。実際の使い方は 2.5 節で体験します。

重要ポイント

Live Server は「なくても学習できるが、あると効率が上がる」補助ツールです。まずは日本語化だけ済ませて先に進んでも問題ありません。この教材では以後、Live Server を使う前提で「保存すれば画面に反映される」ものとして説明します。

2.4 学習用フォルダの作り方とファイル名の付け方

コードを書き始める前に、作業用のフォルダを1つ作っておきましょう。デスクトップなど分かりやすい場所に、html-lesson のようなフォルダを作成します。以後、この教材で作るファイルはすべてこのフォルダにまとめていきます。

この章で作る構成 

html-lesson/          ← 学習用フォルダ（好きな場所に作成）
└── index.html      ← この章でこれから作るファイル

ファイル名を付けるときは、次のルールを守ってください。Web の世界共通のお作法です。

良い例 避けたい例 理由
index.html 自己紹介.html 日本語ファイル名は環境によって文字化けやエラーの原因になる
profile-page.html profile page.html 半角スペースは URL 上で正しく扱われないことがある
about.html About.HTML 大文字・小文字を区別するサーバーもあり、混在するとリンク切れの原因になる

まとめると、半角の英数字・ハイフン（-）・アンダースコア（_）だけを使い、すべて小文字にするのが安全な付け方です。そして第1章の豆知識で触れたとおり、トップページには index.html という特別な名前を使います。

Windows・Mac 共通の注意: 拡張子が見えない場合がある

Windows は初期設定で拡張子（.html の部分）を非表示にしていることがあります。この状態だと index.html.txt のように誤った拡張子で保存してしまう事故が起きがちです。Windows 10 はエクスプローラーの「表示」タブから、Windows 11 はエクスプローラーの「表示」メニュー→「表示」→「ファイル名拡張子」から、それぞれチェックを入れて拡張子を常に表示する設定にしておきましょう。Mac も既定では拡張子が隠れることがあります。Finder メニュー→「設定」→「詳細」→「すべてのファイル名拡張子を表示」にチェックを入れてください。

2.5 最初のページを作る: Hello HTML

準備が整いました。いよいよ最初の HTMLファイルを作成し、ブラウザに文字を表示させてみましょう。難しいことは何もありません。次の手順どおりに進めてください。

  1. 1 VS Code のメニューから「ファイル」→「フォルダーを開く」を選び、先ほど作った html-lesson フォルダを開く。
  2. 2 左側のエクスプローラー欄で「新しいファイル」アイコンをクリックし、ファイル名に index.html と入力する。
  3. 3 エディタ画面に、下記のコードをそのまま入力する。
  4. 4 キーボードの Ctrl + S（Mac は Command + S）で保存する。
index.html 
<h1>Hello HTML</h1>
<p>はじめての HTML ページです。</p>

保存できたら、ブラウザで確認します。方法は2通りあります。

方法A: ダブルクリックで開く

フォルダの中の index.html を、パソコンのファイル一覧からダブルクリックする。既定のブラウザで開きます。

方法B: Live Server で開く

VS Code のエディタ上で右クリック →「Open with Live Server」を選ぶ。以後は保存するだけで自動更新されます。

画面に「Hello HTML」という大きな見出しと、その下に説明文が表示されれば成功です。あなたが書いた最初の HTMLファイルが、ブラウザによって画面に組み立てられました。

ここからが本番です。試しに Hello HTML の文字を好きな言葉に書き換えて、保存してみましょう。Live Server を使っていれば、保存した瞬間にブラウザの表示が切り替わります。使っていない場合は、ブラウザの再読み込みボタン（またはF5キー）を押してください。

HTML を編集する"] --> B["② 保存する
（Ctrl+S）"] B --> C["③ ブラウザで

この「編集 → 保存 → 確認」というサイクルこそ、HTML を学ぶうえでの基本動作です。次章以降、新しいタグを学ぶたびにこのサイクルを繰り返しながら、少しずつページを作り込んでいきます。

画面が変わらないときは

保存を忘れている（VS Code のタブに丸い印が付いていないか確認）、または開いているファイルが違うことがよくある原因です。ブラウザのアドレスバーに表示されているファイルパスが、編集しているファイルと一致しているかも確認してみましょう。

やってみよう 2-1: 自己紹介の1行を追加しよう

作成した index.html に、自分についての1行を追加して表示してみましょう。編集→保存→確認のサイクルを体で覚えることが目的です。

手順

  1. 1 index.html の2行目のあとに、<p>好きな食べ物はカレーです。</p> のように、好きなことを書いた1行を追加する。
  2. 2 ファイルを保存する（Ctrl+S）。
  3. 3 ブラウザを確認し、追加した文章が新しい段落として表示されていることを確かめる。
  4. 4 慣れてきたら、見出しの文字も自分の名前に書き換えて、同じサイクルをもう一度試してみる。

タグの意味はまだ完全に分からなくて大丈夫です。「タグで囲むと段落や見出しになる」という感覚を、実際に手を動かしてつかむことがこの章のゴールです。

理解度確認クイズ

  1. Q1. HTML の学習を始めるにあたって、最低限用意すべきソフトを2つ挙げてください。

    回答を表示

    テキストエディタ（この教材では Visual Studio Code）と、Webブラウザ（Google Chrome など）の2つです。Webサーバーや有料ソフトは学習段階では不要です。

  2. Q2. Live Server 拡張機能を使うと、使わない場合と比べて何が便利になりますか？

    回答を表示

    HTMLファイルを保存すると、ブラウザが自動的に再読み込みされます。手動でブラウザに切り替えて更新する手間がなくなり、編集結果をすぐに確認できます。

  3. Q3. HTMLファイルの名前を付けるとき、避けるべき文字にはどのようなものがありますか。理由もあわせて答えてください。

    回答を表示

    日本語や半角スペース、大文字・小文字の混在は避けるべきです。環境によって文字化けしたり、URL上で正しく扱われなかったり、リンク切れの原因になったりするためです。半角の英数字・ハイフン・アンダースコアを使い、すべて小文字にするのが安全です。

  4. Q4. HTML学習の基本サイクルを、3つの動作で説明してください。

    回答を表示

    「編集する → 保存する → ブラウザで確認する」の3ステップです。このサイクルを繰り返しながら、少しずつページを作り込んでいきます。
