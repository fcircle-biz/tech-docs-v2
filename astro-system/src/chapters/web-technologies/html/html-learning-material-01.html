HTMLとは

HTML（エイチティーエムエル）は、「タグ」と呼ばれる印を文章に付けることで、Webページの構造をコンピュータに伝えるための言語です。この章では、HTML が何なのか、Webページが画面に表示されるまでに何が起きているのか、そして HTML・CSS・JavaScript がどう役割分担しているのか、という全体像をつかみます。

この章で学ぶこと

  • HTML とは何かを自分の言葉で説明できる
  • Webページがブラウザに表示されるまでの流れが分かる
  • HTML・CSS・JavaScript の役割分担を説明できる
  • HTML の歴史と、現在の標準（HTML Living Standard）を知る

1.1 HTML とは何か

HTML は HyperText Markup Language（ハイパーテキスト・マークアップ・ランゲージ）の略で、Webページを作るための言語です。世界中のあらゆるWebサイト — 検索エンジンも、ニュースサイトも、ネットショップも — その土台はすべて HTML でできています。

HTML の役割は、ふつうの文章に <h1> や <p> といったタグという印を付けて、「ここは大見出し」「ここは段落」「ここは画像」と意味（構造）をコンピュータに伝えることです。このように文章に印を付けて構造を表す言語をマークアップ言語と呼びます。HTML はその代表格です。

名前の先頭にある「ハイパーテキスト」とは、文書どうしをリンクでつなげる仕組みのことです。ページ内の文字をクリックすると別のページへ飛べる、あの当たり前の体験こそが HTML の出発点でした。世界中の文書が互いにリンクでつながり、巨大な網（Web＝クモの巣）になっている — これが World Wide Web です。

タグで意味を付ける

文章を囲むだけで「見出し」「段落」「リスト」といった役割を表現できます。覚える基本タグは十数個ほどです。

ただのテキストファイル

中身は文字だけ。専用の高価なソフトは不要で、メモ帳とブラウザさえあれば今日から書き始められます。

どこでも動く共通語

Windows でも Mac でもスマホでも、ブラウザさえあれば同じページが表示されます。Webの世界の共通語です。

用語: HTML は「プログラミング言語」ではない

HTML には「計算する」「条件で分岐する」といった命令がありません。あくまで文書の構造を記述するための言語です。そのため、プログラミングが初めての人でも取り組みやすく、Web学習の第一歩として最適とされています。「難しそう」と身構える必要はまったくありません。

1.2 書いたもの と 表示されるもの

まずは一目で分かる例を見てみましょう。左があなたが書く HTML、右がそれをブラウザで開いたときの表示イメージです。タグで囲まれた部分が、それぞれ「大きな見出し」「段落」「箇条書き」に変身していることに注目してください。

書いた HTML

profile.html 
<h1>自己紹介</h1>

<p>こんにちは！ <strong>山田 太郎</strong> です。</p>

<h2>好きなもの</h2>

<ul>
  <li>コーヒー</li>
  <li>読書</li>
  <li>プログラミング</li>
</ul>

ブラウザでの表示イメージ

自己紹介

こんにちは！ 山田 太郎 です。

好きなもの

  • コーヒー
  • 読書
  • プログラミング

書く側は、文章の前後にタグを添えるだけ。それだけで、ブラウザが「見出しは大きく太く」「箇条書きには先頭に点を」と、あらかじめ決められたスタイルで整えて表示してくれます。あなたは「意味」を書き、ブラウザが「見せ方」を担当する — これが HTML の基本的な考え方です。

重要ポイント

HTML のタグは「文字を大きくする命令」ではなく、「ここは見出しですという意味の宣言」です。結果として大きく表示されるだけ、という順番で理解しておくと、この先の学習がとてもスムーズになります。

1.3 Webページが表示されるまでの仕組み

普段なにげなく見ているWebページですが、アドレスを入力してから画面に絵や文字が並ぶまでには、いくつかのステップがあります。おおまかな流れは次のとおりです。

flowchart TD A["あなたがブラウザで
アドレスを入力する"] --> B["Webサーバー（ページを保管しているコンピュータ）に依頼が届く"] B --> C["サーバーが HTMLファイルを送り返す"] C --> D["ブラウザが HTML を読み取り
構造を組み立てる"] D --> E["CSS で見た目を整え
画面に表示する"]

ここで大切なのは、ブラウザに届くのは「文字が並んだ HTMLファイル」だけだという点です。その文字列を解釈して、見出しや画像を配置し、人が読める画面に組み立てているのはブラウザ（Chrome・Edge・Safari など）の仕事です。この解釈のことをレンダリングと呼びます。

なお、学習中は Webサーバーを用意する必要はありません。自分の PC に作った HTMLファイルをダブルクリックしてブラウザで開くだけで、同じように表示を確認できます。第2章では、実際にその手順を体験します。

豆知識: 拡張子は「.html」

HTML で書いたファイルには、名前の末尾に .html という拡張子を付けます（例: index.html）。特に index.html は「そのフォルダの入口のページ」として扱われる特別な名前で、Webサイトのトップページによく使われます。

1.4 HTML・CSS・JavaScript の役割分担

現代のWebページは、3つの技術が協力して作られています。よく「家づくり」にたとえられる関係を押さえておきましょう。

技術 役割 家にたとえると
HTML 構造・意味を決める（見出し・段落・画像・リンク） 柱や壁などの骨組み
CSS 見た目を整える（色・文字サイズ・余白・配置） 壁紙や内装のデザイン
JavaScript 動きを付ける（クリックで開閉・入力チェック・通信） 自動ドアや照明などの設備

骨組みがなければ内装も設備も付けられないのと同じで、すべての土台になるのが HTML です。だからこそ Web学習は HTML から始めるのが王道とされています。この教材では第11章で CSS の入口にも触れ、HTML が実際に「装飾されて」いく様子を体験します。

よくある勘違い

「HTML で文字の色やサイズを指定する」のは、現在では推奨されていません。見た目の指定は CSS の担当です。昔の HTML には <font> のような装飾用タグがありましたが、役割分担を明確にするために廃止されました。古いWebサイトの記事を参考にするときは注意しましょう。

1.5 HTML の歴史と現在の標準

HTML は 1990年代のはじめ、研究者どうしが論文を共有するための仕組みとして誕生しました。その後、Webの普及とともに何度もバージョンアップを重ねています。

  • 1991年ごろ — ティム・バーナーズ＝リー氏が考案。文書をリンクでつなぐ仕組みとして誕生
  • 1997年 HTML 4 — 広く普及。装飾タグも多く、見た目と構造が混ざっていた時代
  • 2014年 HTML5 — 動画・音声の再生や意味を持つタグが追加され、構造と見た目の分離が徹底された
  • 現在 HTML Living Standard — 「バージョン番号を付けず、継続的に更新し続ける」方式へ移行

現在の正式な仕様は HTML Living Standard と呼ばれ、WHATWG という団体が随時更新しています。「HTML5 が最新版」という説明を見かけることもありますが、いま学ぶべきはこの Living Standard に沿った書き方です。とはいえ基本のタグは何十年も変わっていないため、初心者が最初に覚える内容は昔も今もほとんど同じです。安心して学び進めてください。

調べものは MDN が定番

タグの使い方を調べたくなったら、MDN Web Docs（developer.mozilla.org）という技術文書サイトが定番です。日本語版も充実しており、各タグの意味・使用例・注意点が丁寧にまとまっています。検索するときは「mdn」という語を付け足すと、目的のページにたどり着きやすくなります。

やってみよう 1-1: 本物の HTML を覗いてみよう

エディタの準備は第2章で行います。その前に、普段見ているWebページが本当に HTML でできていることを、自分の目で確かめてみましょう。ブラウザだけあればできます。

手順

  1. 1 好きなWebページ（ニュースサイトなど）をブラウザで開く。
  2. 2 ページの何もない場所を右クリックし、「ページのソースを表示」を選ぶ（キーボードなら Ctrl+U、Mac は Option+Command+U）。
  3. 3 表示された文字の中から、<html>・<head>・<body>・<a などのタグを探してみる。
  4. 4 今は意味が分からなくてまったく問題ありません。「見出しや文章がタグで囲まれている」ことだけ確認できれば成功です。

難しそうな文字列がたくさん並んでいても大丈夫。プロが作ったページには CSS や JavaScript も混ざっています。この教材を終えるころには、その中の HTML 部分がしっかり読めるようになります。

理解度確認クイズ

  1. Q1. HTML とはどのようなものか、「タグ」「構造」という言葉を使って説明してください。

    回答を表示

    文章にタグという印を付けることで、「ここは見出し」「ここは段落」といった文書の構造（意味）をコンピュータに伝えるためのマークアップ言語です。Webページの土台となり、ブラウザがそれを解釈して画面に表示します。

  2. Q2. HTML・CSS・JavaScript の役割を、それぞれ一言で説明してください。

    回答を表示

    HTML は「構造・意味」、CSS は「見た目」、JavaScript は「動き」を担当します。家にたとえると、HTML が骨組み、CSS が内装、JavaScript が設備にあたります。すべての土台になるのが HTML です。

  3. Q3. HTMLファイルに付ける一般的な拡張子と、トップページによく使われる特別なファイル名は何ですか？

    回答を表示

    拡張子は .html です。トップページには index.html という名前がよく使われ、フォルダの入口のページとして扱われます。

  4. Q4. 現在の HTML の正式な標準仕様の名前は何ですか？

    回答を表示

    HTML Living Standard です。WHATWG が継続的に更新する方式で、バージョン番号は付きません。「HTML5」はその前の世代の呼び名として広く使われています。
