ホーム HTML 第4章
第4章 所要時間: 約35分

見出しと段落・文字の装飾

前章までで HTML の骨組み（<!DOCTYPE html> や <head>・<body>）を学びました。この章からは、いよいよ <body> の中身、つまり実際に画面に表示される文章を組み立てていきます。見出し・段落・強調といった、文章を書くうえで最もよく使うタグを、その「意味」とあわせてしっかり理解しましょう。

この章で学ぶこと

  • 見出しタグ h1〜h6 の6段階を理解し、1ページに h1 は1つ・レベルを飛ばさないという正しい使い方ができる
  • 段落タグ p と、改行 br・水平線 hr の役割の違いを説明できる
  • 強調タグ strong と em の意味的な違いを理解し、使い分けられる
  • small・mark・del・code・blockquote などのテキスト系タグを、意味に応じて選べる

4.1 見出し（h1〜h6）— 6段階の使い分け

見出しタグには <h1> から <h6> まで6段階あります。数字が小さいほど「大きな見出し（重要度が高い）」、大きいほど「小さな見出し（詳細な区切り）」を表します。ちょうど本の目次のように、大見出し → 中見出し → 小見出しという階層構造を表現するためのタグです。

書いた HTML

headings.html 
<h1>Webサイトのタイトル</h1>
<h2>第1章の見出し</h2>
<h3>1-1 節の見出し</h3>
<h3>1-2 節の見出し</h3>
<h2>第2章の見出し</h2>
<h3>2-1 節の見出し</h3>

ブラウザでの表示イメージ

Webサイトのタイトル

第1章の見出し

1-1 節の見出し

1-2 節の見出し

第2章の見出し

2-1 節の見出し

見た目（文字の大きさ・太さ）は、ブラウザが各レベルにあらかじめ用意している標準スタイルにすぎません。本当に大切なのは「このページの中で、これはどのくらいの重要度・階層の見出しか」という意味を正しく表すことです。

flowchart TD A["h1: ページ全体のタイトル
（1ページに1つだけ）"] --> B["h2: 大きな章・セクション"] B --> C["h3: 章の中の節"] C --> D["h4: 節の中の項"] B --> E["h2: 別の章・セクション"]

守るべき2つのルール

① h1 は原則1ページに1つだけにする（そのページが「何についてのページか」を示す唯一の見出し）。② レベルを飛ばさない（h2 の次にいきなり h4 を使わず、h2 → h3 → h4 と順番に下げる）。文字を大きくしたいだけの理由で見出しレベルを選ぶのは誤りです。

4.2 段落（p）

文章のまとまりには <p>（paragraph＝段落）タグを使います。1つの話題・内容ごとに <p> で囲むのが基本で、ブラウザは段落と段落の間に自動的に余白を入れて表示します。

書いた HTML

paragraph.html 
<p>HTML の学習を始めて4章目です。</p>
<p>だいぶ基本が身についてきました。</p>
<p>この調子で最後まで頑張りましょう。</p>

ブラウザでの表示イメージ

HTML の学習を始めて4章目です。

だいぶ基本が身についてきました。

この調子で最後まで頑張りましょう。

<p> はブロックレベル要素と呼ばれる種類のタグで、常に新しい行から始まり、前後に余白（マージン）を持ちます。第10章で改めて「ブロックレベル要素」と「インライン要素」の違いを整理しますが、今は「段落＝独立した1つの四角いまとまり」とイメージしておけば十分です。

4.3 改行（br）と水平線（hr）

<br>（break＝改行）は、第3章で学んだ空要素（終了タグを持たないタグ）の代表例です。段落の途中で1行だけ改行したいときに使います。<hr>（horizontal rule＝水平線）も空要素で、こちらは話題の区切り（テーマの切り替わり）を意味する横線を表示します。

書いた HTML

address.html 
<p>〒100-0001<br>
東京都千代田区1-1-1<br>
サンプルビル3階</p>

<hr>

<p>ここから先は営業時間のご案内です。</p>

ブラウザでの表示イメージ

〒100-0001
東京都千代田区1-1-1
サンプルビル3階

ここから先は営業時間のご案内です。

よくある勘違い

<br> を連続で並べて段落と段落の間に大きな空白を作る書き方は避けましょう。段落を分けたいなら素直に <p> を分けるべきです。<br> はあくまで「住所」や「詩」のように、意味的に1つのまとまりの中で見た目上の改行位置を示したいときだけに使います。

4.4 強調：strong と em の意味的な違い

文字を太字・斜体にするタグに <strong> と <em> があります。見た目はそれぞれ「太字」「斜体」ですが、HTML の基本姿勢どおり両方とも「見た目」ではなく「意味」を表すタグです。

タグ 見た目 意味
strong 太字 重要性（ここは特に大事、警告、キーワードなど）
em 斜体 強勢（声に出すならそこを強く読む、というニュアンス）

書いた HTML

emphasis.html 
<p><strong>注意：</strong>提出期限は今週の金曜日です。</p>

<p>今日は<em>本当に</em>暑い一日でした。</p>

ブラウザでの表示イメージ

注意：提出期限は今週の金曜日です。

今日は本当に暑い一日でした。

用語: b・i タグとの違い

<b>・<i> というタグもあります。もともとは見た目のためのタグでしたが、現在は「他に適切なタグがない場合」用に意味が付け直されています（<b>: 他に適切な要素がない、慣習的に太字にする語句／<i>: 別の声・専門用語・他言語の語句など）。強調したいときは意味を持つ <strong>・<em> を使いましょう。

4.5 その他のテキスト系タグ

文章の中には、これまでのタグだけでは表現しきれない意味もあります。よく使われる5つのタグを紹介します。

タグ 意味 表示例
small 注釈・免責事項など小さな補足 この価格は税込みです
mark ハイライト（マーカーで印を付けた部分） 検索結果のキーワード強調
del 削除済み・取り消し線 2,000円 1,500円
code プログラムのコードやコマンド npm install
blockquote 他の文書からの引用（ブロック単位） 他サイトの文章を引用するとき

書いた HTML

text-tags.html 
<p>セール価格は<del>2,000円</del>
<mark>1,500円</mark>です。</p>

<blockquote>
  <p>HTML はハイパーテキストを記述する言語です。</p>
</blockquote>

<p>インストールは <code>npm install</code> で行います。</p>

<p><small>※価格は税込みです</small></p>

ブラウザでの表示イメージ

セール価格は2,000円 1,500円です。

HTML はハイパーテキストを記述する言語です。

インストールは npm install で行います。

※価格は税込みです

豆知識: blockquote と引用元

他人の文章を引用するときは <blockquote> を使い、可能であれば引用元を明示するのがマナーです。cite 属性で出典URLを指定したり、近くに出典のリンクを添えたりする方法があります（リンクの書き方は第6章で学びます）。

4.6 見た目ではなく意味でタグを選ぶ／ホワイトスペースの仕組み

ここまでの内容を貫く HTML の基本姿勢をあらためて整理します。それは「文字を大きくしたいから h2」「太くしたいから strong」ではなく、その文章が持つ意味を考えて、当てはまるタグを選ぶということです。見た目を変えたいだけなら、それは第11章で学ぶ CSS の仕事です。

重要ポイント

意味でタグを選ぶと、検索エンジンがページの内容を正しく理解しやすくなり（SEO）、スクリーンリーダーを使う視覚障害のある方にも文章の構造が正しく伝わります（アクセシビリティ）。これは第10章で詳しく学ぶ「セマンティックHTML」という考え方の入り口です。

もう1つ、初心者がつまずきやすいのがホワイトスペース（空白・改行）がまとめられる仕組みです。HTMLファイルの中でどれだけ空白や改行、タブを入れても、ブラウザは連続するそれらをまとめて半角スペース1個にし、さらに行の先頭と末尾にある空白は取り除いて表示します。

書いた HTML

whitespace.html 
<p>
  こんにちは。
  今日もHTMLを
      学びましょう。
</p>

ブラウザでの表示イメージ

こんにちは。 今日もHTMLを 学びましょう。

ソースコードの中で改行やインデントを入れて見やすく書いても、表示結果には影響しません。だからこそ第3章で学んだインデント（字下げ）は、あなた自身がコードを読みやすくするための工夫であり、見た目を変えるためのものではないと分かります。改行の位置を確実に指定したいなら、4.3節で学んだ <br> を使う必要があるのです。

豆知識: 例外の pre タグ

「書いたとおりに空白・改行を表示したい」という場面もあります。そのときは <pre>（preformatted＝整形済みテキスト）タグを使うと、ホワイトスペースがまとめられずそのまま表示されます。この教材のコード例で使われている灰色の枠も、まさにこの <pre> タグで作られています。

やってみよう 4-1: 見出しと文章タグを使ってみよう

第3章で作った index.html を開いて、この章で学んだタグを実際に書き加えてみましょう。

手順

  1. 1 第2章で作った <h1>Hello HTML</h1> を、ページ全体のタイトル（自分の名前など）に書き換える。
  2. 2 その下に <h2> で「自己紹介」という見出しを作り、<p> で2〜3個の段落を書く。
  3. 3 段落の中で、特に伝えたい部分を <strong>、少し強調したい部分を <em> で囲む。
  4. 4 最後に <hr> で区切り、<small> で「最終更新日：〇年〇月」のような注釈を書く。
  5. 5 保存してブラウザで再読み込みし、見出しの大きさや強調の違いが表示に反映されているか確認する。

h1 の次に h3 を使ってしまっていないか、h1 が2つ以上になっていないか、書き終えたら見出しレベルの並びを見直してみましょう。

理解度確認クイズ

  1. Q1. 見出しタグ h1〜h6 を使ううえで守るべき2つのルールは何ですか？

    回答を表示

    ① h1 は1ページに1つだけにする。② 見出しレベルを飛ばさない（h2 の次にいきなり h4 を使わず、順番に階層を下げる）。文字の大きさを変えたいという理由だけで見出しレベルを選んではいけません。

  2. Q2. strong タグと em タグは、それぞれどのような「意味」を表しますか？

    回答を表示

    strong は「重要性」（特に大事、警告など）を表し、太字で表示されます。em は「強勢」（声に出すなら強く読む部分）を表し、斜体で表示されます。どちらも見た目ではなく意味を表すタグです。

  3. Q3. br タグを段落の間の余白づくりのために連続で並べる書き方が推奨されないのはなぜですか？

    回答を表示

    br は「1つのまとまりの中での見た目上の改行位置」を表す意味のタグであり、段落を分ける意味はありません。段落を分けたいなら p タグを分けるべきで、見た目の余白調整のためだけに br を使うのは意味と見た目を混同した誤用です。

  4. Q4. HTMLファイルの中で空白や改行を複数入れても、ブラウザの表示ではどうなりますか？また、書いたとおりに表示させたいときに使うタグは何ですか？

    回答を表示

    連続する空白・改行・タブはまとめられ、半角スペース1個として表示されます（ホワイトスペースの仕組み）。書いたとおりに空白・改行を表示したい場合は pre タグ（整形済みテキスト）を使います。
