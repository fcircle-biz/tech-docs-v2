ホーム CSS 第8章
第8章 所要時間: 約45分

表示（display）と配置（position）

要素は何も指定しなければ、上から下へ積み重なるか、横に並んで折り返すかのどちらかで表示されます。この章では、その並び方を切り替えるdisplay プロパティと、要素を通常の流れから外して自由な位置に配置するposition プロパティを学びます。カードにバッジを重ねたり、ヘッダーを画面に固定したりと、実務で頻繁に使うテクニックの土台になる章です。

この章で学ぶこと

  • display プロパティの4つの値（block／inline／inline-block／none）の違いを説明できる
  • position プロパティの5つの値（static／relative／absolute／fixed／sticky）を使い分けられる
  • top・right・bottom・left の基準がどの要素になるかを説明できる
  • z-index で要素の重なり順をコントロールできる
  • 親要素に relative、子要素に absolute を指定して、バッジのような重ね表示を作れる

8.1 要素の並び方には決まりがある

HTML の要素は、CSS で何も指定しなくても、ブラウザが決まったルールで並べてくれます。この既定の並び方を通常フロー（normal flow）と呼びます。通常フローには大きく分けて2つの並び方があり、要素の種類によってどちらになるかが決まっています。

div・p・h1〜h6 のようなブロックレベル要素は、横幅いっぱいに広がり、前後で必ず改行されて上から下へ積み重なります。一方、span・a・strong のようなインラインレベル要素は、必要な幅だけを取り、文章の一部のように横に並び続けます（幅が足りなくなったところで自動的に折り返します）。

ブロックレベル要素（div など）

要素A
要素B
要素C

横幅いっぱいに広がり、縦に積み重なる

インラインレベル要素（span など）

要素A 要素B 要素C

必要な幅だけ取り、横に並ぶ

この「ブロックか、インラインか」という性質は、実は CSS の display プロパティの初期値によって決まっています。次の節では、この display を自分で指定して、並び方を切り替える方法を見ていきましょう。

8.2 display の基本4種

display プロパティを使うと、要素の既定の並び方を上書きできます。数ある値の中でも、まず覚えておきたいのは次の4つです。

値 幅・高さの指定 改行 使いどころ
block できる 前後で改行され、縦に積み重なる セクションの区切り、見出し、段落
inline できない（無視される） 改行されず横に並ぶ 文中の一部を装飾したいとき
inline-block できる 改行されず横に並ぶ 幅を決めつつ横に並べたいボタンやバッジ
none - 表示されず、場所も消える 一時的に要素を隠したいとき

特に注意したいのは inline の制約です。width や height を指定しても無視され、上下方向の margin も効きません（左右の margin・padding は効きます）。幅を指定したい、かつ横に並べたい、という場合は inline-block を使うのが定石です。

文章で説明すると分かりにくいので、block と inline の違いを図にしてみましょう。

flowchart TD subgraph BlockDemo["display: block（改行して縦に積み重なる）"] direction TB B1["要素A"] --> B2["要素B"] --> B3["要素C"] end subgraph InlineDemo["display: inline（改行せず横に並ぶ）"] direction LR I1["要素A"] --- I2["要素B"] --- I3["要素C"] end

似ているようで違う: display: none と visibility: hidden

どちらも要素を見えなくしますが、display: none は場所そのものが消え、周りの要素が詰めて配置し直されます。一方 visibility: hidden は見えなくなるだけで、場所（スペース）は残ります。「完全に取り除きたいか」「場所だけ確保しておきたいか」で使い分けましょう。

8.3 position の5種

ここまでの並び方（通常フロー）は、position プロパティの初期値 static のときの動作です。position を変更すると、要素を通常の流れから外して、自由な位置に配置できるようになります。値は次の5種類です。

値 動作 元の場所に空間が残るか
static 既定値。通常フロー通りに配置される（top等は無効） -
relative 元の位置を基準に、見た目だけずらせる 残る
absolute 祖先要素を基準に、通常フローから外れて配置 残らない
fixed 画面（ビューポート）を基準に固定し、スクロールしても動かない 残らない
sticky 普段は relative、スクロールで指定位置に達すると fixed のように貼りつく 残る

特によく使うのは relative と absolute の組み合わせです。fixed はヘッダー固定やスクロールトップボタン、sticky は「スクロールすると見出しが上部に貼りつく」ような表現でよく使われます。

8.4 top・right・bottom・left の基準

top・right・bottom・left（オフセットプロパティ）は、position: static 以外のときだけ効果を持ちます。ただし「どこを基準にずらすか」は、position の値によってまったく異なります。

relative の基準

自分自身の元の位置が基準です。top: 10px なら、何もしなかった場合の位置から10px下にずれます。

absolute の基準

直近にある「position指定のある祖先要素」（static以外の祖先）が基準です。見つからない場合はページ全体が基準になります。

fixed は常に画面（ビューポート）そのものが基準になり、sticky はスクロールする祖先要素と指定した閾値が基準になります。

実務での鉄則

absolute を指定した要素は、思ってもみない場所（ページの端など）に飛んでいくことがよくあります。それを防ぐには、基準にしたい親要素に必ず position: relative を指定しておくのが鉄則です。8.7で実際のコードを確認します。

8.5 z-index（重なり順）

position を指定した要素同士は、見た目が重なることがあります。そのときどちらを手前に表示するかを決めるのが z-index です。数値が大きいほど手前に表示されます。指定がない場合は、HTMLに書かれた順序（後に書かれた方が手前）でおおよそ決まります。

z-index: 1
z-index: 2
z-index: 3
style.css 
/* 数値が大きいほど手前に表示される */
.card-back {
  position: relative;
  z-index: 1;
}
.card-front {
  position: relative;
  z-index: 2;
}

z-index が効かないときは

z-index は position が static（既定値）の要素には効きません。「z-indexを指定したのに重なり順が変わらない」ときは、まずその要素に relative や absolute などの position が指定されているか確認しましょう。

8.6 float の位置づけ

float は、もともと「画像の左右に文章を回り込ませる」ための機能です。かつては Flexbox や Grid が存在しなかったため、この float を無理やり応用してページ全体の段組みレイアウトを組む手法が広く使われていた時期がありました。

style.css 
/* 画像を左に回り込ませ、右側に文章を流す */
.thumbnail {
  float: left;
  margin-right: 16px;
}

しかし float でレイアウトを組むと、親要素の高さが崩れる、要素の順序に制約が出るといった副作用が起きやすく、調整に手間がかかります。現在ではページのレイアウトに float を使う必要はほぼありません。次章以降で学ぶ Flexbox・Grid の方が、少ないコードで狙い通りに組めます。float は「画像の回り込み」という本来の用途で使う、と覚えておけば十分です。

8.7 実例: カードに「NEW」バッジを重ねる

ここまで学んだ relative と absolute の組み合わせを使って、よくある「カードの右上にバッジを重ねる」表現を作ってみましょう。親要素に relative、重ねたい子要素に absolute を指定するのが基本パターンです。

index.html 
<!-- カードの中にバッジ用のspanを用意 -->
<div class="card">
  <span class="badge">NEW</span>
  <h3>新商品のお知らせ</h3>
  <p>この秋の新作が登場しました。</p>
</div>
style.css 
/* 親要素：基準点を作るために relative を指定 */
.card {
  position: relative;
  padding: 20px;
}

/* 子要素：親の右上を基準に配置 */
.badge {
  position: absolute;
  top: -10px;
  right: -10px;
  background: #f97316;
  color: #fff;
  padding: 4px 10px;
}

実際に表示すると、次のようにバッジがカードの角からはみ出すように重なります。

NEW

新商品のお知らせ

この秋の新作が登場しました。

.card に position: relative を指定しているからこそ、.badge の top: -10px; right: -10px; が「カードの右上端」を基準に計算されます。もし親に relative の指定を忘れると、バッジはページの右上端まで飛んでいってしまいます。

やってみよう 8-1: ヘッダーを固定し、バッジを重ねてみよう

これまでとは別の練習用HTMLファイルを用意し、position: fixed と position: absolute を実際に手で書いて動かしてみましょう。

手順

  1. 1 新しい practice.html を作り、ページ上部に <header> を、その下に本文用のカードを1つ用意する。
  2. 2 header に position: fixed; top: 0; left: 0; right: 0; を指定する。ページをスクロールしても header が画面上部から動かないことを確認する。
  3. 3 header の高さぶん、body または直後の要素に padding-top を付ける。付けないと本文の先頭が header の下に隠れてしまうことを確認する。
  4. 4 本文のカードに position: relative を指定し、中に「NEW」バッジ用の <span> を追加して position: absolute; top: -10px; right: -10px; でカードの右上に重ねる。

うまく重ならないときは、まず開発者ツールの Elements パネルでバッジ要素を選択し、右側の Computed（計算後のスタイル）タブで position の値が意図通りかを確認してみましょう。

理解度確認クイズ

  1. Q1. display: inline を指定した要素に width や height を指定するとどうなりますか？また、上下方向の margin はどうなりますか？

    回答を表示

    width・height の指定はどちらも無視され、効きません。上下方向の margin も効きません（左右の margin・padding は効きます）。幅や高さを指定したい場合は inline-block か block を使う必要があります。

  2. Q2. display: none と visibility: hidden は、どちらも要素を見えなくしますが、何が違いますか？

    回答を表示

    display: none は要素が占めていた場所ごと消え、周囲の要素が詰めて配置し直されます。visibility: hidden は見えなくなるだけで、元の場所（スペース）はそのまま残ります。

  3. Q3. position: absolute を指定した要素は、何を基準に top や left の位置が決まりますか？

    回答を表示

    直近にある「position指定のある祖先要素（static以外の position を持つ祖先）」が基準になります。該当する祖先がなければページ全体が基準になるため、実務では基準にしたい親要素に position: relative を指定しておくのが定石です。

  4. Q4. z-index を指定しても要素の重なり順が変わらないことがあります。よくある原因は何ですか？

    回答を表示

    z-index は position が static（既定値）の要素には効きません。z-index を効かせたい要素には relative・absolute・fixed・sticky のいずれかの position を指定しておく必要があります。
