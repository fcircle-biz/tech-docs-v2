Flexboxでレイアウト

第8章では「1つの要素をどう配置するか」を扱いました。この章では、複数の要素をまとめて思い通りに並べるための現代的な仕組み、Flexbox（フレックスボックス）を学びます。ナビゲーションメニューやカードの一覧など、実務サイトのほぼすべてで使われている、CSSレイアウトの主役です。

この章で学ぶこと

  • display: flex の基本的な使い方を説明できる
  • 主軸（main axis）と交差軸（cross axis）の違いを理解し、flex-direction で切り替えられる
  • justify-content と align-items で要素を思い通りの位置に揃えられる
  • gap・flex-wrap・flex を使い、ナビゲーションやカード一覧を実際に組める

9.1 Flexbox とは

Flexbox（フレックスボックス）は、要素を「一列に」きれいに並べるための仕組みです。正式名称は Flexible Box Layout（フレキシブル・ボックス・レイアウト）で、名前のとおり「柔軟な箱」を並べるイメージです。第8章までの display や position は要素を1つずつ動かす発想でしたが、Flexbox は親要素に1行指定するだけで、複数の子要素をまとめて整列できる点が大きな違いです。

使い方はシンプルです。並べたい要素を囲む親要素に display: flex; と指定するだけで、中の子要素が自動的に横並びになります。フロートを使った複雑な調整（第8章の float）はもう必要ありません。

nav.html 
<!-- 3つのリンクを持つナビゲーション -->
<nav class="menu">
  <a href="#">ホーム</a>
  <a href="#">サービス</a>
  <a href="#">お問い合わせ</a>
</nav>
style.css 
/* 親要素に指定するだけで子要素が横並びになる */
.menu {
  display: flex;
}

Flexbox には専用の呼び方が2つあります。今後何度も登場するので、ここで押さえておきましょう。

Flexbox は「1次元」のレイアウト

Flexbox が得意なのは、要素を横一列、または縦一列に並べることです（1次元レイアウト）。行と列を同時に扱う碁盤目状のレイアウトは、第10章で学ぶCSS Grid（2次元レイアウト）の出番です。まずは「一列に並べる」感覚に集中しましょう。

9.2 主軸（main axis）と交差軸（cross axis）

Flexbox を理解するうえでもっとも重要な考え方が、この「2つの軸」です。フレックスコンテナには、アイテムが並ぶ向きである主軸（main axis）と、それに直角な交差軸（cross axis）の2つの軸があります。この先の justify-content や align-items は、すべて「どちらの軸に対する指定か」で意味が決まるため、ここでつまずくと後の内容も混乱してしまいます。焦らず押さえましょう。

軸の向きを決めるのは flex-direction プロパティです。既定値は row（横方向）ですが、column にすると縦方向に変わります。

flex-direction主軸の向き交差軸の向き
row（既定）横方向（左 → 右）縦方向（上 → 下）
row-reverse横方向（右 → 左）縦方向（上 → 下）
column縦方向（上 → 下）横方向（左 → 右）
column-reverse縦方向（下 → 上）横方向（左 → 右）

この関係を図にまとめると、次のようになります。

flowchart TD A["親要素に display: flex を指定"] --> B{"flex-direction の値"} B -->|"row（既定）"| C["主軸 = 横方向 ／ 交差軸 = 縦方向"] B -->|"column"| D["主軸 = 縦方向 ／ 交差軸 = 横方向"] C --> E["justify-content で主軸方向を揃える（9.3）"] D --> E C --> F["align-items で交差軸方向を揃える（9.4）"] D --> F

重要ポイント: 迷ったら「今どっちが主軸？」

Flexbox の配置プロパティは、必ず「主軸用」か「交差軸用」のどちらかに分類されます。既定の row なら主軸＝横・交差軸＝縦、column にすると入れ替わります。次の2節で扱う justify-content（主軸）と align-items（交差軸）は、この対応さえ覚えれば混同しません。

style.css 
/* 縦方向のメニュー（サイドバーなどでよく使う） */
.sidebar-menu {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

9.3 justify-content（主軸方向の揃え）

justify-content は、主軸方向にアイテムをどう配置するかを指定するプロパティです（フレックスコンテナ側に指定します）。既定の flex-direction: row の場合、主軸は横方向なので「横のどこに寄せるか」を決めることになります。

値動作
flex-start（既定）主軸の始点（左）に詰めて並べる
center主軸の中央に集めて並べる
flex-end主軸の終点（右）に詰めて並べる
space-between両端に配置し、アイテムの間だけを均等に空ける
space-around各アイテムの周囲に均等な余白を付ける（両端は半分）
space-evenlyアイテムの間隔と両端の余白がすべて均等になる

9.4 align-items（交差軸方向の揃え）

align-items は、justify-content の交差軸バージョンです。既定の横並び（row）では交差軸は縦方向なので「縦のどこに揃えるか」を決めます。高さの違うアイテムが並んだとき、上・中央・下のどこで揃えるかを指定できます。

値動作
stretch（既定）交差軸方向いっぱいに伸ばして揃える
flex-start交差軸の始点（上）に揃える
center交差軸の中央に揃える
flex-end交差軸の終点（下）に揃える
baseline文字のベースライン（文字が乗る基準線）を揃える

justify-content と align-items をセットで指定すると、上下左右の中央寄せが驚くほど簡単に実現できます。9.7節で実際に組み立てます。

style.css 
.menu {
  display: flex;
  justify-content: center; /* 主軸(横)方向は中央 */
  align-items: center;     /* 交差軸(縦)方向も中央 */
}

9.5 gap（アイテム間の余白）と flex-wrap（折り返し）

アイテム同士の間隔は、以前は左右の margin を個別に指定し、最後の要素だけ打ち消す…といった面倒な調整が必要でした。今は gap プロパティ1つで解決できます。アイテムとアイテムの「間」だけに効き、コンテナの外側には余白を作らないので、意図が明確で事故も起きにくい書き方です。

もう1つ大切なのが flex-wrap です。既定値の nowrap では、アイテムは幅が足りなくても1行に収めようとし、縮んだり、はみ出したりします。wrap を指定すると、収まりきらないアイテムが自動的に次の行へ折り返されます。

style.css 
.cards {
  display: flex;
  flex-wrap: wrap;  /* 収まらない分は次の行へ折り返す */
  gap: 16px;        /* アイテム間の余白（縦横まとめて指定） */
}

flex-wrap の既定値は nowrap です。スマートフォンでレイアウトが崩れる・横スクロールが出てしまう場合は、まず flex-wrap: wrap; を忘れていないか確認しましょう。レスポンシブ対応の細かい調整は第11章でさらに扱います。

9.6 アイテム側のプロパティ

ここまではフレックスコンテナ（親要素）に指定するプロパティでした。ここからはフレックスアイテム（子要素）側に指定する、少し発展的なプロパティを紹介します。まずは全体像だけつかめば十分です。

flex: 1 — 余ったスペースを分け合う

実務でもっともよく使うのが flex: 1; です。複数のアイテムに同じ flex: 1; を指定すると、コンテナの余ったスペースを均等に分け合い、同じ幅で並びます。

style.css 
.cards {
  display: flex;
  gap: 16px;
}
.card {
  flex: 1; /* 3枚とも同じ幅で伸び縮みする */
}
flex: 1;
flex: 1;
flex: 1;

実は flex: 1; は、次の3つのプロパティを一括で指定するショートハンド（省略記法）です。まずは名前と役割だけ知っておけば十分です。

プロパティ役割既定値
flex-grow余ったスペースをどれだけ伸びて埋めるかの比率0
flex-shrinkスペースが足りないときどれだけ縮むかの比率1
flex-basis伸び縮みする前の基準サイズauto

flex: 1; は flex: 1 1 0%;（伸びる・縮む・基準0）の短縮形です。「基準サイズ0から、余りを全員で均等に伸ばす」ため、結果として同じ幅に揃う、という仕組みです。

align-self — 1つのアイテムだけ揃え方を変える

align-items はコンテナ内の全アイテムに効きますが、align-self を使うと特定の1つだけ交差軸の揃え方を上書きできます。

style.css 
.menu {
  display: flex;
  align-items: flex-start; /* 全体は上揃え */
}
.menu .highlight {
  align-self: center; /* この項目だけ中央揃え */
}

Tailwind の flex-1 は本当に flex: 1

このページで使っている Tailwind CSS の flex-1 クラスは、まさに flex: 1 1 0%; を出力するクラスです。上の見本の3つの箱にも実際に付いています。フレームワークのクラス名は、素のCSSプロパティ名を知っていると覚えやすくなります。

9.7 よく使うパターン集

最後に、ここまで学んだプロパティを組み合わせた実務で頻出の3パターンを紹介します。この3つを覚えるだけで、Flexbox の使用頻度の高い場面の大半をカバーできます。

① 横並びナビゲーション（ロゴ左・メニュー右）

ヘッダーの定番レイアウトです。justify-content: space-between; だけで、ロゴを左端に、メニューを右端に押しやることができます。

style.css 
.header {
  display: flex;
  justify-content: space-between; /* 両端に押しやる */
  align-items: center;            /* 縦方向は中央揃え */
  padding: 16px 24px;
}

③ 上下左右の完全中央寄せ

「ローディング表示を画面のど真ん中に置きたい」といった場面の定番解決策です。justify-content: center;（主軸）と align-items: center;（交差軸）を組み合わせるだけで、要素の大きさに関係なく中央に配置できます。かつては margin の計算が必要だった配置が、たった2行で完成します。

style.css 
.overlay {
  display: flex;
  justify-content: center; /* 横方向 中央 */
  align-items: center;     /* 縦方向 中央 */
  height: 100vh;           /* 画面の高さいっぱい */
}
この箱がいつも中央

重要ポイント

この3パターンに共通するのは、すべて親要素（コンテナ）側に数行書くだけという点です。子要素のHTML構造やmarginを個別にいじる必要がありません。まずはこの3つを手元で再現できるようにしておきましょう。

やってみよう 9-1: ナビゲーションバーを Flexbox で組んでみよう

9.3節で見た justify-content の違いを、自分の手で切り替えて体感します。開発者ツールを使えば、ファイルを保存し直さなくてもその場で確認できます。

手順

  1. 1 エディタで nav.html を作り、ロゴ用の <div> と、3つのリンクを持つ <nav> を用意する。
  2. 2 2つを囲む親要素に display: flex; と justify-content: flex-start; を指定し、ブラウザで表示を確認する。
  3. 3 開発者ツール（F12）の Styles パネルで justify-content の値を center → space-between → space-evenly と書き換え、並び方の違いを見比べる。
  4. 4 ロゴが左端・メニューが右端に来る space-between をファイルに保存し、9.7節①のパターンを自分の手で再現できたことを確認する。

値を切り替えるたびにレイアウトが即座に変わるのが体感できれば成功です。「主軸方向に効くのは justify-content」という感覚を、頭ではなく指で覚えてしまいましょう。

理解度確認クイズ

  1. Q1. 「フレックスコンテナ」と「フレックスアイテム」の関係を、「親要素」「子要素」という言葉を使って説明してください。

    回答を表示

    display: flex; を指定した親要素がフレックスコンテナ、その中に並ぶ子要素がフレックスアイテムです。

  2. Q2. flex-direction: column; を指定すると、主軸と交差軸はそれぞれどの向きになりますか。

    回答を表示

    主軸は縦方向（上→下）、交差軸は横方向（左→右）になります。既定の row のときと、主軸・交差軸がちょうど入れ替わります。

  3. Q3. justify-content と align-items の役割の違いを一言で説明してください。

    回答を表示

    justify-content は主軸方向の揃え方、align-items は交差軸方向の揃え方を指定するプロパティです（既定の row なら前者は横、後者は縦）。

  4. Q4. 3つの要素を、余ったスペースを使って同じ幅で均等に並べたいとき、各アイテムに指定するとよいプロパティは何ですか。

    回答を表示

    各アイテムに flex: 1; を指定します（親要素には display: flex; と gap を指定）。余ったスペースを全員で均等に分け合うため、結果として同じ幅で並びます。
