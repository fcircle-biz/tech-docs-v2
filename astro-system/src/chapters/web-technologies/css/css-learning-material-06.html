色と背景

Webページの第一印象は配色でほぼ決まります。この章では、CSS で色を指定する5つの方法、color（文字色）と background-color（背景色）の基本、背景画像やグラデーションの使い方、そして読みやすさを支えるコントラストの考え方までを、順を追って学びます。

この章で学ぶこと

  • 色の5つの指定方法（色名キーワード・16進数・rgb()・rgba()・hsl()）を使い分けられる
  • 16進数カラーコード（RGB各2桁）の仕組みを読み解ける
  • color と background-color を使い分け、背景色が広がる範囲を説明できる
  • 背景画像・グラデーションを指定し、読みやすさに配慮した配色ができる

6.1 色の指定方法

CSS で色を指定する方法は1つではありません。代表的なものだけでも5種類あり、それぞれ得意なことが違います。まずは全体像を一覧で確認しましょう。

指定方法 書き方の例 特徴
① 色名キーワード red, white, tomato 約150種類の英単語。直感的だが細かい微調整はできない
② 16進数 #ff0000, #f00 Web制作で最もよく使われる。RGB各色を2桁の16進数で指定
③ rgb() rgb(255, 0, 0) 赤・緑・青を0〜255の数値で指定。値の意味が分かりやすい
④ rgba() / 8桁hex rgba(255, 0, 0, 0.5) rgb()に透明度（アルファ値 0〜1）を加えたもの
⑤ hsl() hsl(0, 100%, 50%) 色相・彩度・明度で指定。同系色の濃淡調整が直感的

「同じ色を5つの方法で書けるなら、結局どれを使えばいいの？」と思いますよね。試しに、この教材のテーマカラー（オレンジ）を5つの書き方で表現してみましょう。

この教材のテーマカラーを5つの書き方で表現すると、次のようになります。②③⑤はまったく同じ色、④はそこに透明度を加えたもの、①ではこの色を表現できません。

  • 色名キーワード: 表現不可（近似色は darkorange など）
  • 16進数: #f97316
  • rgb(): rgb(249, 115, 22)
  • rgba()（不透明度70%）: rgba(249, 115, 22, 0.7)
  • hsl(): hsl(25, 95%, 53%)

※ 約150種類しかない色名キーワードでは、ちょうどこのオレンジを表現できません。これが色名キーワードの限界です。

ここで②の16進数（じゅうろくしんすう）の仕組みを、もう少し詳しく見ておきましょう。普段使う10進数は 0〜9 の10種類の数字で数を数えますが、16進数は 0〜9 のあとに a(10)〜f(15) を使い、16種類の文字で数を数えます。2桁使うと 00〜ff の256通り（0〜255）を表せ、これは赤・緑・青それぞれの明るさの256段階とぴったり一致します。#rrggbb は、この2桁ずつのペアを3つ並べたものだったのです。

flowchart LR A["#f97316（このガイドのテーマカラー）"] --> B["f9 → 赤(R): 249"] A --> C["73 → 緑(G): 115"] A --> D["16 → 青(B): 22"]

3桁の省略形が使えるのは特定の場合だけ

#ff0000 は ff・00・00 と、3つのペアがどれも同じ文字2つの繰り返し（ff→f、00→0）になっているため #f00 に省略できます。しかしこの教材のテーマカラー #f97316 は f9・73・16 のどのペアも2文字が異なるため、3桁には省略できません。「各ペアが同じ文字2つかどうか」がポイントです。

色の数値を暗記する必要はない

ブラウザの開発者ツールにはカラーピッカー（色見本から選ぶ機能）が付いています。色のついた四角をクリックすれば、16進数・rgb・hslを相互に変換しながら選べます。数値を覚えるより、ツールで選んで確かめる習慣をつけましょう。

6.2 文字色と背景色の基本

色を「どこに」使うかを決める、最も基本的な2つのプロパティが color（文字色）と background-color（背景色）です。名前のとおり、color は要素内の文字の色を、background-color は要素の背景を塗りつぶす色を指定します。

style.css 
/* ページ全体の文字色と背景色 */
body {
  color: #1e293b;
  background-color: #f8fafc;
}

/* カード部分は白背景にする */
.card {
  background-color: #ffffff;
  color: #0f172a;
}

ここで初心者がよく疑問に思うのが、「背景色は要素のどこまで塗られるのか」です。実際に確かめてみましょう。

背景色が塗られる範囲を見てみよう

この要素の内容（テキスト）

オレンジ色に塗られているのは「内容＋パディング（内側の余白）」の部分だけです。点線の外側の白いすき間（マージン＝外側の余白）には背景色が付きません。「内容・パディング・ボーダー・マージン」という4層の考え方は、第7章のボックスモデルで詳しく学びます。

background-color の初期値は「透明」

何も指定しなければ background-color の初期値は transparent（透明）です。指定しない要素は、親要素の背景がそのまま透けて見えます。

重要ポイント: 継承されるのは color だけ

第4章で学んだ「継承」を思い出しましょう。color は子要素に継承されますが、background-color は継承されません（初期値の transparent が使われます）。親に背景色を指定しても、子要素の背景まで自動では色が付かない、と覚えておきましょう。

6.3 背景画像を指定する

背景には単色だけでなく、画像も指定できます。background-image を中心に、画像の表示のされ方を調整する3つのプロパティを合わせて覚えましょう。

プロパティ よく使う値 効果
background-image url("images/bg.jpg") 背景に表示する画像を指定する
background-size cover / contain cover=隙間なく覆う（一部が見切れる） contain=全体を収める（余白ができることも）
background-position center / top / 50% 50% 画像を表示する基準位置を指定する
background-repeat no-repeat / repeat-x 画像を繰り返すかどうか（初期値は repeat）

1枚の写真を要素いっぱいに敷き詰める、よくある指定はこのようになります。

style.css 
/* ヒーロー領域に画像を全面表示する */
.hero {
  background-image: url("images/hero.jpg");
  background-size: cover;        /* いっぱいに拡大縮小 */
  background-position: center;   /* 中央を基準に表示 */
  background-repeat: no-repeat;  /* 繰り返さない */
  background-color: #1e293b;     /* 読込前・失敗時の保険 */
}

よくあるつまずき

url() のパスは、HTMLファイルではなくCSSファイルの場所が基準になります。<img> タグの src とは基準が違うので注意してください。また background-repeat を指定し忘れると、初期値の repeat によって写真がタイル状に並んでしまいます。画像が読み込めない場合に備えて background-color を保険として指定しておくと安心です。

6.4 グラデーション

グラデーション（色のなだらかな変化）は、linear-gradient() という関数で表現します。基本の形は「方向」と「2つの色」を指定するだけです。

style.css 
/* ボタンの背景を左から右へグラデーション */
.btn {
  background: linear-gradient(to right, #f97316, #06b6d4);
  color: white;
  padding: 12px 24px;
  border-radius: 9999px;
}

/* 見出しの背景を斜めにグラデーション */
h2.title {
  background: linear-gradient(135deg, #f97316, #fb923c);
  color: white;
  padding: 16px 20px;
}

方向は to right（左→右）のようなキーワードのほか、135deg のように角度でも指定できます。実際にどう見えるか、代表的な方向を比べてみましょう。

6.5 読みやすさとコントラスト

色は自由に選べますが、「読めること」が大前提です。文字色と背景色の明るさの差をコントラスト（対比）と呼び、これが小さいと、どんなにおしゃれな配色でも文章が読めなくなってしまいます。

悪い例（コントラスト不足）

この文字は背景との差が小さく、とても読みにくくなっています。

良い例（十分なコントラスト）

この文字は背景との差がはっきりしていて、すらすら読めます。

背景画像の上に文字を重ねるときも、同じ注意が必要です。写真の明るい部分に白文字を置くと、文字だけが消えたように見えてしまいます。文字の背後に半透明の色を重ねて地色を安定させる、といった対策がよく使われます。

style.css 
/* 背景画像の上に半透明の黒を重ね文字を読みやすくする */
.hero-text {
  background-color: rgba(0, 0, 0, 0.5);
  color: white;
  padding: 24px;
}

色だけに意味を持たせない

「赤字はエラー、緑字は成功」のように色だけで意味を伝えると、色の識別が難しい人（色覚特性を持つ人）に伝わらないことがあります。アイコンやテキストラベルを併用し、色以外の手がかりも用意しましょう。これはアクセシビリティ（誰にとっても使いやすいこと）の基本です。

コントラスト比の目安

WCAG（Web Content Accessibility Guidelines）という国際的な指針では、通常の文字で4.5:1以上、大きな文字で3:1以上のコントラスト比が推奨されています。ブラウザの開発者ツールや WebAIM Contrast Checker といった無料ツールで、実際の比率を数値で確認できます。

やってみよう 6-1: 配色を試してみよう

これまでの章で使っている練習用のHTMLファイル（なければ見出しと段落だけの簡単なページ）を用意し、色と背景を実際に変えながら配色の感覚をつかみましょう。

手順

  1. 1 body セレクタに background-color を指定し、それに合う color（文字色）を組み合わせて保存する。
  2. 2 見出し（h1 など）に linear-gradient() を使った背景を設定してみる。方向や色の組み合わせを変えて、印象の違いを確かめる。
  3. 3 わざと薄すぎる文字色（背景色に近い色）を指定し、読みにくくなる様子も体験してみる。その後、はっきり読める色に戻す。
  4. 4 開発者ツールのカラーピッカーで色を選びながら、16進数・rgb・hslの表示が連動して変わる様子を観察する。

配色に正解はありません。まずは「読める」ことを最優先に、そのうえで好みの色を試してみましょう。迷ったら、テーマカラー1色＋その補色に近いアクセントカラー1色、くらいのシンプルな組み合わせから始めるのがおすすめです。

理解度確認クイズ

  1. Q1. 16進数カラーコード #00ff00 が表す色は何色でしょうか。RGB各成分（赤・緑・青）の値とともに説明してください。

    回答を表示

    鮮やかな緑色です。#rrggbb の並びで読み解くと、赤(R)=00=0、緑(G)=ff=255、青(B)=00=0 となり、緑だけが最大値でほかは0のため、混じりけのない緑になります。

  2. Q2. color と background-color は、それぞれ何に対して色を指定するプロパティでしょうか。

    回答を表示

    color は要素内の文字の色を指定し、子要素に継承されます。background-color は要素の背景（内容とパディングの部分）を塗りつぶす色を指定し、こちらは継承されません。

  3. Q3. background-size: cover と background-size: contain の違いを説明してください。

    回答を表示

    cover は要素全体を隙間なく覆うように画像を拡大縮小するため、画像の一部が見切れることがあります。contain は画像全体が要素に収まるように拡大縮小するため、画像は見切れませんが余白ができることがあります。

  4. Q4. 背景色に近すぎる薄い文字色を避けるべきなのはなぜでしょうか。「コントラスト」という言葉を使って説明してください。

    回答を表示

    文字色と背景色の明るさの差（コントラスト）が小さいと、文字と背景の境目が見分けにくくなり読みづらくなるためです。特に高齢の方や視力の弱い方、色の識別が難しい方にとっては致命的な問題になり得るため、通常の文字で4.5:1以上のコントラスト比を確保することが推奨されています。
