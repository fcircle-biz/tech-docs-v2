ホーム CSS 第3章
第3章 所要時間: 約40分

セレクタの基本

前章までで、CSSのルールが セレクタ { プロパティ: 値; } という形をしていることを学びました。この章では先頭のセレクタ――「ページのどこにスタイルを当てるか」を指定する部分――を、代表的な7つの種類に分けてじっくり学びます。狙った場所だけに正確にスタイルを当てられるようになれば、CSSでできることが一気に広がります。

この章で学ぶこと

  • 要素・クラス・ID・全称セレクタを使い分けられる
  • クラスセレクタとIDセレクタの違いと、それぞれの使いどころを説明できる
  • 子孫セレクタと子セレクタを使い分けて、ネストした要素を絞り込める
  • :hover などの擬似クラスと ::before などの擬似要素の役割が分かる

3.1 セレクタとは

第2章で確認したとおり、CSSのルールセットは セレクタ { プロパティ: 値; } という形をしています。先頭のセレクタは「これから指定するスタイルを、HTMLのどの要素に当てるか」を表す部分です。

セレクタの指定があいまいだと、狙っていない場所までスタイルが変わってしまったり、逆にどこにも効かなかったりします。CSSでつまずく人の多くは、プロパティの知識よりも先に「セレクタで狙った場所をうまく選べない」という壁にぶつかります。この章では、まず押さえておきたい7種類のセレクタを順番に見ていきましょう。

style.css 
/* ここが「セレクタ」。「pタグに」という指定 */
p {
  color: navy;      /* ここから下が プロパティ: 値 */
  font-size: 16px;
}

セレクタは組み合わせて使える

この章で紹介するセレクタは、単独で使うだけでなく組み合わせて「もっと狭く、もっと正確に」対象を絞り込むこともできます。まずは1つずつの意味をしっかり理解しましょう。

3.2 要素セレクタ — タグ名で指定する

要素セレクタは、h1 や p のように、HTMLのタグ名をそのまま書くもっとも基本的なセレクタです。書いたタグ名と同じ要素すべてに、一括でスタイルが適用されます。

style.css 
/* ページ内のすべての h1 に効く */
h1 {
  color: #c2410c;
}

/* ページ内のすべての a（リンク）に効く */
a {
  text-decoration: none;
}

要素セレクタは「ページ全体の土台になるスタイル」を決めるのに向いています。たとえば body にサイト全体のフォントを指定したり、見出しタグに基本デザインをまとめて当てたりする使い方です。一方で、「同じタグの中でも、ここだけ変えたい」という細かい指定には向きません。そこで登場するのが次のクラスセレクタです。

3.3 クラスセレクタ — もっともよく使うセレクタ

クラスセレクタは、HTML要素に付けた名札（クラス名）を目印にスタイルを当てるセレクタです。CSS側では先頭にピリオド（.）を付けて書きます。実務でも学習でももっとも使用頻度の高いセレクタです。

使うには、まずHTML側で class="クラス名" という属性を要素に付けます。同じクラス名は、1つのページの中で何個の要素にでも繰り返し付けることができます。

index.html 
<!-- class="note" を2つの段落に付ける -->
<p class="note">1つ目の注意書き</p>
<p>ふつうの段落（クラスなし）</p>
<p class="note">2つ目の注意書き</p>
style.css 
/* class="note" が付いた要素だけに効く */
.note {
  background-color: #ffedd5;
  padding: 8px;
  border-radius: 4px;
}

1つの要素には、半角スペース区切りで複数のクラスを同時に付けることもできます。「共通の見た目」と「個別の見た目」を組み合わせられるので、実務ではこの書き方を頻繁に使います。

index.html 
<!-- card と highlight、2つのクラスを同時に付ける -->
<div class="card highlight">
  注目してほしいカード
</div>

重要ポイント

迷ったら、まずクラスセレクタを使うと考えて構いません。何度でも使え、複数組み合わせられる柔軟さから、CSS設計の基本の単位になっています。

3.4 IDセレクタ — 1ページに1つだけの特別な名札

IDセレクタは、先頭にシャープ（#）を付けて書くセレクタです。HTML側では id="id名" という属性で指定します。クラスとよく似ていますが、決定的な違いが1つあります。同じID名は、1つのHTMLページの中で1回しか使えません。

index.html 
<!-- ページ共通のヘッダーに、一意のIDを付ける -->
<header id="site-header">
  サイト共通ヘッダー
</header>
style.css 
/* id="site-header" を持つ要素だけに効く */
#site-header {
  background-color: #1c1917;
  color: white;
}

「一意（ユニーク）である」という性質から、IDは主にページ内リンクのジャンプ先やJavaScriptから特定の要素を1つだけ取得する目印として使われることが多く、見た目のスタイル指定はクラスに任せるという設計が広く採用されています。

注意: スタイル指定にIDを多用しない

IDセレクタはクラスセレクタより「詳細度」と呼ばれる優先度の点でずっと強く、後から書いたクラスで上書きしづらくなります（詳しくは第4章）。スタイル指定には基本的にクラスセレクタを使い、IDはリンク先やJavaScript用の目印として使うと覚えておくと、後々のトラブルを避けられます。

ここまでのクラスセレクタとIDセレクタの違いを、表で整理しておきましょう。

観点 クラスセレクタ（.名前） IDセレクタ（#名前）
1ページ内で使える回数 何個でも・何回でもOK 1回だけ（一意）
HTML側の書き方 class="foo" id="foo"
1要素に複数付けられるか 付けられる（空白区切り） 付けられない（1つだけ）
主な用途 見た目のスタイル指定（推奨） ページ内リンク先・JS連携
詳細度（強さ） 普通 クラスより強い（第4章）

3.5 全称セレクタとグループ化

全称セレクタ（*）は「ページ内のすべての要素」を指定するセレクタです。アスタリスク1文字だけで書きます。すべての要素の余白をリセットする、といった下準備によく使われます。

また、複数のセレクタにまったく同じスタイルを当てたいときは、カンマ（,）区切りで並べて書くことができます。これをグループ化と呼びます。同じ内容を何度も書かずに済むので、コードがすっきりします。

style.css 
/* 全称セレクタ：すべての要素の既定の余白を0にする */
* {
  margin: 0;
  padding: 0;
}

/* グループ化：見出し3種類に同じスタイルをまとめて指定 */
h1, h2, h3 {
  font-family: "Noto Sans JP", sans-serif;
  color: #292524;
}

全称セレクタはページ全体に影響するため便利ですが、多用すると意図しない箇所まで変わってしまうことがあります。「まず全体をリセットしてから、個別に組み立てていく」という下準備の場面で使うのが基本の使い方です。

3.6 子孫セレクタと子セレクタ — ネストを絞り込む

HTMLは要素の中に要素が入れ子（ネスト）になっています。「この親の中にある、この要素だけ」を狙いたいときに役立つのが、子孫セレクタと子セレクタです。書き方はよく似ていますが、意味は大きく異なります。

  • 子孫セレクタ（半角スペース） 親 子 ― 親の中にあれば、何階層下にネストしていても選ばれる
  • 子セレクタ（>） 親 > 子 ― 親の直下の1階層だけが選ばれる（孫は選ばれない）
flowchart TD A[".card（親要素）"] --> B["p（直下の子）"] A --> C["div"] C --> D["p（孫要素）"]
style.css 
/* 子孫セレクタ：.card の中の p なら、何階層下でも選ばれる */
/* 上の図の「直下の子」と「孫要素」の両方に効く */
.card p {
  color: #57534e;
}

/* 子セレクタ：.card の直下の p だけが選ばれる */
/* 上の図の「直下の子」だけに効く（孫要素には効かない） */
.card > p {
  font-weight: bold;
}

「とりあえず内側全部」でよいなら子孫セレクタ、「直下の1階層だけに絞りたい」ときは子セレクタ、と使い分けます。迷ったときは、まず子孫セレクタ（半角スペース）で書き始めるとシンプルです。

3.7 擬似クラスと擬似要素 — 状態や特殊な位置を狙う

最後に紹介するのは、通常のHTML属性だけでは表せない「状態」や「位置」を狙えるセレクタです。コロン（:）の数によって、2つの種類に分かれます。

擬似クラス（コロン1つ）は、要素の「状態」や「並び順」を指定します。代表例は次のとおりです。

  • :hover ― マウスが乗っているときの状態
  • :first-child ― 兄弟要素の中で最初の要素
  • :last-child ― 兄弟要素の中で最後の要素
  • :nth-child(2) ― 兄弟要素の中でn番目の要素
style.css 
/* リンクにマウスを乗せたら色を変える */
a:hover {
  color: #ea580c;
}

/* リスト内、奇数番目の行にだけ背景色を付ける */
li:nth-child(odd) {
  background-color: #f5f5f4;
}

一方、擬似要素（コロン2つ）は、既存の要素の直前・直後に新しい内容を追加するイメージのセレクタです。代表例は ::before（直前に追加）と ::after（直後に追加）です。

style.css 
/* 見出しの直前に「※」の文字を自動で追加する */
h3::before {
  content: "※ ";
  color: #ea580c;
}

コロンの数で見分ける

コロン1つ（:）＝状態や位置、コロン2つ（::）＝内容の追加とおおまかに覚えておけば区別できます。この章では入口だけ紹介しました。使いこなす場面は第9章以降のレイアウトや第12章の装飾で増えていきます。

やってみよう 3-1: ナビゲーションのリンクにクラスを付けて :hover で色を変える

クラスセレクタと擬似クラスを組み合わせて、マウスを乗せると色が変わるナビゲーションを作ってみましょう。

手順

  1. 1 新しいファイル nav-practice.html を作り、<nav> の中に「ホーム」「作品」「連絡先」の3つの <a> リンクを並べる。3つとも class="nav-link" を付ける。
  2. 2 <style> の中に .nav-link {} を書き、text-decoration: none;・padding: 8px 12px; など基本の見た目を指定する。
  3. 3 その下に .nav-link:hover {} を追加し、color をふだんとは違う目立つ色に変える指定を書く。
  4. 4 保存してブラウザで開き、3つのリンクそれぞれにマウスを乗せて色が変わること、マウスを外すと元に戻ることを確認する。
  5. 5 余裕があれば .nav-link:hover に background-color も加えて、変化の見え方を工夫してみる。

class="nav-link" のように共通のクラス名を付けておけば、あとから .nav-link {} を1箇所直すだけで、すべてのリンクのデザインを一括変更できます。これがクラスセレクタの強みです。

理解度確認クイズ

  1. Q1. クラスセレクタとIDセレクタのもっとも大きな違いは何ですか。「使える回数」の観点で説明してください。

    回答を表示

    クラスセレクタは1つのページの中で何個の要素にも、何度でも使えます。一方、IDセレクタは1つのページの中で1回しか使えません（一意）。そのため、見た目のスタイル指定には主にクラスセレクタを使い、IDはページ内リンク先やJavaScriptから要素を特定する目印として使うのが基本です。

  2. Q2. .card p と .card > p は何が違いますか。

    回答を表示

    .card p（子孫セレクタ、半角スペース）は、.card の中にある p 要素であれば、何階層ネストしていても選ばれます。.card > p（子セレクタ）は、.card の直下（1階層下）にある p 要素だけが選ばれ、孫要素以下の p には効きません。

  3. Q3. a:hover と h3::before は、それぞれ擬似クラスと擬似要素のどちらでしょうか。コロンの数をヒントに説明してください。

    回答を表示

    a:hover はコロンが1つなので擬似クラスで、「マウスが乗っている」という状態を指定しています。h3::before はコロンが2つなので擬似要素で、要素の直前に新しい内容（content）を追加します。

  4. Q4. 1つの要素に class="card highlight" のように2つのクラスを付けることには、どんな意味がありますか。

    回答を表示

    「card」という共通の見た目と「highlight」という個別の強調表現を、組み合わせて適用できるという意味です。1つの要素は複数のクラスを半角スペース区切りで同時に持つことができ、それぞれのクラスに書かれたスタイルが両方とも適用されます。
