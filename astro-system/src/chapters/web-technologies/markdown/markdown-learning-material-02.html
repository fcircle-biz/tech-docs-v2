ホーム Markdown 第2章
第2章 所要時間: 約30分

書く準備をしよう

Markdown は、普段使っているテキストエディタが1つあれば今日から書き始められます。とはいえ、「プレビュー機能」を備えたエディタを使うと、書いた内容がどう表示されるかをその場で確認でき、上達のスピードがぐっと上がります。この章では、.md ファイルの正体を知り、自分に合ったエディタを選び、実際に手を動かして最初の Markdown ファイルを作成するところまで進めます。

この章で学ぶこと

  • .md ファイルの正体（拡張子が .md なだけのテキストファイル）を説明できる
  • VS Code・メモ帳・オンラインエディタなど、エディタの選択肢とそれぞれの特徴が分かる
  • VS Code をインストールし、日本語表示に切り替えられる
  • プレビュー機能を使いながら、最初の .md ファイルを作成できる

2.1 .md ファイルとは何か

第1章で見たとおり、Markdown で書いた文書は最終的に .md という拡張子のファイルに保存します。ここで大事な結論を先に言ってしまうと、.md ファイルの正体は、ただの「テキストファイル」です。Word ファイル（.docx）のような専用の複雑な保存形式ではなく、中身は文字がそのまま並んでいるだけの、とてもシンプルなファイルです。

そのため、パソコンに標準で入っているメモ帳のようなソフトでも .md ファイルを開いて編集できます。ただしメモ帳では # や - がただの記号として表示されるだけで、見出しや箇条書きにきれいに変換された状態（プレビュー）を見ることはできません。この「プレビューを見られるかどうか」が、次の 2.2 でエディタを選ぶときの大きなポイントになります。

正体はテキストファイル

中身は文字だけ。Word のような専用の保存形式ではなく、どんなパソコンでも軽く開けます。

拡張子は「.md」

ファイル名の末尾を .md にするだけ。既存の .txt ファイルの拡張子を変えるだけでも扱えます。

どんなソフトでも開ける

メモ帳やテキストエディットなど、文字を扱えるソフトなら何でも中身を開いて編集できます。

豆知識: メモ帳で開くと記号がそのまま見える

.md ファイルをメモ帳やテキストエディットで開くと、# や - が記号のまま表示されます。見出しや箇条書きとしてきれいに変換された状態を見るには、プレビュー機能を持つエディタが必要です。次の節で選び方を見ていきましょう。

2.2 エディタの選択肢を知ろう

Markdown を書くこと自体は、文字が打てるソフトなら何でも可能です。とはいえプレビュー機能があるエディタを使うほうが、書いた記号がどう表示されるかをすぐ確認でき、上達が早くなります。ここでは代表的な3つの選択肢を比べてみましょう。

エディタ 特徴 こんな人におすすめ
Visual Studio Code（VS Code） 推奨 無料・多機能。プレビュー表示や便利な拡張機能が豊富で、他のプログラミング学習にもそのまま使える定番エディタ。 これから本格的に学びたい人、エディタを長く使い続けたい人
メモ帳（Windows）／テキストエディット（Mac） パソコンに標準搭載。インストール不要ですぐ書き始められるが、プレビュー機能はない。 インストールなしでとにかくすぐ試したい人
オンラインエディタ（StackEdit・Dillinger など） ブラウザだけで書ける。インストール不要で、プレビューも同時に確認できる。 会社のPCなどインストールが難しい人、気軽に試したい人

オンラインエディタも十分実用的

この教材では VS Code を使って進めますが、StackEdit や Dillinger などのオンラインエディタでも同じように学習できます。ブラウザで「StackEdit」と検索して開くだけで、インストールなしにすぐ試せます。

2.3 VS Code をインストールして日本語化しよう

ここからは、この教材で使う VS Code（Visual Studio Code） を実際にインストールしていきましょう。VS Code は Microsoft が無料で提供している、世界中で使われている定番のエディタです。

1 公式サイトへアクセスしてダウンロード

ブラウザで code.visualstudio.com を開き、「Download」ボタンをクリックします。使っているOSに合わせたインストーラーが自動的にダウンロードされます。

2 インストーラーを実行する

ダウンロードしたファイルを開き、画面の指示に従って進めます。Windows は「次へ」を押し続けて最後に「インストール」、Mac はアプリをドラッグして「アプリケーション」フォルダへ移動するだけです。

3 VS Code を起動して確認する

インストール後に VS Code を起動します。画面が表示されれば準備完了です。

日本語化する

VS Code は最初、画面表示が英語になっています。拡張機能を1つ追加するだけで、簡単に日本語表示へ切り替えられます。

1 拡張機能アイコンを開く

画面左端に並んだアイコンの中から、四角が4つ組み合わさった「拡張機能」アイコンをクリックします。

2 Japanese Language Pack を検索してインストール

検索欄に「Japanese Language Pack」と入力し、一覧の一番上に出てくる Microsoft 製の拡張機能の「Install」ボタンをクリックします。

3 再起動して日本語表示を確認する

画面右下に表示される案内の「Restart」をクリックすると、VS Code が再起動して日本語表示になります。

2.4 プレビューを表示してみよう

エディタが用意できたら、次はプレビュー機能の出番です。プレビューとは、書いた Markdown がどのように整形されて表示されるかを、その場で確認できる機能です。VS Code では、次の2つのショートカットキーで表示できます。

操作 Windows / Linux Mac
プレビューだけを開く Ctrl + Shift + V Cmd + Shift + V
編集画面とプレビューを横に並べる Ctrl + K の後に V Cmd + K の後に V

「K の後に V」のように表記されるショートカットは、2つのキーを同時に押すのではなく、1つ目の組み合わせを押して離してから、続けて2つ目のキーを押すという意味です。慣れないうちは戸惑いやすいので覚えておきましょう。

重要ポイント

プレビューを見ながら書く、これが Markdown 上達の一番の近道です。「書く → 確認する → 直す」のサイクルをこまめに繰り返しましょう。この習慣さえ身につけば、あとは第3章以降で記法を1つずつ覚えていくだけです。

2.5 あると便利な拡張機能: Markdown All in One

最後に、これから先の学習をもっと快適にしてくれる拡張機能を1つ紹介します。VS Code の拡張機能マーケットプレイスには、Markdown All in One という人気の拡張機能があります。

  • 文字を選択してショートカットキーを押すだけで太字・斜体にできる（例: 選択して Ctrl + B で太字）
  • 見出しから目次（もくじ）を自動生成できる
  • 箇条書きや番号付きリストで改行すると、続きの記号や番号を自動で補完してくれる
  • 表（テーブル）の縦棒の位置を自動で整えてくれる

インストール方法もシンプルです。拡張機能アイコンを開き、検索欄に「Markdown All in One」と入力して、表示された拡張機能の「Install」ボタンをクリックするだけです。今すぐ全部を使いこなす必要はありません。第3章以降で記法に慣れてきたら、少しずつ活用してみましょう。

やってみよう 2-1: 最初の .md ファイルを作ってプレビューしてみよう

ここまで学んだ内容を使って、実際に手を動かしてみましょう。この章の仕上げとして、最初の Markdown ファイルを作成し、プレビューで確認するところまで行います。

手順

  1. 1 VS Code を起動する（インストールが済んでいない場合は、代わりにブラウザで StackEdit などのオンラインエディタを開いてもよい）。
  2. 2 デスクトップなど分かりやすい場所に、markdown-practice という名前の新しいフォルダを作成する。
  3. 3 VS Code の「ファイル」メニューから「フォルダーを開く」を選び、作成したフォルダを開く。
  4. 4 「新しいファイル」を作成し、ファイル名を first.md として保存する（拡張子を .md にするのを忘れずに）。
  5. 5 下のサンプルを入力する（自分の好きな内容に変えてもよい）。
  6. 6 Ctrl+Shift+V でプレビューを表示し、続けて Ctrl+K → V で横並び表示に切り替えて見比べる。

サンプルの内容（first.md）

first.md 
# はじめてのMarkdown

これは私が最初に書いたMarkdownファイルです。

## 好きなもの

- コーヒー
- 読書

**練習中！**

理解度確認クイズ

  1. Q1. .md ファイルの正体は何ですか。「テキストファイル」という言葉を使って説明してください。

    回答を表示

    .md ファイルは特別な保存形式ではなく、ただのテキストファイルです。ファイル名の拡張子が .md になっているだけで、中身は文字だけで構成されています。

  2. Q2. VS Code で編集画面とプレビューを左右に並べて表示するには、どのショートカットキーを使いますか？

    回答を表示

    Ctrl+K を押してから V を押します（Mac は Cmd+K → V）。Ctrl+Shift+V はプレビューだけを表示するショートカットです。

  3. Q3. パソコンに何もインストールせずに Markdown を書いて確認する方法はありますか？

    回答を表示

    あります。StackEdit や Dillinger などのオンラインエディタをブラウザで開けば、インストールなしで Markdown を書いてプレビューを確認できます。
