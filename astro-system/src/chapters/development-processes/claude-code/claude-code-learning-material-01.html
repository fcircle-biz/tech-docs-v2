Claude Codeとは

Claude Code は、Anthropic が提供する「エージェント型（agentic）」のコーディングツールです。この章では、Claude Code が何で、チャット型 AI と何が違い、実際に何ができるのか、そして使いこなすためにどんな心構えが必要なのかという全体像をつかみます。

この章で学ぶこと

  • Claude Code とは何か、誰が提供しているのかを理解する
  • チャット型の Claude.ai との決定的な違いを説明できる
  • 「AI エージェント」という言葉の意味を理解する
  • Claude Code でできることと、5つの利用形態を知る
  • 効果的に使うための3つの心構えを身につける

1.1 Claude Code とは何か

Claude Code は、AI 企業 Anthropic が提供するコーディング支援ツールです。公式には次のように説明されています。

あなたのコードベースを理解し、ファイルを編集し、コマンドを実行し、既存の開発ツールと連携して、作業をより速く進めるのを助けてくれる agentic（自律的に動作する）コーディングツール

ポイントは「理解する・編集する・実行する・連携する」という4つの動詞がすべて含まれていることです。単にコードの続きを提案したり、質問に答えたりするだけではありません。実際に手を動かして、作業そのものを進めてくれるところに Claude Code の本質があります。

コードベースを理解する

プロジェクト全体の構造を自分で調べ、必要なファイルを探し出して読み込みます。

ファイルを編集する

1つのファイルだけでなく、関連する複数のファイルをまとめて書き換えられます。

コマンドを実行する

テストやビルドを実行し、その出力を見て次の行動を判断します。

用語: 「agentic（エージェンティック）」とは

「エージェントのように振る舞う」という意味の形容詞です。人から与えられた目標に対して、次に何をすべきかを自分で判断しながら、完了まで作業を進める性質を指します。この「自分で判断して進める」という点が、後述するチャット型 AI との最大の違いになります。

1.2 Claude.ai と Claude Code の違い

ブラウザで使う Claude.ai（チャット）を使ったことがある方は、「Claude Code は何が違うの？」と思うかもしれません。答えはとてもシンプルです。

Claude.ai と異なり、Claude Code はあなたのファイル・ターミナル・コードベース全体に直接アクセスできます。コードをコピー＆ペーストで行き来させる代わりに、Claude Code 自身がその場に入り込んで作業をこなすのです。

flowchart LR subgraph S1["Claude.ai（チャット）"] A1["あなた"] -->|コードを貼り付ける| B1["Claude"] B1 -->|回答をコピーする| A1 A1 -->|自分で編集・実行する| C1["コードベース"] end subgraph S2["Claude Code（エージェント）"] A2["あなた"] -->|やりたいことを伝える| B2["Claude Code"] B2 -->|自分で読む・編集する・実行する| C2["コードベース"] C2 -->|結果を確認する| B2 end
観点 Claude.ai（チャット） Claude Code
コードの渡し方 自分でコピー＆ペーストする 必要なファイルを自分で探して読む
ファイルの編集 人が回答を写して編集する Claude Code が直接書き換える
コマンドの実行 できない（人が実行する） 実行し、その出力を判断材料にする
位置づけ 相談相手・回答者 AI エージェント（作業の実行者）

1.3 エージェントとは何か

Claude Code を理解するうえで欠かせないのが「エージェント」という考え方です。AI エージェントとは、次のように定義できます。

環境とやり取りし、定められた目標を達成するために行動を起こせるソフトウェア

その中核では、LLM（大規模言語モデル）がリアルタイムでループしながら動作しています。エージェントは目標を達成するために、ツール・外部サービス・ほかの AI エージェントを利用できます。「LLM が考える」だけでなく、「ツールで実際に行動する」「結果を見てまた考える」というループが回ることで、はじめて作業が完了するのです。

flowchart TD A["LLM（考える頭脳）"] --> B["ツール（行動する手足）"] B --> C["環境（ファイル・ターミナル・Web）"] C -->|実行結果| A A -->|目標を達成した| D["完了"]

重要ポイント

LLM ＋ ツール ＋ ループ ＝ エージェント。この3つがそろってはじめて、AI は「答えを返す存在」から「作業を終わらせる存在」になります。このループの詳細は第2章で詳しく学びます。

1.4 Claude Code で実際にできること

Claude Code ができることは、大きく4つに整理できます。

できること 具体例
コードベースを読み、理解する 機能の説明を求める。コード全体にわたってバグを追跡させる。
プロジェクト全体のファイルを編集する ある関数をリファクタリングし、それを参照しているすべてのファイルを更新する。
ターミナルコマンドを実行する ビルドスクリプト・テストの実行、パッケージのインストール。その出力をもとに次の行動を判断できる。
Web を検索する ドキュメントや最新の API リファレンスが必要なときに代わりに調べる。

実際のやり取りは、次のようなイメージで進みます。

terminal — Claude Code セッション例 
$ claude
> ログイン処理でエラーが出ています。原因を調べて直してください。

● src/auth/ 配下のファイルを検索しています…
● src/auth/login.ts を読み込みました。
● 原因はトークンの有効期限チェックが抜けていることでした。修正します。
● npm test を実行しました（12件すべて成功）。
● 修正が完了しました。変更内容を確認しますか？

1.5 Claude Code を使える5つの場所

Claude Code は1つの形だけではなく、次の5つの形態で提供されています。どれを選んでも中身の Claude Code は同じで、操作する画面が違うだけです。

ターミナル

もっとも基本の形。新機能はまずここからリリースされます。本ガイドはこの形を中心に学びます。

Visual Studio Code

拡張機能としてインストール。エディタと並べて使えます。

JetBrains 系 IDE

IntelliJ IDEA などにプラグインを導入して使います。

デスクトップアプリ

Claude デスクトップアプリの「Code」トグルから利用。バックグラウンドで動かしたいときに便利です。

Web

ブラウザから利用。対象は GitHub リポジトリに限られます。リモートで作業したいときに向いています。

本ガイドの進め方

5つの形態それぞれの導入手順は第3章で詳しく扱います。まずは学習用にターミナル版を選ぶのがおすすめです。最新機能が最初に届くうえ、Claude Code の動きがもっとも素直に見えるためです。

1.6 効果的に使うための3つの心構え

Claude Code を使いこなすには、機能を覚える前に「AI がどういう存在なのか」を正しく理解しておくことが近道です。次の3つは、本ガイド全体を貫く前提になります。

1

コンテキストウィンドウには限りがある

コンテキストウィンドウとは、Claude の作業記憶（ワーキングメモリ）です。多くを保持できますが、すべてを一度に抱えられるわけではありません。だからこそ Claude Code は「agentic」であることが効いてきます。コードベース全体を丸ごと読み込まなくても、戦略的に必要な部分だけを探し出して答えにたどり着けるのです。詳しくは第7章で学びます。

2

Claude Code は許可を求める

既定では、コマンドを実行したりファイルを変更したりする前に、必ず確認を取ります。「手取り足取り確認する」使い方も、「ある程度任せる」使い方も選べますが、常に主導権はあなたにあります。この許可モードの切り替えは第4章で扱います。

3

Claude Code は間違えることもある

意図を取り違えたり、バグを混入させたり、必要以上に凝った実装（over-engineering）をしてしまうことがあります。だからこそ要所で確認し続けることが大切です。早い段階で気づけば、修正のコストはずっと小さくて済みます。

注意: 「任せきり」にしない

許可の確認をすべてスキップする設定も可能ですが、慣れないうちはおすすめしません。Claude Code にコマンド実行の自由を与えると、間違いが起きる前に気づくのが難しくなる場合があります。まずは確認しながら進め、動きが読めるようになってから任せる範囲を広げていきましょう。

やってみよう 1-1: Claude Code を任せたい作業を洗い出す

インストール前のこの段階では、まず「自分のどの作業を Claude Code に任せられそうか」をイメージしてみましょう。手を動かす前に活用イメージを持っておくと、以降の章の理解がぐっと早くなります。

手順

  1. 1 直近1週間で自分が行った開発作業を3つ書き出す（例: バグ修正、既存コードの調査、テストの追加）。
  2. 2 それぞれが 1.4 の4つのどれに当てはまるかを確認し、「任せられそう」なものに印を付ける。
  3. 3 印を付けた作業について、Claude Code にどう依頼するかを1文で書いてみる（第4章で実際に試します）。

理解度確認クイズ

  1. Q1. Claude.ai（チャット）と Claude Code の最大の違いは何ですか？

    回答を表示

    Claude Code はあなたのファイル・ターミナル・コードベース全体に直接アクセスできる点です。コードをコピー＆ペーストで行き来させる代わりに、Claude Code 自身がその場に入り込んで作業をこなします。つまり AI エージェントとして動作します。

  2. Q2. AI エージェントとはどのようなソフトウェアですか？

    回答を表示

    環境とやり取りし、定められた目標を達成するために行動を起こせるソフトウェアです。中核では LLM がリアルタイムでループしながら動作し、目標達成のためにツール・外部サービス・ほかの AI エージェントを利用できます。

  3. Q3. Claude Code を効果的に使うための3つの心構えを挙げてください。

    回答を表示

    ①コンテキストウィンドウ（作業記憶）には限りがあること、②Claude Code は既定で許可を求め、主導権は常にあなたにあること、③Claude Code は間違えることもあるため要所で確認し続けること、の3つです。
