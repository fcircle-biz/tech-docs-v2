ホーム Power BI 第1章
第1章 所要時間: 約45分

Power BIとは

Power BI は、社内にたまったデータを集めて整理し、誰でも見て判断できるレポートに変えるための Microsoft のツールです。この章では、そもそも BI とは何か、Power BI は何をしてくれるのか、そしてデータが1枚のレポートになるまでにどんな工程を通るのかという全体像をつかみます。ここで全体の地図を持っておくと、第2章以降で学ぶ個々の機能が「地図のどこの話なのか」が分かるようになります。

この章で学ぶこと

  • BI（ビジネスインテリジェンス）とは何か、なぜ必要とされるのかを説明できる
  • Power BI の役割と、Power BI Desktop・Power BI Service の違いを理解する
  • データがレポートになるまでの一連の流れを、6つのステップで説明できる
  • Excel との違いを整理し、本ガイド全12章の進め方を把握する

本教材で使う題材について

本ガイドでは全章を通して、架空の卸売会社「みらい商事株式会社」（文具・オフィス用品を全国の企業に販売）の売上分析を題材にします。売上明細・商品マスタ・顧客マスタ・店舗マスタ・日付マスタという5つの表を、章を追うごとに取り込み・整形・つなぎ合わせ・計算し、最後にレポートとして共有するところまで進みます。登場する社名・数値はすべて架空のものです。

1.1 BI（ビジネスインテリジェンス）とは何か

BI（ビジネスインテリジェンス）とは、会社にたまったデータを集めて整理し、人が見て判断できる形にする仕組みや活動のことです。難しく聞こえますが、やっていることは「散らばっているデータをかき集めて、きれいに整えて、分かりやすく見せる」の3つだけです。

たとえば、みらい商事の営業部長が「先月、どの商品カテゴリがどの地域で伸びたのか」を知りたいとします。ところが実際には、売上データは販売管理システムの中、顧客の情報は別の Excel ファイル、店舗の一覧は担当者のパソコンの中、というようにデータがバラバラの場所にあることがほとんどです。誰かが毎月それらをコピーして貼り合わせ、手作業でグラフを作り直している——これが BI ツールを入れる前によくある光景です。

集める

Excel・CSV・データベース・Web など、別々の場所にあるデータを1か所に取り込みます。

整える

表記のゆれや空白を直し、表どうしを関係づけて、集計できる形に整えます。

見せる

グラフや表にまとめ、見る人が自分で切り口を変えて確かめられるようにします。

BI ツールを使うと、この一連の作業を一度作れば、あとはデータを更新するだけで繰り返せるようになります。手作業との違いを整理すると次のようになります。

よくある悩み BI ツールを使うとどうなるか
毎月、同じ集計を手作業でやり直している 整形の手順が記録されるので、更新ボタン1つで最新の数字に置き換わります。
人によって数字が違う 「売上金額」の計算方法を1か所で定義するため、誰が見ても同じ数字になります。
「地域別でも見たい」と言われるたびに作り直す 見る人が自分で切り口を変えられるので、依頼と作り直しの往復が減ります。
ファイルがメールで飛び交い、どれが最新か分からない クラウド上の1つのレポートを全員が見るため、版のずれが起きません。

用語: レポートとダッシュボード

この2つは日常会話ではほぼ同じ意味で使われますが、Power BI では区別されます。レポートは複数ページからなり、グラフをクリックして掘り下げられる「分析するための資料」です。ダッシュボードは、1つ以上のレポートなどから重要なグラフや数値を1ページに集約した「一目で状況を把握するための画面」です。詳しくは第10章で扱います。

1.2 Power BI とは

Power BI は、Microsoft が提供する BI ツールです。ひとつのソフトの名前ではなく、役割の違う複数の製品をまとめた呼び名である点に注意してください。新人のうちに混乱しやすいところなので、最初に整理しておきましょう。

名前 何をするもの どこで動くか
Power BI Desktop データを取り込み、整形し、モデルを作り、レポートを作成するためのアプリ。作り手が使います。 Windows PC（無償）
Power BI Service できあがったレポートを共有・公開し、更新を自動化するクラウドサービス。見る人もここにアクセスします。 Web ブラウザ
Power BI Mobile 発行済みのレポートをスマートフォンやタブレットで閲覧するアプリ。 iOS / Android
オンプレミスデータゲートウェイ 社内ネットワーク上の SQL Server など、Power BI Service から直接アクセスできないデータソースとクラウドを安全につなぐ中継役。オンプレミスのデータを Service から更新する場合などに使います。 社内のサーバーや PC

このうち、本ガイドの第2章から第9章までで扱うのは Power BI Desktopです。第10章で Power BI Service に発行し、第11章でゲートウェイや権限といった運用の話に進みます。まずは「作る道具（Desktop）と配る場所（Service）がある」とだけ覚えておけば十分です。

Power BI の立ち位置

Power BI は、Power Apps・Power Automate などと並ぶ Microsoft Power Platform の製品の1つです。同時に現在では、Microsoft の統合データ分析基盤 Microsoft Fabric の中核となる分析・可視化機能としても位置付けられています。Excel や Teams、SharePoint と組み合わせて使え、Excel を日常的に使っている職場ほど導入しやすいのが特徴です。

1.3 Power BI Desktop と Power BI Service

2つの製品の役割分担は、「作るのは Desktop、配るのは Service」の一言に尽きます。Desktop で作ったファイルを Service へ発行（publish）すると、URL を知っている許可されたメンバーがブラウザで見られるようになります。

注意: Power BI Desktop は Windows 専用

Power BI Desktop は Windows でのみ動作します。Mac を使っている場合は、仮想マシンやリモートデスクトップで Windows 環境を用意するか、ブラウザで使える Power BI Service 上でレポートを作成・編集する、という選択になります。学習を始める前に手元の環境を確認しておきましょう。

1.4 データがレポートになるまでの流れ

ここが本章でもっとも大切な部分です。Power BI で、生のデータが1枚のレポートになるまでの典型的な流れを見てみましょう。本ガイドでは、初心者が仕組みを理解しやすいように、次の基本フローに沿って学習します。章構成もこの順番に沿っています。なお実務では、DirectQuery を使う場合や既存のセマンティックモデルに接続する場合など、別の進め方もあります。

ステップ やること たとえるなら 学ぶ章
1. データを取得する 必要なデータがある場所に接続して読み込む 材料の買い出し 第3章
2. 整形する（Power Query） 不要な列を消し、型をそろえ、表記のゆれを直す 下ごしらえ 第4章

重要ポイント

初心者がつまずくいちばんの原因は、2〜4（整形・モデル・計算）を飛ばして、いきなり5（グラフ作成）から始めてしまうことです。土台が整っていないと、グラフは描けても数字が合わなかったり、切り口を変えたとたんに壊れたりします。遠回りに見えても、前の工程から順に積み上げるのが結局いちばん速い道です。

実際の作業は行ったり来たりします

上の図は一本道に見えますが、実務では「レポートを作っていたら列が足りないことに気づいて Power Query に戻る」「指標がおかしいのでリレーションを直す」といった往復が普通に起こります。順番が大事なのであって、一度で完成させる必要はありません。

1.5 Excel との違いと本ガイドの進め方

「グラフを作るなら Excel でもできるのに、なぜ Power BI を使うのか」は、必ず出てくる疑問です。答えはデータの量・更新の手間・複数の表を扱う力にあります。

比較する点 Excel Power BI
扱えるデータ量 1シート約104万行が上限。重くなりやすい 大量データを列指向で圧縮して効率的に集計できる
複数の表の扱い VLOOKUP などで1枚にまとめることが多い 表は分けたまま、リレーションでつないで使う
更新作業 貼り付けと数式の修正を毎回手作業で行う 手順が記録され、更新ボタン1つで再実行される
共有 ファイルを配るため、版がずれやすい クラウド上の1つのレポートを全員が見る
得意なこと 自由な計算、手元での試算、細かい表づくり 決まった指標を繰り返し見る、対話的に掘り下げる

大切なのは、Power BI は Excel を置き換えるものではないということです。手元で自由に試算するなら Excel が向いていますし、毎月・毎週決まった指標を関係者で共有し続けるなら Power BI が向いています。両者は競合ではなく、役割の違う道具です。実際、Power BI のデータ取得元として Excel ファイルを使うことは日常的にあります。

やってみよう 1-1: レポートにしたいデータを書き出す

Power BI をインストールする前に、まず「自分の職場の何をレポートにしたいか」を言葉にしておきましょう。作りたいものが決まっていると、第2章以降の操作がぐっと頭に入りやすくなります。

手順

  1. 1 身の回りで、定期的に集計している数字を3つ書き出す（例: 月別の売上、案件の進捗、問い合わせ件数）。
  2. 2 それぞれについて「誰が見て、何を判断するのか」を1行で書き添える。ここが曖昧なレポートは、作っても使われません。
  3. 3 そのデータが今どこにあるか（Excel・基幹システム・Web など）をメモする。第3章の「データを取得する」で、実際の接続方法と結びつきます。
  4. 4 書き出したメモは第9章まで取っておく。レポート設計を学ぶときに、この「誰が何を判断するか」がそのまま設計の出発点になります。

理解度確認クイズ

  1. Q1. Power BI Desktop と Power BI Service は、それぞれどんな役割ですか？

    回答を表示

    Power BI Desktop は Windows PC にインストールしてレポートを作るためのアプリで、データの取得・整形・モデル作成・可視化を行います。Power BI Service はブラウザで使うクラウドサービスで、Desktop から発行したレポートを共有し、更新や権限を運用する場所です。「作るのは Desktop、配るのは Service」と覚えます。

  2. Q2. データがレポートになるまでの流れを、順番に説明してください。

    回答を表示

    「データを取得する → Power Query で整形する → データモデルで表どうしをつなぐ → DAX で指標を計算する → レポートで可視化する → Power BI Service で共有する」の順です。実務では前の工程に戻ることもありますが、この順番で積み上げるのが基本です。

  3. Q3. 毎月同じ集計を Excel で手作業していた業務を Power BI に置き換えると、何が改善しますか？

    回答を表示

    整形の手順が記録されるため、翌月は更新するだけで同じ集計が再現され、手作業とミスが減ります。また指標の計算方法が1か所に定義されるので人によって数字が変わらず、クラウド上の1つのレポートを全員が見るためファイルの版ずれも起きません。見る人が自分で切り口を変えられるので、作り直しの依頼も減ります。
