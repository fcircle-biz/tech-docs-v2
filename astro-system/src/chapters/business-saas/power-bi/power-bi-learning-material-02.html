ホーム Power BI 第2章
第2章 所要時間: 約60分

Power BI Desktop入門

前章で Power BI 全体の地図を確認したところで、この章からいよいよ手を動かします。Power BI Desktop をインストール・起動し、画面のどこに何があるかを覚え、レポートビュー・テーブルビュー・モデルビューという3つの顔を使い分けられるようになりましょう。最後に、みらい商事の売上データを読み込んで最初の棒グラフを作り、「触ったことがない」という状態から抜け出します。

この章で学ぶこと

  • Microsoft Store 版とインストーラ版の違いを理解し、無償・Windows専用・月次更新という特徴を説明できる
  • リボン・ビュー切り替えアイコン・キャンバス・右側の3つのペインなど、画面の主要な部分の名前と役割を言える
  • レポートビュー・テーブルビュー・モデルビューを、やりたい作業に応じて使い分けられる
  • .pbix ファイルに何が入っているかを理解し、Excel を読み込んで最初の棒グラフを作れる

2.1 Power BI Desktop のインストールと起動

Power BI Desktop の入手方法は大きく分けて2種類あります。どちらを選んでも使える機能は同じなので、まずは自分のPC環境に合うほうを選べれば十分です。

無償で使える

インストールしてレポートを作るところまでは無料です。他の人と共有する段階になって初めてライセンスが関係してきます（第10章）。

Windows専用

第1章で触れた通り、Power BI Desktop は Windows PC でのみ動作します。Mac の場合は仮想環境などの用意が必要です。

月次更新

Microsoft はおおむね月に1回のペースで機能を追加します。学習中に画面が本書と少し違って見えることがあります。

入手方法にはMicrosoft Store 版とインストーラ版があります。違いを整理すると次のとおりです。

比較する点 Microsoft Store 版 インストーラ版
入手先 Microsoft Store アプリ内で検索してインストール Microsoft の公式サイトから .exe をダウンロード
更新方法 Store が自動的に最新版へ更新する 都度ダウンロードし直すか、アプリ内から手動で更新する
必要な権限 管理者権限が無くても入れやすい 環境によっては管理者権限が必要になる
向いているケース 個人PCで気軽に試したい場合 会社支給PCで情報システム部門が配布・管理する場合

会社PCにインストールする前に

新人SEの場合、会社支給のPCには情報システム部門が許可したソフトしか入れられないことがあります。どちらの版を使うかを含め、インストール前に社内ルールを確認しておきましょう。個人PCで学習する場合はどちらを選んでも構いません。

2.2 画面構成をつかむ

Power BI Desktop を起動すると、最初は情報量の多さに戸惑うかもしれません。しかし画面は大きく4つのエリア（リボン・ビュー切り替えアイコン・キャンバス・右側のペイン）に分かれているだけです。ここでいうペインとは、特定の役割を持つ小さな作業パネルのことです。名前と場所を先に覚えてしまえば、以降の章で「〇〇ペインを開いて」と言われたときに迷わなくなります。

名称 画面上の位置 何をするところか
リボン 画面いちばん上 ホーム・挿入・モデリングなどのタブが並ぶ操作の起点。タブを切り替えるとボタンの中身も変わる
ビュー切り替えアイコン 画面左端の縦一列 レポートビュー・テーブルビュー・モデルビューを切り替える3つのアイコン（詳しくは2.3）
キャンバス 画面中央の広い領域 グラフや表（ビジュアル）を実際に配置していく作業スペース。ここがそのままレポートの見た目になる
データペイン 画面右側（上段） 読み込んだテーブルと列の一覧（Sales・Products など）を表示。使いたい列をキャンバスへドラッグする
視覚化ペイン 画面右側（中段） グラフの種類の一覧と書式設定。種類を選び、色やタイトルなど見た目を整える
フィルターペイン 画面右側（下段） 絞り込み条件の一覧。条件を追加して表示データを絞り込む（詳しくは第8章）

整理すると、データペインで「何を使うか」を選び、視覚化ペインで「どう見せるか」を決め、フィルターペインで「どこまで絞り込むか」を調整する、という役割分担です。この3ペインの関係は本ガイドを通してずっと使い続けるので、ここで感覚をつかんでおきましょう。

2.3 3つのビューの使い分け

画面左端のアイコンをクリックすると、Power BI Desktop は3つの異なる「顔」に切り替わります。これをビューと呼びます。どのビューも同じ1つのファイルを見ているだけなので、切り替えてもデータが消えたり壊れたりする心配はありません。

ビュー 見えるもの・できること 主に使う場面 詳しく学ぶ章
レポートビュー グラフや表（ビジュアル）を配置したキャンバス レポートの見た目を作る・整える 第8章・第9章
テーブルビュー 読み込んだデータを Excel のような格子で1行ずつ表示 データの中身を確認する、DAX で計算列を追加する 第7章
モデルビュー テーブル同士のつながり（リレーション）を図で表示 テーブルをつなぐ、つながりを確認・整理する 第5章・第6章

言葉だけだとイメージしづらいので、「今何をしたいか」からどのビューに行けばよいかを図にしておきます。

必要ならDAXで列を追加する"] D --> G["テーブルをドラッグして
リレーションを作成・確認する"]

重要ポイント: 迷ったらレポートビュー

起動直後は基本的にレポートビューが開きます。作業の大半はレポートビューで完結し、テーブルビューとモデルビューは「確認したい・つなぎたいときだけ寄り道する」場所というくらいの感覚で構いません。まずはレポートビューの操作に慣れることを優先しましょう。

2.4 .pbix ファイルとは

Power BI Desktop で保存すると、.pbix という拡張子のファイルが1つできます。この1ファイルの中に、取り込んだデータ・データモデル（テーブルの構造やリレーション、メジャーなどの定義）・レポート（ページやビジュアルの配置）という3つがまとめて入っています。お弁当箱に例えるなら、ご飯・おかず・箱そのものが一体になっているようなイメージです。

この仕組みのおかげで、.pbix ファイルを1つコピーして別のPCに渡すだけで、データも含めてそのまま同じレポートを開けます。反面、データを内部に抱え込むぶんファイルサイズは大きくなりやすい点も覚えておきましょう。

拡張子 中身 データそのものを含むか 主な用途
.pbix データ＋モデル＋レポート 含む 通常の保存・共有。本ガイドではこの形式を使う
.pbit モデルの定義とレポートのデザイン（データを取得する手順や見た目） 含まない（開くたびに読み込みが必要） ひな形として配布し、別のデータで同じ構造のレポートを作る

.pbit（テンプレート）は、たとえば「店舗ごとに同じレイアウトのレポートを配りたいが、データだけ差し替えたい」というときに使う仕組みです。今の段階では「そういうものもある」と名前だけ覚えておけば十分です。

こまめな保存とファイル名の付け方

Power BI Desktop をローカルのフォルダーに保存して使う場合、Word のような自動保存・変更履歴の機能は働きません（OneDrive for Business や SharePoint 上のフォルダーに保存すると、自動保存とバージョン履歴が利用できます）。作業のきりが良いところで Ctrl+S を押す習慣をつけましょう。また「売上分析_v1.pbix」のように連番を付けて保存すると、後から前の状態に戻したいときに助かります。ファイルを安全に共有・管理する方法は、第10章で扱う Power BI Service で解決します。

2.5 最初のレポートを作る

ここまでの用語が分かったところで、実際にみらい商事の売上データを読み込み、「カテゴリ別売上」の棒グラフを1つ作ってみましょう。使うのは Sales（売上明細）と Products（商品マスタ）の2つの Excel シートです。中身はそれぞれ次のようなイメージです（接続方法そのものは第3章で詳しく扱います）。

Products は ProductID・ProductName・Category・UnitPrice（文具は数十円〜数百円、什器は数千円〜数万円程度）という列を持ち、Sales は SalesID・OrderDate・ProductID・CustomerID・StoreID・Quantity・Amount（1行あたり数千円〜数万円程度）という列を持ちます。Category ごとに Amount を合計する、というのが今回作るグラフの中身です。それでは、読み込みからグラフ完成・保存までを順番に進めます。

  1. 1 ホーム タブの データを取得 → Excel ブック を選ぶ。
  2. 2 サンプルの Excel ファイル（売上データ.xlsx など）を選んで開く。
  3. 3 ナビゲーターという一覧画面が開くので、Sales と Products にチェックを入れる（この画面の詳しい見方は第3章で扱う）。
  4. 4 読み込む をクリックする。数秒待つとデータペインに Sales・Products が表示される。
  5. 5 キャンバスの何もないところをクリックし、視覚化ペインで集合縦棒グラフ（複数のカテゴリを横に並べて比較する、いちばん基本的な棒グラフです）のアイコンを選ぶ。キャンバスに空のグラフ枠が追加される。
  6. 6 データペインで Products を展開し、Category を視覚化ペインの X軸 の枠へドラッグする。
  7. 7 データペインで Sales を展開し、Amount を Y軸 の枠へドラッグする。カテゴリごとの合計金額が自動計算され、棒グラフが表示される。
  8. 8 グラフを選択したまま視覚化ペインの 書式（ペイントローラーのアイコン）を開き、全般 → タイトル でテキストを「カテゴリ別売上」に変更する。
  9. 9 Ctrl+S（または ファイル → 名前を付けて保存）で「売上分析_第2章.pbix」として保存する。

数値を置くと自動的に合計される

Amount のような数値の列を 値 の枠に置くと、Power BI は既定で合計（SUM）を計算します。合計・平均・件数などの集計方法は、列名部分をクリックすると変更できます。この「集計方法を自分で定義し直す」という考え方は、第7章の DAX で本格的に扱います。なお、軸や値、書式ペインの項目名などはバージョンによって表記が異なる場合があります。

やってみよう 2-1: 「カテゴリ別売上」の棒グラフを作って保存する

2.5 の手順を実際に自分の手で操作し、3つのビューを行き来しながら結果を確認してみましょう。

手順

  1. 1 2.5 の手順1〜4にしたがって、Sales と Products の Excel を読み込む。
  2. 2 集合縦棒グラフを配置し、Category を軸に、Amount を値にドラッグしてタイトルを「カテゴリ別売上」に変更する。
  3. 3 画面左のアイコンでテーブルビューに切り替え、Sales テーブルの中身が Excel の表のように1行ずつ見えることを確認する。
  4. 4 モデルビューにも切り替え、Sales と Products がどう表示されているかを眺めてみる（リレーションの詳細は第5章）。
  5. 5 レポートビューに戻り、ファイル名「売上分析_第2章.pbix」で保存する。

理解度確認クイズ

  1. Q1. レポートビュー・テーブルビュー・モデルビューは、それぞれどんな作業をするときに使いますか？

    回答を表示

    レポートビューはグラフや表を配置してレポートの見た目を作るとき、テーブルビューは読み込んだデータの中身を Excel のような格子で1行ずつ確認したり計算列を追加するとき、モデルビューはテーブル同士のつながり（リレーション）を確認・整理するときに使います。画面左端のアイコンで、やりたい作業に応じて切り替えます。

  2. Q2. .pbix ファイルには何が入っていますか？

    回答を表示

    取り込んだデータ、データモデル（テーブルの構造やリレーション、メジャーなどの定義）、レポート（ページやビジュアルの配置）の3つが1つのファイルにまとめて入っています。そのため .pbix ファイルを1つコピーするだけで、データも含めて別のPCでもそのまま開けます。

  3. Q3. データペインと視覚化ペインの違いは何ですか？

    回答を表示

    データペインは読み込んだテーブルと列の一覧が表示される場所で、グラフに使いたい列を探して選ぶために使います。視覚化ペインはグラフや表の種類を選んだり、色やタイトルなどの見た目を書式設定する場所です。「データペインで何を使うか選び、視覚化ペインでどう見せるか決める」という役割分担になっています。
