ホーム Excel VBA 第6章
第6章 所要時間: 約90分

セルとセル範囲の操作

第5章では、値を一時的に覚えておく「変数」の使い方を学びました。この章では、その値をいよいよワークシートのセルに書き込み、セルの値を読み取る方法を学びます。VBAで行う自動化は、突き詰めれば「どのセルを指定し、そこに何を読み書きするか」の繰り返しです。セルを指定する2つの方法（RangeとCells）、値の読み書きに使う3つのプロパティ（Value・Text・Formula）、書式の整え方、そして記録マクロにありがちな遅くて壊れやすい書き方（Select）を卒業する方法まで、実務でそのまま使える形でしっかり身につけていきましょう。

この章で学ぶこと

  • RangeとCellsを場面に応じて使い分け、目的のセルを指定できる
  • Value・Text・Formulaの違いを説明し、値と数式を書き分けられる
  • フォント・背景色・罫線・表示形式などの書式をVBAで設定できる
  • Selectを使わずに、対象を直接操作するコードが書ける
  • End(xlUp)で最終行を求め、データ量が変わっても壊れない範囲指定ができる

この章から書き込むデータ: F列「金額」

第1章で紹介したとおり、「売上明細」シートは1行目が見出しで、2行目以降に A列＝日付・B列＝支店・C列＝商品名・D列＝単価・E列＝数量 が並んでいます。この章では、D列（単価）×E列（数量）の計算結果を、初めてF列「金額」にVBAで書き込みます。見出しのF1〜H1はこの章でまとめて用意しますが、値としてのランク（G列）は第7章、エリア（H列）は第10章で追加していきます。

6.1 Rangeでセルを指定する — 番地で場所を伝える

VBAでセルを指定する方法には、大きく2つの流儀があります。1つ目がこの節で扱う Range です。Range は「A1」「A1:E10」のように、Excelの画面に表示されているセル番地をそのまま文字列で指定する方法で、コードを読んだときに「どこを指しているか」が直感的に分かるのが長所です。書き方にはいくつかのパターンがあります。

パターン 書き方 意味
単一のセル Range("A1") A1セルだけを指定する
連続する範囲 Range("A1:E10") A1からE10までの矩形範囲をまとめて指定する
離れた複数のセル Range("A1,C1,E1") カンマで区切ると、離れたセルもまとめて指定できる
名前定義済みの範囲 Range("売上範囲") あらかじめ名前ボックスなどで名前を付けた範囲を、その名前で指定する

どの指定方法を使うときも、必ず気をつけたいことがあります。

ヒント: シート名は省略しない

Range("A1") のようにシート名を省略すると、そのとき画面に表示されている「アクティブシート」が対象になります。マクロ実行時にどのシートが表示されているかは状況しだいなので、省略すると意図しないシートを書き換えてしまう事故につながります。本ガイドでは常に Worksheets("売上明細").Range("A1") のように、シートから明記する書き方で統一します。

このシート→セルという関係をもう少し広げて見てみましょう。第1章で見たオブジェクトの入れ子構造をRangeまで含めて描くと次のようになります。

flowchart TD A["Application
（Excel本体）"] --> B["Workbook
（売上管理.xlsm）"] B --> C["Worksheet
（売上明細シート）"] C --> D["Range
（セル範囲を表すオブジェクト）"] D --> E["1つのセルを表すRange
Range（A1）／Cells（1, 1）"] D --> F["複数のセルを表すRange
Range（A1:E1）／Range（F2:F11）"]

図の説明: Excel VBAでは、1個のセルもセル範囲も、どちらも同じRangeオブジェクトとして扱います。「セル」という別の種類のオブジェクトがあるわけではありません。Worksheets("売上明細").Range("A1") は1つのセルを指すRange、Worksheets("売上明細").Range("A1:E1") は5つのセルをまとめて指すRangeです。Cells(1, 1) もRangeを返します。Cells は「行番号・列番号でセルを指す書き方」であって、別のオブジェクトではありません。

Rangeは番地を人間の言葉でそのまま書けるのが強みですが、「C列の、変数で決まった行」のように計算で位置を決めたい場面には不向きです。次の6.2では、数値で位置を指定できる Cells を見ていきます。

6.2 Cellsで行・列の番号から指定する — 数値で場所を伝える

Cells は Cells(行番号, 列番号) という形式で、行と列を数値で指定する方法です。たとえば Cells(2, 4) は「2行目・4列目」つまりD2セルを指します。列は数値の代わりに列名を文字列で渡すこともでき、Cells(2, "D") と書いても同じD2セルになります。

Rangeが向いている場面

「A1」「F2:F30」のように決まった場所を直接書くとき。離れた複数セルをまとめて指定するときや、名前付き範囲を使うときにも便利です。

Cellsが向いている場面

行番号や列番号を変数で計算しながら指定したいとき。「1行ずつ下にずらしながら処理する」といった繰り返し処理（第8章で本格的に使います）と特に相性が良い書き方です。

RangeとCellsは組み合わせて使うこともできます。Range(Cells(2, 1), Cells(10, 5)) のように、Rangeの引数に2つのCellsを渡すと、その2点を対角とする矩形範囲（この場合はA2:E10）を指定できます。「開始位置」「終了位置」の両方を変数で決めたいときに使う形です。

ここまでは Worksheets("売上明細").Range(...) と毎回シート名から書いてきましたが、同じシートを何度も操作するときは、シートを変数に入れておくと簡潔になります。ただし「もの」を変数に入れるときは、次のように Set という特別なキーワードが必要です。

Setによるオブジェクト変数の使い方 — RangeとCellsで書き込む 
Sub WriteCells()
    Dim ws As Worksheet
    ' シートという「もの」を変数に入れるときは Set を付ける
    Set ws = Worksheets("売上明細")
    ws.Range("F1").Value = "金額"      ' Range は番地で指定する
    ws.Cells(1, 7).Value = "ランク"    ' Cells は 行番号, 列番号 で指定する（G1）
    ws.Cells(1, "H").Value = "エリア"  ' 列は文字でも指定できる（H1）
End Sub

はじめに Dim ws As Worksheet と型を宣言し、続く Set ws = Worksheets("売上明細") で「売上明細シートというもの」をws変数に結び付けています。以降は ws.Range(...)・ws.Cells(...) と書くだけで、毎回シート名を書かずに同じシートを操作できます。

注意: Setの付け忘れに気をつける

Dim ws As Worksheet と宣言したのに ws = Worksheets("売上明細") と Set を付けずに書くと、「オブジェクト変数または With ブロック変数が設定されていません」（実行時エラー91）などのエラーになります。

見分け方はシンプルです。ワークシート・セル範囲・ブックといった「もの」を変数に入れるときは必ずSet、数値や文字列を入れるときはSetを付けない、と覚えておきましょう。

6.3 値を読む・書く — Value / Text / Formula

セルの中身を読み書きするとき、目的に応じて使い分けるべき3つのプロパティがあります。Value は実際の値そのもの（計算結果の数値など）、Text は表示形式を適用した後に画面に見えている文字列（読み取り専用）、Formula はセルに入っている数式そのものです。同じセルに対してこの3つを取得すると、見た目以上に違いがはっきりします。

値・表示文字列・数式の違いを見比べる 
Sub CompareValueTextFormula()
    Dim ws As Worksheet
    Set ws = Worksheets("売上明細")
    ws.Range("F2").Formula = "=D2*E2"                 ' 数式を設定する
    ws.Range("F2").NumberFormatLocal = "#,##0""円"""  ' 表示形式を設定する
    Debug.Print "Value  : " & ws.Range("F2").Value    ' 計算結果の数値
    Debug.Print "Text   : " & ws.Range("F2").Text     ' 画面に見えている文字列
    Debug.Print "Formula: " & ws.Range("F2").Formula  ' 数式そのもの
End Sub

「売上明細」の2行目、D2（単価）が480円、E2（数量）が12個だとすると、Debug.Print（第3章で使ったイミディエイトウィンドウへの出力命令）の結果は次のようになります。

イミディエイトウィンドウの表示例 
Value  : 5760
Text   : 5,760円
Formula: =D2*E2

Value は計算結果の数値 5760 をそのまま返しますが、Text は表示形式（桁区切りと「円」の文字）が適用された後の見た目である 5,760円 という文字列を返します。Formula は計算結果ではなく、セルに入力されている数式 =D2*E2 そのものです。Text は「読み取り専用」なので、セルに値や文字列を書き込むときには使えない点にも注意してください。表示形式そのものは NumberFormatLocal プロパティで設定します。

6.4 書式を設定する — フォント・色・罫線・幅を整える

VBAでは、Excelの画面上でリボンから設定できる書式のほとんどを、セルのプロパティとして設定できます。「売上明細」の見出し行や金額列を例に、よく使うプロパティを見ていきましょう。

プロパティ 例 内容
Font.Bold .Font.Bold = True 太字にする
Font.Size .Font.Size = 14 文字サイズを14ポイントにする
Font.Color .Font.Color = RGB(255, 0, 0) 文字色を赤にする
Interior.Color .Interior.Color = vbYellow 背景色を黄色にする
Borders.LineStyle .Borders.LineStyle = xlContinuous 罫線を引く
HorizontalAlignment .HorizontalAlignment = xlCenter 横方向を中央揃えにする
EntireColumn.AutoFit .EntireColumn.AutoFit 列幅を内容に合わせて自動調整する

色の指定方法には2通りあります。どちらも同じように使えるので、場面に応じて選んでください。

RGB関数で指定する

RGB(赤, 緑, 青) のように、0〜255の数値を3つ組み合わせて色を指定します。RGB(221, 235, 247) のように、細かい色合いを自由に作れます。

組み込み定数で指定する

vbYellow・vbRed・vbBlue など、あらかじめ名前が付いた代表的な色を使います。細かい色合いは選べませんが、手早く指定できます。

これらのプロパティを見出し行 A1:H1 にまとめて設定してみましょう。ただし、プロパティを1つ設定するたびに Worksheets("売上明細").Range("A1:H1") と書き直すのは冗長です。次の6.5では、この冗長さを解消する書き方と、記録マクロにありがちな遅い書き方を卒業する方法をあわせて学びます。

6.5 Selectを使わない書き方とWithステートメント

第3章でマクロの記録を試した人は、記録されたコードの中に Select と Selection が何度も出てくるのに気づいたかもしれません。「まずセルを選択し、選択した範囲（Selection）に対して操作する」という、人間の手作業をそのまま再現した書き方です。

記録マクロに多いSelect中心の書き方（非推奨） 
Sub FormatHeaderRowBad()
    ' 記録マクロによくある書き方：まず選択してから操作する
    Worksheets("売上明細").Activate
    Range("A1:H1").Select
    Selection.Font.Bold = True                    ' 選択範囲を太字にする
    Selection.Interior.Color = RGB(221, 235, 247)  ' 選択範囲を薄い青で塗る
    Selection.HorizontalAlignment = xlCenter       ' 選択範囲を中央揃えにする
End Sub

一見自然に見えるこの書き方には、実務で困る欠点が3つあります。

欠点 内容
実行が遅い 選択のたびに画面が再描画されるため、行数が多いと目に見えて遅くなる
アクティブシートに依存して壊れる 別のシートが表示された状態で実行すると、意図しないシートを書き換えてしまう
画面がちらつく 選択範囲が次々に切り替わるのが見えてしまい、実行中の見た目も良くない

注意: 「選んでから操作する」癖を手放す

記録マクロを見た後は、つい Select → Selection の書き方を真似したくなります。しかし本ガイドでは、対象を選ばずに直接指定する書き方に統一します。Selection.Font.Bold = True ではなく Worksheets("売上明細").Range("A1:H1").Font.Bold = True のように、操作対象をその場で名指しする、と覚えてください。

とはいえ、同じ範囲に対して複数のプロパティを設定するときに、毎回 Worksheets("売上明細").Range("A1:H1") を書き直すのも面倒です。そこで使うのが With 〜 End With です。同じオブジェクトへの指定が続くときにまとめて書け、Withの中では先頭の点（.Font のように）だけを書けば済みます。

Withで見出し行の書式をまとめて設定する 
Sub FormatHeaderRow()
    ' 同じ対象への指定が続くときは With でまとめると読みやすい
    With Worksheets("売上明細").Range("A1:H1")
        .Font.Bold = True                     ' 太字にする
        .Interior.Color = RGB(221, 235, 247)  ' 薄い青で塗る
        .HorizontalAlignment = xlCenter       ' 中央揃えにする
        .Borders.LineStyle = xlContinuous     ' 罫線を引く
    End With
End Sub

With Worksheets("売上明細").Range("A1:H1") で対象を1回だけ指定し、End With までの間はその対象に対する操作だけを書けます。Select を使わずに対象を直接指定しているうえ、同じ範囲を4回書く必要もなくなり、6.4で感じた冗長さも解消されています。

6.6 表の範囲を動的に求める — 最終行を自動で探す

「売上明細」のデータ行数は、月によって増えたり減ったりします。もし Range("F2:F50") のように行番号を決め打ちすると、データが50行を超えたときに数式が入らず、50行に満たないときは空のセルにまで数式が入ってしまいます。そこで使うのが、今何行あるかをそのつど求めるという考え方です。

flowchart TD A["A列の一番下のセル
（1048576行目）"] --> B["上方向に検索
（Ctrl＋↑と同じ動き）"] B --> C["最初に値が見つかったセル
（A11）"] C --> D[".Row プロパティで
行番号を取り出す"] D --> E["lastRow に 11 が入る"]

図の説明: Cells(Rows.Count, "A").End(xlUp) は、A列の一番下のセルから、Ctrl＋↑キーを押したときと同じように上方向へ値のある最後のセルまで移動します。そのセルの .Row を読み取ることで、現在のデータの最終行番号が分かります。

コードでは ws.Cells(ws.Rows.Count, "A").End(xlUp).Row という形で書きます。Rows.Count はそのシートの最大行数（Excel 2007以降は1,048,576行）、End(xlUp) はそこから上方向に検索して最初に値があるセルを返すプロパティです。手作業で表の一番下のセルをクリックしてCtrl＋↑を押す操作と、まったく同じ動きをコードで再現していると考えてください。表全体を一気に扱いたいときは、空行・空列で囲まれたひとまとまりの範囲（見出し行を含む表全体）を返す CurrentRegion（現在の領域）というプロパティも用意されています。

最終行を求めて、金額列にFormulaR1C1で数式を一括設定する 
Sub SetAmountFormula()
    Dim ws As Worksheet
    Dim lastRow As Long
    Set ws = Worksheets("売上明細")
    ' A列の最下端から上へたどり、値のある最後の行番号を得る
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
    ' F2から最終行まで、まとめてR1C1形式の数式を入れる（行番号は自動で調整される）
    ws.Range("F2:F" & lastRow).FormulaR1C1 = "=RC[-2]*RC[-1]"
    ws.Range("F2:F" & lastRow).NumberFormatLocal = "#,##0"
End Sub

"F2:F" & lastRow の & は文字列を連結する演算子です。lastRow が11なら "F2:F11" という文字列が組み立てられ、それがそのまま Range の引数になります。行番号をコードの中に直接書き込んでしまうこと（ハードコーディング）をせず、実行のたびに最終行を求め直しているので、来月データが40行に増えても、コードを直す必要はありません。

数式の指定には Formula ではなく FormulaR1C1 を使いました。Formula = "=D2*E2" のようなA1形式の数式を範囲全体に設定した場合も、Excelが自動的に相対参照として1行ずつずらして展開するため、結果はどちらも同じになります。ただし、そのコードを読んだだけでは「D2・E2はF2から見て何列目にあるのか」が読み取りにくいという弱点があります。R1C1形式は、行（Row）と列（Column）を番号で表す数式の書き方で、「その数式が入っているセルを基準に、どれだけ離れた行・列を参照しているか」がコードにそのまま現れます。

記号 意味 F2の場合 F11の場合
R（数字なし） 同じ行 2行目 11行目
C[-2] 2つ左の列 D列 D列
C[-1] 1つ左の列 E列 E列
→ 実際に設定される数式 =D2*E2 =D11*E11

R に数字を付けなければ「その数式が入っている行そのもの」、C[-2] は「その数式が入っているセルから左に2つ目の列」を意味します。つまり =RC[-2]*RC[-1] は「同じ行の、2つ左の列 × 1つ左の列」であり、F列から見ればD列×E列になります。ws.Range("F2:F11").FormulaR1C1 = "=RC[-2]*RC[-1]" と1つの数式文字列を範囲全体に設定するだけで、F2には =D2*E2、F11には =D11*E11 というように、セルごとに合わせた数式が自動的に展開されます。列の並びが変わったときも「2つ左×1つ左」という書き方のままなら誤りに気づきやすく、A1形式で1つずつ数式を書き換えるより安全です。

重要: 「壊れないコード」を書く基本パターン

Cells(Rows.Count, "A").End(xlUp).Row で最終行を求めてから範囲を組み立てる、という流れは、この先の章（特に第8章の繰り返し処理、第9章のブック操作）で何度も登場する定番パターンです。行番号を決め打ちせず、そのつど求め直す習慣を、この章のうちに身につけておきましょう。

ヒント: "A" & i を "Ai" と書き間違えない

変数の値を使って1つのセル番地を組み立てるときは、Range("A" & i) のように&で連結する必要があります。うっかり Range("Ai") と書いてしまうと、変数iの値ではなく「Ai」という文字どおりの名前として解釈され、エラーや意図しない動作の原因になります。行を変数で動かしたい場面では、Cells(i, "A") のようにCellsを使うほうが書き間違えにくく安全です。

やってみよう 6-1: SetupSalesSheet を作る

「売上明細」シートに対して、この章で学んだ内容をまとめて使うマクロ SetupSalesSheet を作ってみましょう。

手順

  1. 1 F1に「金額」、G1に「ランク」、H1に「エリア」の見出しを追加する。
  2. 2 Cells(Rows.Count, "A").End(xlUp).Row で最終行を求め、Debug.Print で確認する（イミディエイトウィンドウの出し方は第3章を参照）。
  3. 3 F2から最終行まで、FormulaR1C1 で =RC[-2]*RC[-1] の数式と、桁区切りの表示形式（NumberFormatLocal）を設定する。
  4. 4 見出し行A1:H1を With を使って、太字・薄い青の背景・中央揃え・罫線に整える。
  5. 5 A〜H列の幅を EntireColumn.AutoFit で自動調整する。
  6. 6 完成したら「売上明細」シートにデータを3行追加し、もう一度 SetupSalesSheet を実行して、追加した行にも数式が入ることを確認する。

実行前 ―「売上明細」シートの状態

この演習は、下の状態から始めます。A〜E列に10件のデータが入力済みで、F〜H列はまだ何も無い状態です。

    A列        B列    C列            D列   E列
 1  日付        支店   商品名         単価  数量
 2  2026/04/01  東京   A4コピー用紙    480   12
 3  2026/04/01  横浜   付箋セット      320   50
 …（11行目まで、合計10件）
※ F列・G列・H列はまだありません。

実行するコード

SetupSalesSheet（完成例） 
Sub SetupSalesSheet()
    Dim ws As Worksheet
    Dim lastRow As Long
    Set ws = Worksheets("売上明細")

    ' 1. 見出しを追加する
    ws.Range("F1").Value = "金額"
    ws.Range("G1").Value = "ランク"
    ws.Range("H1").Value = "エリア"

    ' 2. 最終行を求めて確認する
    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
    Debug.Print lastRow

    ' 3. 金額の数式と表示形式を設定する
    ws.Range("F2:F" & lastRow).FormulaR1C1 = "=RC[-2]*RC[-1]"
    ws.Range("F2:F" & lastRow).NumberFormatLocal = "#,##0"

    ' 4. 見出し行の書式を整える
    With ws.Range("A1:H1")
        .Font.Bold = True
        .Interior.Color = RGB(221, 235, 247)  ' 薄い青
        .HorizontalAlignment = xlCenter
        .Borders.LineStyle = xlContinuous
    End With

    ' 5. 列幅を自動調整する
    ws.Range("A1:H1").EntireColumn.AutoFit
End Sub

理解度確認クイズ

  1. Q1. Range("F2").Value と Range("F2").Text の違いとして正しいものはどれか。

    • ア. どちらも同じ結果を返す
    • イ. Valueは実際の値、Textは表示形式を適用した後の「画面に見えている文字列」を返す
    • ウ. Textはセルに文字列を書き込むためのプロパティである
    回答を表示

    正解: イ
    金額 5760 に #,##0"円" の表示形式が付いていれば、Value は 5760、Text は 5,760円 を返します。Text は読み取り専用で、書き込みには使えません。

  2. Q2. Cells(3, 2) はどのセルを指すか。

    • ア. C2
    • イ. B3
    • ウ. C3
    回答を表示

    正解: イ
    Cells(行, 列) の順なので、3行目・2列目でB3になります。「行が先、列が後」はRange("B3")のような番地表記（列が先）と順序が逆になるため、混同しやすい要注意ポイントです。

  3. Q3. 金額列に数式を入れる範囲を Range("F2:F50") と決め打ちせず、End(xlUp) で最終行を求めてから組み立てるのはなぜか。

    回答を表示

    「売上明細」のデータ行数は月によって増減するためです。行番号を50に決め打ちすると、データが50行を超えたときに一部の行へ数式が入らず、50行に満たないときは空のセルにまで数式が入ってしまいます。End(xlUp) でそのときの実際のデータ量に応じた最終行を求めれば、行数が変わってもコードを直さずに済みます。

この章のまとめ

  • Rangeは番地で直接指定し、Cellsは行・列を数値で指定する。変数で位置を計算したいときはCellsが向いている。
  • ワークシートやセル範囲など「もの」を変数に入れるときは、必ずSetを付ける。
  • Valueは実際の値、Textは表示形式を適用した文字列（読み取り専用）、Formulaは数式そのものである。
  • Selectを使わず対象を直接操作する。同じ対象への指定が続くときはWith 〜 End Withでまとめる。
  • Cells(Rows.Count, "A").End(xlUp).Rowで最終行を求めれば、データ量が変わっても壊れないコードになる。
