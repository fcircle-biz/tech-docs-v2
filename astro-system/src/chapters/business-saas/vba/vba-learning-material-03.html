ホーム Excel VBA 第3章
第3章 所要時間: 約60分

マクロの記録と実行

第2章でVBEと 売上管理.xlsm の準備が整いました。この章では、まだ1行もコードを書かないまま、Excelの「マクロの記録」機能を使ってVBAを体験します。実際に行った操作がそのままコードに変換される様子を見ることで、「VBAのコードは、Excelの操作を文字にしたものだ」という感覚をつかみます。あわせて記録したマクロを実行する4つの方法、絶対参照と相対参照という2つの記録方式の違い、そして記録機能だけではできないことも確認し、第4章から始まる文法学習への橋渡しとします。

この章で学ぶこと

  • 「マクロの記録」で自分のExcel操作を記録し、再生（実行）できる
  • 記録されたコードを読み、行った操作とコードの各行を対応づけて説明できる
  • 絶対参照での記録と「相対参照で記録」の違いを説明し、使い分けられる
  • 記録マクロでできないことを挙げ、VBAを書く必要がある場面を判断できる

3.1 マクロの記録は「操作の録画」

Excelには、自分が行った操作をそのままVBAのコードに変換してくれる「マクロの記録」という機能があります。プログラミングの知識がなくても使える機能なので、VBAの最初の一歩として最適です。まずは身近なたとえで、この機能の正体をつかみましょう。

動画撮影（たとえ）

録画ボタンを押し、料理や作業の手順を撮影し、停止ボタンを押すと、一連の動きがそのまま動画ファイルになります。あとで再生すれば、同じ手順がそのまま再現されます。

マクロの記録（Excel版の録画）

［マクロの記録］を押し、セルの選択や書式設定を行い、［記録終了］を押すと、行った操作がそのままVBAのコードになります。マクロを実行すれば、同じ操作が再現されます。

記録を開始すると、まず次の4つの項目を確認するダイアログが表示されます。ここで指定した内容も、記録されるコードに影響します。

項目 内容
マクロ名 先頭は文字、以降は文字・数字・アンダースコアのみ使えます。スペースや「－」「！」などの記号は使えません
マクロの保存先 既定は「作業中のブック」。どのブックからでも使いたい場合は「個人用マクロブック」を選びます
ショートカットキー 任意項目。Ctrl＋英字1文字を割り当てられます。大文字で入力すると Ctrl＋Shift＋英字になります（空欄のままでも構いません）
説明 マクロの内容をメモとして残せる欄です。あとで見返すときに役立ちます

実際に体験してみましょう。「売上明細」シートの見出し行（A1:E1）を選択し、太字にして黄色で塗りつぶす、という操作を［マクロの記録］で記録します。手順は次のとおりです。

  1. 1［開発］タブ →［マクロの記録］をクリックする
  2. 2ダイアログでマクロ名などを確認し、［OK］を押す（この時点から記録が始まる）
  3. 3A1:E1 を選択し、太字ボタンを押し、塗りつぶしの色を黄色にする
  4. 4［開発］タブ →［記録終了］をクリックする
sequenceDiagram autonumber participant U as ユーザー participant E as Excel participant V as VBE U->>E: マクロの記録を開始 U->>E: セルの選択・書式設定を操作 U->>E: 記録終了をクリック E->>V: 操作をVBAコードに変換して保存 Note over V: 標準モジュールにコードが残る U->>E: マクロを実行 E->>V: 保存されたコードを読み出す V-->>E: 命令を1行ずつ実行 E-->>U: セルの見た目が変化する

図の説明: 記録中はユーザーの操作がExcelを通じてVBEのコードに変換・保存されます。実行時にはその逆で、保存されたコードをExcelが読み出し、1行ずつ命令として実行することで、記録したときと同じ見た目の変化が再現されます。

ヒント: 記録前に手順を紙に書き出しておく

マクロの記録は、記録を開始してから終了するまでの操作をすべてコードにします。途中でシートを切り替えた、関係のないセルをクリックした、といった操作もそのまま記録されてしまいます。記録を始める前に「①A1:E1を選択 → ②太字 → ③黄色で塗る」のように手順を紙に書き出し、迷わず操作できる状態にしてから記録を開始すると、余計な行が生まれません。

3.2 記録されたコードを読む

記録を終えたら、第2章で開き方を覚えたVBE（Alt + F11）を開き、標準モジュールに追加されたコードを確認してみましょう。先ほどの操作は、次のようなコードになって残っています。

マクロの記録が生成したコード — 見出し行を太字＋黄色にする 
Sub Macro1()
    ' ここから下は「マクロの記録」が自動生成したコード
    Range("A1:E1").Select          ' A1:E1 を選択した
    Selection.Font.Bold = True     ' 選択中のセルを太字にした
    With Selection.Interior
        .Color = 65535             ' 選択中のセルを黄色で塗った
    End With
    Range("A2").Select             ' 最後に A2 をクリックした操作まで記録される
End Sub

一見むずかしそうですが、読み方には決まったパターンがあります。記録されたコードの多くは「①何かを選ぶ → ②選んだものに命令する」という2段構えで書かれています。1行ずつ日本語に訳してみましょう。

  • Sub Macro1() — ここから1つのマクロが始まる。マクロ名を既定の「Macro1」のまま［OK］を押したので、この名前になった
  • Range("A1:E1").Select — ①選ぶ：A1からE1までを選択する
  • Selection.Font.Bold = True — ②命令する：選んだもの（Selection）の文字を太字にする
  • With Selection.Interior ～ End With — 「選んだものの塗りつぶし（Interior）について、まとめて設定する」という範囲を示す書き方
  • .Color = 65535 — 塗りつぶしの色を表す数値。65535は黄色にあたる
  • Range("A2").Select — 記録終了の直前にA2をクリックした操作まで、そのまま記録されている

このように、記録されたコードは「自分が行った操作の順番」をそのまま日本語ならぬVBA語に翻訳したものだと考えると読みやすくなります。

ヒント: 全部読めなくても大丈夫です

セルの塗りつぶし1つを記録しただけでも、自分では意識していない背景パターンやテーマ色のプロパティまで6〜7行にわたって生成されることがあります。これは正常な動作です。自分が意図した操作に対応する行だけを拾い読みできれば十分で、残りは削除しても多くの場合そのまま動きます。迷ったら1行ずつ削除して実行し、結果が変わらなければ「なくても良い行だった」と確認する練習が効果的です。

先ほどのコードには、実は無駄があります。「A1:E1を選ぶ」→「選んだものに命令する」という2段構えをやめて、選択せずに直接命令すると、次のように短く書けます。この書き方は第6章でセル操作を本格的に学ぶときの土台になるので、ここでは「こういう書き方もできる」と知っておくだけで十分です。

Select を使わずに書き直したコード（第6章で本格的に学ぶ書き方） 
Sub FormatHeader()
    ' 選択せずに「A1:E1 に対して直接」命令する書き方
    Range("A1:E1").Font.Bold = True         ' 太字にする
    Range("A1:E1").Interior.Color = vbYellow ' 黄色で塗る
End Sub

vbYellow はVBAがあらかじめ用意している「黄色」を表す名前で、65535 と同じ色を指します。数値より意味が伝わりやすいため、自分でコードを書くときはこうした名前付きの値がよく使われます。

3.3 マクロを実行する4つの方法

記録したマクロは、次の4つの方法で実行できます。場面によって向き不向きがあるので、それぞれの特徴を知っておきましょう。

① メニューから実行

［開発］→［マクロ］でマクロの一覧を開き、実行したいマクロ名を選んで［実行］を押します。もっとも基本的で確実な方法です。

② ショートカットキー

記録時に割り当てたキー（例: Ctrl+Shift+H）を押すだけで即座に実行できます。

③ VBEでF5キー

VBEでカーソルを実行したいプロシージャの中に置き、F5 キーを押します。コードを書きながらの動作確認に向いています。

④ 図形やボタンに登録

シート上に配置した図形やボタンにマクロを割り当て、クリックで実行します。他の人にも使ってもらいたいときに向く方法で、第13章で本格的に扱います。

方法 向いている場面 注意点
①メニューから実行 たまにしか使わない・名前で選んで実行したい マクロ名の一覧から毎回探す手間がある
②ショートカットキー 頻繁に使う操作をすぐ実行したい Ctrl+C（コピー）など、Excel標準のショートカットを上書きしてしまうことがある
③VBEでF5 コードを書きながら動作確認したい VBEを開いている必要があり、シート画面からはすぐ実行できない
④ボタンに登録 他の人にも使ってもらいたい 図形の準備とボタン登録の手間がかかる（第13章）

3.4 絶対参照と「相対参照で記録」

マクロの記録には、もう1つ重要な設定があります。［開発］タブの［相対参照で記録］というボタンです。これがオフ（既定）かオンかによって、セルの移動が記録されるコードがまったく違うものになります。

既定：絶対参照で記録

「A2を選ぶ」のように具体的なセル番地がそのまま記録されます。どこから実行しても、必ず同じセルが選ばれます。

オンにする：相対参照で記録

「今のセルから1つ下」のように現在位置からの相対的な動きが記録されます。実行のたびに、そのときのアクティブセルを基準に動きます。

たとえば「今選んでいるセルから1つ下のセルへ移動する」という同じ操作を、相対参照で記録した場合は次のようなコードになります。

相対参照で記録したコード — 今のセルの1つ下へ移動 
Sub MoveDown()
    ' ActiveCell は「今選択されているセル」
    ' Offset(1, 0) は「1行下・0列右」を意味する
    ActiveCell.Offset(1, 0).Select
End Sub

ActiveCell は「今アクティブになっているセル」、Offset(1, 0) は「そこから1行下・0列右（＝真下）」を意味します。絶対参照で記録した Range("A2").Select と見比べると、書き方の発想がまったく違うことが分かります。

（今のセルの1つ下へ移動）"] --> A["既定のまま記録
＝絶対参照"] S --> B["相対参照で記録を
ONにしてから記録"] A --> AC["コードに具体的な

図の説明: 同じ「1つ下へ移動する」という操作でも、絶対参照は常に同じセルへ、相対参照は実行した時点のセルを基準に移動します。表を1行ずつ処理したい場合は相対参照が、決まった場所だけを操作したい場合は絶対参照が向いています。

注意: 別のシートで実行すると意図しない場所が書き換わることがある

絶対参照で記録すると、Range("A1:E1") のようにセル番地がそのままコードに固定されます。一方でシート名は記録されないため、マクロは実行した時点でアクティブなシートに対して働きます。「売上明細」シートを操作して記録したマクロを、うっかり別のシートがアクティブな状態で実行すると、意図しないシートのセルが書き換わってしまうということです。汎用的に使い回したいマクロは、実行するたびに操作対象を指定し直せるよう自分でコードを書き直す必要があります。この書き方は第6章・第9章で学びます。

3.5 記録マクロの限界と、上手な使い方

ここまで見てきたように、マクロの記録は「実際に行った操作をそのまま再現する」機能です。裏を返すと、行っていない操作や状況に応じて変わる処理は記録できません。具体的には、次のようなことができません。

  • 条件によって処理を変える（例: 金額が10万円以上の行だけ色を付ける）
  • 繰り返しの回数を状況に応じて変える（例: データが100行でも1000行でも対応する）
  • 実行中にユーザーへ入力を求める（例: 集計したい対象の月を尋ねる）
  • 開いているブックの数や名前に応じて、柔軟に処理を変える

これらはすべて、記録機能ではなく自分でVBAのコードを書くことで実現します。「条件によって」は第7章の条件分岐、「繰り返し」は第8章の繰り返し処理、「入力を求める」は第13章のユーザーとのやり取りで扱います。第4章からは、いよいよそのための文法を学び始めます。

重要: 記録機能は「調べる道具」としても一流

記録マクロは初心者向けの機能というだけではありません。「セルの背景色を変えるにはどのプロパティを使えばよいか」のようにプロパティ名やメソッド名を忘れたとき、実際にその操作をマクロの記録で試し、生成されたコードから名前だけを拝借する、という使い方を熟練者も日常的に行っています。すべてを暗記するのではなく、必要なときに調べる辞書として記録機能を使いこなしましょう。

やってみよう 3-1: 見出し行の書式をマクロの記録で作る

練習用にコピーした 売上管理.xlsm を使い、「売上明細」シートの見出し行を整える一連の操作をマクロの記録で作成し、コードを読み解いてみましょう。

手順

  1. 1 「売上明細」シートで［マクロの記録］を開始し、A1:E1を選択 →太字 →背景色を薄い青 →中央揃え →列幅の自動調整、という操作を行ってから記録を終了する。
  2. 2 VBEで生成されたコードを開き、各行の右側に「この行が何をしているか」を自分の言葉で日本語コメントとして書き加える。
  3. 3 見出しの書式を手作業で消してから、記録したマクロを実行し、元の書式に戻ることを確認する。
  4. 4 記録されたコードから .Select と Selection. を取り除いた短い版を別のプロシージャとして書き直し、実行結果が変わらないことを確認する。

理解度確認クイズ

  1. Q1. 記録されたコードにある Selection.Font.Bold = True の Selection は何を指していますか。

    • ア. ブック全体
    • イ. 直前に選択されたセル範囲
    • ウ. アクティブなシート
    回答を表示

    正解: イ
    Selection は「今選択されているもの」を指します。記録マクロは「選ぶ→選んだものに命令する」の2段構えで書かれるため、Select の行と Selection の行はセットで読みます。

  2. Q2. 「金額が10万円以上の行だけ色を付ける」マクロを、マクロの記録だけで作れますか。

    • ア. 作れる
    • イ. 作れない
    回答を表示

    正解: イ
    記録できるのは「実際に行った操作の再現」だけで、条件による判断や繰り返しは記録できません。条件分岐は第7章、繰り返しは第8章で自分でコードを書けるようになります。

この章のまとめ

  • マクロの記録は、記録開始から終了までの操作をそのままVBAコードに変換する機能である。
  • 記録されたコードの多くは「①選ぶ → ②選んだものに命令する」（Select と Selection）の2段構えになっている。
  • マクロの実行には、①メニュー ②ショートカットキー ③VBEでF5 ④図形・ボタンの4つの方法がある。
  • 絶対参照は常に同じセルへ、相対参照は現在位置を基準に動く。「相対参照で記録」ボタンで切り替える。
  • 条件分岐・繰り返し・ユーザー入力など、状況に応じて変わる処理は記録機能では作れず、自分でコードを書く必要がある。

次の第4章では、いよいよ自分の手でVBAのコードを書き始めます。Subプロシージャの書き方、コメントやインデントといった読みやすく書くための作法、そしてオブジェクト・プロパティ・メソッドという考え方を学び、記録機能に頼らずマクロを組み立てる土台を作ります。
