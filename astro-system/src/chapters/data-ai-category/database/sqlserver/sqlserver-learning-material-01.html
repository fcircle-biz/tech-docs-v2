SQL Serverとは

SQL Server は、Microsoft が提供するリレーショナルデータベース管理システム（RDBMS）です。この章では「そもそもデータベースとは何か」という出発点から、SQL Server の特徴・エディション・他のデータベース（特に PostgreSQL）との違いまで、全体像をつかみます。

この章で学ぶこと

  • データベースと RDBMS が何をするものかを、身近な例で説明できる
  • SQL Server がどんな製品で、どこで使われているのかを理解する
  • エディションの違いを知り、学習用にどれを選べばよいか判断できる
  • PostgreSQL をはじめとする他の RDBMS との違いを大づかみに説明できる

1.1 データベースとは何か

データベースとは、たくさんのデータを整理して貯めておき、必要なときにすばやく取り出せるようにした「データの保管庫」です。身近な例では、コンビニのレジ（売上データ）、銀行のATM（口座残高）、通販サイト（商品と注文）など、私たちが毎日使っているサービスの裏側は、ほぼすべてデータベースが支えています。

「Excel でも表は作れるのでは？」と思うかもしれません。実際、少量のデータなら Excel で十分です。しかし、大量のデータを、たくさんの人が同時に、安全に扱うとなると Excel では限界がきます。そこで登場するのが、データベースを管理する専用ソフト DBMS（データベース管理システム）です。

観点 Excel などの表計算 データベース（RDBMS）
データ量 数千〜数万行が実用的な上限 数百万〜数億行でも扱える
同時利用 基本は1人。同時編集は競合しやすい 何百人が同時に読み書きしても矛盾しない
正しさの保証 入力ミスをそのまま保存できてしまう 型・制約でおかしなデータを拒否できる
障害からの復旧 ファイルが壊れたら失われる バックアップとログで復旧できる

DBMS の中でも、データを表（テーブル）の形で管理し、表と表を関係づけて扱うものを RDBMS（リレーショナルデータベース管理システム）と呼びます。本ガイドで学ぶ SQL Server は、この RDBMS の代表格のひとつです。

用語: 「SQL」と「SQL Server」は別物

SQL（エスキューエル）は、データベースに指示を出すための言語の名前です。いっぽう SQL Server は、その SQL を受け付ける Microsoft の製品の名前です。「日本語」と「日本語で話す相手」くらい違うもの、と覚えておきましょう。

1.2 SQL Server とは

SQL Server は、Microsoft が開発・提供している RDBMS です。1989年の初版以来 30年以上にわたって改良され続け、日本国内でも業務システム（販売管理・在庫管理・会計・人事など）の基盤として非常に多く採用されています。とくに Windows Server や .NET／C# で作られた業務アプリケーションと組み合わせて使われる場面が目立ちます。

かつては「Windows でしか動かない」製品でしたが、SQL Server 2017 以降は Linux でも動作し、Docker コンテナとしても提供されています。そのため macOS を使っている方でも、Docker さえあれば学習を始められます（第3章で実際に構築します）。

GUI ツールが充実

SSMS という無償の管理ツールで、画面を見ながらデータベースを操作・確認できます。

業務利用の実績

バックアップ・権限管理・監査など、業務システムに必要な機能が最初から揃っています。

クラウドへ地続き

学んだ知識がそのまま Azure SQL Database などのクラウドサービスで活かせます。

SQL Server で使う SQL は、標準 SQL を Microsoft が独自に拡張した T-SQL（Transact-SQL）という方言です。基本的な SELECT 文などは他の RDBMS と共通ですが、変数・条件分岐・繰り返しといったプログラミング的な書き方は T-SQL 独自のものになります（第9章で学びます）。

1.3 エディションと選び方

SQL Server には用途に応じた複数のエディション（製品グレード）があります。中身のデータベースエンジンは共通で、使える上限や機能に差がある、と考えると分かりやすいでしょう。

エディション 費用 主な用途と制限
Developer 無償 機能は Enterprise と同等。開発・学習・検証専用で本番運用は不可。本ガイドの推奨。
Express 無償 本番利用も可能だが、1データベース 10GB・メモリやCPUに上限あり。小規模用途向け。
Standard 有償 中小規模の業務システム向け。多くの企業システムで採用される標準的な選択肢。
Enterprise 有償（高価） 大規模・高可用性向け。無制限の性能と高度な可用性・分析機能。
Azure SQL Database 従量課金 Microsoft のクラウド上で提供されるマネージドサービス。インストールや OS 管理が不要。

重要ポイント

学習目的なら Developer Edition を選びましょう。無償でありながら機能制限がないため、上位エディションで使われる機能もひととおり試せます。ただし本番システムでの利用は認められていない点だけは必ず覚えておいてください。

1.4 他の RDBMS との違い（PostgreSQL を中心に）

RDBMS には SQL Server のほかに Oracle Database・MySQL・PostgreSQL などがあります。どれも「表でデータを管理し、SQL で操作する」という点は同じです。違いが出るのは、ライセンス（費用）・動く環境・SQL の方言・運用のしかたといった部分です。

製品 提供元 / ライセンス よく使われる場面
SQL Server Microsoft / 商用（無償版あり） Windows・.NET 中心の業務システム、社内システム
PostgreSQL コミュニティ / オープンソース（無償） Web サービス、スタートアップ、クラウド、標準SQL重視の開発
Oracle Database Oracle / 商用 金融・大企業の大規模基幹システム
MySQL Oracle / オープンソース（商用版あり） Web アプリケーション、CMS（WordPress など）

本ガイドでは、各章の最後に「PostgreSQL との違い」のコーナーを設けています。PostgreSQL は無償で人気が高く、SQL Server と比較されることがとても多い RDBMS だからです。まずは大きな違いを俯瞰しておきましょう。

PostgreSQL との違い（全体像）

観点 SQL Server PostgreSQL
ライセンス 商用（Developer / Express は無償） オープンソースで完全無償
SQL の方言 T-SQL（Microsoft 独自拡張） 標準 SQL 準拠＋PL/pgSQL
管理ツール SSMS（高機能な GUI が標準） psql（CLI）中心。GUI は pgAdmin
件数の絞り込み SELECT TOP 10 ... SELECT ... LIMIT 10
同時実行の既定 ロック中心（READ COMMITTED） MVCC 中心で読み取りが待たされにくい
拡張のしかた 製品に含まれる機能を使う 拡張機能（PostGIS 等）を追加できる

いまはすべてを覚える必要はありません。「同じ RDBMS でも、書き方や考え方に違いがある」ことだけ押さえておけば十分です。各章で該当箇所を詳しく扱い、第14章で全体を総まとめします。

ヒント: どちらが優れているの？

優劣ではなく相性で選ぶのが実務の考え方です。Windows Server と .NET で構築された社内システムなら SQL Server、クラウド上の Web サービスでライセンス費を抑えたいなら PostgreSQL、というように、既存環境・チームのスキル・予算から選ばれます。

やってみよう 1-1: 身の回りのデータベースを探す

インストール前のこの段階では、まず「データベースが何をしているのか」を実感することが大切です。紙やメモアプリで手を動かしてみましょう。

手順

  1. 1 自分が今日使ったサービスを3つ書き出す（例: 電車の IC カード、通販サイト、社内の勤怠システム）。
  2. 2 それぞれについて「どんなデータが保存されていそうか」を3項目ずつ挙げる（例: 勤怠なら 社員番号・日付・出勤時刻）。
  3. 3 その項目を「表の列名」として書き直してみる。これが第5章で作るテーブル設計の第一歩になります。

ねらい: データベースは特別なものではなく、「表を作って、そこにデータを貯める」ことの延長線上にある、と体感するのが目的です。

理解度確認クイズ

  1. Q1. 「SQL」と「SQL Server」はどう違いますか？

    回答を表示

    SQL はデータベースを操作するための「言語」の名前、SQL Server はその言語を受け付ける Microsoft 製の「製品（RDBMS）」の名前です。SQL Server で使う SQL は T-SQL という方言になります。

  2. Q2. 学習目的で SQL Server を導入する場合、どのエディションを選ぶとよいですか。その理由も答えてください。

    回答を表示

    Developer Edition。無償で使えるうえ機能は Enterprise 相当のため、学習で試したい機能に制限がかからないからです。ただし本番システムでは利用できません。

  3. Q3. SQL Server と PostgreSQL の違いを、ライセンスと SQL 方言の観点から説明してください。

    回答を表示

    SQL Server は Microsoft の商用製品で（Developer / Express は無償）、SQL 方言は T-SQL です。PostgreSQL はオープンソースで完全無償、標準 SQL への準拠度が高く、手続き型言語には PL/pgSQL を使います。件数を絞る構文も TOP と LIMIT で異なります。
