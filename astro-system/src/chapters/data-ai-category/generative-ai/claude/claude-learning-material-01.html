Claudeとは

Claude（クロード）は、AI企業 Anthropic（アンソロピック）が開発した AI アシスタントです。この章では、Claude がどんな考え方で作られているのか、何が得意なのか、そしてどこで使えるのかという全体像をつかみます。

この章で学ぶこと

  • Claude の設計原則「役に立ち、害を与えず、誠実であること」を説明できる
  • Claude が得意な5つの能力領域を挙げられる
  • Claude.ai・Claude Code・@Claude など、複数の利用経路の違いが分かる
  • 自分の業務のどのタスクを Claude に任せられそうか、候補を洗い出せる

1.1 Claude とは何か

Claude は、AI 企業 Anthropic が開発した AI アシスタントです。文章を書いたり、資料を読み解いたり、データを分析したりと、幅広い知的作業を手伝ってくれます。

ただし Claude を「質問に答えてくれる便利な検索ボックス」だと考えると、その力の半分も引き出せません。Anthropic が Claude に与えている位置づけは「思考のパートナー」です。答えが1つに決まらない複雑な問題について、一緒に考え、案を出し、あなたの判断を助ける——そういう使われ方を前提に設計されています。

用語: 「Claude」と「Claude Code」の違い

Claude は AI そのものの名前であり、ブラウザやアプリから会話できるサービス（Claude.ai）を指すこともあります。Claude Code は、その Claude をソフトウェア開発の作業用に特化させた別のツールです。本ガイドで学ぶのは前者、つまり日常業務で使う Claude のほうです。

設計を支える3つの原則

Anthropic は Claude を訓練するにあたり、Constitutional AI（憲法AI）という独自の手法を使っています。名前のとおり、AI に「守るべき原則（憲法）」をあらかじめ与え、その原則に沿って自分の答えを見直させながら学習させる方法です。その中心にあるのが次の3原則です。

役に立つ (helpful)

依頼の意図をくみ取り、実際に前に進むための助けになる答えを返す。

害を与えない (harmless)

人や社会に危害をもたらす使われ方を避ける。

誠実である (honest)

分からないことは分からないと言い、事実を偽らない。

この3原則は、単なる理念ではなく実際の使い勝手にも表れます。たとえば Claude は、根拠の薄い話題では断定を避けたり、依頼の前提に問題がありそうなときは指摘したりします。「言われたとおりに何でもやる道具」ではなく、判断を持った協働相手として振る舞う点が特徴です。

1.2 Claude が得意な5つの領域

Claude が力を発揮する場面は、大きく次の5つに整理できます。自分の仕事のどれに当てはまるかを考えながら読んでみてください。

一度にどれだけの情報を扱えるか

AI が1回の会話で扱える情報量の上限をコンテキストウィンドウと呼びます。Claude のコンテキストウィンドウは 200Kトークン以上で、これはテキストにしておよそ500ページ分以上にあたります。対応するモデルを使う場合、Pro・Max・Team・Enterprise の各プランでは最大1Mトークンまで扱えます。

用語: トークンとは

AI が文章を処理するときの最小単位です。おおまかには「単語や文字のかたまり1つ」と考えて差し支えありません。細かい換算を覚える必要はなく、「分厚い資料をまるごと読ませても大丈夫な余裕がある」と理解しておけば十分です。

2つの考え方モード

Claude のモデル（Opus・Sonnet など）はハイブリッドモデルと呼ばれ、2つのモードを使い分けられます。ひとつは質問にすぐ答える即時応答モード、もうひとつは時間をかけて段階的に考え抜く Extended thinking（拡張思考）モードです。難しい分析や込み入った判断では後者が力を発揮します（第11章で、ほかの「調べる」機能と比較しながら使い分けを学びます）。

また、答えをそのまま提示するのではなく、あなた自身の考えを引き出すように導く Learning mode（学習モード）という使い方もあります。自分の理解を深めたいときや、判断力を鍛えたいときに向いています。

重要ポイント

Claude アプリは Free・Pro・Max・Team・Enterprise のすべてのプランで利用できます。会話・プロジェクト・メモリ・設定はデバイス間で同期されるので、パソコンで始めた作業をスマートフォンで続けることもできます。

1.4 本ガイドの進め方

本ガイドは全12章で、「基礎 → 改善 → 整理 → 拡張 → 実践」という順に積み上げていく構成になっています。前の章の内容を後の章で使うため、原則として順番に読み進めてください。

第6章〜第9章"] C --> D["拡張
第10章〜第11章"] D --> E["実践

  • プログラミング知識は不要です。営業・マーケティング・財務・人事・法務など、あらゆる職種の方を想定しています。
  • Free プランでも大半の章を追体験できます。一部の機能（第9章のスキル、第11章のエンタープライズ検索など）は有料プランが必要なため、該当箇所で明記します。
  • 読むだけで終わらせないでください。各章末の「やってみよう」を実際に手を動かして試すことが、上達の最短ルートです。

重要ポイント

Claude は知性をもたらし、コンテキストと専門知識をもたらすのはあなた自身です。Claude はあなたの仕事の背景・制約・優先順位を知りません。良い結果は、あなたが持っている情報と判断を持ち込むことで生まれます。この考え方は本ガイド全体を貫く前提です。

やってみよう 1-1: Claude に任せられる仕事を洗い出す

実際に触り始める前に、「自分のどの仕事を Claude に手伝ってもらえそうか」をはっきりさせておきましょう。目的が定まっていると、次章以降の学習効果が大きく変わります。

手順

  1. 1 直近1週間のカレンダーやタスクリストを見返し、時間を使った作業を 5件書き出す。
  2. 2 それぞれが 1.2 の 5つの能力領域のどれに当たるかを分類する（どれにも当てはまらないものは「対象外」とする）。
  3. 3 分類できたもののうち、毎週繰り返している作業に印を付ける。繰り返す作業ほど、Claude を使う効果が積み上がります。
  4. 4 印を付けた作業を1つ選び、第2章で実際に Claude に依頼する題材にする。

ヒント: 「議事録をまとめる」「週次の進捗報告メールを書く」「他部署からの問い合わせに回答する」のような、地味で頻度の高い作業ほど良い題材になります。

理解度確認クイズ

  1. Q1. Claude の設計を支える3つの原則を挙げてください。

    回答を表示

    「役に立つ（helpful）」「害を与えない（harmless）」「誠実である（honest）」の3つです。これらは Constitutional AI（憲法AI）という訓練手法の中心に据えられています。

  2. Q2. Claude のコンテキストウィンドウはどれくらいの大きさですか。また、それは何を意味しますか。

    回答を表示

    200Kトークン以上（テキストにして約500ページ分以上）です。対応モデル利用時は Pro・Max・Team・Enterprise で最大1Mトークンまで扱えます。つまり、分厚い資料をまるごと読ませて質問できるだけの余裕があるということです。

  3. Q3. 「Claude は知性をもたらし、コンテキストと専門知識をもたらすのはあなた自身」とは、どういう意味ですか。

    回答を表示

    Claude は考える力を提供しますが、あなたの仕事の背景・制約・優先順位・社内事情は知りません。良い結果を得るには、あなたが持つ情報と判断を Claude に伝える必要がある、という役割分担を表しています。
