ホーム Claude入門 第3章
第3章 所要時間: 約30分

コンテキストを与える

前章では、プロンプトを「状況・タスク・ルール」の3要素で組み立てる方法を学びました。この章では、それに加えてファイルのアップロードやMemory・Styles・個人設定といった仕組みを使い、Claude にあなたの状況をより深く理解させる方法を学びます。

この章で学ぶこと

  • ファイル・画像をアップロードして Claude に追加コンテキストを与えられる
  • フォローアップ・フィードバック・方向修正・プロンプト編集の4手段を使い分けられる
  • Memory と Styles を設定し、会話をまたいだパーソナライズができる
  • Settings > General の個人設定（preferences）を設定できる

3.1 ファイルをアップロードしてコンテキストを与える

チャットに関連するドキュメントや背景資料をアップロードすると、Claude はその内容を回答に反映してくれます。毎回文章で説明する代わりに、資料そのものを見せてしまう方が早い場面は少なくありません。Claude が扱えるのはテキストだけではなく、画像・グラフ・図表といった視覚的要素も分析の対象になります。

区分 対応形式
ドキュメント PDF、DOCX、CSV、TXT
画像 PNG・JPEG などの一般的な画像形式

アップロードの実践パターン

アップロードが特に役立つのは、次のような場面です。

要点をまとめさせる

ドキュメントをアップロードし、要点をまとめてもらう。

画像を説明・分析させる

画像を共有し、写っているものを説明・分析してもらう。

傾向を特定させる

スプレッドシートを添付し、データの傾向を特定してもらう。

コードを説明・調査させる

コードをアップロードし、動作の説明やバグの発見をしてもらう。

アップロード後の挙動

アップロードすると、Claude は自動的にファイルの内容を解析しようとします。チャット上ではファイルが添付ファイルとして表示され、その内容について続けてプロンプトを送ることができます。

3.2 コンテキストを追加する3つの経路

Claude にあなたの仕事についてさらに多くのコンテキストを与える方法は、アップロードだけではありません。大きく分けて次の3つの経路があります。

経路 概要
アップロード 3.1 で扱った、ファイルや画像をその場で添付する方法
コネクタ Google Drive や Slack など外部サービスと連携する方法（詳しくは第10章で扱います）
カスタム設定 Memory・Styles・個人設定など、Claude 側にあらかじめ登録しておく方法（3.4 で扱います）

実際にあなたが送る1回のプロンプトの裏側では、本文だけでなく、いくつもの情報が合流して Claude への入力になっています。

重要ポイント

プロンプトの言葉づかいを工夫するだけが「コンテキストを与える」ことではありません。アップロード・コネクタ・カスタム設定を組み合わせるほど、毎回ゼロから説明し直す手間が減っていきます。

3.3 Claude の回答を改善していく

Claude との会話は、一度で完璧な答えを引き出すものではなく、繰り返し改善していくことを前提にしています。小さなプロンプトをつなげていくことで、Claude の返答に応じて会話を導いていく自然なやり取りが生まれます。最初の回答が思っていたものと違った場合、次の4つの選択肢があります。

  • フォローアップの質問をする: 回答をもとに、さらに詳しい情報や別の角度、明確化を求める。例:「2番目のポイントについてもう少し詳しく教えてください」
  • フィードバックを伝える: 回答の良かった点・気になった点を伝える。例:「これはいいですね、でもトーンがフォーマルすぎます」
  • 方向修正する、またはやり直す: 意図と違う方向に進んだら軌道修正する。難しければ新しいチャットで会話をやり直し、コンテキストを完全にリフレッシュする。
  • プロンプトを編集して再送信する: 自分のメッセージの鉛筆アイコンをクリックすると、プロンプトそのものを編集して再送信できる。新しいメッセージを追加するのではなく、依頼内容自体を調整したいときに便利。
sequenceDiagram participant U as あなた participant C as Claude U->>C: 最初のプロンプト C->>U: 最初の回答 U->>C: フォローアップの質問 C->>U: 詳細を補った回答 U->>C: フィードバックを伝える C->>U: トーンを調整した回答 U->>C: 鉛筆アイコンでプロンプトを編集し再送信 C->>U: 修正版の回答

用語: フォローアップメッセージ

同じ会話の中で続けて送る追加のメッセージのことです。1通のプロンプトで完璧を目指すのではなく、会話を重ねて少しずつ理想の回答に近づけていく、という考え方が Claude の使い方の基本です。

3.4 Memory・Styles・個人設定でパーソナライズする

Claude が時間とともにあなたに合わせて動作するようになり、プロンプトの力を高めてくれる機能が2つあります。Memory（メモリ）とStyles（スタイル）です。あわせて、すべての会話に適用される個人設定も紹介します。

Memory（メモリ）

会話から重要なコンテキスト——あなたの役割、好み、過去の意思決定、仕事の進め方——を自動的に保存し、新しいチャットのたびに同じことを説明し直す手間をなくす。例えば「B2B企業のマーケティング部門で働いている」と伝えれば、その後もそのコンテキストを覚えている。Settings からいつでも確認・編集・削除でき、すべてのデバイス間で同期される。

Styles（スタイル）

Claude のコミュニケーションの仕方をカスタマイズする機能。簡潔・フォーマル・説明的といったプリセットから選ぶことも、どう書いてほしいかを具体的に説明して独自スタイルを作ることもできる。一度設定すれば、そのスタイルはすべての会話に自動適用される。

個人設定（preferences）

すべての回答で特定の設定を Claude に考慮してほしい場合は、Settings > General の「What personal preferences should Claude consider?（Claude が考慮すべき個人的な設定は何ですか？）」から、すべての会話に適用される個人設定を行えます。Memory が「会話の中で自然に覚えていく」仕組みであるのに対し、個人設定はあらかじめ自分で書いておく設定という違いがあります。

重要ポイント

Memory・Styles・個人設定は、いずれも「毎回ゼロから説明し直す」手間を減らすための仕組みです。一度整えておけば、次章以降で扱う Projects（プロジェクト）などと合わせて、Claude とのやり取り全体がスムーズになっていきます。

やってみよう 3-1: ファイルを添付して、回答を改善しながら仕上げる

アップロードと回答改善の4手段を、実際に手を動かして体験してみましょう。

手順

  1. 1 手元にある PDF か CSV を1つ Claude にアップロードし、「この内容を要約してください」と依頼する。
  2. 2 最初の要約に対して、「もっと簡潔にできますか？」とフィードバックを伝える。
  3. 3 最初に送ったメッセージの鉛筆アイコンをクリックし、「要約してください」の部分を「箇条書き3点で要約してください」に編集して再送信する。
  4. 4 1〜3の3つの回答を見比べ、どの手段がどう回答を変えたかをメモする。

ヒント: 手元にファイルがなければ、社内向けのお知らせメールや議事録のスクリーンショットでも構いません。「もっと簡潔に」だけでなく「もっとフォーマルに」など、トーンの指定も試してみましょう。

理解度確認クイズ

  1. Q1. Claude にアップロードできる主なファイル形式を挙げてください。また、テキスト以外に何を分析できますか。

    回答を表示

    PDF、DOCX、CSV、TXT、および PNG・JPEG などの一般的な画像形式に対応しています。テキストだけでなく、画像・グラフ・図表といった視覚的要素も分析できます。

  2. Q2. Claude の回答が思っていたものと違ったとき使える4つの手段は何ですか。

    回答を表示

    「フォローアップの質問をする」「フィードバックを伝える」「方向修正する、または新しいチャットでやり直す」「鉛筆アイコンからプロンプトを編集して再送信する」の4つです。

  3. Q3. Memory と Styles の違いを説明してください。

    回答を表示

    Memory は会話の中で明かした役割・好み・過去の意思決定・仕事の進め方を自動的に保存し、次回以降の説明を省く機能です。Styles は簡潔・フォーマル・説明的といった回答の文体やトーンをプリセットまたは独自定義で指定し、全会話に自動適用する機能です。「何を覚えているか」と「どう話すか」という異なる役割を持ちます。
