ホーム Claude入門 第2章
第2章 所要時間: 約30分

Claudeとの最初の会話

この章では、Claude.ai の基本画面を確認したうえで、Claude から良い回答を引き出すための「プロンプトの3要素」を学びます。何を書けばよいか迷わなくなることが、この章のゴールです。

この章で学ぶこと

  • Claude.ai で新しい会話を開始し、基本インターフェースを操作できる
  • 「状況を設定する／タスクを定義する／ルールを指定する」の3要素でプロンプトを構成できる
  • 自分のプロンプトを3要素に分解して自己点検できる
  • 4D Framework for AI Fluency の存在と、プロンプト設計が Description に当たることを説明できる

2.1 Claude.ai の基本画面

Claude.ai を開くと、画面下部にテキスト入力欄があるだけの、とてもシンプルな画面が表示されます。難しい設定は必要ありません。この入力欄にメッセージを打ち込み、送信するところから、すべての会話が始まります。

Claude に送るメッセージのことをプロンプトと呼びます。プロンプトは、新機能のコードネームを考えるといった軽い質問から、資料を1つ作り上げるような複雑な依頼まで、幅広く使えます。「何か特別な書き方をしないといけないのでは」と身構える必要はありません。

用語: プロンプト(prompt)とは

Claude に送る指示や質問の文章のことです。難しい専門用語ではなく、単に「Claude への話しかけ方」だと考えてください。

話しかける姿勢

Claude に話しかける際の最良のアプローチは、同僚に話しかけるように、自然に、簡潔に、そして会話的に話すことです。コンピューター向けの特殊なコマンドを覚える必要はありません。隣の席の同僚に頼みごとをするときと同じ言葉づかいで十分です。

重要ポイント

Claude は、あなたのあらゆる業務における能力を高めてくれる、強力で知的な協力者です。Claude は知性をもたらし、コンテキストと専門知識をもたらすのはあなた自身です。この役割分担を意識するだけで、プロンプトの質が大きく変わります。

2.2 プロンプトの3要素

Claude とのやり取りはすべてプロンプトから始まり、そのプロンプトが他のコンテキストと組み合わさることで Claude の回答に影響します。次に Claude と会話する前に、次の3つの要素を意識してみましょう。

flowchart LR A["① 状況を設定する
Context"] --> D["1つのプロンプト"] B["② タスクを定義する
Task"] --> D C["③ ルールを指定する
Rules"] --> D D --> E["Claudeの回答"]
要素 問いかけの例
① 状況を設定する（Context） 自分の役割は何か。目的は何か。Claude が知っておくべき仕事上のコンテキストはあるか。
② タスクを定義する（Task） Claude にどんな行動を取ってほしいか。文章を書く、分析する、何かを作るなど、してほしいことは何か。
③ ルールを指定する（Rules） Claude に使ってほしいスタイルやトーンは何か。求めているものを示すために添付できる例はあるか。

それぞれの要素をもう少し詳しく

状況を設定する（Context）とは、Claude に「あなたが誰で、何のために依頼しているか」を伝えることです。同じ「レポートを書いて」という依頼でも、社内向けの速報なのか、投資家向けの正式な資料なのかで、求められる中身はまったく違います。この背景を省くと、Claude は無難な一般論しか返せません。

タスクを定義する（Task）とは、「書く」「分析する」「作る」といった、Claude に取ってほしい具体的な行動を明示することです。行動が曖昧だと、Claude は何を成果物として出せばよいか判断できません。

ルールを指定する（Rules）とは、文体・トーン・長さ・構成といった仕上がりの条件を伝えることです。「プロフェッショナルな文体で」「箇条書きで」のように言葉で説明するだけでなく、参考にしてほしい文章例を添付するのも効果的な方法です。

2.3 3要素をまとめてみる

まず、3要素を欠いた「悪いプロンプト」と、3要素をすべて含んだ「良いプロンプト」を比べてみましょう。同じ依頼でも、書き方次第で Claude から引き出せる回答の質は大きく変わります。

flowchart TD Q["依頼したいこと
市場調査レポートがほしい"] --> P1["悪いプロンプト
（一言だけ）"] Q --> P2["良いプロンプト
（3要素を含む）"] P1 --> R1["漠然とした一般的な回答"] P2 --> R2["意図に沿った実用的な回答"]
悪いプロンプトの例 
市場調査をして。

これでは、誰のための調査で、何を明らかにしたいのか、どんな形式でほしいのかが一切伝わりません。Claude は仕方なく、当たり障りのない一般論を返すことになります。

良いプロンプトの例（3要素すべてを含む） 
私はインディーズ系ストリーミングスタートアップのマーケティング責任者で、
シリーズAの投資家向けピッチデックを準備しています。
インディペンデント映画ストリーミング市場の現状を調査し、
主要なトレンド、競合のポジショニング、成長機会を特定してもらえますか。
最新のウェブ調査を出典付きで行い、エグゼクティブサマリー、市場分析、
競合状況、成長機会を含む、5ページ以内のプロフェッショナルな
レポートとしてまとめてください。

このプロンプトを3要素に分解すると、次のようになります。

要素 プロンプト中の該当箇所
状況を設定する 新しいインディーズ系ストリーミングアプリの投資家向けピッチデックのためだと伝えている（コンテキストと目的）
タスクを定義する 具体的な行動（市場調査）を、関連する詳細（トレンド、競合、機会）とともに提示している
ルールを指定する 出典付きの最新ウェブ調査を依頼し、プロフェッショナルなレポートとしての構成（5ページ以内、4つの見出し）を求めている

自己点検の習慣

プロンプトを送る前に、「状況・タスク・ルールの3つとも書けているか」を自分で見返す習慣をつけましょう。どれか1つでも抜けていないか確認するだけで、回答の質が安定します。

2.4 プロンプト設計の先にあるもの — 4D Framework

ここまで学んだ3要素によるプロンプト設計は、4D Framework for AI Fluency と呼ばれる、より大きな枠組みの一部にあたります。これは Rick Dakan 教授（Ringling College of Art and Design）と Joseph Feller 教授（University College Cork）の共同研究から生まれたフレームワークで、AI との効果的な協働を可能にする4つの中核的能力を特定しています。

flowchart TD F["4D Framework for AI Fluency"] --> D1["Delegation
委任"] F --> D2["Description
説明"] F --> D3["Discernment
見極め"] F --> D4["Diligence
注意深さ"] D2 --> N["この章のプロンプト3要素は
Descriptionにあたる"]

Delegation（委任）

どの作業を人間が、どれを AI が行うかを決める能力。

Description（説明）

求める出力を明確に定義し、AI のプロセスをガイドする能力。本章の3要素はここに当たります。

Discernment（見極め）

AI の出力やふるまいを批判的に評価する能力。

Diligence（注意深さ）

責任ある倫理的な利用と、AI 活用作業への責任を持つ能力。

4つの能力の詳しい内容は第5章で改めて扱います。ここでは「良いプロンプトを書く力（Description）は、AI をうまく使いこなすための能力の1つにすぎない」ということだけ押さえておいてください。

一度きりで終わらせない

Claude の真の力は、一度きりのプロンプトではなく、継続的で頻繁なやり取りによって発揮されます。最初のプロンプトで完璧な答えを狙う必要はありません。まず送ってみて、返ってきた回答を見ながら会話を重ねていく——この進め方については、次の第3章・第4章で詳しく扱います。

重要ポイント

3要素（状況・タスク・ルール）はゴールではなく出発点です。まずはこの3要素を意識してプロンプトを組み立て、Claude の回答を見ながら会話を続けていく——それが最も確実な上達の道です。

やってみよう 2-1: 一言プロンプトと3要素プロンプトを比べる

第1章の実習で選んだ「Claude に任せたい仕事」を使い、プロンプトの書き方による違いを実際に体感してみましょう。

手順

  1. 1 選んだ仕事について、まずは一言だけの短いプロンプトを Claude.ai に送る（例:「報告書を書いて」）。
  2. 2 同じ依頼を、状況・タスク・ルールの3要素を盛り込んで書き直し、新しいチャットで送る。
  3. 3 2つの回答を見比べ、具体性・使えそうか・自分の状況にどれだけ合っているかの3点で違いをメモする。
  4. 4 3要素プロンプトのうち、自分がつい省略しがちな要素はどれだったかを振り返る。

ヒント: 「状況」を省略しがちな人が多いです。自分の役割や目的を一文添えるだけで、回答の的確さが大きく変わることを確認してみてください。

理解度確認クイズ

  1. Q1. プロンプトの3要素とは何ですか。それぞれ簡潔に説明してください。

    回答を表示

    「状況を設定する（自分の役割・目的・仕事上のコンテキスト）」「タスクを定義する（Claude に取ってほしい具体的な行動）」「ルールを指定する（スタイル・トーン・添付できる具体例）」の3つです。

  2. Q2. 4D Framework for AI Fluency の4つの能力を挙げてください。プロンプトの3要素は、そのうちどれに当たりますか。

    回答を表示

    Delegation（委任）・Description（説明）・Discernment（見極め）・Diligence（注意深さ）の4つです。プロンプトの3要素は、求める出力を明確に定義するDescription（説明）にあたります。

  3. Q3. 「一度きりのプロンプトで完結させる」のではなく、継続的にやり取りを重ねることが勧められるのはなぜですか。

    回答を表示

    最初の依頼だけで、自分の頭の中にある背景・制約・好みをすべて伝えきることは難しいためです。出力を見て「ここをこう変えてほしい」と伝え直すことで、必要なコンテキストが少しずつ補われ、狙いに近い結果へ収束していきます。最初の出力は完成品ではなく、会話の出発点として扱うのが Claude の使い方です。
